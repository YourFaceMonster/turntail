# 렉시오 장성 0.1.0

3인 친구 대전과 AI 2명 연습 모드를 제공합니다. 초대 링크 또는 6자리 코드로 입장합니다. 게임 상태는 D1에 저장하며 요청마다 방의 버전을 비교하여 중복 제출과 동시 변경을 방지합니다. 손패는 해당 자리의 임의 토큰으로만 조회되며 다른 손패 및 숨긴 위층 타일은 응답에 포함하지 않습니다.

## 합의한 규칙

- 숫자 1~15, 네 문양의 총 60개. 각자 손패 12개, 바닥 24개.
- 바닥은 3행 4열, 공개 아래층과 비공개 위층.
- 같은 층의 상하좌우 중 한 곳이 비면 접근 가능. 아래층은 위층도 제거되어야 함.
- 차례마다 제출 또는 한 개 가져오기. 낼 수 있어도 전략적으로 가져오기 가능하며 즉시 턴 종료.
- 자기 손패를 먼저 모두 내면 즉시 종료. 바닥이 소진되어도 계속 진행하며 패스 가능.

## 첫 버전 기본값

- 첫 선: 실제 손패들 중 최약 타일 보유자. 구름3이 바닥에 있을 때도 시작 가능.
- 나머지 두 사람이 제출하지 않으면 마지막 제출자가 선을 잡음. 가져오기도 제출하지 않은 차례에 포함.
- 기본 렉시오 족보, 1~15 스트레이트 서열. 1,2,3,4,5 > 2,3,4,5,6 > 12,13,14,15,1.
- 승수와 잔여 패만 기록하며 칩 정산 없음.
- 브라우저 새로고침 시 같은 기기·같은 브라우저의 마지막 방으로 복귀. 저장소 초기화 또는 다른 기기로 자리 이전은 지원하지 않음.
- AI는 규칙 검증용의 단순 전략. 접속 브라우저가 열려 있을 때 차례 진행.
- 게임 중 자리 교체와 퇴장, 제한 시간, 채팅은 아직 없음.
