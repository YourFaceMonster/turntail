# 0.6.29 · 직업 전투 프로토타입

코드 반영·타입 검사·동작 검증을 완료했다. 운영 빌드와 사이트 배포 상태는 체크아웃 바깥의 `artifacts/deployment-0.6.29.json`에 별도로 기록한다.

## 앞서 요청한 UI와 패

- 아이템 상점의 7종 구매 선택지를 한 화면에 배치한다. 데스크톱은 한 줄, 휴대폰은 4+3, 낮은 가로 화면은 구매 영역과 보유/구매 목록을 좌우로 나눈다. 큰 보유 목록만 내부 스크롤한다. 구매 선택 전후 창 크기를 고정한다.
- 승리 안내 → 잠깐 대기 → 이번 싸움 결과의 순서를 유지하면서 상태창 HP·피해 숫자·흔들림을 결과창과 같은 렌더에서 공개한다. 실제 판정 HP는 싸움 종료 즉시 갱신하므로 생존/스킬 판정은 지연하지 않는다. 저장 재개에서는 이미 지난 결과를 다시 대기시키지 않는다.
- 결과에 `이번 싸움에서 낸 패 N장 × 1 = 기본 피해 N`을 표시한다. 각 상대 줄에 기본 피해, 직업/캐릭터 추가 피해, 방어, 실제 감소량을 함께 표시하고 회복은 양수로 구분한다.
- 일반모드에서 선택한 패 세트를 아이템전에도 적용한다. 입장 셔플·배분·이어서 하기·인게임 패를 맞추며, 장소/테이블 배경은 유지한다.
- 재질 패 10종은 일반 패와 숫자·문양 위치 및 기본 실루엣을 공유한다. 기존 재질 그림에 나무결, 옥의 결, 수정의 면, 현무암의 기공, 월장석 광택, 호박석 내포물, 흑요석 절단면, 세계수의 금빛 결 등을 절제해 보강한다. 별도 이미지 생성 없이 기존 SVG·재질 자산을 사용한다.

## 첨부 문서와 사용자 확정 사항

원문: `docs/reference/rpg-combat-handoff-2026-10-27.md`.

- RPG와 아이템전 모두 직업을 추가한다. 기존 아이템전 캐릭터 선택/고유스킬, 아이템, 유물과 주화 규칙을 유지한다.
- 기본 피해는 **승자가 이번 싸움 동안 제출한 실제 패 수 누적**으로 유지한다. 이긴 사람이 확정될 때만 피해와 직업 효과를 적용한다.
- 도적은 상대 한 명을 무작위 선정해 패를 확인한다. 트리플 승리 자동 스킬은 그 상대 패 2장을 확인하고 양측 각 1장을 무작위 교환한다. 양쪽 4장 이상, 1·2 교환 제외, 수호의 봉인 방어 조건을 따른다. 교환 불가여도 조건에 따른 자동 스킬 1회는 소진되며 이유를 표시한다. 아이템 수량이나 판당 사용 횟수는 소모하지 않는다.

| 직업 | 조건마다 발동 | 카드 한 판에 최대 1회 자동 발동 |
|---|---|---|
| 검사 | 페어 승리 피해 +1 | 스트레이트 승리 피해 +3 |
| 도적 | 싱글 승리 상대 패 1장 확인 | 트리플 승리 상대 패 2장 확인 + 1장 교환 |
| 성직자 | 페어 승리 HP +1 | 풀하우스 승리 HP +5 |
| 마법사 | 트리플 승리 피해 +2 | 포카드 승리 피해 +6 |

HP는 100을 넘지 않는다. 경험치·레벨·마나를 추가하지 않는다. 자동 스킬 사용 여부와 정찰 기록은 다음 카드 판 시작에 초기화한다. 정찰은 발동 시점의 비공개 스냅샷이며 사용한 사람에게만 보인다.

새 RPG의 HP는 싸움별 피해로 계산하며 기존 카드 점수로 HP를 중복 차감하지 않는다. 기존 포인트·운명·보상·유물·해금 흐름은 유지한다. 유물의 첫 피해 방어와 대기 방패는 싸움 피해에서 적용한다. HP 0이면 해당 전투를 끝내고 기존 RPG 운명/보상 흐름으로 넘어간다.

새 아이템전은 직업 추가 피해를 기존 캐릭터 공격과 합산한 뒤 캐릭터 방어를 적용한다. HP 피해로 추가 주화를 지급하지 않는다. 기존 남은 패 점수 정산·주화 부족 HP 차감·HP 0 시 정산 취소는 유지한다.

새 대전/여정부터 직업 상태를 생성하며, 이전 저장의 규칙이나 자원을 변경하지 않는다. 직업 정보는 기존 상태 팝오버에 표시하고, 도적 정찰은 처음부터 고정 크기의 아이콘 자리를 사용해 전투 중 새 줄이 생기지 않게 한다.

## 검증과 밸런스 관찰

두 모드의 조건별 반복/1회 제한, 누적 피해, 승자 전용 발동, HP 100 상한, 캐릭터 스킬 합산, 유물 방어, 1·2 제외 교환, 손패 보존, 수호의 봉인 소모, 아이템 횟수 비소모, 정찰 비공개, 저장 및 다음 판 초기화를 검사했다. 실제 브라우저에서 양쪽 모드의 직업 선택과 포카드 기본 5 + 마법사 6 = 상대별 11 피해를 확인했다.

32회 AI 기초 대전(각 모드·직업별 4회)은 전부 종료됐다. 아이템/유물을 비활성화해 직업 효과를 관찰했고, 아이템전의 기존 캐릭터 스킬과 주화 정산은 유지했다. 무작위 소규모 표본이며 최종 밸런스나 사람 플레이 시간을 입증하지 않는다.

| 직업 | RPG 평균 카드 판 수 | 아이템전 평균 카드 판 수 |
|---|---:|---:|
| 검사 | 7.00 | 6.00 |
| 도적 | 7.75 | 6.00 |
| 성직자 | 7.50 | 5.25 |
| 마법사 | 6.25 | 5.75 |
| 전체 | 7.13 | 5.75 |

문서의 3~5판 가설보다 길고 일부 자동 스킬 발동이 드물다. HP 100과 스킬 수치는 문서 그대로 유지하며 후속 플레이 테스트에서 조정한다. 원자료는 워크스페이스 바깥 `artifacts/profession-balance-prototype.json`, 재측정 스크립트는 `tools/measure-profession-balance.ts`다.
