# 2026-11-03 · 잡화점 간략 목록과 퀘스트 컷씬

후속: 사용자 요청으로 전용 퀘스트 원화를 생성하고 연결했다. [전용 원화 작업 기록](local-quest-art-2026-11-03.md). 아래는 기존 그림을 재사용했던 최초 UI 변경 기록이다.

- 잡화점 상품은 아이콘·이름·가격만 보이는 작은 목록으로 변경했다. 상품을 누르면 효과 설명과 기존 구매 조건/구매 버튼이 펼쳐진다. 소모품과 유물 모두 같은 방식이다.
- 봉인 편지 의뢰/전달, 골목 도둑, 길가의 여행자와 파수탑을 전체 화면 대사형 컷씬으로 연결했다. 기존 프롤로그의 그림 렌더러와 보유 원화를 재사용하며 대사를 읽은 후 마지막 화면에서 행동을 선택한다.
- 수락·대결·약초 전달·조사·돌아가기 선택과 기존 저장/중복 보상 방지를 유지했다. 보상 뒤 후속 대사도 같은 컷씬 형식이다.
- 주점 게시판 표시를 완전히 제거했다.
- 새 원화는 생성하지 않았다. 현재 배경은 기존 주점·눈길·길·돌 발견 컷의 원화를 사용한다.

## 확인과 게시 상태

- `pnpm exec tsc --noEmit`: 이번 변경 파일의 오류는 없으며 기존 bomb 테스트 파일의 nullable 오류 3개로 전체 실패.
- `git diff --check` 통과. 대상 컴포넌트 ESLint는 결과 없이 장시간 대기해 종료했으므로 성공으로 기록하지 않는다.
- 로컬 홈페이지 HTTP 200. 실제 브라우저 클릭과 휴대폰 화면은 이번에 확인하지 않았다.
- 버전 0.6.66 유지. 로컬 저장만 했으며 빌드·커밋·push·배포하지 않았다.
