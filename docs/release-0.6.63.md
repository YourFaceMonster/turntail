# 0.6.63 · 스트레이트 비순환 규칙과 로컬 UI 변경 게시

스트레이트는 숫자가 이어지는 5장만 허용한다. 강한 순서는 1·2·3·4·5 → 2·3·4·5·6 → 11·12·13·14·15 → 10·11·12·13·14 → … → 3·4·5·6·7이다. 12·13·14·15·1 등의 15→1 순환은 스트레이트로 인정하지 않는다. 같은 규칙이 일반·친구 대전, 아이템전, RPG, 자동 선택과 AI의 공통 판정에 적용된다. 스트레이트 플러시도 같은 비순환 판정을 사용하며, 같은 문양의 비연속 5장은 별도의 플러시 규칙을 유지한다. 별도 규칙을 가진 폭탄시장전의 3~15 연속·5장 이상 폭탄은 유지한다.

판정의 순환 예외와 자동 후보 생성의 12 시작 예외를 제거하고 규칙 팝업을 갱신했다. 회귀 검사에서는 11개 연속열 전체의 순서·역순 입력·동문양·모든 순환 조합 거부·실제 제출 거부·후보 생성/응답을 확인한다. 기존 전체 게임 검사는 다음 연출 종료 시각으로 가상 시간을 진행하도록 고쳐 AI가 대기 중인 상태를 반복하지 않도록 했다.

이번 게시에는 앞서 로컬 저장한 주점·지도 확대, 세로 지도 v5/주점 v7, 작은 TEST 도구, 공통 전투 헤더·주화 표시, 유물 두 줄 효과, 컷씬 배경 유지·공통 자막, 주점 인물·벽난로·가방 외곽선 수정도 포함한다. 원본 그림·사용자 저장은 보존한다. 최종 빌드·배포 결과는 루트 artifacts/deployment-0.6.63.json과 검증 기록을 따른다.

확장 검사의 구형 `hp-item-battle.test.ts`는 폐기된 `spark-dart` 사용 기대에서 실패했다. `docs/local-0.6.50.md`와 루트 `artifacts/baseline-checks-0650.json`에 변경 전 소스의 동일 실패가 기록돼 있으며, 이번 통과 수에 포함하지 않는다. `game`과 `visibility-and-rank`의 AI 검사에서는 연출 대기 종료 시각으로 시간을 진행하도록 테스트를 수정했다. 게임 실행의 대기 시간 규칙은 바꾸지 않는다.
