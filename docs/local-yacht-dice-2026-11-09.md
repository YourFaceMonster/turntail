## 후속: 화면 재구성 (같은 날)

사용자 요청: 코리아보드게임즈 "요트 다이스" 제품 구성과 닌텐도 스위치 51 월드와이드 게임즈의 요트 진행 방식을 참고한다. 컵을 흔드는 느낌을 원했다. 배치와 진행 방식만 참고했고, 그림·로고·화면은 가져오지 않았다. 그림은 TURNTALE 카툰 톤으로 새로 그렸다.

- **구성:** 위쪽에 "남길 주사위" 칸, 아래에 검은 테두리와 빨간 펠트 트레이, 트레이 오른쪽 아래에 가죽 주사위 컵, 오른쪽에 크림색 종이 점수표
- **컵 조작**
  - 컵을 누르고 있으면 흔들리고 달그락 소리가 나며, 굴릴 주사위가 컵으로 모인다
  - 손을 떼면 컵이 기울어 주사위가 트레이로 쏟아지고, 굴러가며 흩어진다
  - 짧게 누르면 최소 0.42초 흔든 뒤 쏟는다. 키보드 Enter·Space도 같다
  - 아래 "컵 흔들어 굴리기 / 다시 굴리기" 버튼도 남겼다
- **남길 주사위:** 트레이의 주사위를 누르면 위 칸으로 옮겨지고, 다시 누르면 트레이로 돌아간다
- **하로 차례:** 남길 주사위를 위로 옮김 → 컵 흔들기 → 쏟기 → 점수 기록 순으로 한 단계씩 보여 준다
  - `yachtAiPlan`이 공개 정보만으로 다음 행동을 미리 정하고, 실제 처리도 같은 계획을 따른다
- **화면 정리:** 굴림 횟수를 동그라미 3개로 표시. 1의 눈은 빨간 점. 아래쪽 HP 문구는 하단 메뉴와 겹쳐서 빼고, 머리글의 판돈 표시에 넣었다
- **소리:** 기존 클릭·아이템 효과음을 반복해 흔들기·착지 소리를 냈다. 전용 주사위 소리 파일은 아직 없다
- **이번 검증**
  - `yacht-dice`·`rpg-chapters`·`rpg-rework` 테스트 42/42 통과, 타입 오류 0
  - 브라우저에서 컵 클릭·누르고 흔들기·남기기·재굴림·하로 차례 순서를 확인

## 후속 3: 0.7.6 플레이 피드백 반영 (로컬 · 미배포)

사용자 피드백 7건(2026-11-09). 빌드·배포 요청이 없어 로컬에만 저장했다. 버전은 0.7.6 그대로다.

1. **컵 흔들기 진동**
   - 흔드는 동안 짧은 진동이 반복되고, 쏟을 때와 착지할 때 진동이 한 번씩 온다.
   - `lib/haptics.ts`(신규)를 페이지가 등록하므로 설정의 진동 켜기/끄기를 따른다.
2. **주사위 탭 진동:** 남길 주사위를 누를 때 12ms 진동
3. **족보 기록 연출**
   - 점수를 적을 때 짧은 진동이 온다.
   - 다음 경우에는 트레이 위에 배너가 뜬다. 하로가 적을 때는 파란 배너다.
     - 포카인드·풀하우스·스트레이트
     - 요트(금색 배너, 유물 획득음, 긴 진동)
     - 요트 보너스 +100
     - 숫자 보너스 +35
   - 주사위 5개가 같은 눈이면 금빛으로 빛난다.
4. **"하로" 줄 제거**
   - 점수 타일 아래의 "하로 ·" 줄과 보너스 칸의 하로 진행 표시를 뺐다.
   - 하로 점수는 하로 좌석을 누르면 점수표 팝업으로 본다.
5. **조커 규칙 (야찌 기준)**
   - 요트 칸을 이미 채운 뒤 요트가 또 나오면 조커가 된다.
     - 요트 칸이 50점이면 +100 보너스. 0점이면 보너스는 없다.
   - 적을 칸 우선순위
     - 같은 눈의 숫자 칸이 비어 있으면 그 칸에만 적는다.
     - 그 칸이 차 있으면 아래쪽 족보 칸에 적고, 풀하우스·스몰 15·라지 30을 그대로 인정한다.
     - 아래쪽도 모두 차 있으면 남은 숫자 칸에 적는다.
   - 화면에는 "조커!" 안내가 나오고, 고를 수 없는 칸은 흐리게 표시한다. 하로 AI도 같은 규칙을 따른다.
6. **점수 칸 강조**
   - 위쪽 1~6 칸은 주사위 눈 아이콘으로, 아래쪽 족보 칸은 붉은 테두리로 구분한다.
   - 숫자를 키웠다.
   - 고를 수 있는 칸은 떠오르며 빛나고, 가장 높은 점수 칸은 초록 테두리와 ★로 표시한다.
   - 이미 적은 칸과 못 고르는 칸은 흐리게, 적은 칸에는 ✓를 붙인다.
7. **주사위 눈 흔들림 제거**
   - 착지 때 면을 늘이고 흐리게 하던 애니메이션(`yacht-tumble`)을 뺐다.
   - 이제 주사위 전체만 움직이고 돌며, 눈은 고정된다.

- 기타: 컵을 누를 때 `setPointerCapture` 예외가 나면 무시한다.
- **이번 검증**
  - 요트다이스 테스트 10개(조커·배너 포함)와 관련 RPG 테스트를 합쳐 44개 통과. 타입 오류 0
  - 전체 363개 중 326개 통과, 37개 실패. 실패 37개는 기존과 같다.
  - 브라우저(화면 테스트 모드)
    - `navigator.vibrate` 호출을 기록해 흔들기·쏟기·착지·탭·점수 기록 진동을 확인
    - 자동 진행 중 족보 배너 4회 표시를 확인(내 스몰 스트레이트, 하로의 라지 스트레이트·스몰 스트레이트·풀하우스)

## 후속 4: 남길 칸 순서 · 족보 설명 (로컬 · 미배포)

1. **남길 칸 순서**
   - 이전: 주사위 번호(1~5) 자리로 들어가서 칸이 중간부터 찼다.
   - 지금: 누른 순서대로 왼쪽부터 채운다. 하나를 빼면 나머지가 왼쪽으로 당겨진다.
   - 순서는 화면에서만 기억한다. 새로고침하면 주사위 번호 순으로 다시 놓인다.
   - 하로가 남길 때는 주사위 번호 순으로 놓인다.
2. **족보 칸 설명:** 아래쪽 칸마다 한 줄 설명을 붙였다. 스몰·라지·요트는 고정 점수를 함께 보여 준다.

   | 칸 | 넓은 화면 | 좁은 화면 |
   |---|---|---|
   | 초이스 | 5개 합 | 5개 합 |
   | 포카인드 | 같은 눈 4개 | 4개 같음 |
   | 풀하우스 | 3개+2개 | 3+2 |
   | 스몰 스트레이트 | 4연속 · 15점 | 15점 |
   | 라지 스트레이트 | 5연속 · 30점 | 30점 |
   | 요트 | 모두 같음 · 50점 | 50점 |

  - 설명 표시는 1024×768과 375×812에서 확인
