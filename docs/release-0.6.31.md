# 0.6.31 · 이미지 상점·정산, 아이템 표시와 첨부 BGM

사용자의 후속 사이트 업로드 요청에 따라 로컬 검증을 마친 수정본을 배포한다.

- 이어하기를 포함해 아이템 이미지를 미리 디코딩하고, 준비된 뒤 사용·비행·충돌 시계를 시작한다. 이미지 로드 실패는 수량 소비 전에 처리한다. 동작 줄이기 설정에서는 회전·확대 없는 직선 비행을 표시한다.
- 바닥패를 원래 인덱스의 행·열에 고정한다. 세 번째 줄이 비어도 남은 패를 다시 모으지 않는다.
- 약초 숫자는 진한 초록과 외곽선·그림자로 표시하고, 내 수호의 봉인 표식은 HP 옆에 둔다.
- 새로 생성한 상점·정산 배경을 적용한다. 정산에서 HP 피해 숫자는 빨강, 아이템·스킬 회복 숫자는 초록으로 굵게 표시하며, 주화 부족으로 인한 HP 피해는 주화 줄에 표시한다.
- 첨부 MP3를 일반·아이템·RPG 등 인게임의 반복 BGM으로 사용한다. 기존 음악 켜기/끄기, 볼륨, 상황별 음량과 백그라운드 일시정지를 유지한다.

관련 테스트 14개와 타입 검사를 통과했다. 실제 Home에서 이어하기 후 왼쪽 AI → 내 상태창 비행의 이미지 준비, 세 번째 줄 마지막 패 제거 전후 바닥 15칸의 동일한 위치·크기, HP 옆 봉인 위치를 확인했다. 상점·정산은 390×700, 844×390, 1100×700에서 확인했다. BGM은 첨부 원본과 SHA-256이 같고 로컬 서버에서 `audio/mpeg`로 정상 제공된다.

세부 수정 기록은 `docs/local-0.6.31.md`, 생성 이미지·프롬프트는 `docs/ui-backgrounds-0.6.31.md`를 참고한다. 배포 결과는 체크아웃 바깥 `artifacts/deployment-0.6.31.json`에 기록한다.
