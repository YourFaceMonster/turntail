# 0.6.25 · HP 라벨 크기 통일 및 사이트 배포

사용자 요청에 따라 결과 HP 바의 ‘HP’ 글자를 최대 체력 ‘/100’과 동일한 12px로 맞춘다. 현재 HP 숫자는 큰 표시를 유지한다.

이번 배포에는 로컬에서 확인한 0.6.19~0.6.24 변경을 함께 포함한다: 기존 아이템전2 상점 기반 전투·고유스킬, 메뉴 카드 배치 복원, HP/말풍선/바닥패 배치 수정, 클릭 확인 방식 전투 결과, 전체 캐릭터 HP 순위와 짧은 결과 요약, HP 피해 추가 주화 제거 및 패 점수 정산, 이미지 생성 불꽃과 바늘·봉인 연출, 작은 비공개 손패 미리보기. 과거 버전 저장 호환과 기존 잔액을 유지한다.

검증: TypeScript, 기존 로컬 회귀 검사 결과, HP 및 /100 글자 크기 브라우저 확인, 배포용 프로덕션 빌드. 기존 public 사이트의 공개 범위를 유지해 게시한다.
