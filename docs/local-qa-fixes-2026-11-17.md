## 4. 패배 시 스테이지 다시 도전 (운명력)
- 새 여정은 운명력 3개로 시작. HP 0이 되면 운명력 1개를 쓰고 같은 스테이지를 바로 다시 도전: 내 HP는 시작값(100, 약한 심장 도전이면 70), 상대 HP는 그 스테이지 처음 값. 마지막 매듭 유물도 다시 발동 가능. 운명력 0에서 쓰러지면 기존처럼 여정 종료.
- 정산 창: 쓰러진 판의 HP를 그대로 보여 주고, 운명력 구슬·남은 개수와 "스테이지 N 다시 도전 →" 버튼.
- 지도 HP 칸에 운명력 구슬 다시 표시, 스토리 시작 창에 "운명력 n/3".
- 기존 진행 중 여정(운명력 0으로 저장됨)은 불러올 때 한 번 3개를 받는다(`journey.reworkFate`).
- 화면 테스트 모드의 "실패" 화면은 운명력 0으로 만들어 종료 화면을 그대로 보여 준다.
- 함께 고침: 이어하기 창 "STAGE 9/3" → "STAGE 9/10".
