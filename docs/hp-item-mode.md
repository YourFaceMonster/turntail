# 싱글플레이 정식 아이템전

2026-10-26 사용자 결정에 따라 랜덤 장비 테스트의 전투 구성을 독립된 싱글플레이 아이템전으로 연결했다. 로컬 반영이며 빌드·배포하지 않는다. 수치와 지급량은 이후 실제 플레이로 조정한다.

## 진입과 구성

- 메인 → 싱글플레이 → 아이템전에서 시작·이어하기를 선택한다.
- 나와 AI 2명, 모두 HP 100으로 시작한다.
- 기본 소비 아이템 5종을 각각 2개씩, 총 10개 지급한다. AI도 동일하다. 2장 교환은 추가 아이템으로 남기며 기본 지급에는 넣지 않는다.
- 기존 랜덤 유물 3개 구성을 유지한다. 기존 유물 효과를 재설계하지 않았으며, 준비·경제·스테이지 보상을 전제로 하는 효과는 이 독립 대전의 후속 밸런스 검토 대상이다.
- 아이템과 HP는 카드 라운드 사이에 유지된다. 자동 보충·일괄 회복하지 않는다. 각자 자기 차례 1개, 카드 라운드당 3개 제한이다.

## 종료와 결과

- 라운드 수 제한이 없다. 5라운드를 지나도 모두 HP가 남아 있으면 계속한다.
- 손패를 비우면 해당 카드 라운드를 정산하고, 음수 점수만큼 HP를 차감한다. 기존 유물 피해 감소와 보호는 적용한다.
- 작열탄은 선택 즉시 최대 8 피해를 주며, 이 모드에서는 HP 0까지 내려간다. 누군가 HP 0이 되면 다음 패 제출을 기다리지 않고 바로 대전을 종료한다.
- 카드 라운드 승자와 최종 대전 순위는 별개다. 최종 순위는 남은 HP가 높은 순서이며, HP가 같으면 남은 손패가 적은 쪽이 앞선다. 완전히 같으면 기존 공동 순위 규칙을 따른다.
- AI의 아이템으로 즉시 종료될 때도 추가 카드 행동을 실행하지 않는다. Worker와 제한된 대체 처리 모두 같은 규칙이다.
- RPG 스테이지 이동·운명력 소모·보상 배분·자동 회복을 실행하지 않는다. RPG 여정의 기존 규칙은 별도로 유지한다.

## 저장·기록과 과거 모드

- 새 저장 키는 `turntale-hp-items-v1`이다. 진행 중인 판과 최근 10개 완료·중단 기록을 보관한다.
- 이어하기 목록, 아이템전 로비, 게임 내 전적, 기록실의 아이템전 기록에서 접근한다.
- 일반전·구형 10판 아이템전·점수형 도전·RPG·이전 장비 테스트 저장과 섞지 않는다. 기존 데이터는 자동 삭제·덮어쓰기하지 않는다.
- 새로 시작할 때 이 모드의 진행이 있으면 교체 확인 후 중단 기록을 보관한다. 완료 기록은 같은 대전 ID로 중복 생성하지 않는다. 저장에 실패하면 새 상태를 화면에 적용하지 않는다.
- RPG 허브에서 새 장비 테스트 시작 항목을 제거했다. 과거 테스트는 이전 저장으로만 남긴다. 구형 10판 아이템전도 신규 일반전 설정에서는 제거하고, 과거 이어하기·기록은 보존한다.

## 글꼴과 연출

- 메인 플레이 버튼·튜토리얼·기록실·업적·설정·프로필과 관련 팝업 제목을 굵은 Noto Sans KR 계열로 통일한다. 이전 Jua와 명조 혼용을 제거하고 과도한 글자 외곽선·입체 그림자를 줄인다. 턴테일 로고 그림은 유지한다.
- 새 게임 입장·패 섞기·분배 연출에서 더블클릭 또는 더블탭하면 실제 분배 상태를 그대로 둔 채 마지막 화면 전환으로 건너뛴다.
- 실제 게임과 패가 준비되기 전, 준비 화면, 저장 복귀 연출은 스킵 대상에서 제외한다. 스킵 시 연출 타이머와 움직임을 정리하고 입장 종료 뒤 추가 손패 대기 없이 플레이하도록 한다.

## 검증

- `tests/hp-item-mode.test.ts`: 7라운드 이상 계속 진행, 카드·아이템 HP 0 종료, 최종 HP 순위, AI 및 Worker 대체 처리의 즉시 종료, 독립 저장·교체·중복 기록·실패 처리, 스킵 가능한 단계 경계.
- 기존 RPG 아이템·여정·장비 테스트·저장 슬롯·10판 아이템전·기본 대전 테스트와 타입 검사를 수행한다.
- 실제 화면 취향과 기기별 터치 감각은 사용자 플레이로 확인한다. 빌드·배포·실기 확인 완료로 표시하지 않는다.

## 최근 조정 — 가독성과 타격감

- 낸 패 영역의 좌우 여백을 같게 하고 실제 패 묶음을 중앙에 정렬한다. 낸 패 크기는 현재 장수와 행의 실제 폭으로 제한한다.
- 폐기한 왼쪽 아이템 칸의 여백을 크기 계산에서도 제거한다. 손패와 낸 패에 각각 필요한 높이를 배정해 확대 후 하단 잘림을 방지한다.
- 상대 손패 수는 숫자만 표시하고, HP 색상 위에 흰 반투명 작은 칸으로 구분한다. 내 상태창의 중복 손패 수 문구는 제거한다.
- 상대 말풍선은 상태창 바로 아래에 붙인다. 가로 화면에서도 말풍선을 상대에게 붙이고 기존 손패 쪽 대사 행은 패 공간으로 돌려준다.
- 일반 숫자·두 자리 숫자·특수 2의 실제 SVG 숫자를 크게 조정한다. 기존 그림 전체를 확대하는 방식은 쓰지 않는다.
- 모든 공격·교환·회복·보호·정찰 사용을 중앙의 짧은 텍스트 알림으로 보여준다. 아이템 이름, 사용자와 대상, 필요한 효과를 표시하며 공개되지 않은 패 내용은 넣지 않는다.
- 피격 이미지는 제거한다. 대상 HP창에 피해 숫자를 위로 떠오르며 사라지게 하고, 붉은 점멸·흔들림·진동과 짧은 신음 효과음을 연결한다. 방어된 피해는 별도로 표시한다.
- 신음은 Web Audio로 로컬 합성한다. 외부 음성 서비스·음원 다운로드가 없으며 기존 효과음 볼륨·음소거·진동 설정을 따른다. 움직임 감소 설정에서는 흔들림과 반복 점멸을 줄인다.
- 한 판 3개 제한은 사람과 AI에게 독립적으로 적용한다. 자기 차례 1개 제한은 유지한다. 새 아이템을 소급 지급하거나 자동 보충하지 않는다.

## 최신 조정 — 비밀 방패와 첫 바퀴 제한

- 수호의 봉인은 개별 패 잠금을 폐기하고, 다음 적대적 아이템 1회(직접 HP 공격 또는 1·2장 교환)를 통째로 막는 비밀 방패로 변경한다. 막으면 방패가 소모되며 공격자의 아이템과 사용 횟수도 소모된다.
- 방패는 사용자가 먼저 준비한다. 상대의 방패 준비 상태·아이템 보유량·준비 알림을 숨기며, AI도 자기 방패만 읽는다. 공개 로그에는 준비를 남기지 않고, 실제 방어가 발동할 때만 공개한다.
- 방패가 남아 있으면 중복 준비할 수 없다. 소모되지 않은 방패는 카드 라운드를 넘어 유지한다. 일반 카드 판의 패배 정산·자기 회복·정찰에는 소모되지 않는다. 새 스테이지의 새 AI에게 이전 AI의 방패를 넘기지 않는다.
- 이전 저장의 개별 패 봉인은 불러올 때 비밀 방패 1회로 전환한다. 기존 물품을 임의로 추가하거나 차감하지 않는다.
- 각 카드 라운드의 최초 한 바퀴(3인전은 본 행동 3회)가 끝나기 전에는 모두 아이템을 사용할 수 없다. 유효한 패 제출·가져오기·패스만 본 행동에 해당하며 아이템 자체는 바퀴를 진행시키지 않는다. UI·실제 사용 검증·AI에 같은 제한을 적용한다.
- 아이템 사용 연출에는 내 이름을 아래, 왼쪽·오른쪽 상대를 위에 배치한다. 실제 사용자에서 대상 방향으로 화살표가 향하며, 아이템 그림·광채를 강화한다. 방패 준비는 자신의 화면에만 보인다.
- 바닥 패 영역은 비대칭 오른쪽 패딩을 제거해 실제 테이블 중앙에 정렬한다. 유물 칸과 겹치지 않도록 패 크기에만 좌우 대칭 안전 폭을 적용한다.
- 손패 영역은 카드 두 줄의 간격과 안쪽 여백까지 높이에 포함한다. 추천 행의 최소 높이와 선택 표시가 손패·버튼 경계를 넘어가지 않도록 조정한다.
- 실제 로컬 화면에서 바닥 패 묶음과 바닥 영역의 중심이 일치하고, 손패가 손패 영역·버튼 위쪽 경계 안에 들어오는 것을 DOM 측정으로 확인했다. 진행 중인 판의 HP·손패·물품은 변경하지 않았다.

## 다음 화면 조정 — 아이템 그림 중심 연출

- 하단 `1장 가져오기 / 아이템 / 선택 후 내기`의 좌우 열 너비를 같게 하여 가방 그림을 정중앙에 둔다.
- 가방은 기본 아이템 5종을 한 줄에 표시한다. 그림을 키우고 효과는 짧은 한 줄로 표시하며, 차례별 사용 현황 문장은 제거한다. 사용 불가는 회색 처리하고 자세한 사유는 접근성 이름과 버튼 도움말에서 확인할 수 있다.
- 인게임 로고의 별 세 개만 SVG 클립으로 가린다. 메인 로고 원본은 유지한다.
- 작열탄은 사용자의 자리에서 대상 상태창으로 날아가고, 도착할 때 불꽃과 수치·흔들림·피격음이 맞물린다. 수호의 봉인이 발동하면 시도한 공격 아이템이 방패에 부딪혀 튕기며 `공격/패 교환 차단`을 짧게 보인다.
- 정찰 렌즈는 패 확대 팝업을 띄우지 않는다. 기존 바닥 패에 약한 투시만 남기고 렌즈 그림을 중앙에서 확대·페이드한다. 다른 아이템도 배경 상자와 자리별 축소 표를 지우고 원래 아이콘·빛·실제 사용자/대상 위치로 뜻을 전달한다.
- 패 교환은 중앙 낸 패 자리를 연출 공간으로 잠시 비운다. 손패를 한 번 누르면 같은 패가 선택 공간에 보이고, 같은 손패나 미리보기 패를 두 번 누르면 교환을 확정한다. 선택만 한 상태에서는 자동으로 아이템을 쓰지 않는다.
- 이 수정은 아이템의 수치·소모·비공개 방어 규칙을 바꾸지 않는다.
