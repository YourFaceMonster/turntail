# 자막·세로 관문·장착 유물 크기 · 로컬 0.6.63

2026-11-02 사용자 후속 요청에 따라 수정했다. 이번 요청에는 빌드·게시 지시가 없어 로컬에만 저장한다.

- 프롤로그부터 ST3 연결 컷까지 자막 상자의 배경·테두리·패딩·그림자를 제거했다. 공통 18px 글꼴과 화자 표시를 유지하며 글자에만 그림자를 두어 그림 위에서 읽도록 했다. 화면 전체의 하단 암막도 제거했다. 같은 그림의 연속 대사에서 배경이 유지되는 기존 동작은 보존한다.
- 세로 연결 컷의 `contain`을 `cover`로 바꾸고, 현재 장소에 맞춘 위치 안내를 상단에 표시한다. 관문 그림은 화면을 채워 확대하며, 최종 성채 지도는 성채 쪽 초점을 사용한다. 승인 원본과 세로 그림은 보존한다.
- RPG 전용으로 아이콘을 축소하던 중복 규칙을 제거했다. `relic-rail.css` 하나가 RPG와 아이템전의 공통 유물 패널에 적용된다. 검은 패널의 불투명도·그림자·이중 테두리를 줄이고 아이콘은 공간에 맞게 키운다. 조건/효과 두 줄과 조합 효과·상세 팝업은 유지한다.

- 유물 클릭으로 '금이 간 심장 효과' 팝업 열림 확인.
- ST1 전투 전 연결 컷에서 계산된 자막 배경 투명·테두리0px·글꼴18px, 그림 `cover`와 뷰포트 전체를 덮는 크기 확인. 두 번째 대사에서도 상자 없이 관문·위치 안내와 함께 표시됨을 확인했다.
