# 0.7.9 · 요트다이스 화면 정리 (하로 패널 고정 · 점수 칸 흔들림 제거 · 주사위판 확대)

사용자 요청(2026-11-09): 0.7.8 이후 로컬 수정분을 배포 커밋. 상세 내용은 `docs/local-yacht-menu-2026-11-09.md`의 후속 2·3에 있다.

## 변경 내용
- **하로 족보 패널**
  - 칸 너비에 고정했다. 이전에는 컵을 흔들 때 141px에서 177px로 넓어졌다가 다시 줄었다.
  - 흔드는 동안의 문구는 "흔드는 중"이다.
- **"남길 주사위" 글자:** 남길 칸 위 가운데로 옮겼다. 안내 문구와 남긴 주사위를 덮지 않는다.
- **내 점수 칸:** 색으로만 표시한다. 떠오르기·깜빡임·확대 효과를 없애서 칸 크기가 바뀌어 보이지 않는다.
- **주사위판 크기:**
  - 세로 화면에서 주사위판 뒤에 가려져 있던 "여행자 · 굴림" 줄(34px)을 없앴다.
  - 높이 700px 이하 세로 화면에서는 점수 칸을 줄였다.
  - 375×580 기준 주사위판이 113×118에서 172×181이 됐다.
- **오른쪽 버튼:** "다시 굴리기 · 2회 남음"(두 줄)을 "다시 굴리기 (2회)"(한 줄)로 바꿨다.
