# 세로 주점·컷씬 연속성과 공통 자막 (2026-11-02, 로컬)

기준 0.6.62. 이전 미커밋 작업과 그림 원본을 보존하고 사용자 후속 요청을 반영한다. 이번 빌드·업로드·push는 없다.

- 승인된 가로 주점 v6를 기준으로 같은 방 구조·인물·화풍의 전용 세로 그림 `public/prologue/tavern-portrait-v7.png`를 제작했다. 세로 배경과 인물 움직임 레이어에 연결하고 모르·피오 클릭/빛/클리핑 위치를 조정했다. 기존 세로 v5는 보존한다. 제작은 내장 image_gen, turntale-cartoon-fantasy/imagegen 스킬 적용이며 원문은 story-tavern-v7-prompt.txt다.
- 깜빡임 원인: 기존에는 대사 ID마다 그림·자막을 포함한 전체 컷을 새로 마운트하고, 화면 전체 페이드와 카메라 이동을 다시 시작했다. 특별한 대화 효과를 위해 유지할 동작이 아니었다.
- 변경: 연속 대사에서 그림·초점이 같은 구간을 묶어 배경 DOM과 카메라를 유지한다. 대사만 별도 키로 전환하고 0.22초 나타남/사라짐을 사용한다. 다른 그림으로 바뀔 때만 0.45초 배경 진입 효과를 사용한다. 같은 그림에 다시 돌아와도 중간에 다른 장면이 있었다면 새 구간으로 처리한다.
- 프롤로그·ST1~3 전후·전체 이어보기는 동일한 Noto Sans KR/Arial/sans-serif, 본문18px·500·줄높이1.6, 이름12px, 동일 하단 상자를 사용한다. 관문만 커지던 글자, 암전 장면 중앙 배치와 큰 자간을 해제했다. 모션 감소 설정에서는 애니메이션을 정지한다.
- 대사 내용·순서·기존193초 시간표·스킵/종료 한 번 처리·재감상과 실제 저장 분리는 유지한다. 화면 터치는 350ms 연속 입력 방지를 거쳐 다음 대사로 이동한다.

짧은 연결 컷씬은 해당 시퀀스에서 사용하는 그림만 준비하며 관계없는 프롤로그 전체 그림을 다시 기다리지 않는다. 이미지 준비 실패/시간 제한 때 진행을 영구 정지하지 않게 하던 기존 처리도 유지한다.

이번 검증: 타입 검사·관련20개 검사 통과. 로컬 인앱 임시 탭에서 저장하지 않는 화면 테스트를 사용했다. 프롤로그P07과 ST3 쌍둥이 대사의 실제 글꼴18px, 358×124px 상자(390×740 화면), 동일 하단 위치를 비교했다. ST3_PRE_1→2 및 2→3에서 같은 그림을 유지하며 배경 진입 밝기가 다시0으로 내려가지 않고 이어지는 것을 확인했다. 세로 주점v7 연결·clientHeight/scrollHeight 모두730px·피오 선택과 대화 팝업을 확인했다. 캡처와 실제 스타일 비교는 루트 artifacts/story-continuity/에 보존했다. 실제 휴대전화·청감·모든33개 자막의 실기기 전수 관찰은 미검증이며 자동 검사와 구분한다.
