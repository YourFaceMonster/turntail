# 0.6.61 · 검토 이미지 실제 연결·세로 구도·주점 생동감

2026-11-02 사용자 전체 빌드·사이트 게시 요청에 따라 최신 검토본을 실제 RPG 화면에 연결한다. 직업은 기존 복장·장비·정면 구도를 유지하고 얼굴만 조정한 `face-refine-*` 4종을 사용한다. 중단된 동양 의복 변경안과 이전 얼굴 후보는 게시 화면에 연결하지 않는다. HP 아이템전의 기존 직업 선택 그림은 유지한다.

- ST1: 큰 닫힌 관문과 로웬·루미 → 승부 후 열린 성문.
- ST2: 로웬의 성 안 풍경에 맞춘 목조 집·석조 아치·파란 깃발·성채. 낮의 광장, 두 상대와 군중. 승부 전후 구도와 두 화자의 대사를 연결한다.
- ST3: 기존 실내 쌍둥이 도입 → 두 수호자가 안쪽 길을 열어 주는 새 후속 그림.
- 관문·광장·쌍둥이 전후, 주점, 지도의 전용 세로 그림을 실제 화면에 연결한다. 주점 세로판의 클릭 영역과 지도 위치를 새 구도에 맞춘다.
- 주점은 난로빛의 미세한 변화, 잔의 김, 인물 주변의 은은한 명암 호흡을 더한다. 그림 전체를 변형하지 않는다. 모션 감소 설정에서는 애니메이션을 중지한다.

새 이미지 17종은 원본을 보존하며 버전 파일로 복사했다. 생성 방식은 built-in ImageGen이고 원본·최종 프롬프트는 워크스페이스 `artifacts/rpg-art-review-2026-11-02/`의 기록을 따른다. 최신 게임 연결 파일에는 `r61` 접미사를 사용한다. 추가 이미지 생성 없이 검토본을 연결한 게시다.

타입 검사·관련 연결/저장/재생 검사를 실행하고 같은 소스의 운영 빌드를 Sites 게시 헬퍼로 패키징한다. 실제 실행 결과와 커밋·저장본·배포 상태는 워크스페이스 `artifacts/deployment-0.6.61.json`을 따른다. 실제 기기·청감·운영 저장으로 플레이하는 확인은 별도이며 배포 성공이나 HTTP 응답으로 대신하지 않는다.
