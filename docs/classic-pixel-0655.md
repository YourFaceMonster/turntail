# 일반모드 픽셀아트 버전 — 로컬 0.6.55

2026-11-01. 시작 버전 0.6.54, Git HEAD `d65414abfb20da03ed03b5d42c94b48df2895cf2`. 기존 일반모드와 앞선 RPG·폭탄시장전 미커밋 작업을 보존했다. 이번에는 **기존 일반모드 유지 + 별도 픽셀아트 일반모드 추가**를 수행했다. 폭탄시장전 화면 개편은 이번 변경 범위에 넣지 않았다. 프로덕션 빌드·커밋·push·원격 저장·사이트 업로드는 하지 않았다.

## 사용

- 기존 버전: `/` → 싱글플레이 → **일반모드**.
- 새 버전: `/` → 싱글플레이 → **일반모드 픽셀아트**, 또는 `/classic-pixel`.
- 픽셀 버전에서도 기존 메인 → 싱글플레이 → 일반모드 설정 → 3·4인 선택 → 대전 시작 흐름을 사용한다. 픽셀 버전 설정 제목은 `일반모드 · 픽셀아트`다.
- 픽셀 진행은 픽셀 버전 메인의 이어서 하기로 재개한다. 기존 일반모드 진행을 덮어쓰지 않는다.

## 기존 UI·UX를 유지한 방법

`app/classic-pixel/page.tsx`는 별도 게임 화면을 복제하지 않고 **기존 `app/page.tsx`의 Home 전체를 그대로 렌더링**한다. 외형 컨텍스트만 추가한다. 분배·규칙·AI·바닥 접근·턴·족보·정산 엔진, 레이아웃 계산, 더블탭·드래그·추천·선택·제출·패 비행·입장·이어하기 코드는 공유한다. 이번에 공용 `lib/game.ts`, `lib/bot.ts`, `lib/layout.ts`, `lib/selection.ts`, `lib/tile-gestures.ts`를 수정하지 않았다.

기존 테이블·상대 상태창·손패·제출 공간·버튼의 크기와 위치를 새로 정의하지 않았다. 픽셀 CSS는 색·이미지·그림자·장식 등 외형 속성만 덮어쓰며 배치·크기·변환·애니메이션 속성을 변경하지 않는 검사를 추가했다. 기존 버전에서는 컨텍스트 기본값이 false여서 원래 그래픽 경로를 사용한다. 다른 모드의 대전에서는 픽셀 외형 컨텍스트를 해제한다.

## 그래픽

- 사용자 첨부를 스타일 참고로 삼아 기존 달빛 서재의 창문·성·커튼·책장·의자 구성을 유지한 픽셀 배경을 생성했다.
- 청돌·불찬·돌해·히보의 정체성과 옷을 유지한 픽셀 초상화 4종 아틀라스를 생성했다.
- 기본 호두나무 소재의 결·색을 유지한 픽셀 목재를 생성했다. 기존 월드의 640px 피치·반복 경계·원점을 그대로 사용한다.
- 기본 패와 해금 재질 10종은 기존 React SVG 그래픽 자체를 40×53px로 래스터화했다. **총 660 앞면 + 비활성 숫자용 660 앞면 + 11 뒷면**. 숫자·문양·장식·재질 선택은 원래 것을 유지한다. 비활성 숫자는 기존 회색 표시를 유지하고 문양은 원래 색을 유지한다. 손패·바닥·제출·비행·입장 GPU가 같은 패 컴포넌트를 사용한다.
- 금빛 픽셀 테두리는 코드 SVG와 border-image로 추가했다. 테두리 장식은 레이아웃 크기를 바꾸지 않는다. 본문 글자는 기존 글꼴·크기를 유지한다.
- 입장 전신 캐릭터와 사용자 프로필 사진은 기존 원본을 유지한다. 전신 픽셀 시안은 셀 경계·배경 품질이 적합하지 않아 게임에 연결하지 않고 `artifacts/classic-pixel-20261101/`에 보존했다. 해금 테이블 1~10의 표면 질감은 기존 자산을 재사용하며, 해당 재질 패의 앞·뒷면에는 전용 픽셀 아틀라스를 적용한다.

선택한 이미지 파일은 `public/pixel-classic/room-0655.png`, `portraits-0655.png`, `walnut-0655.png`다. 기존 원본 자산은 덮어쓰지 않았다. **내장 image_gen 사용**, CLI/API fallback은 사용하지 않았다. [모든 생성 프롬프트·출처·선택/미적용 시안 기록](assets/classic-pixel-0655.json).

## 저장 정책

기존 저장 형식이나 Game 객체에 스타일 필드를 넣지 않는다. 픽셀 버전에서 다음 키만 `turntale-pixel-classic:` 접두사가 있는 별도 키에 연결한다.

`jangseong-practice-game`, `jangseong-session`, `jangseong-practice-records`, `jangseong-practice-groups`, `turntale-last-korean-opponents`.

기존 버전에서는 같은 어댑터가 원래 키를 그대로 전달한다. 설정·프로필·업적·하이스코어·해금 등은 기존 기능을 공유하고, 기존 항목을 삭제하거나 초기화하지 않는다. 실제 일반모드 저장을 메모리 저장소에 만든 뒤 픽셀 저장·불러오기·선택 삭제를 해도 원래 진행과 세션이 바이트 단위로 유지되는 테스트를 통과했다. 브라우저 검증용 픽셀 진행은 별도 저장에 남겨뒀다.
