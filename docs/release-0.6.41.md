# TURNTALE 0.6.41

전투와 아이템 연출이 다음 행동에 덮이지 않도록 순서를 정리했다. 미배포 0.6.40의 정산 음악·함정 경고·뒤집기 소리·투시 피해 색 수정도 포함한다.

- 싸움 결과를 승리자·기본 피해·HP 이전/이후·발동 효과가 있는 한 화면으로 통합했다. 불필요한 중간 승리 팝업과 반복 설명을 제거하고 직접 확인할 때까지 유지한다.
- 추가 피해는 빨간 `−`, 회복은 정산 주화와 같은 초록 `+`로 표시한다. 피해·회복 숫자는 작아지면서 HP 위에 남는다.
- 마지막 싸움도 먼저 확인하고 1초 뒤 판 정산을 표시한다. 함정은 4.8초 연출 뒤 1초 여유를 두며 주화와 겹칠 때도 순서대로 보여준다.
- 족보 글자 표시가 끝난 뒤 다음 AI의 아이템이 시작된다. 기존 낸 패는 새 패가 도착한 뒤 투명해진다.
- 작열탄의 바닥 방향을 타일판 기준으로 맞추고 약초의 중복 회복 문구를 없앴다. 상대 아이템 아이콘은 좌우 남은 패 숫자 옆에 배치하고 유물 알림은 반투명으로 표시한다.
- 마법사 포카드·5장 족보 자동 효과는 승리 때마다 발동한다. 기존 수동 게이지 스킬은 유지한다.
- AI 구매의 잔액 차감을 확인하고 누락된 저장 인벤토리에 무료 기본 아이템을 채우던 아이템전 예외를 막았다. 준비금과 보유품 이월 규칙은 유지한다.

상세 요청별 반영·실행한 검사·구형 검사 한계는 [0.6.41 로컬 기록](local-0.6.41.md)을 따른다. 관련 현 규칙 검사 14개와 타입 검사를 통과했다. 사용자의 요청에 따라 최종 소스의 타입 검사·운영 빌드를 패키징에서 실행하고 기존 공개 범위를 유지해 배포한다. 결과는 워크스페이스 `artifacts/deployment-0.6.41.json`에 기록한다. 이전 배포 기록을 이번 빌드 성공으로 표현하지 않는다.
