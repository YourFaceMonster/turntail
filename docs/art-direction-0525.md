# Regional materials · 0.5.25

Nine standalone tabletop textures were created with the built-in image_gen tool in edit mode, using the existing stage atlas as the reference. Every output is 1254 × 1254 pixels, encoded to WebP at quality 94 without upscaling. The existing stage-one sandstone and default walnut remain from 0.5.24. All ten challenge stages now use their own standalone source in the introduction, live surface, preview and slab sides.

Stone and plank grain use a 640 CSS-pixel mirrored repeat. Stages 5, 7 and 10 retain a single centred radial tree cross-section, with fine vector ring detail; they do not repeat a grid of stumps. The final viewport shares the intro texture origin. Side-material canvas caching is bounded to two regions.

## Rendering changes

Each character now paints only its own source cell once to a canvas plane. Mirroring is applied to the artwork wrapper. The 3D seat no longer carries a flattening drop-shadow filter, and the focus fade is applied to the local artwork instead of the whole 3D company. Body sway rises by up to 1.9% and rotates between −0.85° and +1.15°, with independent 3.2–4.1 second phases. Preview bounds reserve 4.5% of body height for movement.

Stage-two tiles now use a light honey base (`#ecd2a2`) and a 22% wood texture, instead of the former dark-brown base with 70% texture. Suit identity and numeric rank are preserved.

## Validation limits

Family switching, visible pair/triple ranks, variant cycling, single-size locking, all-region materials and readiness, isolated character paints, and existing strategy/framing tests passed. Materials and stage-two faces were visually inspected through static renders.
