# 2026-11-03 · 시장 골목 위치·모르 대사·게시판 정리

## 반영 사항

- **시장 뒤 골목** 지도 지점을 오른쪽 아래로 옮기고 경로선을 다시 연결해 마을 잡화점과 간격을 벌렸다. 세로 화면 배치도 같은 방향으로 조정했다.
- 모르를 누를 때마다 유물 조합 팁을 새로 띄우던 연결을 제거했다. 현재 대사는 봉인 편지 의뢰 상태(미수락·골목 조사·편지 회수·완료)에 맞춰 안내하도록 정리했다. “피오가 알려준 골목” 같은 반복 문장은 덜어냈다.
- 주점의 **눈길에 묻힌 부탁** 게시판 의뢰와 보상 선택 UI를 제거했다. 게시판 핫스팟은 클릭되지 않는 빈 게시판 표시로 남겼다.

## 확인

- 기존 소스의 액션·지도 위치·대사 분기를 정적으로 검토했다.
- 화면 플레이·테스트·빌드는 하지 않았다.
- `pnpm exec tsc --noEmit`는 변경 코드 오류 없이 진행됐고, `tests/bomb-classic.test.tsx` 두 곳과 `tests/bomb-market.test.ts` 한 곳의 null 가능성 오류 때문에 전체 통과하지 못했다.
- `git diff --check`는 통과했다. Git은 작업 파일의 LF→CRLF 변환 예정 경고만 표시했다.
- 버전은 `0.6.66` 그대로다. 커밋·push·Cloudflare 배포는 하지 않았다.
