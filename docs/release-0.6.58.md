# 0.6.58 · 프롤로그와 RPG 화면 테스트 게시

2026-11-01 사용자 사이트 업로드 요청. 기존 Sites 프로젝트 `appgprj_6ad9b09474d88191a6bff316295bed46`와 공개 범위를 유지한다. 0.6.56 게시 이후 로컬 변경을 포함한다.

- 0.6.57 폭탄시장전 메뉴 클릭 수정: 클라이언트 이동 오류를 피하는 일반 링크. 당시 실제 클릭 검증은 [그때 기록](local-0.6.57.md)과 구분한다.
- 약 68초 자동 RPG 프롤로그: 설원→주막→승부 직후→낡은 2→석비→기존 지도/ST1. 자막·탭·스킵·음향·가시성 정지/복귀·중복 입장 방지. [상세](rpg-prologue-local.md).
- RPG 메뉴의 프롤로그·화면 테스트와 한 판 통과 테스트. 테스트 진행은 메모리에서만 유지하며 실제 RPG/예전 장비 테스트 저장을 보존한다. [사용법](rpg-preview-local.md).
- 프롤로그·화면 테스트는 주점이 열린 지도부터 시작하며 화면 바로가기에서 주점·지도·프롤로그 재생·ST1~3 화면을 전투 없이 선택한다. 한 판 통과는 승패·HP와 관계없이 판 종료 후 다음 지도를 연다.
- 기존 전투·보상·AI·지도 및 실제 RPG 저장 형식/키를 변경하지 않았다. 이전에 제외한 픽셀 버전은 계속 제외한다.

## 검증과 제한

게시용 최종 타입 검사와 프롤로그·테스트 모드·기존 RPG 지도/스테이지·폭탄 연결 검사를 새로 실행하고, Sites 소스 헬퍼에서 같은 소스의 운영 빌드 결과를 패키징한다. 최종 실행 결과·커밋·저장 버전·배포 결과는 루트 `artifacts/deployment-0.6.58.json` 및 `artifacts/publish-0658/`를 따른다. 빌드와 배포 성공을 미리 가정하지 않는다.

앞선 로컬 검증과 이번 게시용 검증을 구분한다. 기존 전체 테스트 21개 실패나 `RpgJourney.tsx` 원본 조건부 Hook 린트 오류를 이번에 모두 해결했다고 표현하지 않는다. 이번 전체 테스트/전체 린트를 실행하지 않는다.

브라우저 사용이 Work 설정에서 비활성화되어 실제 모바일/PC 화면·주점 직접 이동 클릭·청감은 미검증이다. 정적 렌더·타입/엔진 검사·배포 상태·HTTP 응답을 실제 화면 조작 확인과 혼동하지 않는다. 프롤로그 설원·인물·손·패·석비는 교체 가능한 임시 CSS/SVG 미술이고, 정식 엔딩 자료가 없는 2회차는 데이터/인터페이스만 준비되어 실제 노출되지 않는다.

사용자 저장을 초기화하거나 운영 새 게임을 실행하지 않는다. 이번 업로드 이후 별도 빌드·게시 지시가 없는 수정은 다시 로컬 저장만 한다.
