# TURNTALE 0.6.37

바닥패 수집의 보상과 함정이 분명하게 보이도록 연출을 정리했다.

- 함정 설치 아이콘의 중앙 정렬과 두 자리 숫자의 자연스러운 굵기·크기를 조정했다. 패 문양 원본은 보존했다.
- 도적이 직업 스킬로 투시한 패를 직접 가져오면 상대 각각 1 피해를 준다. 렌즈만으로 본 패에는 발동하지 않으며 재발동하지 않는다.
- 주화를 발견한 뒤 수집자 이름·초록색 +P·지갑 이동·잔액 합산을 순서대로 보여준다. 발견 2.2초, 수집 3.6초 동안 다음 차례가 기다린다.
- 손패 수가 달라져도 바닥 배치를 고정하고 바닥 전체의 흔들림을 제거했다.
- 정산의 바닥 주화 보상을 두 번째 주화 줄로 옮겼다.
- 함정 공개와 확대·쾅·충격파·피해 숫자·캐릭터 반응·웃음 말풍선을 추가했다. 함정과 주화가 겹치면 읽을 수 있도록 순서를 나눈다.

주화는 기존과 같이 도적 1P·다른 직업 3P, 마지막 5P, 겹친 마지막은 도적 6P·다른 직업 8P다. 비공개 패·숨겨진 주화 정보를 일반 AI나 상대에게 공개하지 않는다. 저장 원본과 진행을 보존한다.

## 검증 및 배포

이전 로컬 검증은 [local-0.6.37.md](local-0.6.37.md)에 기록했다. 타입 검사와 관련 기능 20개, 모바일·가로 화면 확인을 통과했고 기존 폐기 spark-dart 기대값 테스트 1개의 실패는 별도로 구분했다.
