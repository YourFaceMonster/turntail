# 0.6.57 · 폭탄시장전 메뉴 클릭 수정 (로컬)

2026-11-01. 공개0.6.56 / Sites112 / 커밋 `3ca01e42492254a67bd19196ed5f27d98b09f337`에서 사용자 보고를 실제 클릭으로 재현했다. 기존 작업 지침에 따라 이번 요청은 로컬 수정·검증만 하며 프로덕션 빌드·커밋·push·게시하지 않았다.

## 원인과 변경

공개 메인 → 싱글플레이 → 폭탄시장전 클릭 시 화면과 URL이 그대로이고, 콘솔에 `[vinext] RSC prefetch setup error: TypeError: f is not a function` 및 클릭 시 `TypeError: e is not a function`이 기록됐다. 버튼 위를 덮은 요소가 원인은 아니었다. 링크는 `/bomb-market`과 정상적인 포인터 입력 상태를 갖고 있었다.

`app/components/SinglePlayer.tsx`에서 이 항목만 `next/link.js`의 클라이언트 이동 대신 일반 `<a href="/bomb-market">`로 변경했다. 브라우저 기본 탐색으로 전용 페이지를 열어 오류가 나는 이동 처리를 통과하지 않도록 했다. 그래픽·스타일·다른 모드·게임 엔진·저장 키는 바꾸지 않았다. `package.json`, `lib/version.ts`를 로컬0.6.57로 올렸다.

## 이번 확인

- 기존 메뉴/픽셀 제외/재질 렌더링 및 폭탄 표시 연결 검사 **12개 통과**.
- TypeScript 검사 통과.
- 실제 로컬 브라우저에서 주소 직접 입력 대신 **싱글플레이 → 폭탄시장전 메뉴를 클릭**해 URL이 `/bomb-market`으로 바뀌고 폭탄 로비0.6.57이 나오는 것을 확인했다. 브라우저 오류 로그 없음.
- 이어서 `폭탄시장전 시작`을 눌러 3인·손패15장·공개시장15장·50점·5판·3초 반응 설정창이 열리는 것을 확인했다. 마지막 새 게임 실행 버튼은 누르지 않아 기존 진행을 교체하지 않았다.
- 공개 사이트는 여전히0.6.56이며 메뉴 수정은 미반영이다. 대신 공개 `/bomb-market` 직접 접근은 실제 브라우저에서 정상 로비 표시를 확인했다.
- 이번 프로덕션 빌드·운영 전체 게임·실기기 터치 확인은 하지 않았다. 앞선 배포에서 메뉴 표시만 확인하고 실제 진입 클릭을 검증하지 못했던 부분을 이번에 재현·수정했다.

로그·화면·수정 전 파일은 워크스페이스 `artifacts/bomb-click-0657/`에 보관한다. `production-errors.json`은 공개 오류 재현, `local-after-click.jpg`는 수정된 로컬 메뉴 클릭 뒤 열린 설정창이다.
