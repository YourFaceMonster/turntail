# 0.6.34 · 아이템전 확장과 사용자 제작 효과음

2026-10-28 사용자의 전체 사이트 업로드 요청에 따라, 마지막 배포 0.6.32 이후의 로컬 변경을 함께 배포한다. 빌드·배포의 실제 결과와 URL은 체크아웃 바깥 `artifacts/deployment-0.6.34.json`에 별도 기록한다.

- 아이템전 직업 특성, 도적의 비공개 바닥 투시·함정과 렌즈 함정 탐지를 연결했다. 새 규칙은 새 직업 아이템전부터 적용하며 기존 저장은 이전 규칙으로 이어간다.
- 기존 RPG 유물 목록을 유지하고, 아이템전의 별도 유물 목록에 신규 7종을 추가했다. 승리한 마지막 족보·문양으로 발동하며 직업 스킬과 중첩한다. 선구자의 눈은 새 아이템전 첫 분배에만 적용한다.
- 유물 7종과 네 직업 이미지를 제작했다. 직업 선택 이미지는 기존 인물 특징을 유지한 정면 구도이며 카드 전체를 채우도록 표시한다. 기존 그림도 보존한다.
- 사용자 제작 효과음 9종을 패 선택·제출·착지·가져오기·차례·라운드 종료·빨간 2·승리 팡파르에 연결했다. 기존 효과음 음량·음소거·리미터를 유지하고 준비 실패 시 합성음을 사용한다.
- 메뉴 BGM `menu-suno-0632.mp3`와 인게임 BGM `table-suno-0631.mp3`를 포함해 기존 음원을 유지한다.

상세 동작·프로토타입 수치·저장 호환은 `local-0.6.33.md`, 효과음 번호·원본 해시·음량 보정은 `local-0.6.34.md`와 `assets/sound-261028.json`을 따른다. 직업 및 유물 수치는 사람 플레이로 추가 조정할 대상이다.

로컬 검사에서 과거 테스트 `hp-item-battle.test.ts`와 `hp-item-mode.test.ts`의 실패 두 건은 수정 전 0.6.32에서도 동일하게 재현했다. 폐기된 바늘탄과 구형 모드 이어하기를 기대하는 항목이며 이번 배포에서 과거 기능을 되살리지 않는다. 배포 준비에서는 신규 규칙·효과음과 관련 회귀 검사 및 타입 검사·운영 빌드를 수행한다.
