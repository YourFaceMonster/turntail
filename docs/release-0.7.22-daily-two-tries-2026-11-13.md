# 0.7.22 · 오늘의 판 2번 도전·도전 횟수 표시·새 패 (2026-11-13)

사용자 요청: "오늘의판 최대 2번까지 도전가능하게하고 도전횟수도 같이 표기해줘 / 만약 동점이면 도전횟수 적은쪽을 1등으로", "오늘의판 다른걸로 한번 바꿔주고", "배포해줘". GitHub main push 후 Cloudflare가 자동 배포한다.

## 변경
- 하루 순위 도전 2번(끝까지 마친 판 기준). 끝나지 않은 판은 기존처럼 다음 판이 이어받는다. 2번을 다 하면 이후는 연습판.
- 두 판 중 높은 점수만 순위에 남는다(같은 점수면 먼저 낸 기록 유지). 1등 표시도 그 판 기준.
- 순위 정렬: 점수 높은 순 → 도전 횟수 적은 순 → 먼저 기록한 순.
- 순위 줄·내 순위에 "도전 N회", 시작 버튼에 (1/2)·(2/2) 표시, 남은 도전 안내.
- `daily_scores`에 `tries`·`open` 열을 자동 추가하고, 기존 행은 완료=1회 사용, 미완료=진행 중으로 옮긴다.
- 패 섞는 기준값 v2(`DAILY_DEAL_VERSION`). 모든 날짜의 패가 이전과 달라진다. 배포 당일 이미 이전 패로 기록한 점수는 그날 순위에 섞여 남는다.
- 버전 0.7.22 (package.json, lib/version.ts).

## 포함하지 않은 것
- 다른 세션의 프롤로그·ST3 special-v2 그림 등 미커밋 파일.
