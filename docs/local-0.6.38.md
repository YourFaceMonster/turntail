# 0.6.38 로컬 변경 및 검증

2026-10-28. 사용자 요청에 따라 로컬에서 수정하고 검증했다. **운영 빌드·원격 저장·push·사이트 업로드는 하지 않았다.** 사이트는 마지막 배포 기록 기준 0.6.37 / Sites 저장본 101이다.

## 이번 변경

- 주화 표시 3.6초 이후 **1.4초의 여유**를 더 둔다. 지갑 합산은 기존처럼 2.6초 시점이며 다음 행동은 주화 연출 시작으로부터 5초 이후 가능하다.
- 주화를 가져오며 싸움이 끝난 경우, 싸움 연출의 기준 시각을 주화와 여유 시간이 끝난 뒤로 옮겼다. 주화 수집과 승리·피해 결과가 동시에 뜨지 않는다. 같은 패의 치명적 함정으로 대전이 끝나도 주화 확인 시간을 유지한다. 실제 지급·피해 계산은 확정하고 화면 표시만 순서대로 진행한다. 과거 주화 기록 때문에 이후 싸움까지 불필요하게 지연하지 않는다.
- 상대 상태창의 `아이템과 방어 준비는 비공개` 문구를 삭제했다. 비공개 데이터 처리 자체는 유지한다.
- 상단 라운드 글자 뒤에 어두운 반투명 바탕·얇은 테두리·음영을 추가했다.
- 상대가 패를 내 3장 이하가 될 때 바닥이 움직이는 현상을 재현했다. `.active-table .felt > *`의 상대 배치 규칙이 `.opponent-hand-alert`의 절대 배치를 덮어, 알림이 바닥 격자의 추가 행이 되고 있었다. 알림 노출 중 바닥 높이가 37px 줄고 패가 18.5px 이동했다. 알림을 직접 자식 오버레이로 고정해 격자 공간을 차지하지 않게 했다. 랠리 오버레이도 명시적으로 고정하고, 낸 패 영역의 흔들림과 바닥 컨테이너의 이동 효과를 차단했다.
- 전역 CSS에 남아 있던 손패 예약 높이 규칙도 `hand-space-h`로 통일했다.

앞선 로컬 변경인 `판당 1회` → `(1회)`도 유지한다. 두 자리 숫자 확대와 직업별 수동 스킬은 [후속 메모](next-update-notes.md)에 보존한 별도 작업이며 이번에 구현하지 않았다. 직업 스킬 수치 제안도 아직 확정값으로 취급하지 않는다.

## 이번에 실행한 검증

- 기능 파일 11개 모두 통과: coin-tempo, pickup-0637, floor-coins, item-battle-1033, hp-item-original-base, hp-battle-summary, character-visuals-0635, fixed-floor-0526, item-shop-0630, rpg-profession-combat, visibility-and-rank. 기존 미배포 문구 변경도 포함해 검사했다.
- 새 coin-tempo 검사는 주화 이후 행동/AI 대기, 주화 다음의 승리·피해 결과 타이밍, 과거 주화 기록 배제, 치명적 함정 시 주화 보상과 최종 결과 대기를 검증한다.
- TypeScript noEmit 검사 통과. 빌드는 실행하지 않았다.
- 메모리 전용 저장을 사용하는 로컬 개발 화면에서 390×844, 320×740, 가로 모드 844×390을 확인했다. 상대 한 장·다섯 장 제출, 랠리 전환, 싸움 종료/새 선, 남은 패 알림의 등장과 사라짐을 프레임별 DOM 좌표로 관찰했다.
- 수정 전 알림 발생 시 **패 Y 이동 18.5px / 바닥 높이 변화 37px**를 기록했다. 수정 후 세로·가로에서 실제 3장/2장 알림의 등장·퇴장 중 **패의 좌표·크기와 바닥 영역 변화가 모두 0**임을 회귀 검사로 확인했다.
- 주화 발견 → 획득자 → 지갑 합산 → 빈 여유 구간 → 승리 → 싸움 결과가 겹치지 않는 것을 화면 기록으로 확인했다. 상대 상태창의 문구 삭제와 라운드 바탕도 확인했다. 최종 검증 탭에서 브라우저 오류 없음.
- 사용자 저장은 읽거나 수정하지 않았다. 개발 검증 진입점은 작업 후 artifacts로 보관하고 앱 루트에 남기지 않는다.

증거는 워크스페이스 artifacts의 `validation-tempo-floor-tests.json`, `validation-alert-floor-regression.json`, `validation-local-0.6.38.json`, `local-0638-coin-fight-timeline.json`, `local-0638-alert-*.json`, `local-0638-final-landscape.png`에 보관한다. 운영 사이트를 수정하거나 이번에 실시간 재검증한 기록은 아니다.
