# 0.6.22 · 이전 결과 UI로 정리

0.6.21의 커진 전투 승리 패널을 없애고, 0.6.20의 작은 초록색 결과창 구성을 유지한다. 제목은 승자·조합 승리를 한 줄로 표시한다. 각 상대의 아바타·이름·HP 전후 수치·피해량은 캐릭터 색상의 HP 바 안에 함께 넣는다. 흡수 포인트와 클릭 안내도 마지막 한 줄에 합친다. 스킬 적용 상세는 접어서 필요할 때 펼친다.

0.7초 충격 대기, 클릭 전까지 유지, AI 행동 대기, 내 HP 중복 문구 수정, 이미지 생성 불꽃, 바늘과 봉인 연출은 유지한다. 라운드 정산창은 이미 적용된 기존 HP 바 내 아바타·이름·등수·HP·증감량 구성을 유지한다.

브라우저 확인: 패널 높이 약 173px, 두 상대의 모든 표시가 HP 바 안에 배치됨. 클릭하면 확인 대기가 해제됨. TypeScript·전투 피드백·현재 모드2 통합 회귀 검사 및 로컬 빌드 통과. 사이트 업로드 없음.
