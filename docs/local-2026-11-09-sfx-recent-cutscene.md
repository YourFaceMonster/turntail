## 변경 내용 (2026-11-08 저녁 작업, 2026-11-09 검증)

### 효과음
- 새 효과음 14개: `public/audio/sfx-261108/*.wav`.
  - 클릭·확인·뒤로·대사 넘김·지도 이동·패스·피격·회복·아이템·방어·유물·이야기 패·클리어·실패.

- 연결 위치

### 최근 패 열
- 지금 판 위에 있는 패는 "최근" 열에서 뺀다(가운데에 이미 보이므로). 그래서 저장 건수를 3건에서 4건으로 늘렸다(`RECENT_TRICK_PLAYS=4`). 화면에는 계속 3칸이 보인다.

### 컷신 다시 시작 버그
- `journeyScenes`·`journeyStoryReel`이 화면을 다시 그릴 때마다 새 배열을 만들었다. 그래서 컷신이 처음부터 다시 시작되고 그림도 다시 불러왔다.
- 대사에 영향을 주는 조건(스테이지·회차·ST7 2등·편지·서브퀘스트 선택)이 같으면 같은 배열을 돌려주도록 캐시했다(`lib/rpg-chapter-scenes.ts`).

## 추가 · 가로 화면 정리 (2026-11-09)

사용자 승인: 가로 화면 UI 문제 4건을 제안한 순서대로 정리.

1. **화면 방향 자동 선택** (`lib/layout.ts` `resolveTableLayout`, `app/page.tsx`)
   - 이전: 표 배치는 항상 세로로 시작했고, 가로는 설정에서 골라야만 켜졌다.
   - 지금: 폰·태블릿을 가로로 들거나 창 높이가 500px 이하인 가로 창이면 가로 배치를 고른다. 넓은 데스크톱 창은 지금처럼 세로 배치다.
   - 설정에서 고른 값을 우선하고, 기기를 다시 돌리면 자동으로 돌아간다.
2. **가로 배치 재구성** (`app/landscape-stacked.css` 신규, 마지막에 로드. `tileLayout`의 `stackedLandscape`)
   - 낸 패 줄을 왼쪽 아래에서 오른쪽 손패 위로 옮겼다. 바닥패가 왼쪽 열 높이를 전부 쓴다.
   - 일반모드·RPG는 손패 제목을 한 줄로 접었다(이름 · 자동 선택). 아이템전은 포인트·스킬 안내가 있어서 두 줄로 둔다.
   - 폭탄시장전 가로 화면은 바꾸지 않았다.
   - 844×390에서 측정한 크기

     | 모드 | 바닥패 | 손패 | 낸 패 |
     |---|---|---|---|
     | 일반모드 | 53 → 77px | 68 → 65px | 48px |
     | RPG ST5 | 66px | 61px | — |
     | 아이템전 | — | 약 55px | — |

3. **가로 최근 패 열:** 바닥패 높이에 맞춰 늘렸다. 글씨는 숫자 10→12px, 이름 8→9px로 키웠다.
4. **RPG·아이템전 가로 유물 칸**
   - 설명 글씨를 8px에서 9.5px로 키우고, 높이를 바닥패에 맞췄다.
   - 이전에는 바닥패 오른쪽 끝을 9px 넘었는데, 지금은 바닥패 안에 들어간다. 바닥패 좌우 여백은 왼쪽 60px(최근 열), 오른쪽 86px(유물 칸)이다.
   - 낸 패 줄이 위로 올라가서, 아래쪽 끝에 붙던 표시도 없어졌다.
