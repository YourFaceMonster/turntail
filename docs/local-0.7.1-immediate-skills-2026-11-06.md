# 0.7.1 · 스킬 즉시 적용·정산창 통합

사용자 확정: 직업 스킬은 즉시 적용, 기본 패 피해와 남은 패 점수/주화만 마지막에 정산한다. 도적의 숨겨진 바닥패 확인은 즉시 본인에게만 누적 공개한다. HP 0 즉시 탈락과 기존 모드별 전투 종료 조건을 유지한다. 수정·검증·빌드·GitHub push·Cloudflare 배포까지 명시 승인받았다.

## 변경

- 먼저 열리던 ‘판 전체 정산’ 리뷰를 roundRules 전투에서 차단하고 기존 ‘이번 판 정산’만 유지한다. 기존0.7.0 저장의 합산 이벤트가 남아 있어도 중복 리뷰를 다시 열지 않는다. 내부 정산 기록은 보존한다.
- 페어 이상 족보 승리 시 검사 무작위1명 공격, 마법사 전체 공격, 성직자 자기 회복을 즉시 HP에 적용한다.0.7.0에서 합의한 낮은 수치를 그대로 사용한다. 추가 피해 조건·게이지·수동 스킬은 되살리지 않는다.
- 도적은 페어 이상 승리 시 즉시 숨겨진 바닥패를 확인한다. 확인한 패는 본인에게만 누적 공개하고 해당 패가 바닥에서 없어지거나 판이 끝나면 정리한다. 트리플 이상 함정은 즉시 설치하고 밟으면 피해도 즉시 적용한다. 자기 회수는 안전하게 제거한다.
- 미발동 함정의 판 종료 피해1은 유지한다. 빈 바닥의 함정 대체 피해1은 발동 시 즉시 반영한다. 이미 탈락한 도적의 함정은 기존 퇴장 규칙으로 제거한다.
- 싱글 기본 피해는 상대 각각1을 적립하고 한 명이 실제 손패를 비웠을 때만 적용한다. 페어 이상은 직업 효과로 대체하므로 기본 피해를 덧붙이지 않는다. 이미 적용한 직업/아이템/유물 피해·회복은 최종 정산에 재적용하지 않는다.
- 소비 아이템·유물의 HP 효과도 즉시 반영하고 기존 방어 유물·방어량·최대 HP·실제 피해량 제한을 적용한다. 결과에는 실제 적용된 총피해·회복을 기록한다.
- RPG는 HP0인 참가자를 즉시 퇴장시키고, 플레이어 HP0 또는 적 전멸 시 기존 패배/보상 절차로 연결한다. 아이템전은 기존처럼 누군가 HP0이면 즉시 대전 종료하며 미완료 손패의 기본 피해/주화를 추가 정산하지 않는다.
- 진행 중 긴 스킬/결투 확인창이나 함정 피해 대기를 추가하지 않는다. 상태에는 ‘스킬 즉시 적용’과 ‘패 피해 N 정산 예정’을 분리하고 최근 직업 효과를 작게 표시한다. 아이템전 종료의 기존 짧은 결과 진입 대기는 유지한다.
- AI는 실제 즉시 피해/회복과 최종 기본 피해를 구분하여 판단한다. 상대 손패와 비공개 바닥패를 의사결정에 제공하지 않는다.

## 저장 호환

0.7.0 진행 중 저장은 이미 쌓인 효과를 즉시 효과로 다시 적용하지 않고 그 판의 이전 큐 정산을 보존한다. 다음 분배부터 immediateSkills 표식을 적용한다. 새 규칙 저장에는 이미 적용한 누계와 아직 적용하지 않은 기본 패 피해를 분리해 보존한다. 복원만으로 공격/회복/정찰을 재발동하지 않는다. 이전 수동 스킬 저장 규칙도 현재 판에 한해 보존한다.
