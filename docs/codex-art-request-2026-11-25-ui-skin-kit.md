# Codex 그림 요청 · UI 스킨 키트 v1 (2026-11-25)

사용자 요청: "전반적으로 AI 같은 화면이 너무 많다. HTML5인 게 티 나지 않게, 창·버튼 같은 곳에 그림을 가져다 쓰자."

지금 창과 버튼은 대부분 CSS로 그렸다. 둥근 사각형에 얇은 금색 테두리, 그라데이션, 그림자를 쓴다. CSS 전체에서 `border-radius` 781곳, `linear-gradient` 377곳, `box-shadow` 546곳이 나온다. 그래서 어느 화면이든 "웹 템플릿" 느낌이 난다. 배경·인물·컷씬은 이미 손그림이라, **그림과 CSS 상자의 질감 차이**가 가장 크게 눈에 띈다.

이번 요청은 이 상자들을 대신할 **손그림 UI 부품 세트**다. 부품을 한 번 만들어 두면 모든 창·버튼에 똑같이 입힐 수 있다.

### 늘어나는 부품(9분할) 그리는 법
창·버튼은 화면마다 크기가 다르다. 그래서 앱이 그림을 9칸으로 잘라 **모서리는 그대로 두고 변과 가운데만 늘린다**(CSS `border-image`).
- 각 항목에 적힌 **모서리 크기(px)** 안에만 장식(금속 모서리, 못, 매듭)을 넣는다.
- 변(모서리 사이)은 늘어나도 어색하지 않게 **같은 무늬가 이어지게** 그린다. 변 가운데에 특별한 장식을 넣지 않는다.
- 가운데 칸은 글자가 올라갈 자리다. 무늬가 약한 단색에 가까운 질감으로 칠한다.
- 버튼처럼 가로로만 늘어나는 부품(3분할)은 왼쪽·오른쪽 끝(캡)과 가운데로 나뉜다. 가운데는 가로로 이어지는 무늬로 그린다.

## 연결 현황 (2026-11-25, 로컬·미배포)
1차 그림은 모두 받아 연결했다. 연결 코드는 `app/ui-kit-2026-11-25.css`에 모았다(늘림 기준: 버튼 캡 130px, 창 모서리 104px). 2차 그림은 아직 받지 않았다.
