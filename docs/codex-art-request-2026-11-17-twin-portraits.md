- 앱은 한 장을 **좌우 반으로 나눠** 왼쪽 = 첫째, 오른쪽 = 둘째로 쓴다(`background-size:200% 100%`). 동그라미·둥근 네모 칸(40~58px)에 얼굴이 들어간다.

## 만들 것
### `public/rpg-twins-v2.{png,webp}`
- 크기 **1024×512**(한 칸 512×512 두 개를 붙인 것). 가운데 경계선은 그리지 않는다.
- 각 칸: 어깨 위 흉상, 얼굴이 칸 중앙. **얼굴(이마~턱)이 칸 높이의 약 45%**, 눈높이는 위에서 약 40%.
- 동그라미로 잘려도 얼굴·머리끝이 잘리지 않게, 칸 가장자리 10% 안에 얼굴을 두지 않는다.
- 배경: 어두운 회랑 실내(ST3 장면의 푸른 창빛 + 주황 화로)를 아주 단순하게, 얼굴보다 어둡게.
- 첫째 칸은 살짝 오른쪽, 둘째 칸은 살짝 왼쪽을 보게 해 둘이 마주 보는 느낌으로.

### (추가) `public/avatars/haro-v1.{png,webp}` · 노름꾼 하로 얼굴
- 요트다이스 상대 하로는 아직 자기 그림이 없어 다른 인물 그림 조각(임시)을 쓴다(`YachtDiceTable.tsx`의 `HARO_PORTRAIT`).
- 인물 기준: `public/story/dice-den-portrait-v1.png`의 하로(안개 나루 나룻배 창고의 노름꾼). 장면과 같은 얼굴·옷으로(깃털 꽂은 챙 넓은 갈색 모자, 곱슬 머리, 귀고리, 짧은 수염, 녹색 목도리, 해진 갈색 코트, 능글맞은 웃음). 모자 그림자가 눈을 덮어도 되지만 입가 웃음은 보이게.
- 크기 **512×512**, 어깨 위 흉상, 얼굴이 가운데. 동그라미로 잘려도 머리끝이 남게. 배경은 어두운 창고, 단순하게.
