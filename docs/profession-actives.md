# 0.7.0 이후 기준

사용자 승인으로 새 판부터 수동 액티브·게이지 대신 족보 승리 자동 적립과 판 종료 동시 정산을 사용한다. 수치·함정·이전 저장 전환은 [0.7.0 명세](local-0.7.0-round-combat-2026-11-06.md)를 따른다. 아래는 진행 중인 구 저장을 위한 이전 규칙 기록이며 새 판의 현재 명세가 아니다.

# 아이템전 직업 액티브 확정 기준

2026-10-28 사용자 첨부 `TurnTale_직업별_액티브스킬_Codex_명세_2026-10-28.md`를 기준으로 한다. 첨부 이후 사용자가 **“명령서에는 투시로 적어놨는데 함정이 맞아”**라고 정정했으므로 도적 액티브는 투시가 아니라 함정 설치다. 첨부 원본은 수정하지 않는다.

## 게이지

- 대전 시작 시 모든 직업 1칸. 판 종료마다 1칸을 충전하고, 남은 게이지와 HP를 다음 판으로 이월한다.
- 턴 전환이나 족보 싸움 승리로는 충전하지 않는다. 판 종료 충전은 같은 판에 한 번만 적용한다.
- 검사·마법사·성직자는 발동 직전 보유 칸을 전량 소비한다. 도적은 정확히 2칸만 소비한다.
- 자신의 차례에 사용하고 패 내기·가져오기 차례와 아이템 사용 횟수는 소비하지 않는다. 사용 연출이 끝나면 같은 차례의 패 행동을 이어간다.

| 직업 | 최대 칸 | 사용 효과 |
|---|---:|---|
| 검사 · 강타 | 4 | 상대 1명 지정. 1/2/3/4칸에 피해 1/2/4/6 |
| 마법사 · 화염 파동 | 5 | 살아 있는 상대 각각에게 1/2/3/4/5칸에 피해 1/2/3/4/6 |
| 성직자 · 치유 | 3 | 자신의 HP를 1/2/3칸에 1/3/5 회복. 최대 HP 100 |
| 도적 · 함정 설치 | 4 | 2칸 고정 소비. 바닥패에 피해 4 함정 설치. 자기 턴당 (1회) |

마법사 5칸은 상대 둘에게 각각 6, 합계 12다. 총량을 나누어 적용하지 않는다. 성직자의 HP가 가득 차거나 대상이 잘못된 경우 게이지를 소비하지 않는다. 피해는 기존 방어 유물·실제 남은 HP·HP 0 종료 처리를 따른다.

## 도적

- 기존처럼 안쪽을 포함해 남아 있는 바닥패의 현재 표면에 설치할 수 있다. 투시 버튼이나 별도 직접 공격 스킬은 추가하지 않는다.
- 게이지가 4이면 설치 후 2가 남는다. 같은 턴에는 재설치할 수 없고 다음 자기 턴에는 남은 2칸으로 다시 설치할 수 있다. 한 판에 1회 제한이 아니다.
- 자기 턴은 판 번호가 아니라 판·현재 행동자·단조 증가하는 패 행동 횟수로 구분한다. 아이템을 썼다는 이유만으로 새 턴이 되지 않는다.
- 설치 위치와 카드 ID는 기존처럼 소유자에게만 필요한 정보만 제공한다. 같은 카드에 자기 함정을 중복 설치하면 소모 없이 거절한다.
- 기존 싱글·트리플 자동 투시는 유지한다. 직업으로 투시했던 정확한 고유 ID의 패를 본인이 직접 가져오면 살아 있는 상대 각각에게 피해 1을 준다. 발동한 패 ID를 기록해 재발동하지 않는다.
- 정찰 렌즈만으로 본 패는 기습 대상으로 확대하지 않는다. 기존 직업 투시 패에 렌즈를 다시 사용해도 이미 있던 직업 표식은 유지한다.
- 다음 판의 바닥패는 새로 분배되므로 기존 판의 함정·투시 표식·기습 소모 기록을 정리한다. 게이지는 보존한다.

## 기존 효과·저장·AI

- 기존 족보 자동 효과와 판당 자동 효과는 별도 상태로 유지한다. 수동 액티브가 자동 효과의 사용 여부를 변경하지 않는다.
- 게이지·턴별 사용 여부·판 종료 충전 기록은 저장한다. 게이지가 없는 이전 저장은 시작값 1칸을 부여하며, 과거 판 수만큼 소급 충전하지 않는다.
- 일반 AI는 자기 게이지·자기 손패·필터링된 바닥 정보·공개 HP만으로 판단한다. 비공개 바닥패와 상대 손패에 접근하지 않는다.
- 기존 유물·주화 1/3/5/6/8P·상점·패 취득 조건은 유지한다. 경험치·레벨·마나 시스템은 추가하지 않는다.

피해/회복 수치의 적절성은 이후 플레이 테스트에서 조정할 수 있다. 이 문서는 이전의 고정 3/4/2 피해·회복 제안과 한 판 1회 수동 스킬 초안을 대체한다.

후속 사용자 요청에 따른 0.6.41 변경: 마법사의 자동 포카드와 5장 족보 추가 피해는 판당 1회 제한 없이 승리 때마다 발동한다. 수동 화염 파동의 게이지 소비·충전 규칙은 유지한다.
