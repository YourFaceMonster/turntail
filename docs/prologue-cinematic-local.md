# 프롤로그 전체 장면 구성 · 2026-11-01 로컬

사용자가 승인한 카툰 판타지 톤으로 기존 68초/10컷 대사와 진행을 실제 장면별 그림에 연결했다. 패와 석비의 두 왕관은 동일한 SVG 도형으로 유지한다.

직접 재생: http://127.0.0.1:58179/prologue-preview

이 화면의 재생 버튼은 저장을 만들거나 RPG 게임을 시작하지 않는다. 오디오를 활성화하고 전체 프롤로그를 재생하며, 종료/건너뛰기 후 다시 재생할 수 있다. 본편의 기존 프롤로그 연결에도 같은 장면이 적용된다.

| 컷 | 화면 |
|---|---|
| P01 | 암전과 시작 문구 |
| P02 | `snow-traveler-v1.png` · 설원을 걷는 방랑자, 눈, 느린 이동 |
| P03 | 승인된 `snow-inn-v3.png` · 주점 쪽으로 접근 |
| P04 | 승인된 `tavern-interior-v2.png` · 주점 실내 |

| P07 | `dawn-road-v1.png` · 다음 날의 길 |

새 그림 5개는 built-in image_gen으로 생성했다. 원본 프롬프트와 생성 파일 경로는 루트 `artifacts/prologue-cinematic-prompts.json`, 프로젝트 자산은 `public/prologue/`에 있다. 이전 이미지도 보관한다. 이전 CSS는 루트 `artifacts/rpg-prologue-before-cinematic.css`에 보관했다.

모든 장면 이미지를 로드/디코드한 뒤 재생 시간을 시작한다. 자동 재생, 탭 진행, 건너뛰기, 백그라운드 정지, 모션 감소 설정을 유지한다. 세로 화면은 장면의 인물·상징을 잘라내지 않도록 전체 가로 프레임과 아래쪽 자막을 사용한다.

이번 검증: 프롤로그 기존 검사 5개 통과, diff 공백 검사 통과, 전용 경로 HTTP 200, 실제 인앱 브라우저에서 도입·장면 전환·자막을 확인했다. 입력 없이 자동 재생이 종료되어 `처음부터 다시 재생` 버튼으로 돌아온 것도 확인했다. 화면 기록은 루트 `artifacts/prologue-cinematic-live.png`.

확장 검증은 프롤로그/화면 테스트 합계 12개 중 11개 통과, 코인 기대값 검사 1개 실패(40 대 60). 전체 타입 검사는 `lib/rpg-phase-one.ts:55`의 `result.players[0].total` 필드 타입 오류 1개로 실패했다. 해당 RPG 정산 코드는 이번 프롤로그 작업 이전의 로컬 변경이며 이번에는 수정하지 않았다. 브라우저 실제 음질·청감 검증을 의미하지 않는다.

이번 변경 뒤 빌드·커밋·push·원격 저장·배포는 실행하지 않았다. 앞선 빌드 성공 기록은 이번 전체 장면 구성 전의 소스 기준이다. 패키지 버전은 0.6.58 유지.
