## 반영 범위

1. 주점 캐릭터 선택 외곽선과 이름 옆 ‘대화’를 제거했다. 원래의 인물 클릭 영역과 이름 버튼은 유지한다.
2. 원화 자체의 인물 부분에 미세 변형을 주고 벽난로·촛불 광원·그림자 이동을 더했다. 컷씬도 발화자에 따라 입·손 주변이 미세하게 움직인다. 새 입 모양이나 손 포즈를 프레임별로 그린 애니메이션은 아니다. 모션 축소 설정에서는 정지한다.
3. 팝업을 약 50% 투명한 따뜻한 유리 배경으로 바꾸고 이름·역할·대사·설명 크기와 색을 구분했다. SVG 닫기 X는 32px 원 안에 16px로 중앙 정렬한다.
4. 싱글 메뉴의 일반·아이템·폭탄시장 세 모드는 한 줄, RPG는 별도 한 줄이다.
5. 네 직업 카드도 모바일 한 줄이며 선택 설명 높이를 164px로 통일했다. 카드 하단의 중복 패시브 설명과 마지막 안내문을 지웠다. 실제 선택 직업의 능력 설명과 규칙은 유지한다.
6. RPG 진입창 제목·장문 안내를 덜어내고 승인 지도 배경을 채웠다. 관문 미리보기는 cover로 확대해 좌우 빈 공간을 없앴다.

8. P05 건네는 패에 다음 장면과 같은 빨간 2·초승달 문양을 넣었다. P07 눈길의 산 사이로 ST1 성이 보인다. 각각 가로·세로 두 장씩 제작했다.
