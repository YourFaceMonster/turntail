## 이번 변경

- 새 그림 12장: 세로용 설원·주점 외관·실내·승부·패 앞면·패 뒷면·새벽길·석비·관문 9장, 가로용 패 앞면·뒷면·석비 3장.
- 패 앞면은 낡은 빨간 숫자 2와 달, 뒷면과 석비는 겹친 두 왕관으로 완성했다. 임시 CSS 패와 석비 문양을 현재 프롤로그 화면에서 제거하고 완성된 그림으로 연결했다. 의도된 암전 도입 컷은 유지했다.
- `lib/rpg-prologue-art.ts`가 각 장면의 가로·세로 파일을 관리한다. `<picture>`는 화면 종횡비에 따라 적절한 그림을 선택한다. 세로 화면도 그림이 화면 전체를 채운다.
- 재생 시작 전에 현재 방향에 필요한 그림 9장을 로드/디코드한다. 재생 도중 방향이 바뀌면 현재 컷·경과 시간을 보관한 채 새 방향 그림을 준비하고 재개한다.
- 자막·건너뛰기·터치 안내에 모바일 안전 영역을 반영했다. 주점 실내의 세로 배경에도 같은 전용 그림을 연결했다.
- 기존 자동 68초/10컷, 탭으로 다음 장면, 건너뛰기, 저장과 분리된 미리보기 동작을 유지한다.
