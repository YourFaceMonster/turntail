# 기본모드·아이템전 배치 변경 · 로컬 반영

후속: 아래 별도 미반영 논의 항목은 이후 [0.6.36 로컬 업데이트](local-0.6.36.md)에서 구현했다. 이 문서는 당시 배치 작업 기록으로 보존한다.

기준: 0.6.35 / Sites 99 배포 이후의 로컬 변경. 사용자 요청 범위는 직전 상태표의 미반영 배치 5개다. 운영 빌드·원격 push·사이트 저장/배포는 실행하지 않았다.

## 반영한 내용

1. 기본모드 왼쪽 상대 점수를 캐릭터 초상화 아래로 이동했다.
2. 기본모드 라운드를 턴테일과 같은 상단 줄 중앙으로 이동했다.
3. 기본모드 상단의 중복 내 점수 표시와 솔로 대전의 빈 정보 줄을 제거했다. 내 캐릭터의 점수는 유지한다.
4. 아이템전 상단에서 모드 이름과 중복 주화 표시를 제거하고 `N라운드`만 중앙에 표시한다.
5. 내 주화를 내 이름·HP 오른쪽에 금색 동전 아이콘과 금액으로 표시한다. 상대 주화 표시는 추가하지 않았다.

RPG 모드와 멀티플레이 대기실의 정보는 기존 경로를 유지한다. 멀티플레이의 초대 링크·턴 타이머는 별도 도구 줄에 남긴다. 작은 화면에서는 상단 버튼 간격을 줄이고, 360px 이하의 중복 프로필 버튼은 내 캐릭터에서 접근하도록 정리했다. 380px 이하 아이템전에서는 함정 버튼을 이미지로 표시하고 HP·주화·조작 도구가 겹치지 않게 크기를 조절했다.

## 이번 검증

- TypeScript: `tsc --noEmit --incremental false` 통과.
- 로컬 개발 서버의 실제 Home 화면에 일반모드/아이템전 메모리 저장을 주입한 별도 검증 진입점을 사용했다. 사용자 실제 저장은 읽거나 쓰지 않았다.
- 1280×720, 390×844, 320×740, 844×390에서 표시와 배치를 확인했다. 작은 화면의 HP/주화/버튼 겹침을 발견해 수정한 뒤 다시 확인했다.
- 중앙 라운드와 상단 버튼의 비겹침, 왼쪽 점수가 초상화보다 아래에 위치함, 상단 중복 정보 줄 제거, 금색 주화가 내 상태에만 표시됨, 모바일 가로/세로 수평 넘침 없음 등을 확인했다.
- 화면 증거: 루트 `artifacts/header-classic-mobile.jpg`, `header-classic-landscape.jpg`, `header-item-mobile.jpg`, `header-item-landscape.jpg`.

개발용 임시 HTML/TSX는 검증 후 루트 artifacts 폴더로 보관한다. 앱 버전 문자열은 배포 전 기준인 0.6.35를 유지한다. 이번에는 전투 규칙·주화 생성 시스템을 수정하지 않아 해당 엔진 테스트를 재실행하지 않았다.

## 별도 미반영 논의

저장 삭제 선택 모드, 상점 구매 불가 회색 처리, 함정 안내/설치 범위/이미지 버튼의 전반 변경, 기존 패 문양에 숫자만 재정렬하는 요청과 바닥 주화 시스템은 이 배치 작업에 포함하지 않았다.

바닥 주화 합의: 라운드당 랜덤 주화 1개. 2층은 획득 전까지 주화 비공개(투시에도 비공개), 1층은 위층을 걷어내면 공개한다. 일반 주화는 도적 1P·나머지 직업 3P, 바닥 마지막 패는 모두 5P, 마지막 패에 랜덤 주화가 겹치면 도적도 포함해 모두 8P 지급이다. 이 규칙은 아직 구현하지 않았다.
