# 0.7.33 · 설정창·지도·주점 토너먼트·참여형 이벤트·일반 정산창 (2026-11-16)

사용자 요청:

- 4~10 지도를 1~3처럼 턴테일 위까지 늘리기.
- 토너먼트 상대를 주점 그림 속 사람으로.
- 이벤트를 그림으로 새롭게.
- 일반 모드 정산창 꾸미기.

## 변경
- **여관 토너먼트:** 상대가 그 주점 식구로 바뀌었다.
  - 안개 나루: 수달 → 도칸 → 모란.
  - 달빛 등불: 검은 고양이 → 리네 → 모로.
  - 옆자리도 같은 주점 식구가 앉는다.
  - 수달·고양이 정식 프로필 그림을 넣었다.
- **지역 2~4 세로 지도:**
  - 위로 220px 늘린 1024×1820 그림을 쓴다.
  - 1지역처럼 화면 전체를 채우고 제목 뒤까지 올라간다.
  - 장소·길 좌표를 옮겼다(`tallMapY`).
- **설정창:**
  - 주점 탁자 머리 그림.
  - 항목별 나무 배지 아이콘 5개.
  - 나무결 배경과 항목 카드.
- **참여형 이벤트 4종(ST4·5·8·9):** 화면 전체 장면 그림에서 물건을 직접 누른다.
  - 젖은 기록: 조각을 가죽 판에 붙이기.
  - 매듭 엮기: 기둥 매듭을 길게 누르기.
  - 성소 살피기: 물건을 눌러 확대 그림 보기.
  - 맞물린 문양: 원판을 돌리면 제단에 불이 들어온다.
  - 세로·가로 그림이 따로 있다.
- **일반 모드 정산창:** 오늘의 판 결과 화면 모양으로 맞췄다.
  - 주점 머리 그림.
  - 금테 패널.
  - 1·2·3등 메달.
- **테스트 수정:** `tests/region-inns.test.tsx`가 가끔 실패하던 원인을 고쳤다.
  - 원인: 무작위 보상으로 모르의 깃펜이 들어오면 조합법을 2개 배운다. 게임은 설계대로 동작했고, 테스트의 기대값이 틀렸다.
- **버전:** 0.7.33.
