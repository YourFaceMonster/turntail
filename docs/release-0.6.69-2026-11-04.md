# TURNTALE v0.6.69 · 2026-11-04 RPG 대사·UI 개선

## 반영 내용

- 첨부 지시서의 프롤로그·ST1~3·모르·피오·세린·도둑·여행자 대사와 이야기 다시 보기 동기화.
- 사용자 재확인에 따라 도둑 단독 1등은 편지 반환, 2등·공동 1등은 재도전 가능, 3등은 재도전 불가·모르 실패 대사 후 본편 계속. 주점의 잘못된 재도전 제한은 제거.
- 잡화점 위아래 간격 축소, 이름과 가격 사이 효과 설명, 기존 클릭 상세 설명 유지.
- RPG 판 정산의 중복 현재 HP 문구 제거. 실제 피해·회복을 별도 누적하고 주화 부족 HP 피해는 피해 합계에 포함되었음을 표시. 기존 전투·HP·주화 계산은 유지. 기존 저장의 미기록 구간은 전체 피해로 단정하지 않고 기록 범위를 표시.
- 강타 SVG 칼날·가드·손잡이·칼자루 장식 비례 수정.
- 스테이지 클리어 화면에 기존 승리 컷씬 배경 적용. 결과·보상 선택·다음 이동 순서 정리. 가로에서 세 보상이 함께 보이도록 간격 조정.
- 컷씬 그림 변경 시 이전 그림 위에 새 그림을 0.48초 동안 겹치는 전환 적용. 같은 그림에서 대사만 바뀌면 그림 유지. 퀘스트 도움/발견 전후에도 그림 전환을 이어가며, 줄별 화자를 지원.
- 주점·도둑 순위 목록 자동 번호 제거. 실제 동점 순위 표시. 3판 종료 제목·최종 순위·주화 보상·NPC 마무리 안내 강화.
- 대결 중단·포기 정책은 사용자 보류 상태 유지.

## 이번 검증

- TypeScript --noEmit 통과.
- 관련 14개 테스트 파일의 검사 43개 통과: 대사·순위·동점·저장 복원·보상·스테이지 진행·유물·스킬·HP 집계·상점·컷씬 데이터·결과 UI.
- 로컬 브라우저: 화면 테스트의 잡화점 844×390에서 설명·가격·구매 확인. 실제 결과 컴포넌트로 클리어 보상 844×390 및 390×740 배치 확인. 실제 강타 SVG 형태 확인. 실제 전환 컴포넌트에서 이전/신규 그림 동시 DOM 유지 확인.
- UI 확인용 임시 경로는 빌드 전에 제거. 게임 저장을 변경하지 않는 폐기 가능한 테스트만 사용.
- 앞선 대사 작업에서 확인한 기존 journey-polish 검사 1개의 오래된 tavern-motion-wide 기대값은 별도 이슈로 남겨 두었다. 이번 43개 통과 기록과 구분한다.
- 공개 사이트 전체 퀘스트·전체 전투 재생은 아직 미검증.
