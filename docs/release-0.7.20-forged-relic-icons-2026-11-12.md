  - 0.7.19에서 쓰던 임시 아이콘(재료 그림 빌려 쓰기)을 없앴다.
- 앱 표시용 그림: 256×256 WebP(`<id>-v1.webp`, 장당 약 16~23KB).
  - 원본 1254px PNG와 Codex의 무손실 WebP(장당 0.56~0.96MB)는 public에 그대로 둔다.
  - 줄인 이유: 기존 유물 아이콘은 128px, 약 26KB다.
- 버전 0.7.20 (package.json, lib/version.ts).
