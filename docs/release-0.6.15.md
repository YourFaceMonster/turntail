# 0.6.15 — 새 아이템 시작 지급

밸런스 테스트를 위해 새 아이템전1의 시작 지급품에 엿보는 눈과 바늘탄을 각각 2개씩 추가했다. 기존 5종과 합쳐 7종 각 2개, 총 14개로 시작한다. 사용자와 AI 두 명에게 동일하게 지급한다.

- 시작 안내에 7종 전체와 지급 수량을 표시한다. 모드2의 상점 가격 안내에도 판매 중인 7종 전체를 표시한다.
- 미사용 아이템 보관, 판당 2개 사용, 아이템·스킬의 같은 차례 상호 배제는 유지한다.
- 모드2의 구매 시작 방식과 RPG 지급품은 변경하지 않는다. 이전 저장에는 추가 지급하지 않으며 새 모드1 대전부터 적용한다.
- 족보·돈 정산·고유스킬·저장 회귀 검사와 타입 검사 후 로컬 빌드를 실행한다. 사이트 업로드는 하지 않는다.
