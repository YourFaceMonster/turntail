## 적용한 동작

- 일반모드의 나무 테이블·기존 패 그림·캐릭터·메인 메뉴·설정·추천·손패 배치·더블탭·드래그·패 비행·입장·재개를 공유한다. 새 픽셀 이미지는 사용하지 않는다.
- 기존 바닥 영역을 공개 시장으로 사용한다. 15칸을 유지하고 구매한 뒤 빈 칸을 표시한다. 가운데 패도 살 수 있으며 일반모드의 외곽/덮개 제한을 적용하지 않는다.
- 3인, 손패 15장씩, 시장 15장, 시작 50점, 5판, 구매 3점, 트릭 아웃, 잔여 패 정산, 첫 소진자 적립금, 공동 최종 순위는 독립 폭탄 엔진 규칙을 따른다.
- 일반 족보와 포카드/동문양 연속 폭탄 후보를 기존 추천·직접 선택에 연결했다. 6~26장 조합은 같은 제출 영역의 높이 안에서 여러 줄로 표시한다.
- 반응 3초 중 일반 턴 AI·구매·패스는 멈추며, 자기 차례 밖에서도 유효한 폭탄을 선택·제출할 수 있다. 유효 폭탄이 있으면 `폭탄 가능`을 표시한다. 새 제출마다 3초를 다시 시작한다.
- UI 입력과 AI/타이머는 같은 상태 번호를 비교한다. 먼저 처리된 입력 뒤의 오래된 상태 번호는 거부한다. 기존 일반 AI 루프는 이 경로에서 실행하지 않는다.
- 점수·아웃·확정 순위, 판수, 시장 적립금, 반응 시계를 표시한다. 가로 화면에서도 적립금/반응 시계가 보이며 시장과 손패는 기존 좌우 배치를 사용한다.

## 저장과 재개

저장 `turntale.bomb-market.save.v1`, 전적 `turntale.bomb-market.records.v1`을 유지하므로 앞선 폭탄시장전 저장도 같은 경로에서 재개한다. 유효 상태를 먼저 검증·저장한 다음 화면에 반영한다. 완료 5판 전적은 경기 ID로 중복 방지한다. 일반모드/도전/RPG 진행·전적·업적에 폭탄 경기 결과를 기록하지 않는다.

반응 중 저장을 재개하거나 화면 비활성/설정·규칙·전적·프로필에서 돌아오면 **3초를 새로 부여**하고 상태 번호를 갱신한다. 닫혀 있던 동안의 경과 시간으로 폭탄 기회를 잃지 않는다. 재개 입장 연출 동안 AI와 반응 처리는 멈춘다. 일반 턴 재개는 패·점수·시장·트릭을 바꾸지 않는다.

## 실행과 남은 범위

기존 개발 서버 `http://127.0.0.1:58179/` → 싱글플레이 → **폭탄시장전**, 또는 `/bomb-market`. 기존 서버를 교체하거나 공개 사이트를 변경하지 않았다.

AI 구매/폭탄 빈도와 점수 경제는 추가 플레이 밸런스 검토 대상이다. 실제 휴대폰, 브라우저 5판 완주, 다중 탭 동시 저장 병합은 이번에 검증하지 않았다. 게임 전개/정산의 5판 완주는 엔진 자동 진행 검사다. 픽셀 작업은 보류 상태로 남겼고, 공개 사이트에는 이 로컬 변경을 게시하지 않았다.
