# v0.6.69 · UI 피드백 후속 게시

사용자가 확인한 맵10항목·추가4항목·열쇠/철문 모양 개선을 수정하고 커밋·빌드·업데이트하도록 승인했다. GitHub main 및 Cloudflare Worker만 사용한다. 버전0.6.69, 숫자/문양 내부ID·서열·게임 규칙·저장 스키마·업적·효과는 유지한다.

## 반영

- 상단 로고의 SVG clipPath ID를 인스턴스마다 다르게 만들어 숨은 게임 헤더와 지도 로고의 충돌을 제거했다. 중복 로고 SSR 검사 포함.
- HP 글자는 왼쪽 정렬, 주화는 두 번째 줄 오른쪽 끝. 아바타 버튼은 meter 바깥에 두어 접근성과 클릭을 유지하고 이름/직업/HP/주화/장착 수/기술의 간략 팝업을 연결했다.
- 장소 원42px, 선택 영역118×78px로 확대. 주점/잡화점 이미지는32px이며 원과 중심 좌표가0px 차이임을 브라우저에서 확인했다.
- MAP/가방 그림36px, 유물 프레임36px로 통일하고 가방 크기를 줄였다. 주점 소문 수첩은 왼쪽 아래로 이동.
- 기본 여정/팝업/상품/주화 배경은 검은색 계열. 대화창은 기존290px에서156px(짧은 가로146px)으로 약 절반 축소, 검은 배경 불투명도32%. 선택지는 세로 두 줄. ‘다음’ 버튼을 제거하고 텍스트/장면 탭과 키보드 진행은 유지한다.
- 작은 대화창에 맞춰 문장/단어 경계로36자/예상2줄 단위 페이지를 구성한다. 원문 글자·화자·그림 출처는 보존. 마지막 페이지에만 선택지를 표시하고 보상/승부 처리는 그대로 유지한다.
- 잡화점 이름/설명은 정적인 두 줄 정보이며 상세 팝업과 클릭 동작은 제거했다. 긴 효과 문구는 읽을 수 있는 두 줄 요약으로 표시하고 구매 불가 사유는 가격 아래로 분리했다. 구매 계산과 실제 효과는 바꾸지 않았다. 남아 있던 붉은 송곳니의 ‘해 문양’ 표시도 왕관으로 정정했다.
- 실제 패/장식/타이틀의 공유 SVG 열쇠는 고리와 줄기를 중앙 정렬하고 아래 가로 날을 좌우 대칭으로 정리했다. 철문은 아치형 문틀·두 문짝·중앙 자물쇠와 열쇠구멍으로 변경해 작은 크기에서 읽히도록 했다. 폭탄 픽셀 표시도 정리했다. 기존 원화의 물리적인 열쇠/건축물은 재생성하지 않았다.

## 이번 검증

관련15개 파일33개 검사 통과. 타입 검사 통과. 세로390×844/가로844×390 로컬 컴포넌트 화면에서 로고 중복 상황, 프로필 버튼/닫기, 주화 오른쪽, 아이콘 중심, 작은 투명 대화, 탭 넘김, 세로 선택지, 잡화점 상세 미표시를 확인했다. 사용자 저장을 건드리지 않는 임시 경로를 사용했고 삭제했다. 기존 별도 모드 실패19개는 이전 기록으로 유지하며 이번 검사 통과에 포함하지 않는다.
