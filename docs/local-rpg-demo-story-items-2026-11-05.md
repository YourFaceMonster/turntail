# RPG 데모 스토리·아이템 정리 — 로컬 미커밋

기준 HEAD 5165797, 버전 0.6.69 / pnpm 11.25.0 유지. 앞선 잡화점·퀘스트·보석 미게시 수정은 보존했다. 운영 빌드·커밋·Push·Cloudflare 배포는 수행하지 않았다. 이번 화면 확인은 로컬 개발 서버와 저장하지 않는 테스트 모드만 사용했다.

## 1. 확정 스토리 합본 적용

- 원본 P01~P19 지시서는 `prologue-revision-approved-2026-11-05.md`에 보존했다. 스토리보드 번호와 실제 페이지 ID를 분리하고 기존 P01/P02/P03/P04/P05/P06a/P06b/P07/P08/P09 식별자는 유지한다.
- 원문 대사·화자를 그대로 문장/단어 경계에서 나눴다. 총53페이지. 길이에 따라 자동 읽기 시간을 계산하며, 기존 탭·스킵·백그라운드 정지·한 번만 종료·동일 배경 카메라 유지 구조를 사용한다. 전체 감상 안내 시간도 실제 데이터 합산으로 표시한다.
- 첫 문장 `패 한 장으로 시작된 여행도 있었다.`를 검은 화면 중앙에 배치했다. 원래 목적지 노르문, 우연한 주점 승부, 왕관2 앞면/두 왕관 뒷면, 돌기둥과 같은 표식을 발견하되 의미는 모른다는 흐름을 유지한다.
- ST1/2 전투·NPC와 ST3 기존 쌍둥이 응답5개를 유지했다. ST3 후일담은 철문2 전달 → 두 철문 뒷면 → 왕관2와 비교 → 같은 묶음일 가능성 → 성화의 영역 옛 기록 → 미완의 물음으로 끝난다. 다른 패의 정확한 위치·네 장의 최종 목적·두 왕의 희생은 공개하지 않았다.
- 새 이미지는 제작하지 않았다. 프롤로그는 기존 앞/뒷면·돌기둥·노르문 원화를 사용하며, ST3 새 대사는 기존 쌍둥이/마을 배경 위에 표시한다. 새 패의 앞/뒷면이나 전달·비교 그림은 아직 없으므로 그림으로 완성됐다고 표현하지 않는다.
- 스토리 전용 `storyCards`는 손패·유물·소모품과 분리했다. 현재 구현 ID는 `crown-two`, `iron-gate-two` 두 개뿐이다. 첫 패는 새 여정의 프롤로그/스킵 완료 시 저장되는 준비 객체에 포함되며, 두 번째 패는 실제 ST3 클리어 기록에 따라 지급된다. 다시 보기에는 지급 콜백이 없다.
- 새 화면 없이 기존 여행 가방·RPG 기록·데모 완료 화면에 텍스트 수집 목록을 넣었다. 별도 이미지를 임의로 그리지 않았다.
- 새 선택 필드는 기존 저장에 없어도 로드된다. 기존 여정의 첫 패와 ST3 클리어 증거가 있는 두 번째 패를 복원한다. 읽기만으로 저장 원문을 다시 쓰지 않는다. 완료 시 active가 비어도 아카이브 수집 기록이 남는다. 새 여정에는 그 여정의 첫 패만 넣고, 아카이브는 과거 발견 기록을 유지한다. 종료 전적만 남고 실제 여정이 없는 옛 저장에서 두 번째 패를 임의로 지급하지 않는다.
- 이전 `ST3_POST` 시청 기록으로 새 후일담이 가려지지 않도록 `ST3_POST_CARDS` 키를 구분했다. ST3 완료를 정식 일반 엔딩으로 해석하지 않으며, 2회차 진엔딩/후속 프롤로그 선택 조건은 유지했다.

### 필요한 원화 — 제작하지 않음

| 원화 | 수량·용도 | 유지할 내용 |
|---|---|---|
| 검은 철문2 앞면 | 독립 패 원화1장 | 검은 철문 문양·숫자2, 왕관2와 같은 재질/낡은 테두리 계열 |
| 검은 철문2 뒷면 | 독립 패 원화1장 | 두 철문 표식, 앞면과 마모·모서리 일치 |
| ST3 패 전달 장면 | 가로/세로2장 | 기존 쌍둥이·방랑자·성채·야간 조명과 연결 |
| 왕관2/철문2 비교 장면 | 가로/세로2장 | 첫 패의 겹친 두 왕관과 새 패의 두 철문을 함께 읽을 수 있는 구도 |

최소6개 원화 파일. 독립 패 원화를 합성해 전달/비교 장면을 구성할지는 원화 검토 후 결정한다. 현재 프롤로그 왕관2·두 왕관·돌기둥 원화는 재사용 가능하다. ST6 성화2/두 성화, ST9 비밀의 열쇠2/두 열쇠는 장기 기획 목록에만 두고 이번 원화 제작/기능 범위에 포함하지 않았다. ST10 진입 조건도 구현하지 않았다.

## 2. RPG 데모 아이템·유물 정리

- `rpg-demo-catalog.ts`에서 여정형 RPG 1~3단계만 적용되는 목록/가격을 분리했다. 일반 RPG 카탈로그·아이템전 가격과 규칙은 유지한다.
- 신규 소비 아이템은 응급 약초30 / 작열탄45 / 수호의 봉인40 / 엿보는 눈30 / 뒤바뀐 운명45 / 정찰 렌즈10의6종이다. 기존 저장 상점에 렌즈45가 남아 있어도 데모 화면·단품 구매·일괄 구매 모두10으로 계산한다.
- 붉은 약병·수호의 붕대·달빛 수프·운명의 저울은 데모 신규 판매에서 제외했다. 기존 보유품과 기존 사용 코드는 삭제하지 않았다.
- 핵심 유물8종은 금이 간 심장·회복의 등불·파수꾼의 푸른 유리·바람의 문양·전사의 문장·생명의 문양·태양의 문양·붉은 송곳니다. 푸른 유리는 기존 파수탑 퀘스트로만 획득하며 상점/일반 보상에서 제외한다. 따라서 상점 유물 표시는7종이다. 나머지 제외12종의 ID·효과·장착·보유·도감은 보존한다.
- 시작 금이 간 심장, ST1 회복의 등불 고정. ST2는 미보유 전투 유물 후보2개 중1개 선택. 후보는 클리어 시 결정해 저장하며 로드 후 재추첨하지 않는다. 선택 전 수령을 차단한다. 후보가 부족하면 남은 후보만 제공하며, 소진됐어도 주화/회복은 유지한다. ST3는 기존 방식의 미보유 일반 유물1개와 별도 철문2 스토리 패를 받는다.
- 이전 미수령 저장의 보상 후보만 새 데모 목록에 맞게 복원한다. 이미 지급된 보상 기록과 소지품을 소급 변경하지 않는다. ST2 선택은 새 optional 필드로 저장하며 기존 단일 보상 기록도 읽는다.
- 기본 주화30/HP30, 구 저장 기본 회복10 차감 보정, 유물/조합 추가 회복은 유지한다. 유물 전체 보유 무제한·종류별1개·장착3개를 유지한다. 현재 데모 효과는 장착한 유물만 사용한다.
- 약초는 준비 중 기존 여행 가방에서도1개씩 사용하며, 전투 중 내 차례 사용 조건도 유지한다. 두 경로 모두 기존 `emergencyHerbHealing`을 사용해 기본10/푸른 유리 장착15/상한100/가득 찼을 때 차단/정확히1개 소모를 맞췄다.
- 렌즈의 내부2층 선택·사용자에게만 공개·소모·일반 패 획득·도적과 독립된 상태 처리는 기존 코드를 그대로 유지했다. `game.ts`, `rpg-items.ts`, `rpg-profession-combat.ts`, `hp-item-shop.ts`, 기존 음원·원화·잠금 파일은 이번 작업에서 변경하지 않았다.
