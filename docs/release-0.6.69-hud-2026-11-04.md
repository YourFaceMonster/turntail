# TURNTALE v0.6.69 · 지도 HUD·대화·장면 원화 개선

## 요청 반영

- 지도 상단: 기존 인게임 로고, 장소, 저장·설정. 아바타·전적 중복 제거. 로고·장소 아래 기존 HP바·주화·직업 표시.
- 지도 하단: MAP 버튼 / 기존 배낭 이미지 버튼 / 기존 장착 유물 3칸. 유물 효과 팝업과 여행 가방의 장착 기능 유지. MAP 메뉴에서 이야기 다시 보기·저장 후 나가기 제공.
- 지도에서 실제 저장과 기존 설정 창 연결. 화면 테스트는 사용자 저장에 쓰지 않음.
- 세린은 질문과 다음 문장을 두 줄로 구분. 대사를 의미·문장 단위로 나누고 단어 중간 줄바꿈 방지. 피오·세린도 주점 그림 위에 퀘스트와 같은 대화 UI 사용.
- 퀘스트 본문·화자·선택지 글자 규격 통일. 여행자는 원본을 보존하면서 화면 구도를 확대·이동해 중앙에 배치.
- 푸른 유리는 짧은 발견 대사 뒤 별도 획득 팝업으로 이미지·효과·상태·기존 수령/교체 선택지 표시. 기존 자동 획득·가방 한도·회복량 효과 유지.
- 달의 마을 제목 장면은 기존 지도 건축을 참고한 먼 마을 전경으로 교체. 검은 소나무와 알아볼 수 있는 파수탑을 가로·세로로 생성·연결.
- 강타는 기존 아이콘 칼을 참고해 image_gen으로 분리·정리한 투명 PNG 사용. 기존 휘두르기·궤적·적중 연출 유지. 칼 원본 PNG의 투명 픽셀 존재도 별도 검사.
- 로컬 대기 중이던 상품 네 칸 한 줄 배치, 여백 축소, 같은 그림 유지/같은 장소 오버랩/다른 장소 순차 페이드도 함께 포함.
- 첨부 사진의 비활성 패 깨짐 가능 경로를 줄이기 위해 중복 SVG 필터·그룹 투명도를 제거. 회색 잉크와 문양 원본은 유지. 해당 모바일 단말의 깨짐 해결 여부는 이번에 확정하지 못했다.

## 이미지 및 생성 기록

새 원화 5개는 public/prologue, public/quests, public/item-battle-v1/skills에 저장했다. 원본·이전 변형은 보존했다. 실제 prompt·참고 이미지·생성 원본·저장 위치·크기는 [생성 기록](art-generation-2026-11-04.json)에 기록했다. built-in image_gen을 사용했으며 CLI 생성은 사용하지 않았다.
