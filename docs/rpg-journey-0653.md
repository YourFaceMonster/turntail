# 0.6.53 · 달 1~3 지도·주점 로컬 프로토타입

2026-11-01. Phase 0 이후 사용자의 계속 진행·마무리 요청에 따라 구현했다. **로컬 저장만 수행했으며 프로덕션 빌드·커밋·push·사이트 게시를 실행하지 않았다.** 사용자가 화면 검증은 나중에 하기로 선택했다.

## 연결한 흐름

직업 선택 → 시작 유물 → 달의 길 지도 → ST1 → 보상 선택 → 지도 → 선택형 주점 또는 바로 ST2 → 보상 선택 → 유적/숲길 또는 바로 ST3 → 기존 1~3 체험 완료.

- 지도는 기존 테마 지도 이미지를 재사용한다. 현재 위치·잠김·완료·선택으로 닫힘을 표시한다. 전투는 목적지 확인 후 시작하며 자동 진입하지 않는다.
- 주점은 기존 실내 배경과 초상화를 재사용한다. 모르 이야기, 피오 상점, 세린 3판 승부, 벽난로 휴식, 여행 가방, 지도 복귀 문을 클릭하는 장소다. 전부 방문할 필요는 없다.
- 상점은 기존 약초·작열탄 및 가격을 그대로 사용하고 재고를 공유한다. 재입장으로 재고가 초기화되지 않는다. 휴식도 기존 RPG 40/80주화와 HP 20/45를 재사용한다.
- 새 탐험형 여정만 유물 3장착+3가방을 적용한다. 주점에서 정비하며, 가방이 가득 차면 장착 해제 대신 보관 유물과 교체한다. 시험 조합도 장착한 두 유물로만 작동한다.
- 모르의 사실 기반 단서 1개를 중복 없이 기록하고 RPG 아카이브에 영구 보존한다. NPC 관계도·전체 소문 수첩 콘텐츠를 완성한 것은 아니다.
- 세린 승부는 기존 노아이템 3인 기본 규칙 3판이다. 내부 Game을 RPG 저장 안에 보관하며 본편 HP·운명·ST·스킬·아이템을 변경하지 않는다. 중단 후 같은 판으로 재개하고, 완료 후 주점으로 돌아온다. 일반전 기록·업적·하이스코어 동기화에는 반영하지 않는다.
- 주점 보상은 해당 주점의 첫 3판 완료에 한 번만 지급한다. 주점 재방문과 추가 3판 승부는 다시 보상을 주지 않는다. 동점은 같은 순위다.
- ST2 뒤 갈림길은 실제 자원 결과가 다르고, 선택한 반대편은 닫힌다. 탐색 자체를 생략하고 ST3으로 갈 수 있다.

## 시험 수치 — 최종 밸런스 확정 아님

`lib/rpg-journey.ts`의 `JOURNEY_TRIAL`에 분리했다.

| 항목 | 현재 시험값 |
|---|---|
| 유적 | HP −8, 최소 1 유지 / 주화 +15 |
| 숲길 | HP +8, 최대 100 |
| 주점 3판 보상 | 1/2/3등 12/8/4주화, 해당 주점에서 한 번 |

미확정 수치를 최종 기획으로 취급하지 않는다. 기존 일반전·HP 아이템전 가격·효과·AI 전략을 바꾸지 않았다.

## 저장·이전 진행 보호

- `RpgRun.journey.version=1`이 있는 **새 게임에만** 탐험 흐름을 켠다. 기존 0.6.52 RPG 및 이전 RPG 저장을 자동으로 변환하지 않는다.
- 기존 새 RPG 키 `turntale-rpg-journey-phase1-v1`에 선택 노드·갈림길 결과·소문·미니승부·지급 여부를 함께 저장한다. 기존 모드 키에 미니승부를 쓰지 않는다.
- 저장 성공 뒤에만 실제 플레이 상태를 반영하는 기존 복제/저장 흐름을 유지한다. 저장된 미니승부의 본편 참조는 ID뿐이며 순환 객체를 만들지 않는다.
- 새 탐험 저장과 중첩 미니승부의 버전·기본 형태를 검사한다. 지원하지 않거나 손상된 형식은 원문을 보존한 채 오류를 반환한다.
- 화면용 여정 뷰에는 미니승부 전체 Game 대신 진행 요약만 전달한다. 다른 좌석의 패·토큰이 새 여정 데이터에 노출되지 않게 한다.
