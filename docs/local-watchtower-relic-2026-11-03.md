# 2026-11-03 · 파수탑과 파수꾼의 푸른 유리 로컬 구현

## 플레이 흐름

1. 길가의 여행자에게 응급 약초를 건네면 지도에 **검은 소나무 파수탑**이 열린다.
2. 파수탑에서 한 번의 조사 버튼으로 푸른 빛의 정체를 확인한다.
3. 무너진 탑은 예전 눈길 여행자를 안내하던 봉화였고, 그 빛은 유물 **파수꾼의 푸른 유리**에서 나온다.
4. 유물은 전투 장비나 가방 칸에 넣지 않는 이야기형 발견물이다. 다음 여정에서 숨은 장소를 여는 단서로 기록한다.

## 구현 범위와 저장

- 여행자 이벤트 완료 시 지도 파수탑 노드가 열린다.
- 파수탑 조사 결과와 완료 지점을 RPG 여정 저장에 기록하고, 같은 유물을 중복 발견하지 않도록 막는다.
- 소문 수첩에 유물의 이름과 후속 숨은 장소 관련 설명을 남긴다.
- 앱 버전은 `0.6.66` 그대로다. 로컬 변경이며 빌드·커밋·push·배포하지 않았다.

## 이번 작업 확인

- 소스 연결과 저장 경로를 정적으로 검토했다.
- 테스트와 화면 플레이 검증은 하지 않았다.
- `pnpm exec tsc --noEmit`에서 이번 변경 코드 오류는 나오지 않았고, 기존 세 테스트 파일 위치의 nullable 타입 오류로 전체 검사는 통과하지 못했다: `tests/bomb-classic.test.tsx` 두 곳, `tests/bomb-market.test.ts` 한 곳.
- `git diff --check`는 통과했다. 줄바꿈 LF→CRLF 경고만 있었다.
