# 잡화점 한 줄 배치·장면 전환 수정 · 2026-11-04 (로컬)

사용자 지시: 이번 수정은 로컬에 반영하고, 별도로 업데이트하라고 할 때까지 빌드·GitHub push·Cloudflare 배포하지 않는다. 버전0.6.69 유지.

## 변경

- 상품 행을 이미지·이름 / 설명 / 가격 / 구매의 독립된 4개 칸으로 분리. 가로·세로 모두 한 줄 유지. 가격도 30주화처럼 한 줄로 표시.
- 이전 공통 상품 패딩 !important와 공통 버튼 최소 높이가 새 행 높이를 덮어쓰던 문제를 확인해 해당 상품 행 범위에서만 해제. 행38px·아이콘26px로 조정.
- 긴 설명은 한 줄 말줄임. 이름이나 설명을 누르면 기존 전문 팝업을 연다. 구매 불가 회색 표시와 기존 구매 로직은 유지.
- 같은 그림의 대사 변경은 배경 전환 없음. 같은 장소의 자세·그림 변경은0.48초 오버랩. 장소 변경은0.24초 페이드아웃 후0.24초 페이드인.
- 이미지 자체의 별도 페이드인을 제거하고 전환 레이어 한 곳에서만 투명도를 제어한다. 이전 그림은 기존 키로 유지해 재생성 시 페이드가 다시 시작되지 않도록 했다.
- 새 그림을 디코딩한 후 전환해 이미지 로딩 중 이전 그림이 먼저 사라지지 않도록 했다.
- 약초 전달·파수탑 조사·유물 수령처럼 장소가 유지되는 행동은 전체 화면 페이드 대상에서 제외. 실제 장소 이동은 기존 화면 전환을 유지하고 장소 변경 또는 오류까지 이전 화면의 페이드 완료 상태를 유지한다.
