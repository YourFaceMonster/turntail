# 추가 QA (2026-11-19, 공개 0.7.36 · 보고만 · 미수정)

방법: 화면 없는 Edge(새 프로필, 375×812)로 **테스트 모드가 아닌 실제 새 여정**을 시작해 프롤로그 → 지도 → ST1 이야기 → 대결을 자동으로 끝까지 진행(패는 단순 자동 선택). 공개 사이트 첫 화면 무게도 측정.

## 실제 흐름에서 확인된 것 (정상)
- 새 여정 → 프롤로그 건너뛰기 → 철문의 영역 지도 → ST1 확인 창 → 이야기 장면(무음) → 대결 곡 재생까지 막힘 없음.
- 14판 진행 후 내가 HP 0 → "운명력 1개 사용 · 남은 2개" 안내 → "스테이지 1 다시 도전"이 동작. 내 HP 100, 상대 HP 25·30(ST1 시작 체력)으로 돌아감. 정산 숫자(손실·획득·넘친 회복 피해)도 서로 맞음.
- 튜토리얼 창 Esc 닫힘 정상. (첫 시도에서 안 닫힌 건 새 Edge 프로필의 계정 동기화 창 때문이었고, 깨끗한 프로필에서는 정상.)

## 보고할 것
1. **ST1이 너무 길 수 있음 (밸런스 · 결정 필요):** ST1 상대 시작 HP는 25·30인데, 판을 이기면 패 정산 회복으로 **최대 100까지** 차오른다(로웬 25 → 100). 그래서 자동 진행 기준 ST1 한 스테이지가 14판·약 19분 걸렸다. 실제 사람은 더 잘 두겠지만, 첫 스테이지에서 상대 체력이 시작값의 3~4배까지 오르는 구조라 길어질 수 있다.
   - 선택지 예: 상대 회복 상한을 그 스테이지 시작 HP로 묶기 / 상대만 회복량 절반 / 지금대로 두기.
   - 11-17 기록: 사용자는 `RPG_STAGE_HP` 표를 낮추는 것은 거절했다. 이 선택지는 표를 건드리지 않는다.
2. **첫 화면이 무거움 (속도):** 공개 사이트 첫 화면에서 그림을 약 4MB(전체 4.7MB, 요청 26개) 내려받는데, 첫 화면에 보이지 않는 그림이 대부분이다 — 일반 대전 상대 그림 5장(blue·red·haetae·hiboringji·hibo-seated, 약 1.9MB), 탁자 재질(walnut·stone·wood, 약 1.5MB). `GameEntrance.tsx`의 미리 불러오기 목록에 있는 그림들이다. 휴대폰 데이터로 처음 들어올 때 늦어질 수 있다. 메뉴에서 일반 대전을 고를 때 불러오도록 미루면 첫 화면은 1MB 안쪽이 된다(출처는 고치기 전에 한 번 더 확인).
3. **지도 위 내 이름이 "나":** 닉네임을 정하지 않으면 지도 HUD에 "나 · 패싸움 여행자"로 나온다. 대결에서는 "나"가 자연스럽지만 지도 HUD에서는 어색할 수 있다(예: "방랑자").
4. (작음) 화면 없는 브라우저에서 이야기 장면이 끝난 뒤 왼쪽 위 "턴테일" 로고에 초록 포커스 테두리가 남는 경우가 있었다. 휴대폰 터치에서는 보통 안 보이지만, PC에서 Tab 없이도 보이는지 확인이 필요하다.

## 이번에도 못 한 것
- 스테이지를 **이겨서** 끝나는 실제 흐름(자동 진행이 져서 팡파르 → 결과 곡 이어짐은 이번에도 실제로 못 들음. 테스트 모드에서는 팡파르 재생·배경음 멈춤 확인).
- 실제 휴대폰(아이폰 소리 잠금·진동·홈 화면 아이콘), 멀티플레이 두 기기, 예전 저장 이어하기, 카카오톡 미리보기.

## 수정 결과 (같은 날, 사용자 승인 1·2·3·4 "ㄱㄱ", 로컬 · 미배포)
1. **상대 최대 체력 = 스테이지 시작 체력:** `rpgMaxHp(run,seat)`가 상대 자리에서는 `rpgEnemyMaxHp`(그 스테이지 `RPG_STAGE_HP`, 도전 규칙 "사나운 적"이면 1.2배)를 돌려준다. 화면은 같은 값을 써서 ST1이 "HP 25/25 · 30/30"으로 시작(화면 없는 Edge에서 확인). `RPG_STAGE_HP` 표는 그대로.
   - 부작용: 상대가 체력이 가득 찬 채로 판을 이기면 넘친 회복이 진 쪽(나 포함)에게 피해로 간다(0.7.10 넘친 회복 반격 규칙). 그래서 스테이지는 짧아지고 내 남은 HP는 조금 낮아진다.
   - 봇 시뮬레이션(모든 자리를 게임 AI가 둠, 운명력 재도전 없음, 바꾸기 전 16여정 · 바꾼 뒤 10여정):
     | | 바꾸기 전 | 바꾼 뒤 |
     |---|---|---|
     | 여정 전체 판 수(평균 합) | 약 78판 | 약 59판 |
     | ST1 평균 판 수 | 5.6 (최대 23) | 1.4 (최대 3) |
     | ST9 평균 / 최대 | 14.0 / 48 | 8.4 / 20 |
     | 클리어 때 내 HP(ST5~10) | 86~100 | 74~93 |
     | 끝까지 클리어 | 81% | 80% |
   - 주의: ST1은 평균 1.4판이라 첫 스테이지가 너무 빨리 끝날 수 있다(봇 기준). 실제로 해 보고 짧으면 ST1만 시작 체력을 올리는 방법이 있다(표 변경이라 사용자 결정 필요).
   - 예전 저장에서 스테이지 도중인 상대 체력이 새 상한보다 높으면, 다음 판 정산 때 상한으로 내려간다.
   - 테스트: 상대가 상한보다 높은 체력에서 시작하던 정산 테스트 9곳(rpg-rework·relic-clarity·systems-0710)을 상한 안의 값으로 바꾸고 기대값을 손으로 다시 계산해 맞춤.
2. **첫 화면 미리 불러오기 미룸:** `GameEntrance`에 `warm`을 추가. 첫 화면에서는 대전용 그림을 불러오지 않고, 싱글·멀티 메뉴나 스토리 창을 열거나 게임이 시작될 때 불러온다. 네트워크 기록: 첫 화면 그림 요청 3개(로고·배경·아바타) + 메뉴 곡. 싱글 메뉴를 열면 대전 그림 13개를 그때 불러옴.
3. **지도 이름:** 닉네임이 없으면 지도 위에 "방랑자"로 표시(대결 화면은 "나" 그대로).
4. **로고 초록 테두리:** 이야기 장면·대화·전투 기록·지난 대사 창이 닫힐 때 초점은 돌려주되 테두리는 안 보이게(`focusVisible:false`) 5곳. 화면 없는 Edge에서 대결 진입 후 로고 테두리 없음 확인.
