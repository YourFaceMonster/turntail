# 0.6.23 · HP 배치와 주화 정산 기준 수정

사용자가 확정한 기준: HP 피해로 추가 주화를 지급하지 않는다. 아이템전2의 싸움·공격 아이템은 HP만 변경하고, 정상 판 종료 시 기존 남은 패 차이 점수로 주화를 정산한다. 미지급 손실의 HP 전환은 유지한다. 고유스킬 보상·다음 판 준비금·상점 순서·가격·사용 한도는 기존대로 유지한다.

이미 받은 HP 피해 보상은 소급 차감하지 않는다. 저장된 잔액과 이전 보상 기록은 보존하며, 이어하는 대전에서도 다음 피해부터 추가 주화를 지급하지 않는다. 과거 규칙으로 지급된 기록이 같은 판 정산에 남아 있으면 ‘이전 규칙 보상’으로 표시한다. 옛 비전투 모드 저장의 규칙은 기존 호환을 유지한다.

결과 HP 바: 왼쪽 아바타·이름, 가운데 빨간 피해량, 오른쪽 큰 현재 HP. 전투 결과에서 ‘HP 흡수 +2P’ 표시를 제거하고 규칙 안내를 수정한다. 작은 결과창과 클릭 종료·충격 대기·기존 아이템 연출은 유지한다.

검증: 실제 현재 모드2 생성 경로에서 싸움·플레이어/AI 공격 아이템·방어·마지막 패·치명타가 추가 주화를 만들지 않는지, 정상 패 점수 주화 정산·돈 부족 HP·독립적인 스킬 보상·준비금·저장 잔액 보존을 검사한다. TypeScript와 로컬 빌드를 수행하며 사이트에는 배포하지 않는다.
