## 1. 대표 아이콘 (512×512)

- 기존 앱 아이콘 `public/icon-512.png`(512×512, 약 348KB)을 기준으로 한다. 상점 아이콘과 게임 탭 아이콘이 같아 보여야 한다.
- 그대로 쓸 수 있으면 복사본을 사용하고 README에 "기존 아이콘 사용"이라고 적는다. 작은 크기에서 잘 안 보이면 같은 디자인을 유지한 채 대비·여백만 다듬는다.
- 투명 배경이면 원스토어에서 어떻게 보일지 확인하고, 필요하면 불투명 배경으로 만든다.
- 글자를 넣지 않는다.

## 2. 그래픽 이미지 (1024×578)

- 원스토어 메인 화면에 노출되는 배너다. 게임 분위기가 한눈에 보여야 한다.
- 참고 원본:
  - 공유 그림 `public/og-turntale-v1.jpg`
  - 프롤로그 `public/prologue/snow-inn-v3.png`(중간 밝기 기준)
  - 주점 `public/prologue/tavern-interior-v2.png`(어두운 실내 기준)
  - 네 문양: 왕관·열쇠·성화·철문
- 로고 "턴테일"은 앱 화면의 워드마크 모양을 따른다. 넣을 글자는 로고 하나 정도로 최소화한다.
- 가장자리 약 8%에는 중요한 그림을 두지 않는다. 상점이 잘라서 보여 줄 수 있다.
- 카드 패를 그릴 때는 게임의 일반 대결 패 모양을 따른다. 이야기 특별 패 디자인(`docs/story-keepsake-art-guide.md`)은 일반 패에 퍼뜨리지 않는다.

## 3. 스크린샷 (4~6장, 9:16 세로)

- **반드시 실제 게임 화면을 캡처한다.** 없는 기능이나 연출을 그려 넣지 않는다. 상점 심사와 이용자 신뢰 문제가 있다.
- 캡처 대상은 **0.7.41 이후 화면**이다. 0.7.41에서 친구 채팅을 삭제했다. 채팅 버튼이나 채팅 창이 보이는 화면은 쓰지 않는다. 0.7.41은 2026-11-20에 배포했다. 공개 사이트 https://turntail.yousexybaby.workers.dev 또는 원스토어판 https://turntale-onestore.pages.dev 에서 캡처해도 된다.
  - 로컬 실행: 루트 `.claude/launch.json`의 `turntale-store-dev`(Vite 스토어 설정, 포트 5195). 일반 `turntale-dev`는 현재 Sites 연결 오류로 뜨지 않는다.
- 크기는 세로 화면으로 캡처한다. 예: 390×844 뷰포트를 2배로 찍은 뒤 728×1294 등으로 줄여, 가로·세로 모두 1300px 이하로 맞춘다.
- 추천 장면 (4~6장 선택):
  1. 메인 메뉴 (로고, 싱글·멀티·튜토리얼)
  2. 대결 장면. 바닥 패와 손패가 보이는 실제 판, 페어나 5장 족보를 내는 순간이면 좋다.
  3. 스토리모드 지도 (지역 지도와 스테이지 아이콘)
  4. 스토리 컷씬 또는 주점 장면 (엔딩 이후 내용은 피한다)
  5. 유물 보상 선택이나 HP 정산 화면
  6. 오늘의 판 결과·순위 화면, 또는 요트다이스
- 캡처 위에 짧은 설명 문구를 넣는 것은 선택이다. 넣는다면 아래쪽 띠에 한 줄로 넣고, 게임 화면을 가리지 않는다.
- 다른 사람의 닉네임·프로필 사진이 보이는 화면(오늘의 판 순위 등)은 피한다. 쓸 경우 테스트용 이름만 보이게 한다.
- 브라우저 주소창·개발 도구·"테스트 모드" 표시가 화면에 나오지 않게 한다.
