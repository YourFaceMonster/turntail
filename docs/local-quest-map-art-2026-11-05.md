# 지도·퀘스트 원화 후속 수정 (로컬 미게시)

버전 0.6.69 유지. 이전 세린/운명력/밤 배경/철문 D/30 HP 변경은 보존했다.

## 이번 변경

- 지도 가로·세로 2장: 겨울 주민·상인·경비를 추가하고 파수탑을 주변 건물에 어울리는 크기로 축소했다. 둥근 돌탑, 왼쪽 소나무, 오른쪽 목조 전망대와 작은 건물을 유지한다. 지도 깃발은 승인된 D 철문 표식으로 통일했다.
- 도둑 퀘스트 위치를 숲에서 시장 뒤의 좌판·상자·돌길이 있는 골목으로 이동했다. 가로 좌표 82/49, 세로 84/58. 경로선도 같은 좌표로 변경했다. 세로 지도/핀 전환은 화면 너비 대신 지도와 동일한 종횡비 조건을 사용한다.
- 축소한 파수탑의 표시와 경로도 가로 28/31, 세로 29/28로 조정했다. 위치 ID·퀘스트 해금·저장 형식은 유지한다.
- 새 지도는 실제 지도 CSS, 장면 미리 불러오기, 여정 진입의 가로·세로 지도 및 ST3 마지막 전경에 연결했다. 프롤로그의 먼 마을 풍경과 다른 전투 원화 전체를 이번에 재생성한 것은 아니다.
- 도둑 가로·세로 2장: 패 상자의 바닥은 지면에 둔 채 윗면을 올려 왼쪽 팔꿈치·팔뚝이 자연스럽게 상자에 닿게 수정했다. 상자 위 소품도 함께 올렸다.
- 편지를 돌리는 가로·세로 신규 컷 2장: 첫 설명 대사의 모든 페이지는 새 컷, 다음 대사부터는 높인 상자의 기존 구도 컷으로 연결했다. '이야기 다시 보기'에도 설명 대사와 새 컷을 추가했고, 최초 장소 진입 시 새 컷을 미리 불러온다. 한 장의 정지 원화에 손가락 위 편지의 기울기와 회전선을 표현한 것이며, 편지 물체를 별도 실시간 회전시키는 애니메이션을 추가한 것은 아니다.
- 여행자 도움 전/후 가로·세로 4장: 인물의 정체성·의상·수레와 소나무·다친 다리는 유지하고, 비대칭 표정과 단순한 명암의 손그림 2D 카툰으로 재작화했다. 인물은 도움 전에는 아픈 표정, 도움 후에는 안도한 표정을 사용한다.
- 도둑 컷의 패 소품도 2 왕관·1 열쇠·4 철문으로 맞췄다. 이야기와 보상 수치는 변경하지 않았다.

## 이번 검증

- 직접 관련 10개 테스트 파일·37개 검사 통과. 신규 컷의 대사 페이지별 연결/다시 보기/도움 전후 원화와 상태 보존/지도·경로·마지막 전경 연결/기존 퀘스트 보상과 저장/컷씬 페이지 및 전환 포함.
- 14개 현재 퀘스트 PNG의 시그니처·해상도·가로/세로 비율 검사 통과. 새 지도 2장도 직접 시각 확인했다.
- 타입 검사 및 diff 공백 검사 통과.
- 원화는 직접 시각 확인했다. 기존 Work 설정의 로컬 브라우저 비활성 상태로 이번 실제 화면 클릭·가로/세로 브라우저 동작은 미검증이다. 앞선 작업의 별도 result-progress 기존 실패 기록은 유지한다.
- 빌드·커밋·push·원격 저장·배포하지 않았다.

- 기존 v2 원본 보존. 실제 지도/진입/미리 불러오기/ST3 마지막 전경을 모두 public/prologue/iron-gate-village-map-{wide,portrait}-v3.png로 연결. [전체 프롬프트·생성 기록](art-generation-map-rowen-2026-11-05.json).
