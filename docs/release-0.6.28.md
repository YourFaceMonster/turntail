# 0.6.28 · 단일 아이템전

- 아이템전1을 선택·새 대전 시작·이어하기·기록 진입에서 제거했다. 기본/전투·상점 선택 탭을 없애고 기존 아이템전2를 단일 **아이템전**으로 표시한다.
- 로비·인게임 제목·상점·정산·새 대전 확인창·이어하기 목록에서 모드 번호를 제거했다. 새 대전은 항상 기존 아이템전2의 전투·상점·스킬 규칙으로 시작한다.
- 현재 아이템전2의 저장 키, 진행, HP·주화·소지 아이템·스킬·랜덤 상대를 그대로 유지한다. 예전 아이템전1 저장은 읽거나 변환하거나 삭제하지 않고 남겨두며, 손상된 예전 저장도 현재 이어하기 오류를 만들지 않는다. 내부의 이전 규칙 계산과 저장 호환 코드는 보관한다.
- 캐릭터 30명 랜덤 등장 및 0.6.27의 게임 규칙은 유지한다.

## 확인

아이템전1 저장의 비파괴 숨김, 현재 저장의 정확한 복원, 손상된 이전 저장 무시, 선택/이어하기/상점/결과창의 단일 모드 표기를 검사했다. 기존 저장·전투·상점·스킬·캐릭터 검사를 함께 실행한다.
