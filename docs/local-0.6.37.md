# 0.6.37 로컬 변경 및 검증

2026-10-28. 사용자 지시에 따라 **로컬 수정·기능 검사·개발 화면 확인까지만** 수행했다. 운영 빌드, 원격 저장, push, 사이트 업로드는 하지 않았다. 배포 보관 기록의 최신 버전은 0.6.36 / Sites 저장본 100이다.

## 반영한 8개 요청

1. 함정 설치 버튼을 grid 중앙 정렬로 고정하고 이미지의 투명 여백을 고려한 광학 보정(-0.8%, +1.5%)을 적용했다. 원본 이미지는 보존했다.
2. 두 자리 숫자의 가로 압축(textLength/lengthAdjust)을 제거했다. 같은 Trebuchet Bold 계열의 자연스러운 폭과 굵기를 사용하며 33px로 낮춰 원래 문양 안에 담았다. 한 자리 50px와 원래 문양 SVG는 유지했다. 기본 패의 두 자리 숫자는 같은 잉크 외곽선을 더해 굵기를 보완했다.
3. 아이템전 도적이 **직업 스킬로 투시한 패를 직접 가져오면 상대 각각 1 피해**를 준다. 직업 투시에 source 표식을 저장하고 회수 시 소모한다. 렌즈만으로 본 패, 다른 사람이 회수한 패, 다른 직업에는 발동하지 않는다. 기존 직업 투시 패에 렌즈를 다시 써도 표식을 잃지 않는다. 출처가 없는 이전 저장의 투시를 임의로 직업 투시로 바꾸지는 않는다. 방어 유물·체력 하한과 대전 종료·정산을 적용한다.
4. 주화는 큰 금색 발견 표시 후 수집자 이름과 초록색 +P를 보여준다. 지갑까지 이동한 다음 표시 잔액이 올라간다. 저장 데이터의 잔액 지급은 즉시 확정하고, 표시만 연출 시점에 맞춰 보류한다.
5. 아래층 주화 발견은 2.2초, 실제 수집은 3.6초 동안 확인한다. 수집자 표시는 1.1초부터, 이동은 1.7초부터, 지갑 합산은 2.6초부터다. 다음 차례도 같은 시간까지 기다린다. 함정/기습과 겹치면 충격 이후 주화 표시를 시작해 제목이 겹치지 않게 했다.
6. 세로 배치의 손패 예약 높이와 유물 레일을 손패 수와 무관한 hand-space-h로 통일했다. 강한 패에 연결됐던 바닥/전체 화면 흔들기 효과도 제거했다. 낸 패·캐릭터·개별 효과 애니메이션은 유지한다.
7. 정산의 바닥 주화 +P를 별도 세 번째 줄에서 두 번째 주화 줄로 옮겼다. 판 정산 금액과 구분해 중복 합산하지 않는다. 투시 회수 피해는 기습 항목으로 분리했다.
8. 함정을 밟으면 함정 이미지가 드러나고, 커지는 쾅 효과·충격파·피해 숫자·피격 초상 반응·설치자 초상의 웃는 듯한 반동과 "히히, 걸렸네!" 말풍선을 보여준다. 기존 초상에 모션을 적용했으며 새 표정 그림을 생성한 것은 아니다. 말풍선과 피해 숫자는 상태창의 overflow에 잘리지 않게 별도 화면 레이어에 표시한다.

주화 수치는 그대로다: 라운드당 무작위 1개, 도적 1P/나머지 3P, 마지막 5P, 중복 마지막은 도적 6P/나머지 8P. 위층 주화와 덮인 아래층 주화는 공개하지 않는다. 효과 데이터에도 비공개 패 ID와 다른 플레이어의 지갑 잔액을 싣지 않는다. 같은 패의 기습·함정·주화를 모두 처리한 뒤 대전을 종료하여 치명적 동시 발동도 빠짐없이 정산한다. 모션 감소 설정에서는 큰 움직임을 생략하고 읽을 시간과 문구는 유지한다.
