# 2026-11-03 · 주점 상호작용 로컬 수정

## 요청과 적용

- “주막” 표기를 지도 노드와 주점 화면에서 “주점”으로 통일했다.
- 주점 배경 전체에 적용되던 SVG 왜곡 필터를 제거했다. 햇살과 그림자는 위치를 옮기지 않고 밝기만 천천히 바뀌도록 했으며 벽난로 빛/불꽃 연출은 유지한다.
- 모르 대화는 닫기 버튼 없이 화면을 눌러 첫 인사와 소문을 넘긴 뒤, 마지막 화면을 다시 누르면 주점으로 돌아오게 했다. 바깥 영역을 눌러 대화가 갑자기 닫히지 않게 했다.
- 게시판 버튼의 사각 포커스 윤곽을 제거하고 키보드 포커스는 게시판 글자의 빛으로 표시한다.
- “눈길에 묻힌 부탁” 이동 퀘스트 시안은 사용자 피드백에 따라 제거했다. 너무 복잡하고 동기가 약하다는 의견을 반영해 현재는 기획만 논의한다. 사용자가 원하는 방향은 간단한 마을맵 클릭 이동, 주점 미니게임/내기, NPC 대화로 다음 루트의 사실 해금, 회복약을 특정 이벤트에 건네고 유물 받기다. 상세 아이디어는 다음 업데이트 메모에 기록했다.

## 확인 결과와 남은 점

- 사용자가 오른쪽 로컬 브라우저에서 보여준 런타임 오류를 확인했다. 오류 메시지는 `discount is not defined`이며 `JourneyShopContent`에서 발생했다. 상품 버튼에서 계산하던 상인의 저울 할인 여부를 같은 화면의 여행 가방 안내에서도 사용하면서 부모 범위에는 선언하지 않은 것이 원인이었다. 잡화점 화면에서도 같은 할인 조건을 계산하도록 수정했다.
- 수정 반영 뒤 RPG 테스트 모드의 “프롤로그·화면 테스트”에서 지도, 잡화점, “눈길의 주점”을 차례로 열어 런타임 오류가 사라진 것을 확인했다. 이 테스트 모드는 진행을 저장하지 않는다.
- 모르 대화를 테스트 화면에서 직접 눌러 두 단계 진행과 마지막 클릭 후 주점 복귀를 확인했다. 화면 계산 스타일은 배경 `filter:none`, 햇살 `tavern-warm-light`, 그림자 `tavern-shadow-breathe`, 게시판 윤곽 `none`으로 확인했다.
- 패가 초기 로딩/배분 중 일그러져 보이는 증상은 현재 재발하지 않았다. 사용자가 다시 발생하면 캡처를 제공하기로 했으므로 패 애니메이션/렌더링 코드는 건드리지 않았다.
- 이동형 부탁 퀘스트는 이번 피드백에 따라 소스에서 제거했다. 퀘스트 구현이나 테스트는 하지 않았다.
- 이번 수정은 로컬 소스와 README/기획 메모만 변경했다. `git diff --check`를 확인했고, 빌드·커밋·push·배포는 하지 않았다.
