# 로컬 · 컷씬 연출 보강 (2026-11-16, 미배포)

사용자 지시: "1에서 4까지 전부하다 연출만 보강해보자 / 코덱스md서줘". 그림 1~4번은 Codex 요청서(`docs/codex-art-request-2026-11-16-cutscene-tiles.md`)로 넘겼고, 5번(코드 연출)만 여기서 했다.

## 변경
- `lib/story-fx.ts`: 컷 효과 5종.
  - `tile`: 패 놓는 소리와 살짝 튀는 움직임.
  - `slam`: 묵직한 패 소리와 흔들림.
  - `shake`: 땅이나 다리가 떨림.
  - `zoom`: 말하는 사람 쪽으로 빠르게 다가감.
  - `flash`: 무언가 드러날 때 빛 한 번.
  - 소리는 대결 중 패 소리(`sfx-261028/03-tile-land`, `04-tile-slam`)를 그대로 쓴다.
- `RpgPrologue`: 컷에 들어갈 때 효과를 한 번 실행한다. 그림만 움직이고 대사 상자는 그대로다. 움직임 줄이기 설정이면 움직임을 건너뛴다.
- 효과를 붙인 곳:
  - 프롤로그 "낡은 패 한 장을 테이블에 올려놓았다" → `tile`.
  - ST4~10 승부 직전 클로즈업 줄 → 기본 `tile`.
  - 보스 줄(카르덴 "테이블에 앉아라", 재온 "패를 내라", 첫 번째 수호자 "답은 패로 해라") → `slam`.
  - ST5 다리 흔들림 → `shake`.
  - ST6 카르덴 첫 줄, ST7 루엔 첫 줄 → `zoom`.
  - ST4 왕관 흔적, ST8 별자리 기록 → `flash`.
  - ST6 승부 후 첫 줄과 ST10 특별 패 4장 → `tile`.
  - ST10 마지막 패 → `slam`.
- `app/story-motion.css`: 번쩍임 효과를 추가하고, ST5 랜턴과 ST8 등불이 은은하게 깜빡이게 했다.
