# 0.7.8 · 요트다이스 메뉴·하로 12칸 점수판·주사위 겹침 방지·유물 칸 짧은 문구

## 변경 내용

### 요트다이스 (상세 `docs/local-yacht-menu-2026-11-09.md`)
- **싱글플레이 메뉴**
  - 아이템전 카드 자리에 요트다이스 카드를 넣었다.
  - 하로와 판돈 없이 1:1 연습판을 한다. 결과 화면에서 "한 판 더"와 "메뉴로 돌아가기"를 고를 수 있다.
  - 아이템전 코드는 남겨 두고, 메뉴에서만 뺐다. 최종 배포 때 삭제한다(사용자 확정).
- **하로 패널**
  - 하로 자리 왼쪽에 하로의 12칸 점수판(1~6 / 초이·포카·풀하·스몰·라지·요트)을 띄운다.
  - 성공한 칸은 금색, 0점으로 버린 칸은 붉은 칸에 취소선, 방금 적은 칸은 파란 테두리다.
  - 윗줄에는 "하로 방금 요트 50점"처럼 나온다. 하로 차례에는 굴림 상황과 "굴림 n/3"이 나온다.
- **남길 주사위 칸:** 주사위가 "남길 주사위" 글자를 덮지 않는다.
- **주사위 겹침 방지:** 어떤 굴림에서도 두 주사위 중심이 21.5 이상 떨어진다.
- **1의 빨간 눈:** 디자인이라 그대로 둔다.
- **주사위판 화면:** 메뉴 위를 확실히 덮는다(z-index, 불투명 배경).

### 새 RPG 장착 유물 칸 (상세 `docs/local-relic-rail-short-2026-11-09.md`)
- 유물 12개에 "조건 / 효과" 두 줄 요약을 넣었다(예: 5장 승리 / 정찰 +1).
- 휴대폰 세로 화면에서 긴 설명이 잘리거나 아이콘과 겹치지 않는다.
- 유물을 누르면 뜨는 팝업에는 전체 설명이 그대로 나온다.
