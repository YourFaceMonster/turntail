# 주점 캐릭터 외곽선 수정 · 로컬 0.6.62

## 가방 경계 재작성 · v6

사용자 지적에 따라 v5 가방 경로를 다시 작성했다. 특히 세로 침낭 왼쪽, 옆 주머니와 스트랩 주위에서 선이 배경 상자 쪽으로 벌어진 부분을 수정했다. 원본 픽셀의 색상 경사와 재측정한 경계 기준점을 사용해 좁은 경계 구간을 추적하고, 0.9px 허용 오차로 중복 꺾임을 줄였다. 가로 가방 오른쪽과 상자 사이의 경계도 보완했다. 원본 그림에는 변경이 없다.

가로/세로 가방 부분을 원본 2배 크기로 나란히 겹쳐 확인했다. 검토 화면 `../../artifacts/tavern-contours/bag-source-review-v6.jpg`의 녹색은 진단용이며 실제 UI는 기존의 얇은 금빛 선이다. 추적 스크립트와 픽셀 검토 자료는 `../../artifacts/tavern-contours/`에 보존했다. 이번 타입 검사와 관련 검사3개 통과. 인앱 로컬390×740/844×390 화면 확인과 세로 가방 그림 클릭으로 정비 팝업 열림 확인. 최종 화면 `portrait-v6.jpg`, `wide-v6.jpg`를 같은 폴더에 저장했다. 이전 v5 검증과 구분한다. 로컬 저장만 완료했으며 빌드·게시는 하지 않았다.

## 벽난로·세린 머리카락 · v4

벽난로의 점선 사각형을 없애고 가로/세로 원본의 돌 돌출부와 화구 내부 경계에 맞춘 열린 SVG 경로를 추가했다. 내부는 투명하고 인물과 같은 얇은 금빛 선을 사용한다. 기존 휴식 버튼은 작은 이름표로 남기고, 벽난로 그림 자체의 클릭도 기존 휴식 팝업에 연결했다. 세로 이름표가 화면 왼쪽으로 잘리지 않도록 위치를 조정했다.

세린은 세로 머리카락의 정수리·옆머리·흘러내린 가닥의 곡선을 확대 격자에서 다시 조정했다. 피오 세로 다리 선 제거는 유지한다.

이번 타입 검사 통과, 여정/상점 검사3개 통과. 인앱 로컬390×740 세로와844×390 가로 확인, 벽난로 그림 직접 클릭으로 '벽난로 곁' 팝업 열림 확인. 화면은 `../../artifacts/tavern-contours/portrait-v4.jpg`, `wide-v4.jpg`. 로컬 저장만 했으며 빌드·게시는 하지 않았다.

이전 검증은 작은 화면에서 선 표시와 동작을 확인한 것으로, 실제 캐릭터 경계 일치 확인이 부족했다. 사용자 지적에 따라 모르·피오·세린의 가로/세로 경로를 다시 작성했다. 아래의 초기 기록은 이번 수정 전 기록이다.

- 원본의 확대 격자와 원본 크기의 청록색 진단선을 겹쳐 깃털·부리·어깨·후드·귀·망토·부츠 위치를 재측정했다. 진단용 색은 게임에 적용하지 않는다.
- 가로/세로 원본 좌표는 `scripts/tavern-contour-paths.mjs`, 정규화된 컴포넌트 재생성은 `node scripts/generate-tavern-contours.mjs`로 보존했다.
- 세린의 손·팔을 가로지르는 하단 선을 제거했다. 가려진 부분은 열린 경로로 끝내 가구를 가로질러 연결하지 않는다.
- 이번 TypeScript 검사 통과, 여정/마을 상점 관련 검사 3개 통과. 로컬 실제 주점 844×390/390×740 확인, 모르 몸체 클릭과 피오 이름 버튼으로 대화 팝업 열림 확인.
- 이번 최종 화면은 `../../artifacts/tavern-contours/wide-v2.jpg`, `portrait-v2.jpg`이며 앞선 v1 화면과 구분한다. 격자 검토 자료는 같은 폴더의 `review/`에 보존했다.
- 로컬 저장만 했으며 빌드·게시하지 않았다. 실제 휴대전화 터치는 미검증이다.
