# 0.7.4 · RPG 정산 화면 복원 · 정찰 2층 한정 · 최근 패 표시 · 폭탄시장 룰 변경

사용자 요청(2026-11-08): RPG 작업요청 4건 수정 후 커밋·배포.

## 변경 내용

### RPG
- **이번 판 정산 화면 복원:** `app/components/RpgReworkResult.tsx`를 아이템전 정산 카드 형식(자리 색·초상화·HP바·등수·손실/획득/최종)으로 되돌림. 유물 보상 선택은 유지.
- **정찰은 2층(위) 패만:** `lib/rpg-rework.ts` `scoutRpgFloor`가 1층 패까지 정찰 후보로 넣던 문제 수정. 1층 패를 칸 오른쪽 아래에 반쯤 줄여 그리던 `scoutedLower` 뷰·렌더·CSS 제거. 화면 표시와 AI 바닥패 선택은 원래 2층 정찰만 써서 이전 저장의 1층 정찰 기록은 노출되지 않음.
- **최근 패 표시(신규):** RPG 모드·세로 화면에서 바닥패 격자 왼쪽에 "최근" 열.
  - 그 판에서 최근 낸 패 3건을 고정으로 표시(최신이 위). 패스 제외. 선이 바뀌어도 유지하고 새 판 시작 때만 비움.
  - 최신은 자리 색 테두리·●, 이전 것은 흐리게·○. 이름(자리 색) + 작은 숫자 패, 한 줄 3장.
  - 격자 5열(2인 6열) 유지, 기록이 없을 때는 점선 빈 칸.
  - `lib/game.ts` `Game.trickPlays`·`RECENT_TRICK_PLAYS`, `app/components/RpgRecentPlays.tsx`, `app/page.tsx`, `app/rpg-phase-one.css`.

### 폭탄시장전 (이전 로컬 미커밋 작업 포함, 사용자 확정)
- 매 판 검정 3 보유자가 선. 검정 3이 시장에 있으면 가장 약한 패를 받은 사람이 선.
- 아무도 이길 폭탄이 없으면 3초 반응 생략.
- 반응 마감 이후 폭탄 제출을 엔진에서도 거절.
- 자세한 내용: `docs/bomb-market-0654.md`의 "룰 변경 — 2026-11-08".
