# 0.6.18 — 모드2 통합과 싱글플레이 메뉴 정리

사용자 확인에 따라 새 싸움 공격·돈 정산·고유스킬·아이템 지급을 모두 아이템전2로 통합했다.

## 새 대전

- 아이템전1: 기존 HP 대전. 기본 아이템 5종 각 2개, 아이템 피해·회복과 카드 패배 피해를 판 종료에 정산한다. 돈 상점·싸움별 공격·고유스킬은 없다.
- 아이템전2: 규칙 버전 3. 시작 HP 100·돈 20P·아이템 7종 각 2개, 토토·로웬·루미 캐릭터 선택과 고유스킬, 싸움별 공격, 즉시 아이템 효과, 정상 판 점수의 돈 정산·부족분 HP 차감, 판 결과 뒤 선택 구매 상점을 통합한다.
- 모드2의 새 규칙에는 이전 HP 흡수 포인트와 매판 8P 준비금을 중복 적용하지 않는다. 카드 판 돈 정산과 즉시 스킬 보상만 적용한다.
- 사용 횟수, 교환 조건, 비공개 정찰, 아이템 이미지와 작열탄·바늘탄 연출은 유지한다.

## UI

- 싱글플레이는 첫 줄에 일반모드·아이템전, 둘째 줄에 RPG모드를 배치한다. 큰 카드·반복 설명·영문 분류를 제거하고 작은 선택 버튼으로 정리했다.
- 아이템전 로비는 각 모드의 실제 규칙·시작 지급품을 분리한다. 고유스킬 캐릭터 선택은 새 모드2에만 표시한다. 긴 규칙은 접어둔다.
- 상점과 결과창을 동시에 표시하지 않는다. 새 모드2 결과에는 돈 내역만 표시하며 이전 포인트 획득 내역을 중복 표시하지 않는다.
- 모드2 새 대전 확인창은 모드2의 저장 슬롯을 조회한다. 이전에 모드1의 저장 설명을 표시하던 부분을 수정했다.
- 시작 지급 목록은 전술 아이템 모듈의 순환 초기화 순서에 영향을 받지 않도록 독립된 상수로 둔다.

## 이전 저장

- 진행 중인 저장을 초기화하거나 중간에 다른 규칙으로 바꾸지 않는다.
- 이전 모드1 테스트 저장은 규칙 버전 2로 계속 진행한다. 이전 모드2 저장은 기존 포인트 흡수·상점 규칙으로 계속 진행한다.
- 이전 저장은 로비·이어하기 목록에 구분해 표시한다. 새 통합 규칙은 새 아이템전2부터 적용한다.

검증: 새 모드2 전투·스킬·정산·다음 판 충전·상점 순서·무지원금·중복 포인트 방지, 원래 모드1, 이전 모드2, 저장 분리·이전 모드1 테스트 저장의 호환성, 로비·정산 UI 표시, 타입 검사와 프로덕션 빌드. 검증한 소스로 기존 사이트에 배포한다.
