# TURNTALE 0.6.46 · 아이템전 배경·패 독립 랜덤

사용자가 ‘주사위’는 ‘패’를 뜻한 것이라고 정정했고, 기본모드는 유지하며 아이템모드만 변경하도록 지정했다. 이 지시와 빌드·기존 사이트 업로드 요청을 반영한다.

- 아이템전 새 대전마다 기존10개 테이블 배경과10개 패 재질을 각각 독립 선택한다. 같은 번호가 우연히 나올 수 있다.
- 선택값을 대전에 저장해 다음 판·이어하기 중에는 바꾸지 않는다. 기존 저장은 이전처럼 배경과 같은 패 재질을 유지하고 다시 뽑지 않는다.
- 시작 연출, 손패, 바닥패, 낸패·이동 패는 같은 패 재질을 사용한다. 배경·공간 연출은 배경 선택을 따른다.
- 상단에는 실제 배경 이름과 실제 패 재질을 따로 표시한다.
- 기본모드의 디자인 선택·기본 패·배경은 유지한다. RPG 진행 단계·아이템 가격·주화·HP·스킬·AI 규칙을 추가 변경하지 않는다.
- 미배포0.6.45의 스킬 이미지·주화 로딩/순서·유물창·선택 잘림·바닥 고정·배경/패 이름·마법사5장추가피해+4 수정도 함께 포함한다.

## 검증과 게시

이번 관련 기능 검사23개 파일 통과. 독립된 두 랜덤 선택, 저장·다음 판 유지, 기존 저장 재추첨 방지, 기본모드·RPG 상태 유지, 테이블과 패 렌더 분리를 검사했다. [기능 검사 원문](../../artifacts/checks-0646.json).

로컬 분리 저장에서 배경9·패2를 지정해 실제 화면의 배경/표면은9, 손패·바닥패 재질은2(호두나무), 안내는 ‘잿불 제단 / 호두나무’인 것을 확인했다. 기본모드에서 기본 나무판·클래식 패·기존 뒷면15개가 유지되고 랜덤 패 재질이 적용되지 않는 것도 확인했다. 사용자 저장은 사용하지 않았다.

최종 소스 타입 검사와 운영 빌드는 이번 게시 과정에서 새로 실행한다. 결과·소스 커밋·저장본·공개 화면 확인 범위는 워크스페이스 `artifacts/deployment-0.6.46.json`에 기록한다. 앞선0.6.45의22개 검사파일·128모의대전 결과와 이번 검사를 구분하며, 수치를 바꾸지 않아 모의 대전을 다시 실행하지 않았다.
