## 재생과 음량

`lib/sound-assets.ts`에서 사용자 입력 시 9개를 미리 가져와 AudioContext별로 한 번 디코딩한다. 이후 게임 이벤트는 캐시된 버퍼로 즉시 재생한다. 각 클립은 재생 종료 시 노드를 해제하며 기존 `effectOutput()` 버스에 연결하므로 효과음 음량·음소거·기존 리미터가 적용된다.

원본별 피크가 약 0.025~1.0으로 크게 달라, 디코딩 시 측정한 피크와 효과음별 목표값으로 재생 gain을 보정했다. 증폭 상한은 24배다. 파일을 다시 인코딩하지 않았으며 BGM 음량은 별도다. 이는 피크 기준 보정이며 사람의 체감 음량을 동일하게 맞췄다는 뜻은 아니다.

첫 입력 직후 파일이 아직 준비되지 않았거나 파일 조회·디코딩 실패·무음 파일이면 기존 합성음으로 대체한다. 늦게 끝난 로딩이 이미 지난 게임 이벤트를 뒤늦게 재생하지 않는다. 미제공 7종은 기존 합성음을 유지한다.
