# 0.6.17 — 바늘탄의 가벼운 포물선 공격

바늘탄을 작열탄과 같은 포물선·비행 시간·방패 접촉 시점으로 맞췄다. 기존 바늘탄 전용 1.6초 단축 시간을 제거하고, 작열탄처럼 사용자 관련 공격은 2.8초, AI끼리는 2.5초의 동일한 타임라인을 사용한다. 크기와 충격 강도로 두 공격을 구분한다.

- 바늘탄의 작은 투사체, 작은 충돌 링과 불꽃, 짧은 섬광으로 가벼운 타격을 표현한다.
- 바늘탄 상태창 흔들림은 약 2px·190ms로 줄이고 작열탄은 기존 7px·400ms의 묵직한 반응을 유지한다.
- 바늘탄은 짧고 부드러운 중음 타격음과 8ms 진동을 사용한다. 바늘탄에 겹쳐 나오던 무거운 slam 효과와 고통 음성을 제외한다.
- 바늘탄이 수호의 봉인에 막힐 때도 같은 접촉 시점에 튕기며, 방어 효과음과 진동은 가볍게 재생한다.
- 피해량, 아이템 사용 조건, 고유스킬, 가격과 시작 지급량은 그대로다.

검증: 사용자→AI, AI→사용자, AI→AI의 명중·방어 타임라인과 차례 해제 시점 일치, 기존 아이템 회귀 검사, 타입 검사, 로컬 HTTP 200 및 0.6.17 표시. 프로덕션 빌드를 수행한다. 실제 화면과 소리의 체감은 로컬에서 사용자가 확인한다. 사이트에는 업로드하지 않는다.
