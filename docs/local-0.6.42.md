# 0.6.42 · 후속 화면·결투 흐름 수정, 로컬 저장만

2026-10-29. 시작 소스는 0.6.41, Git HEAD `c66c87eff99f2ca0b9b194db5a2ee533306a27a7`이며 작업 시작 Git은 깨끗했다. 마지막 배포는 0.6.41 / Sites 103이다. 이번 요청은 **저장만**이므로 빌드·push·원격 저장·사이트 배포를 하지 않았다. 아래 변경은 미배포 로컬 파일 기준이다.

## 요청별 변경

1. 회색 손패의 SVG 전체 회색 필터를 없애고 숫자·문양 잉크와 투명도로 구분한다. 비활성 손패에는 흔들림·이동·전환을 적용하지 않는다.
2. 결투 결과를 `n번째 결투 → 이긴 캐릭터 승리!와 HP → 싱글 전투 · n점 피해 → 진 캐릭터 1 → 진 캐릭터 2 → 발동 효과` 순서로 배치했다. 남은 HP 순 정렬과 등수 표시는 제거했다. 피해 수치는 해당 결투의 기본 피해, 개별 HP 행은 실제 추가 피해·방어·회복을 포함한 전후 HP다.
3. 작열탄의 폭발 그림을 회전시키지 않는 이전 방향으로 복원했다. 투사체 도착 좌표와 폭발 기준을 분리해 폭발 이미지 박스의 **아래 변**을 대상 HP 상태창 아래 변에 맞춘다. 원래 폭발 이미지 파일은 유지했다.
4. 손패 선택 시 레이아웃에 영향을 주는 안내 공간을 고정하고, 판·바닥·낸 패 컨테이너를 `overflow:clip`으로 바꿨다. 숨긴 영역으로 브라우저가 버튼 포커스를 따라 내부 스크롤하는 경로를 막고 손패 레이아웃을 격리했다. 기존 사용 가능한 손패 이동·선택 기능은 유지한다.
5. `이름님이 선을 잡았습니다`와 선 안내 뒤에 어두운 반투명 바탕을 넣었다.
6. 매 판 자동 준비금을 0으로 바꿨다. 실제 기존 코드는 4P가 아닌 8P였다. 첫 시작 20P·기존 저장 지갑·이월 아이템·게임 중 획득 주화는 보존한다. 상점 설명도 수정했다.
7. 중앙 아이템 연출의 캐릭터명에 검정 외곽선과 그림자를 적용했다.
8. 결투 결과 피해는 더 진한 빨강 `#e53935`로 표시하고, HP 오른쪽 `/100` 위에 작아져 남도록 배치했다. 회복은 기존 밝은 초록 `#4dff88`을 유지한다.
9. built-in ImageGen으로 짙은 비취색 중앙과 금빛 문양 테두리가 있는 새 결투창 배경을 생성했다. [이미지](../public/item-battle-v1/duel-panel-v1.png), [원문 프롬프트·원본 경로·해시](assets/duel-panel-0642.json). 원본 생성 파일도 보존한다.
10. 약초 중앙에 덧붙던 `응급 약초`를 빼고 사용자 이름만 다른 아이템과 같은 크림색·검정 외곽선으로 표시한다. 회복 숫자는 HP 창에 표시한다.
11. 승리창 중심을 기존 타일판 중앙보다 30px 내려 약간 위쪽 중앙에 배치한다. 화면 경계 안으로 제한하는 로직을 유지한다.
12. 검사 대상 선택 문구를 붉은 바탕·테두리·글자로 강조하고 선택 가능한 상대 상태창에도 붉은 외곽선을 표시한다.
13. 검사 `강타 준비`를 `강타!`로 바꾸고 상대 상태창 위에 검격·교차 베기·타격 섬광·짧은 흔들림을 추가했다. 실제 HP 타격 시점에 충격을 맞췄다. 모션 감소 설정에서는 흔들림을 생략한다.
14. 결투 승리 연출 대기를 1.5초에서 2초로 늘렸다. 결과창 확인 전 다음 턴 잠금과 마지막 결과 확인 후 판 정산 1초 대기는 유지한다.
15. 결투가 끝나 서버 상태의 낸 패가 비워져도 해당 결투의 공개 낸 패 사본을 보여준다. 패 주변에 금빛을 넣고 제출자 이름에 `승리!`를 표시한 뒤 정산창으로 넘어간다. 오래된 저장에 사본이 없으면 비공개 정보로 복원하지 않는다.
16. 새 아이템전 AI는 선에서 페어·트리플·5장 족보, 남은 손패의 조합 보존, 직업 보너스와 공개 HP의 마무리를 평가한다. 싱글에 대응할 때는 같은 장수 규칙을 유지하며 전략적 가져오기도 가능하다. 학습 기능이 아닌 선택 기준 수정이다. 일반 AI는 자기 손패·상대 공개 패/장수·공개 HP만 사용한다. 워커 실패 대체 경로도 같은 정책을 쓴다.
17. 첫 판에만 적용하던 아이템 잠금을 **모든 라운드의 첫 결투가 끝날 때까지** 적용했다. 사용자·AI 모두 같은 규칙이다. 아이템과 별개인 게이지 직업 스킬은 기존 규칙을 유지한다.
18. 페어 뒤 멈춤에는 첫 족보 안내 대기가 있었다. 싱글·페어·트리플 첫 안내를 3.4초에서 2초로 줄이고 캡션은 1.1초로 조정했다. 반복 소개는 0.65초, 5장 족보 소개는 3.4초로 유지해 아이템이 소개 도중 끼어들지 않게 한다. 결투 승리 연출 2초는 별도다.

## 이번 실행한 검증과 한계

- 관련 기능 검사 **13개 파일 통과**. 상세 출력은 워크스페이스 `artifacts/checks-0642.json`. 승리자 우선 SSR, 결투 번호, 공개 낸 패 보존·옛 저장 처리, 초기 자금과 다음 판 이월, 1·2·5라운드/세 자리 모두 첫 결투 아이템 잠금, 기존 아이템·함정·주화·직업 스킬, AI의 선 페어·트리플·5장 제출과 숨은 정보 무시를 검사했다.
- `tsc --noEmit --incremental false` 통과. 운영 빌드를 대신 실행하지 않았다.
- 새 CSS 56개 규칙의 구문 파싱과 `git diff --check`를 통과했다. 이는 실제 스타일 계산·레이아웃 측정과는 다르다.
- 이번 환경에서 로컬 브라우저 사용이 Work 설정으로 꺼져 있다는 도구 응답을 받았다. 따라서 회색 패 깜빡임·선택 시 판 이동의 실제 재현/픽셀 측정, 새 배경/베기/폭발의 모바일 화면 검증은 **미실행**이다. 레이아웃·좌표·스타일·SSR 검사와 실제 화면 검증은 구분한다. 이전 0.6.41의 화면 검증을 이번 결과로 재사용하지 않는다.
- 배포·운영 사이트 확인은 하지 않았다. 게임 저장·첨부·기존 배포 보관본은 삭제하지 않았다. 임시 QA 진입점은 앱에서 워크스페이스 artifacts로 옮겨 보관했다.
- `artifacts/duel-preview-0642.html`은 새 배경과 결투 본문을 서버 렌더링한 독립 정적 시안이다. 브라우저 실행이나 앱 빌드 결과가 아니며 실제 모션·레이아웃 검증을 대체하지 않는다.
