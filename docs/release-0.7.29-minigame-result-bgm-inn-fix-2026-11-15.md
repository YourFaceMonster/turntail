## 변경
- **결과 화면 BGM:** `public/audio/shuffling-shadows-suno-0729.mp3`(Suno 내려받기 "Shuffling Shadows"). 예전 짧은 합성 승리음 대신 이 곡이 반복 재생된다.
- **ST2 대결 BGM:** `public/audio/duel-d-suno-0729.mp3`(Suno 내려받기 "카드 듀얼"), `musicScene` `duel-d`. 그동안 기본 대결곡으로 대신하던 자리.
- **여정 미니게임 BGM:** `public/audio/minigame-suno-0729.mp3`(Suno 화면 녹화본, MP3 프레임 단위로 3.34초~159.74초만 남김, 156초). 하로 요트다이스 승부, 안개 나루 "높을까 낮을까", 달빛 등불 "기록 맞추기"가 열려 있는 동안 `musicScene` `minigame`(`lib/minigame-music.ts`).
- 내려받기 파일 2개는 계정 이름·Suno 주소가 든 ID3 태그를 지웠다. 원본 3개는 `artifacts/bgm-2026-11-13/`(Git에 올리지 않음).
- **지역 주점 버그:** 0.7.24~0.7.28에서 스테이지 클리어 뒤 지역 주점에 들어가면 주점 대신 지난 판 정산 창이 다시 떠서 "다음 스테이지"가 "지도에서 다음 승부를 선택해 주세요." 오류로 막혔다. 원인은 `app/page.tsx`의 여정 화면 열림 목록에 `inn`이 빠진 것. 목록을 `JOURNEY_SCENE_LOCATIONS`(`lib/rpg-journey.ts`)로 옮기고 `inn`을 넣었다. 기존 저장은 그대로 이어진다.
- **프롤로그 배경 소리(이전 로컬 작업 포함):** 바람·모닥불 소리가 컷마다 다시 시작하지 않고 같은 소리로 이어지며 서서히 켜지고 꺼진다(`lib/rpg-prologue-audio.ts`, `RpgPrologue.tsx`).
- 버전 0.7.29.
