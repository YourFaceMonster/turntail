# 턴테일 4.0 — 모드별 저장과 공중섬 여정

## 저장과 진입

- 메인의 싱글플레이에서 일반모드 / 도전모드를 선택한다.
- 일반모드 안의 일반 대전 / 10판 도전은 기존 규칙을 유지한다.
- 이어서 하기는 최신 세션 포인터가 아니라 일반 게임, 스테이지 저장, 온라인 방을 각각 읽어 선택 목록으로 표시한다.
- 일반과 스테이지는 독립 슬롯이다. 서로 시작하거나 저장해도 다른 모드의 저장은 바뀌지 않는다.
- 같은 모드의 저장이 있을 때 새 시작은 취소 / 새로 시작하기 확인창을 거친다.
- 도전 교체는 이전 도전의 종료 기록과 새 도전 저장을 한 번의 쓰기로 처리한다. 확인하지 않은 교체와 저장 실패는 기존 진행을 보존한다.
- 저장을 읽지 못한 모드는 경고를 표시하고 다른 모드의 이어하기는 제공한다. 데이터 초기화로 오류를 숨기지 않는다.

## 공중섬 지도

제공받은 맵의 비율을 유지해 10개 거점과 점선 경로를 겹친다. 미개방 거점도 눌러 장소·재질·상대 소개를 볼 수 있지만 입장할 수 없다. 현재 승부 이어하기와 다음 스테이지 출발은 저장 상태에 맞춰 활성화한다. 클리어 결과의 다음 단계 버튼은 지도를 먼저 연다.

## 스테이지 분위기

`docs/reference/stage-art-direction.md`의 열 장소·짧은 설명·장소 서사·서른 상대 이름과 호칭을 사용한다. 최종 관문은 아르덴(흑금룡), 녹스(그리핀), 로제아(봉황)다. 상대 이름과 초상화는 게임 중에도 표시한다. 기존 저장은 손패·순서·점수·ID를 유지하면서 해당 지역의 상대 표시를 적용한다.

바닥과 도입 장면은 지역에 맞는 조명·표면·맵 영역을 공유한다. 패 몸체에는 재질별 SVG 결, 기공, 광물 면, 내포물과 뿌리 조각을 사용하며, 문양의 외형·조각 기법을 달리한다. 숫자 위치·공통 크기·기존 식별 색은 유지한다. 앞면 개체차는 패 ID로 안정적으로 고정하며, 뒷면은 같은 스테이지에서 모두 동일해 비공개 정보를 담지 않는다.

도입 GPU도 실제 앞면·뒷면을 한 번 래스터화하며 옆면을 재질 색으로 맞춘다. 셔플 동선과 60개 패의 분배 규칙은 유지한다. 일반모드에는 새 재질이나 상대를 적용하지 않는다.
