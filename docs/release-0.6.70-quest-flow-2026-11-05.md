# 0.6.70 퀘스트 진행·안내 정리

사용자 요청: 폐허·숲 삭제 및 앞서 확인한 나머지 퀘스트 문제 반영 후 업데이트. 앞선 여행자 컷씬 원복도 함께 포함한다.

- 폐허·숲과 빈 town-event의 실행 분기, 노드 타입, 분기 보상·CSS를 제거했다. 옛 저장을 읽을 때는 호환 모듈에서만 기존 노드 흔적을 정리한다. HP·주화·아이템·편지 상태는 유지하고 원본 저장 문자열을 읽기만으로 덮어쓰지 않는다.
- 주점을 모든 ready 준비 구간에서 재방문할 수 있다. ST2 이후 모르 퀘스트 시작·세린 승부·편지 반납이 가능하다. 편지를 반납하지 않고 지도로 나갔다 돌아와도 완료할 수 있다.
- 모르의 수락 선택지를 명시하고 미수락 선택지와 구분했다. 수락 후 골목이 열린다는 대사 및 보상 안내 추가.
- 편지 반납 보상을 10→30주화＋소문1개로 올렸다. 완료한 퀘스트에 소급 중복 지급하지 않는다. 도둑 승부 자체에서 별도 주화를 지급하지 않아 재도전 보상 반복 획득이 생기지 않는다.
- 도둑 승부 시작 전 단독1등 성공·2등/공동1등 재도전·3등 최종 실패를 설명한다. 세린 첫 세트만12/8/4주화, 재대결0 안내는 유지한다.
- 재도전 대기 중 시설 이용 제한은 유지하며 상점·주점·여행자 이용 불가를 화면에 명시했다. 최종 ST3 진입 전 남은 퀘스트를 마무리하라는 안내 추가.
- 저장 슬롯에 여정 운명력 n/3 표시. 기존 소문 수첩은 지도에서도 계속 열 수 있다.
- 다친 여행자 가로/세로v2, 도움 이후 가로v2/세로v3로 복원. 원본 이미지 모두 보존.
- package.json과 lib/version.ts의 표시 버전을0.6.70으로 올렸다. 이후 배포도 패치 버전·앱 표시·기록을 일치시킨다.
