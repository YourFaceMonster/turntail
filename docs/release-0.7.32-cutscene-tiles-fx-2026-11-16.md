# 0.7.32 · 컷씬 패 다시 그리기·연출 보강 (2026-11-16)

사용자 후기: 컷씬의 게임 장면에서 패에 숫자·그림이 없거나 인게임 패와 다르다. "1에서 4까지 전부하다 연출만 보강해보자", "이미지생성완료했다카네 고고", "연출보강도해보자 고고", "이제 배포해보자 고고".

## 변경

### 컷씬 패 다시 그리기
Codex가 그린 묶음 1이다. 16장면을 세로·가로로 그려 모두 32장이다. 요청서는 `docs/codex-art-request-2026-11-16-cutscene-tiles.md`.

- **빈 패에 숫자·문양 넣기:** ST4·5·7·8·9 승부 전 장면.
- **문양만 있던 패에 숫자 넣기:** 프롤로그 내기, ST6 승부 전, ST9 승부 후.
- **엎어 둔 패를 스테이지 뒷면 재질로:** ST4~10 승부 직전 클로즈업, ST10 승부 후.
- `lib/rpg-chapters.ts`에 가로 그림 버전 표(`WIDE_VERSION`)를 새로 두었다.
- 이전 그림 파일은 지우지 않고 남겼다.

### 컷씬 연출 보강
효과는 `lib/story-fx.ts`에 있다.

- **효과 종류:**
  - 패 놓는 소리: 대결 중 패 소리를 그대로 쓴다.
  - 묵직한 패 소리와 화면 흔들림.
  - 화면 떨림.
  - 말하는 사람 쪽으로 빠르게 다가가기.
  - 무언가 드러날 때 번쩍임.
- **동작 방식:**
  - 그림만 움직이고 대사 상자는 그대로 둔다.
  - 움직임 줄이기 설정이면 움직임을 건너뛴다.
- **효과를 붙인 곳:**
  - 프롤로그.
  - ST1~10 승부 전후 대사: 승부 직전 줄, 보스의 승부 선언 대사, 관문 열림, 다리 흔들림, 특별 패가 드러나는 장면 등.
- ST5 랜턴과 ST8 등불이 은은하게 깜빡인다.
