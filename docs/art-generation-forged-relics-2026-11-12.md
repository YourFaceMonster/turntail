# 합성 전설 유물 아이콘 4종 생성 (로컬 미게시)

요청: `docs/codex-art-request-2026-11-12-forged-relics.md`.

## 저장 파일

`public/rpg-items-v1/relics/` 아래에 다음 이름의 PNG·WebP를 각각 저장했다.

- `whole-heart`: 붉은 심장의 균열을 청록 보석빛 선으로 메운 하나의 심장.
- `gamblers-hourglass`: 가죽 장갑이 감싼 모래시계와 다시 흐르는 모래.
- `undying-lantern`: 손잡이에 붉은 매듭을 묶은 등불.
- `forked-mirror`: 갈라진 손거울 안에서 서로 다른 방향을 가리키는 금색·파랑 바늘.

## 생성과 검증

- 내장 image_gen 사용. TURNTALE 손그림 2D 카툰 판타지 스킬과 각 재료 아이콘 2개를 참조했다.
- 각 이미지 1회 생성, 탈락본 없음. 각 생성본을 직접 확인했으며 재료 특징을 한 물건에 통합하고 글자·숫자·승부 패 문양을 배제했다.
- PNG·WebP 모두 1254×1254 RGBA. 디코딩·크기·알파 범위(0~255) 확인 통과. WebP는 lossless로 저장해 투명 가장자리와 원본을 보존했다.
- 생성 원본 복사본·최종 프롬프트·참조·저장 스크립트·검증 JSON은 `artifacts/forged-relics-2026-11-12/`에 보존했다.
- 기존 재료 아이콘과 다른 세션의 작업은 덮어쓰지 않았다.

## 인계

요청서대로 앱 연결 및 `FORGED_TEMP_ICON` 제거는 Claude가 담당한다. 이번 작업은 이미지와 생성 기록만 로컬 저장했다. 빌드·커밋·push·배포는 하지 않았다.
