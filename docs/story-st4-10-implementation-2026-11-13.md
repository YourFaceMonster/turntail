## 이벤트가 붙은 곳

| 이벤트 | 여는 곳 | 성공하면 |
|---|---|---|
| ST4 젖은 기록 | quest-4 "말려 살핀다" | 결과 3줄 추가. ST4 승리 후 "…나누어 맡았다" |
| ST5 매듭 | quest-5 "돕는다" | 결과 1줄 추가 (승리 후 타래 대사는 도움 여부로 이미 갈림) |
| ST7 장부 | ST7 승부 전 장면 두 번째 줄 | 승리 후 시온 대사. 2회차 진엔딩에서 회수 |
| ST8 성소 | quest-8 "읽는다" | 결과 2줄 추가. 승리 후 방랑자 대사 |
| ST9 문양 | quest-9 "살핀다" | 결과 1줄 추가 |

- 이벤트는 실패하면 그 자리에서 다시 할 수 있다. 건너뛰면 원래 결과 문장으로 진행한다.
- 메인 진행은 막지 않는다. 보상(HP·유물)은 없다.
- ST7 장부를 건너뛰면 원래 내레이션("2등 자리 옆에는 이름 없이 왕관 표식…")을 보여 준다.

## 이번 검증

- 타입 검사 통과.
- 전체 테스트 430개: 412 통과 · 0 실패 · 18 건너뜀(은퇴 테스트).
- 로컬 개발 서버, 휴대폰 크기 375×812에서 직접 해 봄:
  - **ST4 조각:** 틀린 순서 → 흩어지며 안내 → 맞는 순서로 성공 → 결과 6줄. 저장에 `quest-4: read / solved`.
  - **ST7 장부:** 장면 두 번째 줄에서 표가 뜨고 5초 기다려도 넘어가지 않음 → 3번째 줄 선택 → 계속 → 다음 줄로 진행(처음부터 다시 시작하지 않음). 저장에 `st7-ledger: solved`.
  - 퀘스트 장면(z-index 1500) 뒤에 퍼즐이 가려지던 문제를 이 확인 중에 찾아서 고쳤다(1600).
  - 테스트용 저장은 확인 후 지웠다. 이 브라우저에는 원래 여정 저장이 없었다.
- 실제 화면에서 해 보지 않은 것:
  - ST5 매듭(길게 누르기), ST8 성소, ST9 문양: 자동 테스트로 화면이 뜨는 것만 확인
  - 실제 승부를 거쳐 승리 후 대사와 엔딩까지 가는 전체 진행
  - 가로 화면
