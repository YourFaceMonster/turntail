# 0.6.10 — 아이템전2 경제·연출·정산 조정

- 새 아이템전2는 20P 시작, 다음 판 준비금 8P. 가격은 렌즈 3P, 운명 6P, 봉인 6P, 작열탄 10P, 약초 5P.
- 구매 수량 제한과 5개 의무 구매를 제거했다. 구매 없이 시작할 수 있고 미사용 아이템은 수량 제한 없이 다음 판에도 보관한다. 판당 사용 한도 2개와 자기 차례 1개는 유지한다.
- 진행 중 저장의 포인트·물품을 초기화하지 않는다. 과거 저장에서 이미 소모된 물품은 소급 복원하지 않는다.
- 두 HP 아이템전에서 공격·회복은 판중 예정 효과로 기록하고, 카드 판이 끝나면 한 번만 HP에 반영한다. 작열탄으로 예정 HP가 0이 되어도 현재 카드 판은 마친다. HP로 판정하는 실제 종료 시점도 결과 정산이다. RPG 여정은 기존 즉시 효과를 유지한다.
- 결과창에 HP 바와 아이템 피해·약초 회복·카드 패배 피해를 분리한다. 포인트도 아이템과 카드 승리 획득분을 따로 표시한다.
- 작열탄의 주황색 하단 장식을 제거하고 중앙 확대를 거치는 연속 곡선으로 이동한다. 방패·투사체 도착·피격음·다음 차례에 같은 시간표를 적용한다. 방패는 상태창 전체를 감싸고 공격은 반사되어 돌아온다.
- 사용자 관련 연출은 최대 2.4초, AI끼리는 최대 1.4초. 공개되지 않는 AI 방패 준비에는 연출 대기를 넣지 않는다. 앞선 카드 확인 시간을 아이템에 다시 적용하지 않는다.
- 사용 표시는 캐릭터창 옆 아이콘으로 바꾸고 하단 사용 제목을 제거한다. 약초 회복 안내는 대비 높은 문구로 남긴다. 아이템 중심은 화면 중앙보다 28px 아래다.
- 교환 선택의 음영·빈 선택 칸·복제 미리보기를 제거했다. 내 패를 고른 뒤 상대 버튼을 한 번 누르면 실행한다. 상대 버튼은 상태창 색, 강조한 이름, 곡선 왼쪽 위 화살표를 사용한다. 아이템을 먼저 보여준 뒤 교환 패가 이동한다.

검증: 새 경제·저장·정산·교환·시간표 회귀 테스트와 HP 아이템전, 기존 RPG 아이템·RPG·차례 진행 테스트, 타입 검사. 화면·실제 플레이 확인은 사용자가 진행한다.
