# 0.5.17

- 바닥의 가져올 수 있는 패를 더블탭/더블클릭하면 바로 1장을 가져옵니다. 같은 패를 330ms 안에 두 번 눌렀을 때만 실행합니다. 다른 패를 연속해서 누르는 것은 선택 변경입니다.
- 바닥 패를 내 쪽(화면 아래)으로 끌었다 놓아도 가져옵니다.
- 손패를 먼저 선택한 뒤 선택된 패 중 하나를 위로 끌어 놓으면 선택한 조합 전체를 냅니다. 선택 패들이 함께 움직이며 충분히 밀면 빛으로 실행 가능 상태를 보여줍니다.
- 기존 선택/가져오기/내기 버튼과 키보드 조작을 유지했습니다. 제스처도 버튼과 같은 유효성 검사·요청·저장·패 이동 애니메이션을 사용합니다.
- 패 크기에 따라 44~78px 이상, 가로 이동보다 세로 이동이 1.4배 이상일 때 실행합니다. 천천히 움직여도 됩니다. 짧은 움직임·잘못된 방향·불가 조합·상대 차례에는 실행하지 않습니다. 드래그 뒤의 클릭으로 선택이 다시 바뀌거나 동작이 중복되지 않게 막았습니다.
- 손가락 추가, 포인터 취소, 창 이탈, 앱 숨김, 선택·정렬·턴·판·화면 방향 변경은 진행 중인 제스처를 취소합니다. 회전된 가로·세로 화면의 방향도 변환합니다.

## 검증

제스처 방향·거리·속도와 더블탭 경계값, 선택·게임·바닥 패 유지·턴 지연·도전 저장 회귀 테스트 및 TypeScript 통과. 독립 React 검증 화면에서 실제 브라우저 입력으로 더블클릭 1회 실행, 아래로 끌어 가져오기, 두 장 선택 후 위로 밀어 1회 제출, 불가 조합 유지, 90도 방향 변환을 확인했습니다. 실제 도전 판에서도 바닥 패 더블클릭으로 30→29장 전환과 이동 애니메이션을 확인했습니다. 같은 판에서 손패 선택 후 위로 밀어 10→9장으로 제출되는 것과 기존 제출 연출도 확인했습니다. 독립 검증 페이지는 배포물에서 제외했습니다.
