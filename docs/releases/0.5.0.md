# 턴테일 0.5.0

도전모드 추가 이후 버전은 0.5.0에서 이어간다. 다음 배포 수정은 0.5.1, 0.5.2처럼 패치 번호를 올린다. `lib/version.ts`가 화면 표시의 공통 버전이며 `package.json`도 같은 값으로 유지한다.

## 화면과 지도

- 외부 테이블 크기는 유지하고 내부를 6px씩 들여놓는다. 상단 캐릭터 창과 아바타를 줄이고 둥근 내부 경계에 맞춘다. 줄어든 사용 영역은 공통 패 크기 계산에 반영한다.
- 지도 거점은 반투명 원과 작은 숫자 배지로 표시한다. 잠긴 거점 이름은 선택/초점 시 확인한다.
- 지도만 독립적으로 스크롤한다. 현재 여정과 전적 버튼은 같은 지도 창 안에 고정해 접근한다.
- 거점 팝업은 스테이지마다 바탕·조명·강조색이 다른 10개 팔레트를 사용한다.
- 전체 순위 창은 같은 외곽 크기를 유지하며 2·3·4인 필터 변경 중에도 결과 영역을 유지한다. 이전 조회 결과는 로딩 표시로 덮고 새 결과를 받은 뒤 교체한다. 실패 시 이전 분류의 순위를 새 분류로 표시하지 않는다.

## 패와 테이블

- 모든 앞뒷면은 공통 `TilePrism`의 원근 형태·아랫면·모서리를 사용한다. 손패, 바닥, 이동, 중앙 제출, 도입 애니메이션에서 같은 SVG를 쓴다.
- 이동 패는 별도 작은 패 스타일을 사용하지 않고 원래 크기를 고정한다. SVG 정의 ID를 각 인스턴스에 독립적으로 부여해 이동 중 다른 패의 클립/재질을 참조하지 않는다.
- 스테이지별 실제 재질 테이블을 도입과 인게임에서 공유한다. 작은 재질 이미지 하나를 화면 전체로 확대하지 않고 원래 크기에 가까운 패턴으로 배치한다.
- 배경 방은 확대 카메라에서 분리해 화면 크기로 유지한다. 도입 패 아틀라스는 192×264 셀로 선명도를 높이며 기존 GPU 두 번의 그리기는 유지한다.

## 이어하기

- 저장 단계의 테마를 실제 게임 화면이 마운트되기 전부터 사용한다.
- 저장된 상대 얼굴·이름·점수·남은 패 수와 패를 들고 기다리는 모습을 먼저 보여준다. 공개 정보만 사용한다.
- 이어하기 접근은 2.4초, 게임 화면 연결은 0.85초다. 실제 저장 패를 다시 섞거나 나누지 않는다.
- 이미지 준비를 기다린 뒤 접근하고, 배경·상대·실제 테이블을 점차 연결한다. 모션 감소 설정은 기존처럼 연출을 건너뛴다.

## 검증

`tests/release-050.test.tsx`에서 표시 버전, 정지/이동의 공통 패, 두께, 열 가지 테이블/팝업 팔레트, 순위 결과 영역을 확인한다. 기존 스테이지 UI, 저장 슬롯, 배치, 도입 순서·측정·GPU 프레임 테스트와 타입 검사 및 빌드를 수행한다. 작은 크기의 SVG 이미지로 입체 패의 질감·숫자·문양을 확인한다. 실제 모바일 브라우저 화면/터치/프레임 측정은 이번 검증에 포함되지 않는다.
