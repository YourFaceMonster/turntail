# 턴테일 0.6.0

이번 버전의 기준 상태를 0.6.0으로 저장한다.

- 기본모드 테이블을 0.5.25의 원탁으로 복원: 상판 재질, 테두리, 다리와 진입 장면 렌더링을 이전 상태로 되돌림.
- 0.5.26에서 추가한 고밀도 앤티크 다리·중앙 기둥·장식과 기본모드 가구의 추가 재질 렌더링을 제거.
- 깔린 패와 낸 패의 크기를 고정하고, 손패가 늘어날 때 손패만 축소하는 개선은 유지.
- 추천 족보 전환 시 선택 가능 패 갱신, 여러 페어·트리플 숫자 표시 개선 유지.
- 도전모드 10개 스테이지의 재질·가구 및 기존 게임 규칙과 저장 형식 유지.
- 메뉴와 게임 화면의 표시 버전 및 package.json을 0.6.0으로 통일.

0.5.26의 원목 테이블 실험은 Git 이력과 docs/art-direction-0526.md에 기록으로 남기며, 현재 버전에는 적용하지 않는다.

## 검증

- 타입 검사 통과.
- 손패 증가 시 깔린 패 크기 고정, 배치, 추천 족보, 기본/도전 재질, 원탁 다리, 버전 일치 관련 기존 검사 7개 통과.
- 테이블 구현 파일 7개가 0.5.25와 바이트 단위로 일치함을 확인.
- 브라우저 재생 및 실제 기기 프레임 개선은 미확인: 미리보기 서버가 PID 14의 기존 /site 서버 잠금으로 시작되지 않음.
