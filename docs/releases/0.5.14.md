# Turntale 0.5.14

- Replaced the collapsing tile handoff with constant solid body depth. Lower/upper floor faces remain separated through camera lift and opponent fade. Tile art dissolves onto a stationary cap rather than rotating that cap through its body. Smoothed the fine body grain and phase-boundary drawing.
- Added a projected Canvas renderer sharing the WebGL atlas, frame buffer and camera model for browsers without WebGL2. Graphics context loss or unavailable artwork still uses a short live-board fade. Stale tile art is no longer initialized during menu exit between games.
- Enlarged the seated monsters while preserving headroom. Start greetings are now screen-space panels with 17–22px text, avatars and one speaker at a time. Shuffle lasts 3.6s to allow reading, without increasing the physics planning budget.
- Rebuilt table supports as projected solid faces with an explicit tabletop mask: four legs, feet, stretchers and a thick slab. This replaces CSS 3D flattening that hid the legs. The seated camera leaves the base in view before focusing on the table.
- Remaining count now fits inside one small white badge: number beside the vertically stacked “남음”, with no “장”. The dialogue row gains width.
- One settings panel contains music/effects volume (0–100%), independent mute, a tile-sound preview, vibration, fullscreen and portrait/landscape. The header uses a settings icon; small accidental mute toggles were removed.
- Effects, ambient tension, shuffle and result sounds share one persistent gain bus. Muting silences scheduled sounds too. User preferences and both volume values persist; returning to the page resumes an already-unlocked audio context. Music slider changes ramp promptly.

Validation: TypeScript, production build, physics/rules/entrance/audio regression suites; new tests sample solid tile depth and fades at 121 points per phase, validate visible furniture across desktop/phone/landscape, persistent gain/mute behavior and the Canvas fallback. Browser checked volume changes, mute persistence across reload, new-game completion, count badges, settings and the Canvas opening. This cloud browser lacks WebGL2, so the WebGL shader path and physical phone haptics/speaker balance have not been visually/audibly verified here.
