# 턴테일 0.5.2

## 패 · 테이블 컬렉션

- 기본 오리지널 1개와 기존 스테이지 콘셉트 10개를 11개 세트로 묶는다. 각 세트는 패 앞면·뒷면·테이블을 함께 적용한다.
- 프로필에서 미리 보고 선택한 뒤 프로필 저장을 누른다. 잠긴 세트는 해당 스테이지 클리어 조건을 표시하고 선택을 막는다.
- 일반·멀티·도전모드 모두 내 화면에 장착 세트를 적용한다. 도전 장소·상대·규칙은 장착과 별도로 유지한다. 멀티 상대의 개인 설정을 변경하지 않는다.
- 이전 활성 도전과 전적의 클리어 수를 읽어 기존 보상을 복원한다. 새 도전을 시작해도 해금은 유지하고, 새 보상을 얻어도 자동 장착하지 않는다.
- 클리어 화면에 새 세트 해금을 표시한다. 컬렉션은 이 브라우저의 로컬 저장이며 계정 간 동기화는 포함하지 않는다.

## 표현과 연출

- 노란색을 `#f6c600`으로 밝히고 기본 패 숫자에 `#876300` 외곽선을 사용한다.
- 기본 패 앞면에만 가는 기하학 테두리·길로셰 문양을 추가한다. 10개 스테이지 세트의 디자인은 유지한다.
- 제출패 착지 시 0.28초간 플레이 영역을 흔든다. 기본 2.5px, 빨간 2는 5px이다. 모션 감소 설정에서는 끈다.
- 이어하기도 원형 테이블에서 시작한다. 저장패 좌표는 바꾸지 않고 전체를 포함하는 원형 상판을 뒤에 놓는다.
- 넓은 원형 충돌 회피를 실제 사각형 모서리의 SAT 접촉·충격량·마찰·각운동량 계산으로 교체한다. 4개 하위 단계와 반복 제약 해결을 입장 전에 나누어 계산한다. 재생은 기존 GPU 일괄 그리기 및 compositor 경로를 사용한다.
- 테이블 아래의 고정 바닥과 4개의 세로 등주를 같은 3D 공간에 배치한다. 테이블·패·주변 물체가 하나의 시점 투영을 공유해 관찰자가 다가갈 때 시차와 가림이 함께 바뀐다.

## 검증

11개 세트의 해금·이전 전적 복원·선택 저장·잠금·재도전 유지·저장 실패를 확인한다. 기본 패에만 문양이 포함되는지, 12개의 60패 물리 장면에서 접촉·충격량·회전·관통 오차·이웃 변화·원형 경계가 유효한지, 배분까지 연결되는지 검사한다. 저장·스테이지·타입 검사 및 프로덕션 빌드를 수행한다. 모바일 실기의 프레임 수치는 별도 확인 대상이다.
