# Turntale 0.5.15

- Current-journey badge uses white text with a black stroke and shadow.
- Repainted the existing floating-island map, keeping its original illustrated style. The central bridge-rest is now a distinct islet (stage 5: 49%,43%); the guardian gateway is at 80%,40%. Removed the waterfall-to-sanctuary shortcut and the lower-right-stairs-to-guardian shortcut. Nine consecutive stage routes use painted-walkway waypoints instead of straight lines between nodes. Stage IDs, unlock rules and saved progression are unchanged.
- Start greetings are comic speech bubbles beside each projected character face, with directional tails, a short pop animation, bounded 16–21px screen-space text and one speaker at a time. Stage opponents use their own character quotes. No bottom speech bar.
- Tile-action source gain is five times the prior baseline, with a clearer midrange knock. UI taps use a smaller boost. A shared compressor contains peaks; existing music/effect volume and mute preferences remain available.
- Four new original 16-bar music arrangements with lead phrases, answering chimes, offbeat chord comping, walking bass and tonal drums. Contrasting reed bridge and layered returning phrase. Menu 116 BPM, game 128, victory 136, reflection 104. Loudness normalized to -18 LUFS with -1.5 dBTP target. Source: scripts/compose-music-0515.py; track metadata: public/audio/music-0515.json.
- Removed the automatic near-end wind/noise/heartbeat layer. The visible endgame cues remain; background music and action audio handle the atmosphere.
