# 0.5.16

- 하이스코어는 전체·개인 각각 부문별 상위 10개만 유지합니다. 일반·친구 전적은 최근 10판, 도전 전적은 최근 10회를 저장합니다. 이전 기록은 최고점 후보부터 옮기고 초과 항목을 정리합니다. 진행 중인 손패·스테이지 저장은 보존합니다.
- 패의 두께와 문양 색은 유지하면서 둥근 비대칭 모서리, 거친 도트 모양의 가장자리 사용 흔적, 낮은 광택과 평면적인 명암을 적용했습니다. 손패·이동·시작 장면이 같은 벡터 원본을 사용합니다.
- 로컬 AI의 전략 계산을 전용 Web Worker로 분리했습니다. 화면이 숨겨지면 계산 워커·활성 요청·시계·AI 타이머·CSS 효과를 멈추고, 복귀 시 비행 효과를 정리하고 현재 판을 다시 표시합니다. 중단된 시작 장면은 인게임 페이드인으로 복구합니다. 실제 Android 시스템의 ‘응답 없음’ 알림은 이 환경에서 재현하지 못했습니다.
- 상대 상태창 아바타를 26px에서 36px(좁은 가로 화면 30px)로 확대하고 세로 중앙에 맞췄습니다.
- 도전 10개 지역의 현재 상대 20명을 전신 일러스트로 제작했습니다. 시작 장면과 아바타가 같은 이미지의 전신/얼굴 부분을 공유합니다. 기존 이름·대사·지역·재료 콘셉트와 저장 ID는 유지했습니다. 도전 지역 재료가 실제 손패 및 시작 장면에도 반영됩니다.
- 시작 말풍선의 색 그림자를 없앴습니다.

## 검증

TypeScript와 운영 빌드 통과. 순위·동점·중복 제거·기록 이전/보관량의 실제 SQLite/API 테스트, 온라인 10판/타임아웃/권한·기록 원자성, 도전 저장/마이그레이션, 시작 카메라/패 연속성, 이어하기, 20개 전신·아바타 좌표, AI 워커 취소·미지원 대체 경로를 검증했습니다. 브라우저에서 도전 시작, 내 패 제출 후 AI 두 턴, 저장 후 이어하기와 손패·점수 유지, 아바타 배치를 확인했습니다. 클라우드 브라우저의 탭 전환은 실제 모바일 앱의 백그라운드 전환을 재현하지 않으므로 별도 기기 검증이 필요합니다.
