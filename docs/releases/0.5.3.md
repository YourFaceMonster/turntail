# 턴테일 0.5.3

## 부드러운 입장

- 렌더 루프에는 60fps 상한이 없다. `requestAnimationFrame`과 브라우저 compositor의 화면 갱신 주기를 그대로 따른다.
- 섞기 물리 경로를 기존 3초 144단계에서 3초 360단계(120Hz)로 높인다. 시간 간격에 맞춰 힘·감쇠·이동을 조정해 재생 속도가 빨라지지 않게 한다.
- 카메라 경로도 초당 120개 변환을 사전 계산하며, CSS compositor와 GPU가 같은 카메라 애니메이션 시계를 읽는다. 실제 매 프레임에서 시간에 따라 보간한다.
- 계산은 입장 전에 작은 작업으로 나누어 수행한다. WebGL 그리기는 기존 두 번의 일괄 그리기를 유지한다. 브라우저 또는 화면이 60Hz만 제공하는 경우 앱 코드로 이를 강제로 120Hz로 바꿀 수는 없다.

## 고정된 방과 테이블

- 입장 장면에서 예전 방 사진·확대 지도와 임시 등주·가장자리 장식을 제거한다. 필요한 패·목재·초상화만 준비하며 배경용 예전 이미지를 불러오지 않는다.
- 한 공간에 원형 상판, 아래 테두리, 네 목재 다리, 발 접점 그림자, 돌 바닥과 후면 벽을 배치한다. 다리는 상판 아래에서 시작해 같은 높이의 바닥에 닿는다.
- 시점 접근의 앞 70%는 같은 눈높이 각도(상판 기준 72°)로 걸어간다. 도착한 뒤 마지막 30%에서 상판을 내려다본다. 테이블·다리·패·방의 투영이 함께 바뀐다.
- 이어하기도 이 원형 테이블을 사용하며 저장패의 위치와 공개 범위는 그대로 유지한다.

## 검증

120Hz 물리 샘플·사각형 접촉·회전·배분 연결, 원형 테이블 안의 네 다리 부착 위치와 발 높이, 상판/바닥 접점의 투영 차이, 카메라 120Hz 경로와 끝점, 저장 복원·컬렉션, 타입 검사와 빌드를 확인한다. 실제 120fps 지속 여부는 120Hz 지원 실기에서 별도로 측정해야 한다.
