# 턴테일 0.5.1

- 지도 거점은 투명한 큰 터치 원과 선명한 30px 숫자 배지를 분리한다. 지도 자체와 거점 좌표는 고정한다.
- 실제 폭포 위치에 흐름을 마스킹하고 물결, 안개, 바람 입자를 더한다. CSS 애니메이션만 사용하며 문서가 숨겨지거나 설명창이 열리면 멈춘다. 모션 감소 설정에서는 끈다.
- 0.5.0의 사다리꼴 입체 패를 기존 100×132 평면 SVG로 되돌린다. 손패·제출·이동에서 동일한 아트를 유지하고 SVG 자원 ID는 인스턴스마다 독립적으로 둔다.
- 패 재질의 결·미세무늬 대비를 높인다. 테이블은 패 아틀라스 확대를 없애고 별도의 목재 원본과 벡터 돌결을 사용한다. 목재 이미지의 실제 크기는 1254×1254이며 업스케일하지 않는다.
- 섞기는 양방향 쓸기와 두 국소 소용돌이로 이웃 패를 바꾼다. 기존 60개 패의 연속 충돌 검증과 GPU 일괄 렌더링을 유지한다. 계산은 입장 전에 짧게 나눠 수행한다.
- 시점 접근은 2.4초, 섞기 3초, 배분 2.1초다. 시점 접근을 끝낸 다음 섞는다. 원근 투영과 방의 느린 시차, 주변을 지나가는 가장자리로 테이블에 다가가는 느낌을 준다.
- 이어하기는 저장된 보드를 커튼 아래에서 먼저 마운트해 좌표를 측정한다. 바닥의 위층/공개된 아래층, 내 손패와 중앙 제출패는 그 위치에 고정하고 카메라만 접근한다. 가려진 아래층과 AI 손패는 사용하지 않는다. 재섞기·재배분은 없다. 이어하기 접근은 3.6초다.

## 목재 이미지

기본 imagegen 도구로 생성한 `public/turntale-walnut-051.webp`를 사용한다. 프롬프트: “seamless flat albedo material scan of fine polished dark warm walnut wood, exactly overhead, sharp fine grain and subtle pores, uniform diffuse light; no objects, edges, perspective, text, hotspot, vignette or blur.” 원본 PNG에서 크기를 바꾸지 않고 WebP로 저장했다.

## 검증

저장패 공개 범위·불변성·회전 좌표, 실제 원근 투영과 GPU/DOM 시점 정합, 섞기 충돌·이웃 변경, 스테이지 UI/저장 및 타입·빌드를 확인한다. 모바일 실기 터치와 프레임 성능 수치는 별도 확인 대상이다.
