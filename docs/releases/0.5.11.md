# 0.5.11

- Speech uses a dark 72% opacity background and only the spoken line. On wide screens, a left speaker's bubble occupies the outer left gutter and a right speaker's bubble the outer right gutter. Compact screens keep each bubble below its own panel, within its horizontal bounds. All bubbles ignore input and disappear after a short display.
- Replaced the old bust/two-arm silhouette with lightweight solid seated figures: a neck, clothed torso and collar, upper arms, sleeves, forearms, palms/finger detail, bent thighs and shins, and a backed chair. Existing portrait textures and individual clothing palettes identify the characters. Models are static 3D CSS volumes, not animated skeletal meshes, and use no additional 3D engine.
- The seated camera starts closer (minimum scale .56 instead of .46) at 64 degrees rather than 58. The established shuffle → arrange → zoom → overhead order and exact final framing remain.
- Opponent backs now fade smoothly over 66% of the overhead lift (approximately 858 ms), separate from the much shorter body-to-controls flattening. The compositor and GPU use the same fade interval. Tabletop landings and concealed faces remain unchanged.
- Reduced the CSS fallback's shuffle keyframe list from 313 to 157 per tile while preserving its first and last poses. The full simulation and GPU playback retain the original samples. Tabletop surfaces now paint above the support attachment points.

Validation: TypeScript and production build; outward/bounded speech geometry, monotonic opponent opacity, camera continuity and closer framing, reduced fallback endpoints, solid-model structure, opening table bounds/supports, conversation privacy and stage/intro continuity. Static browser previews checked character proportions and their table placement. Browser game checks use the CSS fallback; physical-phone GPU frame rate is not measured, so stutter is not claimed fully eliminated.
