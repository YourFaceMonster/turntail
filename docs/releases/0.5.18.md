# 0.5.18

- 캐릭터 대사·시작 말풍선·지역 대사에 한국어 어절 단위 줄바꿈을 적용했습니다. `다음`이 `다/음`으로 갈라지지 않습니다. 인게임 대사는 기존 두 줄 공간을 유지합니다.
- 도전의 10지역 × 4문양에 서로 다른 숫자 메달·외곽 조각·상징을 넣었습니다. 손패·바닥·이동·시작 렌더러는 동일한 벡터 원본을 사용합니다. 숫자·패 색·강약·룰은 유지했습니다.
- 10개 지역 테이블에 새 손그림 재질을 적용하고 상판과 옆면이 같은 재질을 사용하게 했습니다. 돌·바위는 불규칙한 가장자리와 두꺼운 몸체, 나무는 나이테·뿌리, 제단은 단차를 표현합니다. 기본 테이블의 네 다리는 유지합니다.
- 도전 캐릭터를 테이블 가장자리와 높이에 맞춰 배치하고, 하체가 상판을 뚫거나 무릎이 드러나지 않게 가렸습니다. 기존 전신과 얼굴 이미지·이름·대사는 유지합니다.
- 지도에 새 무리 3개, 흔들리는 실제 다리 영역 4곳, 불꽃·등불 18곳, 반딧불 24개와 강화한 폭포·물결을 넣었습니다. 스테이지 버튼과 길의 위치는 고정이고, 숨김/다른 모달/동작 줄이기 설정에서 효과를 멈춥니다.
- 새 도전을 시작할 때 지도나 기존 판을 유지한 상태로 중앙에서 어둡게 덮고, 완전히 덮은 뒤 게임을 교체합니다. 전환 초기·준비 단계에는 새 테이블 받침을 렌더링하지 않으며, 지역 캐릭터·재질도 먼저 디코딩합니다.
- 지도에 **10개 테이블 둘러보기**를 추가했습니다. 미개방 지역도 캐릭터·재질·패를 앉은 시점/탑뷰로 확인할 수 있습니다. 경기 생성·점수·진행·저장을 사용하지 않는 시각 미리보기입니다.
- 깔린 패 슬라이딩 조작을 제거했습니다. 바닥 더블탭/선택 후 가져오기 버튼과 손패 위로 밀어 내기는 유지합니다.

## 검증

40종 문양·숫자 장식의 구별, 10개 상판/몸체 재질과 그림 좌표, 입체 면의 연결·투영, 뿌리/제단 형상, 도전 자리 높이, 지도 효과 구성, 바닥 슬라이드 제거와 손패/더블탭 유지 테스트 통과. 관련 도전·저장·입장·패 연속성 회귀 테스트 및 TypeScript 검증을 수행했습니다.

브라우저에서 1~10지역 전환과 앉은 시점/탑뷰를 확인했습니다. 독립 시작 전환 화면에서 `menu-out`의 새 받침 수가 0이고 이전 화면이 남아 있는 것, `prepare`에서 받침 수 0·완전 불투명 덮개를 확인했습니다. 좁은 말풍선의 `다음` 렌더링이 하나의 사각형으로 줄바꿈되는 것을 확인했습니다. 실제 휴대폰 성능과 운영체제 전환은 이 환경에서 재현하지 않았습니다.
