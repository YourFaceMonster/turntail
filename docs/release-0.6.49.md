# 0.6.49 · 메뉴 패 장식 정리와 생성형 배경

사용자의 6개 요청과 이번 빌드·기존 사이트 업로드 요청을 반영한다.

| 요청 | 반영 |
|---|---|
| 메인 버튼의 패 제거 | 싱글플레이·이어서 하기·멀티플레이 버튼에서 패 렌더러를 제거하고 텍스트·화살표를 중앙에 맞춤 |
| 일반모드 미리보기 패 | 미리보기 전용39×53px 패 두 장에 균일한 라운드 모서리·매끈한 그라데이션·부드러운 테두리 적용. 기존 SVG 문양을 사용하며 게임 내 패 렌더링과 별개 |
| 싱글플레이 배경 | 내장 image_gen으로 만든 달빛 여관·호두나무 프레임·해/별/달/구름 장식 배경 |
| 일반모드 배경 | 일반모드 설정창에 촛불·광택 목재·녹색 펠트 배경 |
| 아이템전 배경 | 직업 선택 로비에 길드 회랑·청록 보석·보랏빛 테두리 배경 |
| 하단 문구 제거 | ‘각 모드는 독립적으로 자동 저장되며 진행 기록을 섞지 않아요.’ 삭제 |

선택창의 제목·버튼·입력 필드·직업 카드는 실제 HTML로 유지한다. 생성 이미지에 UI 글자나 버튼을 넣지 않았다. 직업 cartoon-v4·기존 저장·게임 규칙은 이어간다. 메뉴 안 아이템전 소개는 ‘포인트 상점 · 직업 스킬’로 줄여 한 글자만 다음 줄로 떨어지던 현상을 함께 정리했다.

## 이미지 및 이번 검증

3개 최종 WebP는 `public/ui/single-menu-0649.webp`, `classic-setup-0649.webp`, `item-lobby-0649.webp`다. 1024×1536 원본을 보존하고 형식만 변환했다. 전체 약481KiB. 원본과 최초 싱글 배경 후보도 워크스페이스 `artifacts/menu-scenes-0649-originals/`에 보관한다. [전체 프롬프트·원본/최종 경로](assets/menu-scenes-0649.json).

390×844와360×740 로컬 브라우저에서 메인 패 장식0개, 싱글 선택창의 하단 안내 없음, 미리보기 패 두 장의 동일한39×53px 규격, 세 배경 적용, 일반모드 입력창·아이템전 직업 이미지 로드를 확인했다. 가로 넘침 없음. 대전을 새로 시작하거나 저장을 삭제하지 않았다. 휴대폰 실기기 검증은 아니다. 새 CSS 구문 파싱도 통과했다. UI 변경으로 기능·AI 모의 대전을 새로 실행하지 않는다.

최종 타입 검사·운영 빌드는 이번 게시 과정에서 새로 실행한다. 소스 커밋·Sites 저장본·운영 확인 범위는 워크스페이스 `artifacts/deployment-0.6.49.json`에 기록한다.

사용자가 추가로 정한 향후 작업 원칙: **별도 빌드·사이트 업로드 요청이 없으면 수정 후 로컬 저장만 한다.** 루트 AGENTS.md에 같은 지시를 보존했다. 이번 요청에는 빌드·업로드가 명시되어 있다.
