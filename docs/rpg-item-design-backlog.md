# 아이템전 확장 후보

현재 구현 목록과 앞으로 검토할 후보를 구분한다. 최신 로컬 구현은 아래 항목을 기준으로 하고, 이후의 기획 내용은 검토 이력으로 보관한다.

## 최신 로컬 구현 — 2026-10-26

최신 방어 규칙: 수호의 봉인은 비공개 준비 후 첫 공격·교환 아이템 1회를 방어한다. 개별 손패 잠금은 폐기했다. 첫 바퀴 전에는 아이템을 사용할 수 없다. 자세한 현재 규칙은 [HP 아이템전 문서](hp-item-mode.md)를 따른다.

최신 사용 제한은 자기 차례 1개·카드 한 판당 3개다. 사람과 AI에게 같은 제한을 적용하며, 아래 예전 2개 제한 기록보다 우선한다.

최신 변경: [싱글플레이 정식 아이템전](hp-item-mode.md)으로 진입 경로와 저장·결과를 분리했다. 새 모드는 5라운드 제한 없이 HP 0에서 종료하며 작열탄으로도 즉시 끝날 수 있다. 아래의 5판 테스트 관련 내용은 이전 구현 기록이고, 신규 공식 진입에는 적용하지 않는다.

사용자 구현 요청에 따라 기본 5종을 연결했다. 이번 수치는 로컬 플레이용 시험값이다.

| 기본 아이템 | 구현 효과 |
| --- | --- |
| 정찰 렌즈 | 원하는 2층 패 1장 확인. 외곽 제한 없음. |
| 뒤바뀐 운명 | 내 패 1장 선택 ↔ 상대 무작위 1장. 양쪽 손패 3장 이상. 상대가 봉인한 패는 추첨에서 제외. |
| 수호의 봉인 | 내 패 1장을 현재 카드 판의 상대 교환으로부터 보호. 제출은 가능하고 제출·새 카드 판 시작 때 해제. |
| 작열탄 | 선택한 상대에게 즉시 HP 8 피해, 상대 HP 최소 1. 사용 후 정상적으로 패 내기·가져오기·패스 가능. |
| 응급 약초 | 자신의 HP 10 즉시 회복, 최대 100. HP가 가득 차면 사용 불가. |

- 운명의 저울(2장 교환)은 추가 아이템으로 기존 효과를 유지한다. 양쪽 손패 5장 이상 조건과 봉인 제외를 적용한다.
- 직접 HP 공격에도 기존 금이 간 심장·붕대 보호를 적용한다. 아이템 피해는 카드 점수나 승리 포인트를 생성하지 않는다.
- AI도 같은 전술 효과와 자기 차례 1개·카드 판당 2개 제한을 사용한다. 자기 손패·공개 HP·공개 아이템 목록·보호 개수만으로 판단하며 상대 숨은 패·다른 사람의 렌즈 정보·보호된 패의 정체는 읽지 않는다. 기존 쌍둥이 보스의 별도 공유 규칙은 유지한다.
- 새 테스트는 플레이어와 AI 각각 기본 5종 × 2개, 총 10개 지급한다. 랜덤 유물 3개와 카드 대전 5판 제한은 유지한다. 2장 교환은 이 기본 지급에서 제외한다.
- 일반 RPG의 새 상대에게는 기본 5종 각 1개를 지급한다. 같은 스테이지의 카드 판마다 자동 보충하지 않으며, 다음 스테이지의 새 상대에게 새 구성을 지급한다. 과거 저장의 상대 구성이 없을 때는 해당 AI의 차례에만 초기화하고 사람의 아이템을 바꾸지 않는다.
- 왼쪽 인게임 아이템 칸을 제거하고 중앙 배낭에서 수량·설명·사용 가능 여부를 보여준다. 보호 패는 손패 자물쇠로 표시하고, 사용 결과는 짧은 알림으로 보여준다.
- 기존 테스트 이어하기에는 물품을 소급 지급하지 않는다. 10개 구성을 사용하려면 새 테스트를 시작한다. 새 상태는 선택적 필드로 저장해 기존 저장을 유지한다.
- 상대에게 약초 사용과 방호 부적은 계속 보류한다. 스토리와 유물 컨셉은 유지한다.
- 로컬에만 반영하며 빌드·배포하지 않는다. 타입 검사와 관련 규칙 테스트만 수행한다.

### 최신 UI·사용 방식 보정

- 메인 플레이 버튼은 궁서 느낌의 명조에서 둥근 표시용 Jua 글꼴로 변경한다.
- 배낭은 하나의 목록에서 사용 가능한 아이템 뒤에 사용 불가 아이템을 정렬한다. 사용 불가 항목은 회색으로 표시하며, 별도 사용 가능·사용 불가 제목과 구역 나눔을 없앤다.
- 작열탄은 패 제출 연계를 폐기하고 즉시 피해로 변경했다. 피격은 대상 HP창의 타격 표시·흔들림과 기존 설정을 따르는 진동으로 표현한다. 이전 저장에 남은 미발동 준비 상태는 불러올 때 아이템과 사용 횟수를 반환한다.
- 패 교환은 손패 더블클릭·더블탭으로 지정하면 자동 진행한다. 별도 확인·취소 버튼 팝업을 제거하고, 패 선택 중에는 바깥 터치·Esc로 닫을 수 있다. 2장 교환은 서로 다른 패를 각각 더블클릭한다.
- 회색 효과는 손패 영역 전체가 아니라 실제 패 한 장씩만 제외한다. 상대 패는 중앙 위쪽 자리에서 먼저 뒤집혀 공개된 후 서로 자리를 바꾸고 각 소유자에게 이동한다. 이동 패는 손패와 같은 정면 그림을 사용하고 두꺼운 측면·3D 회전 표현을 제거한다.
- 상대 남은 패 수는 흰 패 배경을 없애고 HP창 안으로 넣는다. 왼쪽 캐릭터의 오른쪽 끝, 오른쪽 캐릭터의 왼쪽 끝에 배치한다.
- 신규 3종 이미지는 기존 교환·렌즈 그림을 참고해 built-in ImageGen으로 다시 만들었다. [이미지 파일과 실제 생성 프롬프트](rpg-item-image-prompts-v2.md)를 보관한다.

## 현재 검토 방향 — 아이템전의 재미 우선

초기 논의의 사용자 의견: 스토리와 유물은 현재 컨셉을 유지하고, 카드 승부 중 사용할 아이템의 선택과 재미에 집중한다. 아래는 최초 기획 당시의 검토 기록이며 실제 적용 여부는 위 최신 로컬 구현을 따른다.

아래 수치·지속 시간·지급 방식은 비교를 위한 **미확정 시험안**이다. 가격과 드롭 확률도 아직 정하지 않는다.

### 현재 코드에서 확인한 차이

- 실제 전투 중 사용 가능한 아이템은 교환 2종과 정찰 렌즈뿐이다.
- 붉은 약병(HP 20), 달빛 수프, 수호의 붕대(다음 스테이지 피해 15 방어)는 준비 구간에서 사용한다. 아래 전투용 후보로 기존 효과를 자동 교체하지 않는다.
- RPG HP는 스테이지 종료와 순위에 쓰인다. 직접 피해는 카드 숫자·족보·승패 점수를 바꾸지 않아도 스테이지의 결과에는 영향을 준다.
- 현재 전술 아이템은 플레이어만 사용한다. 방어·패 잠금을 시험하려면 적의 제한된 아이템 사용도 함께 필요하다.

### 최신 대화 정리: 적은 종류와 사용 연계

- 기본 후보는 정찰 렌즈·뒤바뀐 운명·수호의 봉인·작열탄·응급 약초 5종으로 좁힌다. 종류를 늘리기보다 각 역할과 카드 플레이 사이의 연계를 우선한다.
- 방호 부적은 응급 약초와 HP 보존 역할이 겹치므로 기본 후보에서 제외하고 보류한다. 패 방어는 수호의 봉인으로 구분한다.
- 2026-10-26 최신 사용자 결정: 기본 소비 아이템은 위 5종으로 하고, 2장 교환인 운명의 저울은 추가 아이템 1종으로 둔다(총 5+1종). 희귀도·지급 빈도는 미정이다. 현재 게임의 지급 구성은 변경하지 않는다.
- 작열탄을 패 제출에 연계해 발동시키는 안을 검토한다. 구체 피해량, 효과 예약·소모 시점, 제출하지 못했을 때 처리는 아직 미정이다.
- 연계 예시는 렌즈로 필요한 바닥패 확인·가져오기 후 불필요한 패 교환, 교환으로 얻은 핵심 패를 이후 차례에 봉인하는 방식이다. 같은 차례 연속 사용을 허용한다는 뜻은 아니며 기존 사용 횟수 제한 안에서 검토한다.

#### 예외 아이디어 보관: 상대에게 약초 사용

2026-10-26 사용자 요청으로 저장한다. 응급 약초의 기본 대상은 자신이다. **상대 회복은 예외 후보로만 보관하며 기본 기능이나 다음 시험의 필수 기능으로 넣지 않는다.**

가능한 사용 맥락은 특정 상대의 HP가 0이 되어 스테이지가 끝나는 것을 늦추고 카드 승부를 이어가는 경우다. 실제로 그 선택이 이득인 상황이 충분히 있는지는 확인되지 않았다. 그런 상황이 플레이에서 확인될 때 회복 대상 확장과 악용 가능성, 적의 사용 판단을 함께 재검토한다. 상대 지정 조건·수치·비용은 미정이며 구현하지 않는다.

### 먼저 비교할 구성: 기본 5종 + 2장 교환 추가 1종

| 우선순위 | 구분 | 아이템 | 미확정 시험 효과 | 기대하는 선택 |
| --- | --- | --- | --- | --- |
| 유지 | 패 공격 | 뒤바뀐 운명 | 기존 내 패 1장 선택 ↔ 상대 무작위 1장 교환 | 조합을 깨거나 불필요한 패를 보낼지 |
| 유지 | 정보 보조 | 정찰 렌즈 | 기존 2층 패 1장 투시 | 바닥에서 가져올 패를 미리 확인할지 |
| 추가 후보 | HP 공격 | 작열탄 | 선택한 상대 HP 8 피해 | 위협적인 상대를 누를지, 스테이지 종료를 앞당길지 |
| 추가 후보 | 회복 | 응급 약초 | 내 HP 10 즉시 회복, 최대 100 | 교환·공격 기회를 쓰면서 생존을 택할지 |
| 추가 후보 | 패 방어 | 수호의 봉인 | 내 패 1장을 현재 카드 판 동안 교환 추첨 대상에서 제외 | 강한 2를 지킬지, 완성된 조합의 핵심 패를 지킬지 |
| 추가 1종 | 패 공격 | 운명의 저울 | 기존 2장 교환 | 기본 5종 외 추가 아이템으로 유지, 희귀도·지급 빈도는 미정 |
| 후속 비교 | 흡수 | 흡혈 가시 | 상대에게 실제 준 HP 피해만큼 내 HP 회복, 피해량 4 후보 | 공격과 회복을 묶은 효과가 두 역할을 대체하는지 확인 |

응급 약초는 전투용 신규 후보이며, 준비용 붉은 약병 HP 20 효과를 축소한다는 뜻이 아니다. 이름과 아이콘은 효과가 정리된 뒤 정한다. 작열탄의 즉시 피해 수치는 초기 비교안이며, 최신 패 제출 연계안의 발동 방식은 위 정리를 따른다.

### 카드 판을 끊지 않는 HP 처리 초안

- 자기 차례 본 행동 전에 사용하며, 사용 후에도 정상적으로 패 내기·가져오기·패스를 진행한다.
- 기존 전술 제한인 자기 차례 1개, 카드 판당 2개에 공격·회복·방어를 함께 포함하는 안부터 비교한다. 회복만 별도 무제한으로 두지 않는다.
- 첫 시험에서는 직접 공격으로 HP를 1 미만으로 내리지 않는 안을 우선 검토한다. 카드 판은 끝까지 진행하고, 기존 카드 판 정산에서 스테이지 종료와 순위를 판정한다. 이후 마무리 공격이 필요한지는 별도로 비교한다.
- 대상 HP가 이미 1이거나 내 HP가 가득 차는 등 실제 효과가 없는 사용은 막고 아이템도 소모하지 않는다. 방어로 막힌 유효 공격은 사용으로 처리한다.
- 직접 공격은 카드 대전 점수·카드 승자·승리 포인트를 생성하지 않는다. 회복도 포인트 배분이나 기존 유물 발동을 임의로 발생시키지 않는다.
- HP 방어를 다시 검토할 경우 직접 피해·카드 판 정산 피해 적용 여부와 기존 유물 피해 감소·붕대의 중첩 순서를 먼저 정한다. 현재 기본 후보는 패 보호만 포함한다.
- 흡수 후보를 시험한다면 표기 피해가 아니라 방어와 HP 1 제한을 거친 실제 감소량으로 회복한다.
- HP 변화는 대상 상태창에서 짧은 피격·회복 표시와 실제 변동 수치로 보여주는 방향이다. 큰 팝업이나 추가 확인으로 매번 플레이를 끊지 않는다.

### 패 잠금과 적 아이템 사용 초안

- 봉인된 패는 정상 제출할 수 있다. 상대의 교환 추첨에서만 제외하며, 제출하거나 현재 카드 판이 끝나면 봉인이 사라진다.
- 상대에게는 보호된 패의 개수만 보여주고 숫자·문양은 공개하지 않는다. 플레이어는 자기 보호 패에 자물쇠 표시를 본다.
- 양쪽 손패 최소 조건(1장 교환 3장 이상, 2장 교환 5장 이상)에 더해, 상대의 교환 가능한 패 수가 필요한 교환 장수 이상인지 확인한다. 부족하면 대상 선택을 막고 아이템은 소모하지 않는 안이다.
- 방어의 효용을 확인하기 위해 적도 공격·교환 아이템을 제한적으로 쓰는 시험이 필요하다. 적마다 소량의 보유량을 두고 공격 가능 상태를 간단히 예고하는 안을 검토한다. 구체 횟수는 미정이다.
- 적은 자기 손패와 공개 정보만으로 아이템을 고른다. 숨은 상대 패와 봉인된 숫자를 읽지 않으며, 별도 반응 팝업을 요구하는 실시간 방어 방식은 첫 시험에서 제외한다.

### 우선 보류하거나 덜어낼 것

- 방호 부적: 다음 HP 피해 최대 8 흡수 초안은 회복과의 역할 중복으로 보류한다. 기존 준비용 수호의 붕대를 삭제하거나 변경하지 않는다.
- 연속 피해·기절·차례 강탈·강제 패스·족보 무시: 카드 승부의 흐름과 규칙 부담을 크게 바꾸므로 보류한다.
- 광역 HP 공격·큰 고정 피해·전투 중 대량 회복: 타깃 선택과 카드 판 결과의 비중을 먼저 확인한 뒤 검토한다.
- 반사·방어 해제·정보 방어: 기본 공격과 방어의 효용을 확인한 다음 추가한다. 대응 아이템부터 과도하게 늘리지 않는다.
- 선택 교환권: 기존 직접 선택 교환과 역할이 겹치므로 별도 아이템 추가를 보류한다.
- 조합 나침반: 기존 자동 선택·족보 후보 표시와 차별점이 생기기 전에는 보류한다.
- 운명의 저울은 삭제하지 않는다. 현재 테스트 모드 지급도 그대로 두고, 다음 시험 구성에서 희귀화·교대 지급 여부를 비교한다.

### 5판 테스트를 바꾼다면 확인할 것

현재 테스트 코드는 변경하지 않는다. 다음 시험 구성 후보는 정찰 렌즈를 시작할 때 항상 포함하고, 나머지 2칸에 공격·회복·방어·교환을 번갈아 지급하는 방식이다. 카드 판 사이에는 사용한 만큼 빈 칸만 보충하는 시험을 검토하되, 남은 아이템이나 유물은 자동으로 버리지 않는다. 렌즈를 매 판 다시 지급할지는 별도 결정이다.

비교 시 유물과 상대 조건을 가능한 한 고정하고 다음을 본다.

- 카드를 어떻게 낼지뿐 아니라 아이템을 지금 쓸지 고민되는가?
- 직접 공격의 타깃과 사용 시점이 스테이지 결과에 의미 있게 작용하는가?
- 회복·방어가 실제 선택되는가? 적이 아이템을 쓰지 않아 방어가 무의미하지 않은가?
- 카드 판의 승패가 여전히 중요하게 느껴지는가?
- 3칸 때문에 아이템을 아끼거나 남길 선택이 생기는가? 같은 역할의 아이템만 쌓이지 않는가?
- 재미없는 후보는 빼고, 자주 쓰지 않아도 결정적인 순간에 가치가 있는 후보는 구분해 평가한다.

## 방어 후보: 강한 패를 지키는 선택

| 후보 이름 | 역할 | 검토할 효과 |
| --- | --- | --- |
| 수호의 봉인 | 패 보호 | 내 손패에서 지킬 패를 선택해 교환 대상에서 잠근다. 2 등 높은 서열의 패를 보존할 수 있다. |
| 철벽 주머니 | 교환 방어 | 다음 교환 공격 1회를 막고 소모된다. |
| 반사 부적 | 대응 | 교환 공격을 받았을 때 취소하거나 되돌리는 대응 아이템 후보. |
| 비밀 망토 | 정보 방어 | 손패를 조사하는 공격을 제한한다. 바닥패 투시는 별도 규칙으로 구분한다. |

영구적으로 모든 강한 패를 잠그는 방식은 피한다. 보호 장수·지속 시간·사용 비용을 제한하고 상대에게 보호 상태의 존재를 알려 대응 여지를 남긴다.

아직 정할 내용:

- 보호 장수와 지속 시간: 다음 공격 1회 / 내 다음 차례 / 현재 카드 판 중 선택.
- 교환 대상에서 보호 패를 제외하고 재추첨할지, 보호 패에 맞으면 교환 전체를 막을지.
- 교환 가능한 패가 부족할 때 사용 차단·공격 실패·아이템 반환 중 어떤 규칙을 적용할지.
- 대응 아이템의 사용 시점과 현재 시험 제한(내 차례 1개, 한 판 2개)에 포함할지.
- 상대에게는 보호 개수만 공개하고 보호된 숫자·문양은 숨길지. 일반 AI는 숨은 패를 읽지 않는다.

## 추가 공격·보조 후보

| 구분 | 후보 | 목적 |
| --- | --- | --- |
| 공격 | 봉인 해제 도구 | 방어 효과를 한 번 제거하는 대응 수단. |
| 공격 | 손패 정찰 | 제한된 상대 패를 잠깐 확인. 보호 아이템과 함께 설계한다. |
| 보조 | 선택 교환권 | 교환 후보·대상을 조절해 무작위성에 대응. |
| 보조 | 조합 나침반 | 현재 손패의 조합 정보를 제공하되 자동 승리나 숨은 패 열람은 하지 않는다. |

목표는 공격 → 보호 → 보호 해제·보조의 선택이 생기도록 만드는 것이다. 새 효과는 테스트 전용 후보로 먼저 검증하고, 기존 일반전·저장 데이터에 자동 적용하지 않는다.
