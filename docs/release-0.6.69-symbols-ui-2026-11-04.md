# v0.6.69 · 네 문양·프롤로그·맵/주점 UI 후속 게시

2026-11-04 사용자가 커밋·업데이트를 요청했다. GitHub main과 Cloudflare Worker만 사용한다. 버전은0.6.69 유지.

## 게시 범위

- 왕관/비밀의 열쇠/성화/철문 문양과 패·장식·규칙/튜토리얼·관련 안내 통일. 내부 패ID·숫자·서열·저장키·업적ID·효과는 유지.
- 프롤로그 전달자 정면 시선 및 빨간2 왕관 그림. 낯선 표식 대사는 겹친 두 왕관 뒷면과 연결. 초반 스포일러와 새로운 후반 사건은 추가하지 않음.
- 검은 소나무 파수탑에 맞춘 지도, 주점/잡화점 건물 그림과 투명 아이콘. 원본은 보존.
- 지도/주점 공통 오버레이 HUD: 로고·중앙 장소·저장/설정·HP 아바타·MAP/가방/장착 유물.
- 주점/퀘스트 고정 크기 대화창·왼쪽 정렬·다음 페이지·마지막 선택지의 옅은 배경.
- 잡화점54px 상품 행, 설명 두 줄, 이름 가운데 정렬, 전체 설명 팝업. 가방 내용과 게임 규칙은 유지.

## 이번 게시 전 검증

이번 턴에15개 검사 파일의32개 검사 통과. 타입 검사 및 운영 빌드5단계 통과. Git 원격과 커밋 차이0/0, diff 공백 검사 통과, 임시 검토 경로 없음. 빌드에는 큰 클라이언트 청크와 라우트 정적 분류 안내가 남아 있지만 정상 완료했다.

앞선 로컬 수정 턴에는 세로390×844/가로844×390 HUD·대화·상점, 대화창290px 유지, 마지막 선택지, 전체 설명 팝업을 확인했다. 이번 공개 배포 확인과 구분한다.

기존 별도 폭탄/전술 검사 실패19개는 변경 전 HEAD에서도 동일 재현했으며, 이번32개 검사 통과로 전체 검사가 통과했다고 표현하지 않는다. [관련 기록](four-symbols-implementation-2026-11-04.md), [UI 기록](journey-ui-followup-2026-11-04.md).

## 게시 결과

소스 커밋·Worker 버전·공개 파일 확인은 실제 배포 후 추가한다. 이후 별도 배포 요청이 없는 수정은 다시 로컬 저장만 한다.


초기 소스0d1a555 / Worker37bc1e3d-aa67-41c7-b96c-f5a3ccbb9a39 배포 후 공개 파일17개 일치를 확인했다. 공개 메인 화면 검토에서 배경 원화의 장식 패에 옛 문양이 남은 것을 발견해 가로/세로 배경 그림2장을 새 문양으로 추가 보정했다. 원본을 보존하고 새 PNG와 CSS 참조를 후속 커밋/빌드/배포한다. 창밖 실제 달·별과 배경 구도는 유지한다.
