# 0.6.32 · 첨부한 메뉴 BGM

새 첨부 MP3를 원본 그대로 `public/audio/menu-suno-0632.mp3`에 저장하고, 메인 메뉴 및 메뉴 안의 선택창에서 반복 재생하도록 연결했다. 플레이 중에는 앞서 첨부한 `table-suno-0631.mp3`를 사용한다. 기존 음악 켜기/끄기, 볼륨, 사용자 입력 후 재생, 화면이 숨겨질 때 일시정지를 유지한다.

첨부 원본과 복사본의 SHA-256이 동일함을 확인했다. 타입 검사와 운영 빌드는 배포 준비 과정에서 수행한다. 배포 결과는 체크아웃 바깥 `artifacts/deployment-0.6.32.json`에 기록한다.
