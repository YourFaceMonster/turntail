# 0.6.59 · 프롤로그 전체 장면·세로 대응

2026-11-01 사용자 사이트 업로드 요청에 따른 게시 소스다. 게시 완료 여부와 저장본·커밋·배포 ID는 루트 `artifacts/deployment-0.6.59.json`의 실제 결과를 확인한다.

## 포함 내용

- 승인된 손그림 2D 카툰 판타지 프롤로그 68초/10컷. 설원 이동·주점 접근·실내·승부·패 앞/뒷면·새벽길·석비 문양 대조·달의 영역 진입 장면.
- 전용 세로 구도 9장과 가로 구도 자동 선택, 현재 방향 이미지 준비 후 재생, 재생 중 화면 방향 변경 대응, 안전 영역 자막과 건너뛰기.
- `/prologue-preview`에서 저장에 영향 없이 전체 재생과 반복. 본편과 RPG 화면 테스트도 같은 장면을 사용한다.
- 주점 실내 그림과 세로 전용 배경. 승인 이전 그림과 생성 기록은 보관한다.
- 앞선 로컬 RPG 변경: 상단 STAGE 표기, 상단 상태 표시 정리, 장착 유물 3칸, 전투 코인 증감과 부족 금액의 HP 차감.
- 게시 준비 중 발견한 정산 타입 오류 수정: 결과 플레이어의 선택적 `total` 필드를 타입에 반영했다. 한 판 통과 테스트에서는 이미 정산된 판의 손실을 클리어 처리 때 다시 차감하지 않는다. 회귀 검사는 실제 판 정산과 클리어 보상 1회 적용을 각각 확인하도록 갱신했다.

## 이번 검증과 제한

- 최종 타입 검사 통과.
- 프롤로그, 화면 테스트, RPG 진행/여정/화면 관련 검사 14개 통과, 실패 0. 전체 검사 실행을 의미하지 않는다.
- 로컬 세로 390×844 및 가로 844×390에서 실제 그림 선택·자막·재생을 확인했다. 화면과 프롬프트는 이전 로컬 작업 기록에 연결되어 있다.
- 새 운영 빌드와 배포 결과는 루트 배포 JSON에 별도로 기록한다. 과거 성공 기록을 이번 빌드나 현재 공개 화면 검증으로 간주하지 않는다.
- 운영 새 게임·저장 초기화는 하지 않는다. 실제 모바일 기기와 청감 검증은 미실시다.

사용자의 이번 업로드 요청에 한해 빌드·소스 저장·게시를 진행한다. 이후 별도 빌드·업로드 요청이 없는 변경은 로컬 저장만 한다.
