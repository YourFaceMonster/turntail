# 유물 설명·발동 표시 정리 (로컬, 2026-11-11)

사용자 승인: A안(설명·발동 피드백) + C1(깃펜·나침반·거울은 갖고만 있어도 적용). 수치 조정(B안)은 미승인이라 손대지 않음. 빌드·배포 없음.

## 바뀐 점
- 유물 12종 설명을 "언제 → 무엇" 한 줄(effect)과 풀이(detail)로 정리. 정찰·선견지명은 풀이에서 설명. (`lib/rpg-rework.ts`)
- 장착 유물을 누르면 풀이 줄 표시. 장착 칸 짧은 문구 `정찰 +1`→`바닥 +1장` 등.
- 발동 알림(칸 반짝임 + 카드): 장갑·모래시계·푸른 유리(바닥 패 확인), 심장(챕터 첫 장착), 반지·매듭·등불(실제 회복된 때만), 거울(보상 후보 +1), 깃펜(소문 추가). 상아 주사위는 기존 그대로.
- 정산 화면 내 HP 칸에 `유물 · 두 번째 반지 HP +3 · 회복의 등불 HP +5` 줄 추가(`rework.relicHeals`).
- 보상 화면: "이번 챕터(ST1~3)가 끝날 때까지 유지" / 보스 "1개만 다음 챕터로" 안내, 거울 효과 표시, 소지형 유물 배지.
- 나침반: 가방 + 정산(준비) 화면에 다음 보상 후보 표시(보스 스테이지 뒤에는 챕터가 바뀌므로 숨김).
- 바닥 정찰 문구: `바닥 패 N장 확인`, AI가 정찰하면 이름을 앞에 붙임, 보너스는 `유물 +N`.
- 소지형 3종: 보상으로 받아도 자동 장착 안 함, 장착 불가(가방에 "갖고만 있어도 적용"), 예전 저장에서 장착돼 있던 것은 칸에서 자동으로 빠짐.
- 트레이가 마운트되기 2.5초 이내에 기록된 발동도 알림을 띄움(스테이지 시작 직후 심장 등).

  - 실측(대사 252개, 실제 CSS·Noto Sans KR): 360px 수정 전 1~3글자 줄 11개 / 6글자 이하 63개 → 수정 후 0 / 0. 375px도 0 / 0. 단어 중간 끊김·2줄 칸 넘침 0 유지.
- 지도 "이야기 다시 보기" 퀘스트 장면이 새 RPG 규칙을 따름(`QuestReplay` `rework` 전달): 모르 "주화 30" → "HP 5 회복", 여행자 약초 → HP 나눔 치료 대사, 파수탑 "약초 10→15" → "바닥 패 1장을 몰래". 예전(레거시) 저장은 원래 문구 유지. 테스트 `tests/quest-replay-rework.test.tsx`.
