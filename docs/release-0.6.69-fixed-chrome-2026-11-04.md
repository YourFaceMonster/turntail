# v0.6.69 고정 탐험 UI 후속 수정

사용자 승인한8가지 수정과 빌드·GitHub·Cloudflare 배포.

소문 수첩을 지도/주점/퀘스트 공통 하단 슬롯으로 통합하고 어디서든 열 수 있게 했다. 장소별 잔여 inset/여백 차이를 제거하고 상단/하단 크기·좌표를 통일했다. 컷씬은 UI 뒤까지 전체 화면으로 표시하고 대화창만 하단 UI 위로 제한했다. HP창 안에 이름/직업을 넣고 아바타 정보 동작을 유지했다. 벽난로 표지를 대화창보다 위로 이동했다. 잡화점 HP +10 등 핵심 수치를 굵게/회복은 초록색으로 강조했다. 지도 원형 버튼을 투명한 검은 음영으로 바꿨다. 장소 이동은 그림을 준비하면서190ms 페이드아웃 후220ms 페이드인, 같은 장소 대화 페이지 전환은 기존 그림 유지. 공통 UI는 페이드 위에 표시한다.

이번 검증: 관련7개 테스트 파일14개 검사 통과, TypeScript 검사 통과, 운영 빌드 통과. 로컬 세로390×760에서 지도/주점/여행자 HUD 좌표(상단0,0 / 하단0,704)가 동일하고, 퀘스트 전체 화면390×760·대화 하단684로 하단 UI와 분리됨을 확인. 퀘스트에서 수첩 열기/닫기, HP창 안 이름/직업, 잡화점 HP +10 초록색/두께800 확인. 기존 저장 없는 RPG 미리보기 사용. 과거40개/별도 모드19개 실패 기록과 이번 검증은 구분한다. 전체 전투·퀘스트 연속 진행 및 실제 사용자 단말은 미검증.

배포 결과는 완료 후 기록. 버전0.6.69 유지. 이후 별도 배포 요청 없는 수정은 로컬 저장만 한다.
