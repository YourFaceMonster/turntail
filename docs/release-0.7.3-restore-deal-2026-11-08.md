# 0.7.3 · RPG 손패·바닥패 수 원래 규칙 복원

사용자 요청: 0.7.2에서 바뀐 손패·바닥패 수가 바뀌면 안 된다. 원래 규칙으로 되돌려 배포한다.

## 변경 내용

| 구분 | 0.7.2 | 0.7.3 (원래 규칙) |
|---|---|---|
| 3인전 | 손패 12장씩 · 바닥 24장 (4×3) | 손패 10장씩 · 바닥 30장 (5×3) |
| 2인전 | 손패 18장씩 · 바닥 24장 (4×3) | 손패 12장씩 · 바닥 36장 (6×3) |

- `lib/game.ts`: 새 RPG 전용 12/18장 분배와 4열 고정을 제거하고 기본 `startingHandSize`·열 계산을 사용한다.
- 안내 문구: `RpgJourney`, `RpgReworkResult`, `RpgPreviewTools`, `app/page.tsx`의 장수 표기를 실제 분배 기준으로 바꿨다.
- `tests/rpg-rework.test.tsx`: 기대값을 10/30, 12/36으로 갱신하고, 0.7.2 진행 중 판을 불러온 뒤 다음 판부터 원래 분배로 돌아가는 검사를 추가했다.
- 정찰·HP 정산·유물 등 0.7.2의 나머지 개편은 유지한다. 기본모드·폭탄시장전·독립 아이템전은 변경 없음.
- 수정 코드는 PC 작업 폴더의 미커밋 0.7.3 변경(2026-11-07 14:12)을 그대로 가져왔다.

## 이번 검증 (클라우드 작업 공간, Node 22.23.4, pnpm 11.25.0)

- TypeScript `--noEmit` 통과.
- `tests/rpg-rework.test.tsx` 28/28 통과.
- 전체 검사: 수정 전 338개 중 291 통과·47 실패, 수정 후 339개 중 292 통과·47 실패. 실패 47개 목록이 동일하고 새 실패 없음.
- 운영 빌드(`pnpm run build`) 통과.

## 배포 방식

이번부터 Cloudflare Workers Builds의 GitHub 연동으로 배포한다. `main` push 시 Cloudflare가 빌드·배포한다. 공개 사이트 확인 결과는 README에 기록한다.
