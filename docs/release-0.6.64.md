# 0.6.64 · 영화식 자막·세로 컷씬·장착 유물

사용자 빌드·기존 사이트 업로드 요청으로 앞서 저장한 자막/관문/유물 UI 수정을 게시한다.

- 컷씬 자막은 배경 상자 없이 그림 위에 공통18px 글자로 표시한다. 화자·글자 그림자와 같은 그림의 연속 대사 유지 동작을 보존한다.
- 세로 연결 컷은 화면을 채워 확대하고 상단에 현재 장소를 표시한다. 성채 지도는 해당 위치에 초점을 둔다.
- RPG의 별도 유물 축소 규칙을 정리해 아이템전과 공통 패널 크기를 사용한다. 그림 확대, 투명한 패널·얇은 테두리, 두 줄 효과와 상세 팝업을 적용한다.

이전 로컬 화면 검증은 `cinema-relic-local.md`에 기록했다. 이번 타입/관련 검사·운영 빌드와 실제 배포 결과는 루트 `artifacts/deployment-0.6.64.json`에 별도로 남긴다. 원본·저장·게임 규칙과 Sites의 기존 공개 범위를 보존한다. 이후 별도 빌드·게시 요청 없는 수정은 로컬 저장만 한다.
