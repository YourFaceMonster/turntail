# 확인 후 승인한 UI 후속 수정 · 로컬 미게시

버전 0.6.69, 시작 HEAD bedcb0f. 앞선 미게시 기본 회복 30 HP 통합 변경을 보존했다.

## 반영

- 세린 이번 판/3판 최종 결과는 한 줄에 순위 → 아바타 → 이름으로 표시. 오른쪽 누적 순위 배지를 제거하고 합산 점수만 표시한다. 이번 판은 판 순위, 최종은 합산 순위로 정렬하며 공동 순위를 유지한다. 최종 결과의 강조도 합산 1등을 따른다. 일반 게임과 편지 내기의 기존 두 순위 표시는 유지한다.
- 운명력은 이미지젠으로 생성한 투명 보석 3칸으로 표시. HP 창 안 아바타 위에 배치하고 소진된 보석은 흐리게 표시한다. 지도/주점/퀘스트/프롤로그의 공통 JourneyHud를 사용한다. 보석 파일의 투명 알파 확인(모서리 alpha 0).
- ST2 포코·밀라의 가로/세로 대화 원화 4장을 밤 조명으로 편집하고 전투 전후 대사 및 표정 전환에 연결했다. 인물·건축·카메라·패 배치를 유지하고 기존 낮 원본을 보존했다. 전투 테이블 환경 원화는 기존 밤 장면을 유지한다.
- 지도/주점/진입/감상 소개/다음 지역 내레이션의 '달의 영역' 표시를 '철문의 영역'으로 변경. 천체 묘사·파일명·저장 ID는 유지한다.
- 이미지 생성은 built-in image_gen 사용. 프롬프트·원본 경로·저장 경로: [생성 기록](art-generation-reviewed-ui-2026-11-05.json). 최종 파일: public/ui/fate-gem-v1.png, public/prologue/square-{poko,mila}-{wide,portrait}-night-v4.png.
