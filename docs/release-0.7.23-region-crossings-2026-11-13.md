# 0.7.23 · 영역 이동 컷씬·스테이지 확인 창·오늘의 판 꾸미기 (2026-11-13)

사용자 요청: "오늘의 판 너무 밋밋한데 꾸며줘", "스테이지 확인 창도 좀 더 꾸며보자", "맵과 맵 사이 이동할 때 컷씬 넣으면 좋을 것 같아, 개연성 포인트도", "이미지 생성됐어, 연결하고 완성하고 업데이트까지". GitHub main에 push하면 Cloudflare가 자동 배포한다.

## 변경
- **영역 이동 컷씬**(`lib/rpg-chapter-scenes.ts`)
  - ST3→4, ST6→7, ST9→10에 6~8컷짜리 이동 장면을 넣었다. 새 영역의 첫 스테이지에 처음 들어갈 때만 원래 장면 앞에 나온다.
  - 재도전 때는 나오지 않는다. "이야기 다시 보기"에서는 항상 볼 수 있다.
  - 이야기 흐름: 지나온 영역을 떠남 → 모은 패 회상 → 새 영역이 보임 → 경계를 넘음 → 다음 상대에게 이어짐.
  - 경계를 넘는 장면에서 HP 회복과 유물 1개 규칙을 이야기로 설명한다.
  - 두 번째 여정에는 구간마다 다른 대사가 한 줄씩 추가된다.
  - Codex가 만든 그림 6장(`public/story/cross-{4,7,10}-{depart,border}-portrait-v1`)을 연결했다.
- **스테이지 확인 창**(`app/components/JourneyDestinationHead.tsx`)
  - 모든 스테이지: 위쪽에 스테이지 그림을 넣고, 상대 얼굴을 보여 준다. 금색으로 꾸몄다.
  - ST4·ST7·ST10: 영역 지도, "새 영역" 리본과 문양, 영역 안 길(ST7→8→9) 표시, 규칙 안내 상자를 넣었다.
- **오늘의 판 창**: Codex가 만든 전용 배너(`public/ui/daily-table-banner-v1`)를 넣었다. 따뜻한 주점 색으로 바꾸고, 1~3위에 금·은·동 메달과 왕관, 금색 버튼을 넣었다.
- **지도 위쪽 제목**: 영역이 바뀐 뒤 "열쇠의 영역 · ST6"처럼 어긋나던 표시를 "다음 · ST7 달빛 고목"으로 고쳤다.
- 테스트 `tests/region-crossings.test.tsx`를 추가했다.
- 버전 0.7.23 (package.json, lib/version.ts).
