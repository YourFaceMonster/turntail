# TURNTALE 0.6.5

## 도전 패의 가독성·사용감

10개 스테이지의 네 문양과 숫자 1·2·8·12·15를 렌더링해 확인했다. 문양색은 유지한다. 숫자에 2.6 단위의 짙은 윤곽과 5.6 단위의 밝은 외곽을 겹쳐, 밝고 어두운 재질 모두에서 구분되게 한다. 문양에도 같은 두 겹 처리를 적용한다. 특히 2스테이지의 직조 장식 대비를 낮춰 숫자와 경쟁하지 않게 했다.

광택과 사진 텍스처 비중을 줄이고, 굵고 불균일한 테두리·모서리 파임·작은 긁힘·사용 흔적을 더했다. 패마다 다섯 단계의 사용감을 고정 시드로 배분한다. 숫자 중앙은 훼손하지 않는다. 뒤집힌 패는 모두 같은 뒷면을 사용해 마모 흔적으로 숨은 패를 식별할 수 없게 유지한다. 손패·제출·이동·등장 아틀라스는 같은 원본 그림을 사용한다.

## 가로 화면

- 라운드와 내 점수: 화면 맨 위 중앙. 별도 가로줄을 차지하지 않는다.
- 왼쪽: 상대 창, 바닥 패, 그 아래 제출 패.
- 오른쪽: 화면 높이를 모두 쓰는 내 패와 조작 버튼.
- 열 너비는 1.24:1로 배분한다. 상대 남은 패 수는 캐릭터 카드 안으로 통합한다.
- 손패 크기는 바닥 크기와 독립적으로 계산한다. 824×348 테이블 영역의 10장 손패는 높이 78px, 바닥 패는 50px로 계산한다. 손패가 늘면 손패만 축소한다.

## 싱글 10판 아이템전

진입: 싱글플레이 → 일반모드 → 10판 도전 → 일반전 / 아이템전.

| 아이템 | 효과 | 지급 |
| --- | --- | --- |
| 정찰 렌즈 | 선택한 접근 가능한 위층 비공개 패 하나를 이번 차례에만 확인 | 도전 전체 3개 |
| 기록 두루마리 | 이번 판에 이미 제출된 패 목록을 문양별로 확인 | 도전 전체 3개 |
| 전술 부적 | 현재 차례의 합법적인 행동 후보 하나 제안 | 도전 전체 3개 |

한 판에 아이템 하나만 사용할 수 있다. 사용해도 패·차례·점수·족보·제출/가져오기 규칙을 바꾸지 않는다. AI에도 같은 수량과 판별 제한을 적용한다. AI의 정찰은 합법적 외곽 한 장만 읽고, 다른 비공개 패는 확인하지 않는다. 아이템 정보는 해당 좌석에만 표시하고 행동 후 만료한다.

아이템전 저장은 일반전과 분리한다. 완료한 판의 승패·누적 점수, 최근 10판, 완료한 10판 합산 TOP 10을 별도 기록한다. 일반 하이스코어·전체 순위·일반 업적에 합산하지 않는다. 기기·브라우저 로컬 저장이며 멀티·스테이지 여정에는 아이템을 제공하지 않는다.

## 인원·친구 대전

새 게임과 순위 화면의 인원 선택은 3·4인으로 바꿨다. API에서 새 2인 방 생성을 거부한다. 이전 2인 로컬 저장은 삭제하지 않고 이어하기 목록에서 제외한다. 내부 구버전 규칙 판독은 유지한다.

3인 친구 대기실에서 방장은 AI 하나를 추가하거나 뺄 수 있다. 실제 친구 둘과 AI 하나가 모두 모인 뒤 시작한다. 경기가 시작된 후 인원을 변경할 수 없다. 처음부터 참여한 AI는 정상 참가자로 정산하고 사람 두 명의 전적을 각각 남긴다. 사람의 시간 초과 대체는 기존과 같이 무효 처리한다.

## 검증

- 모든 스테이지·문양의 렌더링 이미지 확인, 외곽선·문양색·다섯 마모 단계 테스트.
- 아이템 10판 완료·수량·판별 제한·규칙 불변·정보 만료·별도 저장·전적·순위 제외·중복 집계 방지.
- 실제 API/D1 계약 테스트로 2인 방 차단, 방장 권한, AI 추가/제거, 동시 폴링 정산과 두 사람의 전적 저장 확인.
- 일반 게임 12판 완주, 스테이지 점수·저장, 저장 슬롯, 업적, 가로 치수·기존 세로 치수 검증.
- TypeScript 및 프로덕션 빌드.

브라우저를 통한 전체 UI 확인은 연결 제한 때문에 완료하지 못했다.
