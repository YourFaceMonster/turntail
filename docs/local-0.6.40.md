# 0.6.40 로컬 피드백 수정

2026-10-28. 작업 시작 HEAD `940be32fe26ee2969f35b3c8e0878ddb5bee157b`, 당시 최신 배포는 0.6.39 / Sites 102다. 이번 네 가지 수정은 로컬에 적용했으며 빌드·push·원격 저장·사이트 업로드하지 않았다.

## 변경

1. **이번 판 정산 음악**: 예전 `victory/reflection-0515.mp3` 결과 BGM 연결과 별도 Web Audio 결과 음악을 제거했다. 정산 표시 시 오늘 제공한 `15_승리 팡파르.mp3`의 기존 복사본 `/audio/sfx-261028/15-victory.mp3`만 오디오 요소 하나에서 한 번 재생한다. 정산 전 결과 연출 동안은 테이블 BGM을 유지하고 정산 표시 때 전환한다. 재생을 마친 뒤 화면 클릭으로 음악이 다시 시작하지 않는다. 결과 음악은 BGM 설정·음량을 따른다. 메뉴·테이블 음악과 원본 파일은 보존한다.
2. **함정 경고**: 기존 패 왼쪽 아래 함정 아이콘에 붉은 바탕·테두리·안쪽 빛을 추가했다. 14px 표시 안에서 2.2초 주기로 천천히 밝아지고 어두워진다. 바닥패 자체를 움직이지 않으며 함정 없음 표시는 녹색을 유지한다. 모션 감소 설정에서는 붉은 정적 표시를 사용한다. 비공개 위치 공개 범위는 기존 그대로다.
3. **패 뒤집어 가져오기 소리**: 바닥패 가져오기 `draw` 오디오 진입점에서 재생을 막았다. 오늘 제공한 5번 녹음과 로딩 실패 시 합성음 모두 출력하지 않는다. 선택·제출·착지·내 차례 소리와 가져오기 진동은 유지한다. 녹음 원본과 매핑 기록을 삭제하지 않는다.
4. **투시 회수 피해**: 상대 상태창의 `b` 색상 규칙이 피해 숫자의 빨간색을 덮어쓰던 문제를 수정했다. 실제 피해 숫자·공격 아이콘을 `#ff6652`로 직접 지정하고 방어 표시는 구분했다. 효과가 끝날 때까지 피해 숫자를 읽을 수 있게 유지한다.
