# 0.6.11 — 로컬 수정·빌드 전용

사용자 요청에 따라 Sites 저장·소스 push·배포를 진행하지 않는다. 배포 사이트는 0.6.10을 유지한다.

- 상점은 그림을 눌러 담고 담은 그림을 눌러 취소하는 UI로 복원했다. 자유 구매·20P 시작·미사용 물품 보관·판당 2개 사용 규칙은 유지한다.
- 자신의 준비된 수호의 봉인은 상태창에 문양으로 표시한다. 상대 준비 상태는 계속 비공개이며 발동 시에만 방패 연출을 공개한다.
- 방패의 금속성 잔향과 공격 충돌음을 효과음 설정에 연결했다. 작열탄은 예비 동작·포물선 투척·불꽃 충격·반사를 강화했고 AI끼리도 2.5초로 늘렸다. 바늘탄은 작은 충격과 낮은 소리를 사용한다.
- 정찰 렌즈는 기존 패 윤곽 그대로 표시하고, 라운드 내 해당 패가 실제로 가져가질 때까지 사용자의 투시만 유지한다. 여러 번 사용한 투시도 각각 유지한다. 공개 사용 알림에는 사용자 이름·아이템만 표시하며 타인에게 정찰한 위치나 패 내용을 보내지 않는다.
- 새 아이템 `엿보는 눈`은 선택한 상대 손패 무작위 1장을 사용자에게만 공개한다(4P). 해당 패가 상대 손패를 떠나면 확인 정보도 사라진다. `바늘탄`은 3 피해의 작은 공격이다(4P).
- 뒤바뀐 운명은 양쪽 4장 이상, 운명의 저울은 기존 5장 이상. 양쪽의 1·2를 교환 대상에서 제외한다. 인원별 장수 조건은 공개 정보로 검사하고, 상대의 교환 가능 패가 없는지는 사용 이후에만 판단한다. 이때 물품과 사용 횟수를 소모하고 교환 불가 안내를 표시한다.
- 교환 대상 창은 같은 색의 작은 아바타·이름 버튼으로 단순화했다. 화살표를 제거하고 아이템 위치를 올렸다. 선택한 실제 패에서 상대에게 직접 이동하는 1초 교환으로 바꿨다.
- 다른 아이템의 중앙 표시도 올리고 사용자 이름을 위에 표시한다. 약초는 2.4초 유지한다. 사용 배지의 검은 원형 배경을 제거했다.
- 상대 손패 3·2·1장을 알림과 점점 진해지는 붉은 숫자·테두리로 강조한다. 차례인 상대 상태창은 확대하고 다른 상대는 조금 축소한다. 중앙 제출자 이름도 확대했다.
- 결과는 참가자별 색과 HP 바, 간결한 원인별 증감 요약으로 정리한다. 사용 이력은 사용자 순으로 묶어 대상과 방어 결과를 같은 줄에 표시한다. 사용 이력·남은 손패는 각각 기본 접힘 상태다.

검증: 0.6.11 비공개 정찰·새 아이템·교환 제한·실패 소모·접힘 결과·상점 회귀 검사, 기존 HP 아이템전·RPG·관련 테스트와 타입 검사. 실제 기기에서의 연출·소리 체감은 사용자 확인 대상이다.
