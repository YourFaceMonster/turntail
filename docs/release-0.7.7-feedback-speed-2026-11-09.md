# 0.7.7 · 요트다이스 피드백 · 폭탄시장 시작 단축 · 이미지/효과음 경량화 · 여행자 응급처치

사용자 요청(2026-11-09): 0.7.6 이후 로컬 수정분을 모두 커밋하고 업데이트.

## 변경 내용

### 요트다이스 (상세 `docs/local-yacht-dice-2026-11-09.md` 후속 3·4)
- **진동**
  - 컵 흔들기·쏟기·착지, 주사위 탭, 점수 기록 때 진동이 온다.
  - `lib/haptics.ts`(신규)를 통해 설정의 진동 켜기/끄기를 따른다.
- **족보 연출**
  - 포카인드·풀하우스·스트레이트를 적으면 배너가 뜬다. 하로가 적을 때는 파란 배너다.
  - 요트는 금색 배너, 요트 보너스와 숫자 보너스도 배너로 알린다.
  - 주사위 5개가 같은 눈이면 금빛으로 빛난다.
- **조커 규칙 (야찌 기준)**
  - 요트 칸을 채운 뒤 요트가 또 나오면 +100(요트 칸이 50점일 때)
  - 같은 눈 숫자 칸 → 아래쪽 족보 칸 → 남은 숫자 칸 순서로 적는다.
- **점수 칸**
  - 숫자 칸은 주사위 눈 아이콘으로, 족보 칸은 붉은 테두리로 구분한다.
  - 가장 높은 점수 칸은 ★로 표시한다.
  - 족보 칸 아래에 한 줄 설명이 붙고, 스몰·라지·요트는 15·30·50점 고정 점수를 보여 준다.
- **하로 표시:** 타일 아래 "하로" 줄을 뺐다. 하로 점수는 좌석을 누르면 점수표로 본다.
- **남길 칸:** 누른 순서대로 왼쪽부터 채운다.
- **주사위 눈 고정:** 착지 때 면이 찌그러지던 애니메이션을 없앴다.

### 폭탄시장전 · 로딩 (상세 `docs/local-bomb-load-speed-2026-11-09.md`)
- 폭탄시장전 새 판은 약 10초짜리 입장 연출을 건너뛴다. 판 위 첫 분배 연출은 유지한다.
- 효과음 14개를 MP3로 바꿨다(약 1.5MB → 약 340KB). 원본 WAV는 그대로 남겼다.
- 이미지 PNG 230개를 WebP로 바꿨다(548.6MB → 68.6MB). 원본 PNG는 남겼다.
  - 코드는 WebP만 참조한다. 단 ST4~10 최종 그림의 예정 경로(`FINAL`)는 PNG로 남겼다.
- 최근 패 열에서 싱글·페어를 가운데 정렬한다.

### 길가의 여행자 (상세 `docs/local-wayfarer-hp-aid-2026-11-09.md`)
- 새 RPG에서는 HP 5를 나눠 응급처치한다. HP 5 이하이면 할 수 없다.
- 새 RPG에서 "돕기" 버튼이 늘 꺼져 있던 버그를 고쳤다.
