# 0.6.60 · RPG 이야기 연결·그림/UI 및 폭탄시장전 즉시 시작

2026-11-02 사용자 사이트 업로드 요청에 따라 기존 Sites 프로젝트와 공개 범위를 유지해 게시했다. 0.6.59 공개 이후 현재 체크아웃에 저장된 RPG 작업과 최신 폭탄시장전 진입 변경을 함께 반영했다.

## 포함 내용

- RPG 컷씬 흐름을 핸드오프 문서의 장면 순서에 맞춰 ST1~3 전후 이야기로 연결하고, 화면 테스트와 전체 연속 감상 진입을 반영한다.
- 공중섬 지도·설산 관문·광장·주점·요새 컷씬과 인물 구성을 연결한다. 까마귀 주점 주인장 모르는 실내에서 읽히도록 눈빛/외곽 조명을 보강하고, 로웬 곁의 부엉이와 스테이지 3 쌍둥이 보스의 실내 장면을 반영한다.
- 승인된 손그림 2D 판타지 화풍에 맞춘 RPG 주점·인물·맵 그림, 장면 구도, 지도/UI 및 주점 대화 배치를 반영한다.
- 장착 유물 슬롯 크기와 승리 결과 글자/패 광택 순서를 조정하고, RPG 싱글플레이 메뉴에서 한 판 통과 버튼만 제거한다. 기존 테스트 데이터와 연결은 보존한다.
- 폭탄시장전은 기존 세부 규칙과 저장 형식을 유지하며, 모드 선택 후 별도 로비를 표시하지 않고 저장된 판은 바로 이어서, 저장이 없으면 새 게임으로 진입한다. 잘못된 저장을 덮어쓰지 않고 오류를 안내한다.

## 이번 게시 검증과 한계

- `pnpm exec tsc --noEmit` 통과. Sites 게시 헬퍼에서 운영 빌드 5단계가 통과했다. 기존 클라이언트 번들 크기 및 일부 라우트 분류 안내는 있었지만 빌드 실패는 없었다.
- 앞서 실행한 RPG 관련 검사 16개 통과 기록은 [로컬 변경 기록](rpg-update-2026-11-02-local.md) 및 [연속 감상 기록](rpg-story-reel-local.md)을 따른다. 이번 게시 시 전체 검사군을 새로 실행한 것으로 표현하지 않는다.
- 공개 `/`, `/bomb-market`, `/prologue-preview`가 각각 HTTP 200을 반환했다. 이는 경로 응답 확인이며 실제 화면 조작 검증은 아니다.
- 실제 기기 상호작용·청감·운영 저장 데이터로 새 게임을 실행하는 검증은 하지 않았다.
- 사이트는 공개 범위를 유지해 배포 성공했다. Sites 버전은 115, 소스 커밋은 `6bb8db442ef3c7e5808afb04c603dd1f68932ef1`, 운영 URL은 [TURNTALE](https://lexio-jangseong.peppyeft256.chatgpt.site)이다. 자세한 저장본·배포·빌드 기록은 워크스페이스 `artifacts/deployment-0.6.60.json`에 보관한다.
