# 턴테일 RPG 전투 시스템 — Codex 핸드오프
작성일: 2026-10-27
상태: 방향 합의 / 수치 임시

## 목표
기존 패 게임 규칙과 UI를 유지하면서 직업별 조건부 스킬을 추가한다. 경험치·레벨업·마나 시스템은 도입하지 않는다. 로그라이크와 콘텐츠 해금형 성장은 유지한다.

## 전투 기본
- 테스트 기준 초기 HP: 100
- 여러 라운드에 걸쳐 HP를 감소시키며 HP 0이면 탈락
- 승리한 패 제출에 대해서만 실제 낸 패 수만큼 기본 피해 적용
- 승리하지 못한 패 제출에는 피해 없음
- 기존 패 소모, 족보, 승패 판정 및 아이템·유물 규칙 유지

## 직업 스킬 (프로토타입)
| 직업 | 패시브: 조건 충족 시 매번 | 액티브: 라운드당 최대 1회, 조건 충족 시 자동 발동 |
|---|---|---|
| 검사 | 페어 승리 시 추가 피해 +1 | 스트레이트 승리 시 추가 피해 +3 |
| 도적 | 싱글 승리 시 상대 패 1장 확인 | 트리플 승리 시 상대 패 2장 확인 및 패 교환 효과 |
| 성직자 | 페어 승리 시 HP 1 회복 | 풀하우스 승리 시 HP 5 회복 |
| 마법사 | 트리플 승리 시 추가 피해 +2 | 포카드 승리 시 추가 피해 +6 |

- 마나 소비 없음. 패시브는 조건마다 발동, 액티브는 라운드당 1회.
- 회복은 최대 HP를 초과하지 않음.
- 도적의 패 교환 대상·방식은 기존 게임 구조 확인 후 확정.
- 실제 구현된 족보 명칭·구성이 다르면 임의로 족보를 추가하지 말고 확인 요청.

## 구현 지침
1. 현재 코드의 라운드 경계, 승리 판정, 피해 대상, 패 수 계산부터 확인한다.
2. 직업 데이터 및 조건부 스킬을 기존 승리 판정에 연결한다.
3. 액티브 사용 여부를 라운드 시작에 초기화한다.
4. 간단한 발동 연출을 추가하고 기존 아이템·유물과 충돌을 확인한다.
5. 기존 UI와 패 게임 규칙은 임의로 변경하지 않는다.

## 검증
- 평균 전투 길이(우선 3~5라운드 가설), 직업별 피해·회복·발동 빈도 확인
- HP 100과 스킬 수치는 임시이며 플레이 테스트 후 조정
- 모호한 부분은 추측 구현하지 말고 질문
