# 0.6.51 · 메뉴·전투·정산 및 UI 최소 수정 게시 소스

2026-10-30 사용자 요청에 따라 현재 로컬 변경을 기존 공개 사이트에 저장·게시한다. 기존 주소와 공개 범위를 유지한다. 이전 공개 기록은0.6.50 / Sites109이며, 이번 저장본·소스 커밋·배포 결과는 워크스페이스 artifacts/deployment-0.6.51.json에 별도로 기록한다.

## 이번 게시 대상

- [앞선 로컬0.6.51 변경](local-0.6.51.md): 메인3버튼 크기 통일, 결투 중복HP 제거, 층별 주화 안내, 정산 높이와 피해·회복·최종 증감, 화염 폭발/우측 반전, 강타와 스킬 팝업.
- 일반전 가로 바닥 크기에 실제 column 패딩·간격과1.28배 낸 패 높이를 반영. 손패·좌석·클리핑은 유지.
- HP 아이템전은 잔액이 없어도 상품 설명·가격을 열람할 수 있고, 담기와 구매는 기존 잔액·중복 제한을 유지.
- 상점 안내에 ‘빠르게 두 번’을 명시. 기존450ms 인식 조건은 유지.
- 아이템전 접근성 이름만 ‘아이템전 상태’로 구분하고 RPG 명칭은 유지.

## 앞선 로컬 검증과 이번 게시 검사

이번 UI 최소 수정에서 관련 테스트5개와 타입 검사를 통과했다. 실제 브라우저에서3인1·2라운드,4인1라운드,844×390·667×375 가로/390×844 세로/1280×800 PC를 확인했다.844×390에서 바닥 하단299px·클립284.484px이었던 것이 수정 후281px·292.172px로 맞춰졌다. 실제0P 상점의 상품6개를Enter·Space로 열람했고 담기 차단·정상 구매·저장 재개도 확인했다.

위는 게시 전 로컬 작업에서 실행한 결과다. 이번 게시 과정에서는 최종 타입 검사와 운영 빌드를 새로 수행한다. 그 결과와 실제 공개 화면에서 확인한 범위는 배포 JSON을 따른다. 운영 전체 게임을 다시 플레이한 것으로 표현하지 않는다.

모바일 실기기·스크린리더·RPG 실제 플레이·HP0 최종 대전 종료·모든 직업 연출은 미검증 상태를 유지한다. AI·가격·효과·정산·유물·저장 구조는 이번 UI 최소 수정에서 변경하지 않았다.

사용자의 기본 방침은 계속 ‘별도 빌드·업로드 요청이 없으면 로컬 저장만’이다. 이번 요청에 한해 저장·게시가 승인되었다.
