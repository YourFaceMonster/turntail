# 0.6.43 · 아이템전 AI 판단 강화 — 로컬 저장

2026-10-29 KST. 사용자의 “AI부터 강화하고 그 뒤 밸런스를 판단하자” 요청을 반영했다. 기존 0.6.42 미배포 작업을 보존했고, **게임 규칙·HP·직업 수치·가격·주화 보상은 변경하지 않았다.** 빌드·push·원격 저장·배포하지 않는다. 마지막 배포는 0.6.41 / Sites 103이다.

## 바뀐 판단

- **최종 순위와 생존:** 실제 종료 시 HP·잔여 패 동률 규칙으로 1/2/3등을 구분한다. 계속해 1등을 노리는 선택과 지금 상대를 탈락시켜 2등을 확보하는 선택을 비교한다. 항상 최약체나 사용자만 공격하는 정책이 아니다.
- **패 내기와 응수:** 선뿐 아니라 상대 족보에 응수할 때도 자기 직업의 추가 피해·회복·반복 발동 여부와 상대 공개 정보를 반영한다. 누적 제출 패 피해도 포함한다.
- **판 종료·지갑:** 안전하게 손패를 비울 수 있으면 불필요하게 바닥을 더 가져오지 않는다. 손패 증가가 판 정산의 돈 부족·HP 감소로 이어지는 위험도 자기 지갑 기준으로 평가한다. 상대의 숨긴 지갑을 읽지 않는다.
- **게이지:** 현재 사용 효과와 다음 충전의 기회비용을 비교한다. 건강할 때 낮은 게이지를 무조건 소비하지 않고, 끝내기·생존에 필요하면 사용한다.
- **수동 스킬·아이템 통합:** 패 행동, 스킬 먼저, 아이템 먼저, 스킬→아이템, 아이템→스킬의 후보를 같은 기준으로 비교한다. 회복 후 광역 공격을 해야 1등이 되는 상황을 구분한다.
- **실행은 한 번씩:** 선택한 첫 행동만 실제 수행하고 연출 뒤 바뀐 실제 정보를 받아 재판단한다. 가상으로 예상한 교환 패나 비공개 패를 실제 행동에 사용하지 않는다.
- **도적·바닥:** 자기 직업 투시로 생긴 회수 기습, 정찰 렌즈와의 차이, 확인한 함정, 공개 주화, 자신이 바로 가져올 패에 함정을 낭비하는 경우를 평가한다. 미래 상대 취득 가능성은 추정이다.
- **상점:** 자기 직업·손패·HP·보유품·예산과 잔액 여유를 바탕으로 최대 2개를 선택한다. HP가 위급하면 약초 가치를 높인다. 상품 가격·인간 플레이어 구매 규칙은 그대로다.
- **경로 통합:** UI 앞단의 구형 ‘스킬 먼저/아이템 먼저’ 분기를 새 아이템전에서 우회한다. 워커·워커 실패 대체 경로·`botMove`가 같은 계획을 실행한다. 기존 일반모드·RPG·스테이지 AI는 유지한다.

## 공정성·계산 범위

`item-battle-plan.ts`는 관찰 가능한 상태만 평가한다. 상대 손패, 덮인 아래층, 상대 지갑·방패·게이지·인벤토리를 외부에서 추가해도 선택과 점수가 달라지지 않는 검사를 넣었다. 자기 투시·자기 손패·자기 예산은 사용한다.

현재와 다음 패 행동, 해당 결투 결과, 스킬/아이템의 두 행동 순서를 비교하는 제한된 탐색이다. 미래 전체 대전을 완전 탐색하거나 학습 모델을 훈련한 것은 아니다. 비공개 상대 방어·미공개 패·장기 주화 수입을 정확히 안다고 가정하지 않는다. 진행 중 순위 전망과 상대 응수 가능성은 휴리스틱이며 실측 승률 예측값이 아니다.

보통 상황에서는 기존의 손패 정리 판단을 보존한다. 탈락·결투 누적 피해·지불 불능 위험이 가까우면 HP와 순위 평가를 강하게 적용한다. 손패가 18장을 넘으면 자기 패의 낮은/높은/중간 18장 구간으로 후보를 제한해 계산량을 묶는다. 일부 조합을 놓칠 수 있으며 최적 수 보장은 하지 않는다.

## 이번 검증

관련 기능 검사 **17개 파일 통과**, `tsc --noEmit --incremental false` 통과. 자세한 원문은 워크스페이스 [checks-0643.json](../../artifacts/checks-0643.json)에 있다. 기존 0.6.42 UI·주화·함정·저장 검사를 재실행했고 일반 AI·스테이지 AI·기하 검사도 포함했다. 구형 규칙 3의 은퇴 아이템 기대 테스트를 신규 규칙 4 통과 수에 포함하지 않는다.

신규 주요 사례:

1. 불리한 판에서 3등 위험을 줄이고 2등으로 끝내기.
2. 선두와 HP가 가까울 때 최하위 처치 대신 선두 공격으로 역전 노리기.
3. 건강한 검사의 낮은 게이지 보존.
4. `약초 → 광역 스킬`로 1등, 반대로 하면 2등인 상황을 올바른 순서로 실제 실행.
5. 죽을 수 있는 결투를 양보하지 않고 성직자의 페어 회복 응수 선택.
6. 마법사의 응수 포카드 추가 피해와 판당 1회 제한 제거 상태 반영.
7. 검사의 페어 추가 피해로 1등 확정.
8. 공개 주화 미끼보다 확인된 치명적 함정 회피.
9. 1/2/5라운드 첫 결투 아이템 잠금과 연출 중 다음 행동 잠금 유지.
10. 자기 손패를 한 번에 비울 수 있는 싱글·페어·트리플·5장 선택.
11. 직업 4종·예산 0/3/5/8/10/20P 구매 한도와 비공개 정보 무시.
12. 위급 시 약초 구매, 건강할 때 불필요한 약초 구매 회피.
13. 워커가 없는 Node 환경에서도 같은 회복 우선 계획 실행.
14. 18/24/36장 큰 손패의 합법 행동과 유한 점수 확인. 이번 데스크톱 검사에서 약 58~93ms 범위였다. 36장과 여러 아이템을 함께 평가하는 사례도 약 59ms·318개 후보로 확인했으며 모바일 실측값은 아니다.

## 전체 대전 비교

최종 판단식 조정에 쓰지 않은 **시드 9001~9096 × 신규 AI 자리 3곳 회전 = 평가 288대전**을 수행했다. 각 시드의 전원 기존 AI 대조 대전 1개, 총 96개도 별도로 실행했다. 따라서 실제 시뮬레이션 실행은 384대전이다.

| 평가 대상 자리 결과 | 신규 0.6.43 | 대응 전원 기존 0.6.42 대조군 |
|---|---:|---:|
| 1등 | 108/288, **37.5%** | 96/288, 33.3% |
| 2등 | 92/288, 31.9% | 96/288, 33.3% |
| 3등 | 88/288, **30.6%** | 96/288, 33.3% |

대응 자리 기준 이전보다 순위가 좋아진 사례 69, 나빠진 사례 56, 같은 사례 163이다. 큰 손패 보완 뒤 동일 조건으로 재실행해 같은 순위 분포를 재현했다. 최종 재검증의 데스크톱 판단 시간은 중앙 약 0.49ms, 95백분위 약 1.17ms, 최대 약 6.94ms였다. 이 값은 해당 모의 대전의 일반적인 손패 기준이며 큰 손패 검사·네트워크·그림 로딩·기기 UI 시간을 포함하지 않는다.

근거: [최종 비교 JSON](../../artifacts/ai-benchmark-0643-final.json), [최종 코드 재검증](../../artifacts/ai-benchmark-0643-final-recheck.json), [비교 스크립트](../../artifacts/benchmark-ai-0643.ts), [0.6.42 카드 정책 보관](../../artifacts/ai-0642-baseline.ts).

비교 조건은 새 정책 1명 대 기존 정책 2명, 좌석 회전, 동일 시드 출발, 전원 AI다. 대칭성을 위해 사용자 전용 유물을 비우고 UI 대기 시간은 건너뛰었다. 실제 패·HP·돈·아이템·직업 스킬은 게임 함수를 사용했다. 기존 정책의 스킬·아이템·구매 우선순위는 비교 스크립트에 재현했으며 과거 배포 바이너리를 실행한 비교는 아니다. 기존 카드 정책 파일은 수정 전 보관본을 사용했다.

**개선 신호는 있으나 큰 격차나 통계적 우위를 확정할 정도로 해석하지 않는다.** 사람 상대의 실제 승률, 모든 직업의 균형, 실제 유물 포함 대전, 모바일 체감을 보증하는 결과도 아니다. 모든 직업이 같은 수치로 강해졌다고 결론 내리지 않았다.

초기 시제품은 HP 보전에 치우쳐 패를 너무 가져오는 문제로 비교 결과가 나빴다. 그 결과를 숨기지 않고 `ai-benchmark-0643-prototype1.json` 및 pilot 기록으로 보존했다. 패 소진·정산 부채·안전한 판 종료의 가치를 보강한 뒤 최종 비교를 분리했다. 이전 holdout 기록의 288대전 결과는 후속 위급 구매·큰 손패 보완 전이며 최종 수치와 혼합하지 않는다.
