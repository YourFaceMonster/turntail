# 2026-11-03 · 길가의 여행자 이벤트 로컬 구현

## 플레이 흐름

1. RPG 지도에서 **길가의 여행자** 장소를 선택한다.
2. 응급 약초(`emergency-herb`)가 가방에 있으면 한 개를 건넬 수 있다. 없으면 보유 아이템을 쓰지 않고 지도로 돌아간다.
3. 건네면 가방에서 약초 한 개를 소모하고 주화 8개와 **검은 소나무 파수탑** 소문을 받는다.
4. 소문은 봉인 편지의 북쪽 유물 단서를 구체화한다. 파수탑 조사와 이야기형 유물 발견은 [후속 로컬 기록](local-watchtower-relic-2026-11-03.md)에 이어서 반영했다.

## 구현 범위와 저장

- 지도 장소, 여행자 이벤트 화면, 인벤토리 수량에 따른 선택 버튼, 보상 액션을 연결했다.
- 완료 상태는 `wayfarerHerbGiven`과 완료 장소 목록에 저장하며 중복 보상을 막는다.
- 공개 RPG 뷰에서는 기존과 같이 미니게임 내부 저장을 숨긴다. 새 이벤트는 기존 여정 데이터의 선택 필드만 사용한다.
- 앱 버전은 `0.6.66` 그대로다. 로컬 변경이며 빌드·커밋·push·배포하지 않았다.

## 이번 작업 확인

- 소스와 액션 연결을 정적으로 확인했다.
- 테스트와 빌드는 실행하지 않았다.
- `pnpm exec tsc --noEmit`는 변경 코드 오류 없이 진행됐고, 테스트 파일 `tests/bomb-classic.test.tsx` 두 곳과 `tests/bomb-market.test.ts` 한 곳의 null 가능성 오류 때문에 전체 통과하지 못했다.
- `git diff --check`는 통과했다. 저장소의 LF→CRLF 줄바꿈 경고만 표시됐다.
- 실제 화면 플레이 검증은 하지 않았다.
