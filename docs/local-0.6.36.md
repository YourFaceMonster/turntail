# TURNTALE 0.6.36 · 로컬 업데이트

2026-10-28 사용자 요청의 모든 미반영 항목을 로컬에 구현했다. 이전 배포는 0.6.35 / Sites 99이며 이번 소스는 운영 빌드·원격 push·Sites 저장/배포를 하지 않았다.

## 바닥 주화

- 현재 직업형 아이템전의 라운드마다 실제 바닥패 1장에 무작위 주화 1개를 배치한다. 최종 분배·선구자의 눈 교환 이후 배치한다.
- 2층 주화는 실제로 가져오기 전까지 숨긴다. 렌즈와 도적 투시도 패 내용만 보여주며 주화는 드러내지 않는다.
- 덮여 있는 1층 주화도 숨긴다. 위층을 걷어 1층 패가 드러나면 표식과 관찰자 본인이 받을 금액을 표시한다. 위층을 걷은 사람이 아닌, 주화가 붙은 패의 실제 수집자에게 지급한다.
- 일반 주화는 도적 1P, 검사·성직자·마법사 3P다. AI도 실제 직업에 따라 같은 금액을 받는다.
- 마지막 바닥패는 모든 직업에 5P. 그 마지막 패에 무작위 주화도 있으면 직업별 일반 주화를 합산하여 **도적 6P(5+1), 나머지 직업 8P(5+3)**다. 덮인 2층 주화의 존재는 마지막 보너스 표식에도 미리 노출하지 않는다.
- 함정이 함께 있어도 주화는 수집하고 함정 피해는 별도로 적용한다. 치명적인 함정도 주화 지급 이후 처리한다. 일반 패 정산과 바닥 주화 수입은 정산 표시에서 구분한다.
- 주화 획득 시 지갑에 즉시 합산하고 동전 이동·초록색 `+NP`를 표시한다. 상대의 지갑 잔액은 새로 표시하지 않는다.
- 위치·소진 여부·이벤트·획득 합계는 게임 저장에 보존한다. 이어하기로 위치가 다시 뽑히지 않는다. 기존 진행은 실제 이어하기 시 한 번 배치하여 저장하며, 저장 목록을 읽는 동작만으로는 데이터를 바꾸지 않는다. 다음 라운드에는 새로 배치한다.
- 필터링된 플레이어/AI view에는 비공개 주화 ID·위치·층·남은 여부를 포함하지 않는다. AI의 주화 선택과 함정 유도는 공개된 표식과 자신의 손패/정찰 정보만 사용한다.

## 삭제·상점·함정

- 이어하기는 개별 즉시 삭제 대신 `저장 삭제 → 체크박스 선택 → 선택한 N개 삭제 확정`을 사용한다. 선택이 없으면 확정 버튼을 비활성화한다. 취소하면 체크를 지운다.
- 여러 저장 삭제는 모든 대상을 먼저 검증한 뒤 반영한다. 다른 대상이 변경됐거나 중간 저장이 실패하면 전체 선택을 보존/복구한다. 완료 기록·도감·해금·설정·선택하지 않은 저장을 보존한다.
- 상점은 이번 구매에 담은 금액을 뺀 잔액으로 감당할 수 없는 상품을 회색으로 비활성화한다. 담기 취소 시 상태를 다시 계산한다. 기존 최종 구매 금액 검사도 유지한다.
- 함정은 외곽·격벽의 가져오기 접근 규칙과 별개로, 남아 있는 어느 바닥패 위치에도 설치할 수 있다. 덮인 아래층이 아닌 현재 표면의 패에 붙는다. 실제 가져오기는 기존 외곽 규칙을 따른다.
- 함정 버튼은 이미지로만 표시한다. 사용 완료/불가 상태는 회색이다. 다시 누르면 설치 선택을 취소한다.
- 설치 안내 팝업·긴 설치 완료 토스트를 제거하고 낸 패 공간에 `함정을 설치할 패를 선택하세요` 한 줄을 표시한다. 설치 표식은 패 안쪽에 유지한다.
