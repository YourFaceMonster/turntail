# TURNTALE 0.6.36

바닥패의 주화를 수집하는 아이템전 규칙과 사용자 요청의 화면 정리를 반영했다.

- 라운드당 랜덤 주화 1개. 2층은 획득 전까지 숨기고, 1층은 위층을 걷어낸 뒤 공개한다. 투시와 AI에 비공개 주화 정보를 전달하지 않는다. 저장 후 이어하기에서도 위치를 유지한다.
- 일반 주화는 도적 1P·다른 직업 3P, 마지막 바닥패는 모두 5P다. 둘이 겹치면 **도적 6P(5+1), 다른 직업 8P(5+3)**를 지급한다.
- 이어하기에서 별도 삭제 모드로 항목을 체크하고 삭제를 확정한다. 다중 삭제 실패 시 복구하며 완료 기록·해금·설정을 보존한다.
- 상점에서 담은 금액을 뺀 잔액으로 살 수 없는 상품은 회색으로 비활성화한다.
- 함정은 안쪽을 포함한 모든 남은 바닥패 위치에 설치할 수 있다. 이미지 버튼과 낸 패 공간의 한 줄 안내를 사용한다. 실제 패 가져오기 규칙은 유지한다.
- 이전 패 문양을 그대로 복원하고 숫자만 문양 내부에 맞춘다. 라운드·점수·주화 위치와 모바일 배치를 정리한다.

## 검증 기록

배포 전 로컬 검증에서 타입 검사와 관련 기능 검사 16개, 모바일 세로·가로 및 데스크톱 화면 확인을 마쳤다. 이후 도적의 겹침 보상을 6P로 수정하고 주화 기능 검사와 타입 검사를 다시 통과했다. 그 이전 8P 화면 증거는 당시 기록으로 보존한다. 상세 구현·검증은 [local-0.6.36.md](local-0.6.36.md)를 따른다.

이번 운영 빌드는 최종 소스에서 별도로 실행한다. 빌드·소스 커밋·Sites 저장본·배포 결과는 워크스페이스 루트 `artifacts/deployment-0.6.36.json`에 기록한다. 배포 성공 여부는 해당 결과를 따른다.
