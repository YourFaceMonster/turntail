# 0.6.21 · 로컬 연출 확인용

사이트 배포 없이 로컬 빌드만 진행. 0.6.19/20의 아이템전 규칙과 저장 호환을 유지한다.

- 싸움 종료 즉시 상태창 충격과 낮은 타격음을 내고, 700ms 뒤 전투 정산창을 연다.
- 시간 제한과 감소하는 진행 막대를 없앤다. 화면 클릭·확인 버튼·Enter/Space·Escape로 닫기 전까지 확인창을 유지하고, 다음 AI/사용자 행동과 최종 라운드 정산을 기다리게 한다.
- 어두운 초록 패널, 절제된 금색 테두리, 캐릭터 색상의 피해 행, HP 전후 숫자와 HP 바를 사용해 전투 정산 디자인을 다듬는다.
- 내 상태창의 중복 고유스킬 배지를 제거해 HP 뒤에 스킬 문구가 겹치지 않게 한다. 스킬 버튼과 사용 상태는 손패 도구 영역에 유지한다.
- 작열탄 아이템 그림은 그대로 유지. 이미지 생성 도구로 만든 투명 8프레임 불꽃·연기 아틀라스를 충돌 효과에 사용한다. 원본 PNG와 WebP, 프롬프트/생성 기록을 보관한다.
- 바늘의 촉을 실제 궤적 방향에 맞추고, 최대 크기 근처의 좌우 반전에 따른 방향 보정과 좌우 발사 시 각도 연속성을 처리한다. 작은 충돌은 짧은 금빛 파편으로 구분한다.
- 뒤바뀐 운명 일반 교환은 1초를 유지. 봉인에 막히면 680ms에 접촉하고, 총 1.6초 동안 보호막 섬광·접촉 고리·되튕기는 패를 보여준다.

검증: 전투/아이템/스킬/모드2 경제/기존 모드/레이아웃/저장 회귀 테스트, TypeScript, 로컬 빌드. 브라우저에서는 충격 직후 정산창이 아직 없는 상태, 이후 표시, 자동 종료 없이 대기 유지, 확인 후 행동 재개를 확인했다.

기존 `stage-ui.test.tsx`의 카드 뒷면 팔레트 대비 조건 실패는 0.6.20에서 기록한 별도 사안이며 해당 팔레트는 이번에도 수정하지 않았다.
