# TURNTALE 0.6.68 · 여정 상태창과 퀘스트 연출

## 변경 사항

- 여정 지도에 플레이어 아바타, 이름, 직업, HP 막대, 장착 유물과 여행 가방 버튼을 추가했다. 지도에서 유물 장착·해제를 할 수 있다.
- 마을 잡화점 상품을 세 화면 크기 모두 3열로 배치했다.
- 퀘스트 대사와 화자 표기를 RPG 컷씬 자막의 18px·12px 규격에 맞추고, 대화 패널 바탕을 제거했다.
- 도둑의 팔이 상자 윗면에 걸쳐지도록 신규 가로·세로 그림을 연결했다. 원본과 이전 버전은 보존했다.
- 파수탑 유리 발견 컷씬에서 푸른 유리 위치에 맞춰 빛이 맥동하게 했다.
- 여정 위치 전환에 페이드 인·아웃을 적용했다.

## 이번 검증

`pnpm run build` 운영 빌드 5단계 통과. 클라이언트 청크 크기 안내가 출력됐지만 빌드는 정상 완료했다. 배포 후 공개 메인 경로 HTTP 200 및 HTML의 0.6.68 표시, 도둑 가로 v3·세로 v4 이미지 HTTP 200을 확인했다. 모든 퀘스트 플레이를 공개 사이트에서 재실행하지는 않았다.
