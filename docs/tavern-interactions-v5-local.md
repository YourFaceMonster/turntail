# 주점 인물·팝업·마을 상점 (2026-11-02, 로컬)

후속 가로 화면 수정: 세로와 같은 방 구조로 만든 `tavern-landscape-v6.png`를 현재 가로 주점에 사용한다. [가로·세로 구조 통일 기록](tavern-landscape-v6-local.md)을 따른다. 아래 v5 가로 그림은 이전 이력으로 보존한다.

실제 기준 0.6.61. 앞선 지도 작업의 미커밋 변경과 승인 원본을 보존했다. 이번 빌드·업로드 요청은 없어 로컬 파일만 수정했다.

- 세린: 기존 은발 땋은 머리·복장·자리·포즈를 유지하면서 표정·손·명암을 손그림 카툰으로 다듬은 가로·세로 그림을 연결했다. 새 자산은 `public/prologue/tavern-serin-v5.png`, `public/prologue/tavern-portrait-v5.png`다. 이전 이미지는 보존했다.
- 세로 그림: 뒤쪽 왼쪽 벽난로를 도기·장작 선반으로 교체했다. 왼쪽 아래 벽난로는 유지하고 휴식 클릭 영역과 불빛 효과를 그 위치로 옮겼다.
- 클릭 표시: 세 인물의 클릭 영역에 테두리·대화 표시·포커스 강조를 넣었다. 벽난로와 가방에는 점선 테두리를 표시한다.
- 움직임: 그림에서 인물 상반신 영역을 클리핑한 레이어를 미세하게 움직인다. 별도 관절 리깅이나 전신 애니메이션은 아니다. 불빛·촛불의 크기/밝기 변화, 주변 그림자, 기존 김과 명암 호흡을 함께 사용한다. 모션 감소 설정에서는 정지한다.
- 팝업: 본문 아래에 붙이던 UI 대신 `document.body`에 중앙 모달을 렌더링한다. 배경을 어둡게 하고 본문 스크롤을 잠그며 Escape·닫기·바깥 클릭으로 닫는다. 탭 포커스를 팝업 안에 유지하고 닫으면 복원한다.
- 상점: 승인된 마을 지도 안에 별도 `마을 잡화점` 버튼을 추가했다. 기존 관문 승부 후 전투 준비 상태에서 열며 기존 구매 처리·영역별 재고·할인·소지 한도·저장을 사용한다. 상점 팝업을 열고 닫는 것으로 진행이나 보상은 바뀌지 않는다.
- 피오: 주점에 그대로 두고 구매 UI를 제거했다. 여우 여행자의 짧은 대화 3개를 순서대로 들을 수 있다. 저장 스키마·진행 노드 ID는 바꾸지 않았다.

생성은 승인된 turntale-cartoon-fantasy + imagegen 스킬을 적용한 내장 image_gen이다. 프롬프트 원문은 `tavern-v5-prompts.json`이다.

이번 검증: 타입 검사 통과. 대상 컴포넌트 린트 오류 0개, 기존 img 사용 경고 3개. 기존 여정·연결 컷 4개와 신규 마을 구매/저장·피오 역할 검사 2개, 총 6개 통과. Work 설정에서 브라우저 사용이 비활성화되어 실제 가로·세로 화면 조작 및 애니메이션 체감 검증은 수행하지 못했다. 빌드·원격 저장·커밋·push·배포 없음.
