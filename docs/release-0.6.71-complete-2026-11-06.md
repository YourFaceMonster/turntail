# 0.6.71 손패·대화창·프롤로그 통합 업데이트

사용자가 중단했던 커밋·업데이트를 재승인하고 손패 GPU 대응을 포함한 모든 로컬 수정의 커밋·배포를 요청했다. 공개 버전0.6.70을 확인한 후, 미게시0.6.71을 이번 통합 배포 버전으로 사용한다. 원래 pnpm@11.25.0과 잠금 파일은 유지한다.

## 변경

- 손패 SVG의 강제 backface-visibility:hidden 제거, muted 일반/스테이지 패의 SVG 내부 회색 면, 기존 손패/내부 그룹 filter·opacity 제거. 문양 색·선택 상태·부모 isolation/contain 및 애니메이션 판정 유지.
- 봇 탐색 Worker 재사용, 시간 초과/오류 대체 판단, 동시 요청·취소 분리, 여정 미니게임 전송 제외 및 복원.
- 대화는 실제 글꼴·너비·아이템 아이콘을 측정해 최대 두 줄 분량을 다음 페이지로 넘기되, 문자열에16자 강제 줄바꿈을 넣지 않는다. 폰트 로딩·회전 후에도 읽던 위치를 보존한다.
- 대화창 크기는 유지하고 본문19.5→18px, 모르 화자 이름은 본문 버튼 밖 같은 위치에 고정.
- 도둑·세린 미니게임에서 내 아바타/HP 이름/상단 프로필 클릭은 정보를 열지 않는다. 다른 모드 동작은 유지한다.
- 보상창은 동적 viewport·상하 safe-area·테두리를 포함하는 높이 제한과 내부 스크롤로 하단을 보호한다. 낮은 가로 화면의 세린 보상 이미지/여백도 조정했다.
- 프롤로그19개 사건·화자·노르문이라는 원래 목적지·붉은2·두 왕관·돌기둥 설정을 유지하며 중간 분량으로 정리:48→30개 자막, 공백 제외710→505자. 강제 줄바꿈0. 문안 prologue-moderate-2026-11-06.md. 과거 원문 보존.
- backface만 제거한 격리 비교 HTML·최소 패치는 루트 artifacts/tile-backface-check-2026-11-06에 보존하며 운영 게임에는 진단 화면을 추가하지 않는다.

## 검증

- 앞선 동일 대화/프롤로그 소스 관련10개 파일52개 검사 통과. 글꼴/폭 측정 기반 페이지·문장 보존·읽던 위치·두 미니게임 프로필 클릭 무반응·기존 저장/보상/컷씬 회귀 포함.
- 손패 관련 최신10개 검사 중8개 통과. 기존 interaction-polish-0650의 문양 color와 stage-ui의 뒷면 대비 실패2개는 이번 HEAD 로더 비교에서도 동일 재현했다. 비교 로그는 루트 artifacts/tile-backface-check-2026-11-06/current-tests.log 및 baseline-tests.log.
- 봇/손패 앞선 로컬 운영 빌드15개 통과 기록은 release-0.6.71-bot-tile-2026-11-05.md에 보존한다. 전체 테스트가 통과했다고 표현하지 않는다.
- 이번 최종 TypeScript noEmit·diff·운영 빌드5단계 통과. 라우트 정적 분류 한계 안내는 기존과 동일. 로그 ../../artifacts/release-0.6.71-complete-2026-11-06-build.log.
- Android Chrome 실기기·DevTools Layer borders·글리치 소멸·보상창 실제 화면은 미검증이다. 앞선 컴퓨터 사용은 브라우저 URL 확신 부족으로 정책 검증에서 중단됐다. backface와 합성 레이어 생성의 인과는 아직 가설이며 실기기 해결을 확정하지 않는다.

## 게시

GitHub main push 및 Cloudflare 운영 배포 진행 중. 이후 별도 빌드·배포 요청 없는 수정은 로컬만 저장하며 다음 변경 배포 버전은0.6.72부터 진행한다.
