# 0.6.13 — 도전모드 메뉴 정리

로컬 수정·빌드만 진행한다. 사이트에는 업로드하지 않는다.

- 싱글플레이의 점수형 스테이지 도전과 일반·멀티플레이의 10판 도전 선택을 제거했다. 일반모드, 아이템전1·2, RPG 모드를 제공한다.
- 도전 지도, 시작·이어하기·포기·결과 화면과 전적 탭을 앱에서 연결 해제했다. 이전 10판 아이템전의 이어하기·기록 진입도 제거했다.
- 메인 이어하기는 일반 대전·아이템전·RPG·멀티플레이를 유지한다. 스테이지 및 10판 도전 저장은 조회 대상에서 제외하며 삭제하지 않는다. 사용하지 않는 도전 저장이 손상돼도 이어하기 오류를 표시하지 않는다.
- API에서도 신규 도전 생성과 이전 도전 방의 재접속·행동을 차단한다. 이전 방 데이터는 변경하지 않으며, 접근 시 재사용할 수 없는 방 연결 포인터만 해제한다.
- 하이스코어에서 10판 합산 선택과 도전 안내를 제거하고 단판 기록을 표시한다. 이전 점수 데이터는 삭제하지 않는다. 아이템전 기록 버튼을 현재 아이템전 기록으로 안내한다.
- 도전 전용 업적 3개를 목록과 전체 업적 달성 조건에서 제외했다. 현재 업적은 일반·히든 17개와 전체 달성 1개다. 기존 저장 업적은 유지한다.
- 보유한 패·테이블 세트를 계속 선택할 수 있다. 더 이상 얻을 수 없는 도전 세트의 잠금·클리어 안내는 표시하지 않는다. 이전 보상을 복원하기 위한 저장 읽기와 RPG에서 함께 사용하는 지역 테마·아바타는 유지한다.
- 새 모드1의 싸움 공격·즉시 아이템 효과·돈 정산과 모드2 규칙을 유지한다.

검증: 일반·아이템전1·2·RPG 이어하기 보존, 도전 저장 제외와 원본 보존, 손상된 저장 분리, 실제 API의 도전 차단과 일반 친구 대전, 업적 집계·전체 달성, 메뉴·순위 표시를 확인한다. 타입 검사와 로컬 프로덕션 빌드를 실행하며 실제 화면은 사용자가 확인한다.
