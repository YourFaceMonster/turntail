# 0.6.48 · 중간 톤 직업 초상화와 세로 화면 개선

사용자가 확정한 cartoon-v4 검사·도적·성직자·마법사 이미지를 직업 선택창과 싱글플레이 미리보기에 적용한다. 기존 성인 판타지와 귀여운 카툰의 중간 비율이며, 얼굴 크기와 눈높이를 맞췄다. 이전 이미지와 생성 원본·프롬프트를 보관한다. [이미지·로컬 검증](local-0.6.48.md).

함께 포함하는 미배포0.6.47 수정: 세로 화면 유물칸 너비·문구, 낸 패의 이동·잘림, 일반모드 좌우 이름/점수, 메인/모드/이어하기/멀티 메뉴, 기본9단계와 아이템전4단계 튜토리얼. [요청별 반영·검증](local-0.6.47.md).

## 이번 게시 검증

이전 로컬 검증 이후 소스·자산28개 해시 일치를 확인했다. 0.6.47의 기능 검사7개, 0.6.48의 직업 선택 렌더·기존 회귀·CSS 검사와390/360px 세로 화면 확인은 이전 검증 기록이다. 이번에 반복 실행한 검사로 표현하지 않는다. 게임 수치와 AI 정책은 바꾸지 않았으며 모의 대전을 새로 실행하지 않는다.

최종 타입 검사와 운영 빌드는 이번 게시 과정에서 새로 실행한다. 소스 커밋·검사 결과·Sites 저장본·게시 상태와 운영 화면의 확인 범위는 워크스페이스 `artifacts/deployment-0.6.48.json`에 기록한다. 기존 사이트의 공개 범위를 유지한다.
