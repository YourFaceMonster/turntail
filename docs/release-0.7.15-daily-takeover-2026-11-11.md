# 0.7.15 · 오늘의 판: 끝나지 않은 순위 판 이어받기

사용자 보고(2026-11-11): 오늘의 판 화면에 "오늘 첫 판을 시작했어요"인데 참가 0명, 내 점수가 없음.
원인: 그날 처음 연 판만 순위 판이라, 그 판을 끝내지 못하면(나감·앱 종료·재시작) 기록이 `done=0`으로 남고 이후 판은 모두 연습판이 되어 그날은 순위에 오를 수 없었다. 운영 D1 데이터는 직접 보지 않았다.
사용자 선택: A안 — "a로해보자".

## 변경 내용
- `lib/daily-server.ts` `claimDailyAttempt`: 오늘 순위 판이 끝나지 않았으면(`done=0`) 새로 연 판이 순위 판을 이어받는다(행의 room code 교체). 예전 판은 code가 달라져 점수를 쓸 수 없다. 순위 판이 끝난 뒤(`done=1`) 판은 연습판.
- `DailyBoard.tsx`: 끝나지 않은 상태 안내 "오늘 순위 판이 아직 끝나지 않았어요. 새로 시작하면 그 판이 순위 판이 돼요", 버튼 "오늘의 판 다시 시작 →". 운영 데이터는 지우지 않았다. 기존 `done=0` 행은 다음 판이 이어받는다.
- 알려진 한계: 같은 날은 패가 같아서, 중간에 나가 패를 미리 본 뒤 다시 할 수 있다(사용자가 알고 선택).
