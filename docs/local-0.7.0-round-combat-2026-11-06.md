# 0.7.0 · 족보 자동 스킬과 판 종료 동시 정산 (로컬)

사용자 승인: 낮춘 직업별 수치, 도적 페어 이상 바닥패 확인, 한 명 손패 소진 시 일괄 정산. 버전 0.7.0으로 변경하고 로컬 커밋. 빌드·원격 push·배포는 요청 범위에 없으므로 실행하지 않는다.
시작 HEAD: c4ab6a8. 시작 시 추적·미추적 Git 변경 없음. package.json과 lib/version.ts를 0.7.0으로 맞췄으며 앱 표시는 기존 APP_VERSION 연결을 사용한다.

## 확정 규칙

효과는 제출만으로 발동하지 않고 **해당 족보로 작은 싸움에서 승리했을 때** 적립한다. 마지막 손패를 낸 족보도 포함한다. 판당 발동 제한과 수동 게이지는 새 규칙에서 사용하지 않는다.

| 승리 족보 | 검사: 무작위 1명 피해 | 마법사: 상대 각각 피해 | 성직자: 자기 회복 | 도적: 바닥패 확인 / 함정 피해 |
|---|---:|---:|---:|---|
| 페어 | 2 | 1 | 2 | 1장 / 없음 |
| 트리플 | 3 | 2 | 3 | 1장 / 2 |
| 스트레이트 | 4 | 2 | 4 | 1장 / 3 |
| 플러시 | 4 | 2 | 4 | 1장 / 3 |
| 풀하우스 | 5 | 3 | 5 | 1장 / 4 |
| 포카드 | 6 | 3 | 6 | 2장 / 5 |
| 스트레이트 플러시 | 8 | 4 | 8 | 2장 / 7 |

- 싱글은 모든 직업이 상대 각각 기본 피해 1을 적립한다. 페어 이상은 표의 효과로 대체하며 기존 누적 제출 장수 기본 피해를 더하지 않는다.
- 검사 싱글/페어 보너스, 마법사 트리플/5장/포카드 추가 피해, 성직자 두 번째 페어 추가 회복, 도적 투시 패 회수 기습·기존 자동 교환을 새 규칙에 겹쳐 적용하지 않는다.
- 검사 무작위 대상은 승리 순간 확정하고 저장한다. 적립 후 상대의 예정 HP가 0 이하여도 실제 정산 전까지는 계속 참가하고 공격할 수 있다.
- 기존 유물 효과는 유지하고 피해·회복은 같은 장부에 적립한다. 방어 유물과 방어량은 최종 합산 피해에 적용한다.

## 도적

- 페어 이상마다 아직 모르는 숨겨진 위층 바닥패를 우선 확인하고, 본인에게만 공개한다. 확인한 패는 남아 있는 동안 누적 표시한다. 남은 비공개 패가 부족하면 가능한 만큼만 확인한다.
- 트리플 이상이면 남아 있는 바닥패의 현재 표면 중 함정이 없는 곳에 무작위로 1개 설치한다. 설치 위치는 본인만 안다. 비공개 패의 숫자를 설치 위치 선택 근거로 사용하지 않는다.
- 상대가 가져가면 표의 함정 피해를 적립하고 함정을 소모한다. 본인이 가져가면 피해 없이 제거한다.
- 판 종료 시 남은 함정은 각각 무작위 상대 1명에게 피해 1을 적립한 후 소멸한다. 마지막 족보의 함정도 동일하다. 바닥패가 없거나 설치할 빈 곳이 없으면 대기 피해 1로 적립하여 마지막 기술이 무효가 되는 일을 막는다.
- 일반 AI에는 자기 손패·자기 정찰·자기 함정·공개 정보만 전달한다. 상대 손패와 숨겨진 바닥패는 새 전투 판단에도 제공하지 않는다.

## 정산과 진행

1. 진행 중 공격·함정·회복은 장부에만 기록한다. 정찰·패 교환·수호의 봉인 같은 비 HP 기능은 필요한 시점에 즉시 처리한다. 소비 아이템의 피해/회복도 같은 판 종료 정산에 포함한다.
2. 한 명이 손패를 모두 비우면 마지막 족보 효과까지 적립하고 기존 남은 손패 점수 결과와 판 승자를 먼저 기록한다.
3. 남은 함정을 정리하고 전원에 대해 `판 시작 HP - 방어 후 피해 + 회복`을 함께 적용한다. HP는 0~최대 HP 범위로 제한한다. 시작부터 HP 0인 이전 탈락자는 회복으로 부활하지 않는다.
4. 기존 주화 정산·잔고 부족 피해·전투 종료·RPG 보상/재도전 절차를 이어간다. 동시 HP 0은 기존 모드 판정(RPG 자기 HP 0 우선, 아이템전 HP/남은 손패 순위)을 따른다.
5. 새 판에서 적립·정찰·함정을 초기화하고 정산된 HP를 이어받는다. 정산 완료 표식과 기존 판 결과 ID로 중복 적용을 방지한다.

스킬 버튼·게이지 표시를 새 규칙에서 제거했다. 족보 소개 대기는 일반 패 이동 시간 650ms로 줄이고 작은 싸움별 2초 결과창과 함정 피해 대기를 없앴다. 진행 중에는 작은 적립 표시만 보이며, 판 종료에 전원 합산 HP 결과를 한 번 보여준다. 모든 기술을 순서대로 재생하지 않는다. 기존 주화 발견·패 이동의 필요한 대기는 유지한다.
직업 선택·상태·프로필·튜토리얼·아이템전 규칙을 새 설명으로 연결했다.

## 저장 호환

진행 중인 구 저장은 이미 적용한 피해·게이지·손패를 재계산하지 않고 현재 판의 이전 규칙을 유지한다. 다음 분배부터 roundRules 표식으로 새 규칙을 적용한다. 새 규칙 진행 중 저장에는 적립량·무작위 대상·함정 위력·정산 여부를 함께 보존한다. 이전 전투 기록을 새 적립으로 다시 적용하지 않는다. 직업 전투가 없는 일반/미니게임과 기존 비직업 모드는 유지한다.
옛 수동 스킬 테스트는 tests/fixtures/legacy-profession.ts를 통해 명시적으로 이전 저장 규칙을 검사한다. 실제 다음 판 전환은 새 통합 검사에서 별도로 확인한다.
