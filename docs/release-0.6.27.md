# 0.6.27 · 아이템전 주민 30명

- 새 아이템전1·2 시작 시 기존 10개 지역의 주민 30명 중 상대 2명을 중복 없이 무작위로 배정한다. 아이템전2는 내가 선택한 전투 캐릭터도 제외한다. 카드 판이 바뀌거나 저장을 불러와도 같은 상대를 유지하며, 새 대전에서 다시 뽑는다.
- 아이템전2의 플레이어 선택 화면은 기존 토토·로웬·루미 3명 구성을 유지한다. 상대 30명은 공격·방어·운영 각 10명으로 나눠 기존 효과(승리 피해 +1 / 싸움 피해 2 방어 / 승리 주화 +2P)를 공유한다. 각자의 설정에 맞춘 스킬 이름을 붙이며 횟수·사용 조건·아이템 제한·주화 정산은 기존과 같다.
- ImageGen으로 전신이 없던 토토·도담·이온·방울·브람·태엽·나비르·아스텔·베스·로제아 10명의 앉은 전신을 제작했다. 기존 전신과 초상 이미지를 참조해 화풍과 인물 특징을 유지했고, 실제 투명 알파를 보존한 WebP로 연결했다. 생성 프롬프트와 원본 경로는 `docs/assets/0.6.27-character-generation.json`에 기록했다.
- 기존 전신의 오르비·엘라 연결을 수정하고 아스텔은 새 흰여우 전신을 사용한다. 모든 30명이 고유한 전신과 같은 그림에서 가져온 아바타를 사용하며, 더 이상 누락된 주민에게 다른 사람의 전신을 대신 보여주지 않는다. 갑주·사슴·도마뱀·용·그리핀의 얼굴 구도도 다듬었다.
- 입장 장면에서 실제 배정된 상대가 사용하는 이미지 파일을 미리 불러온다. 기존 지역 미리보기와 아바타도 동일한 인물 연결을 사용한다. 도전모드 메뉴를 다시 추가하지 않는다.

## 확인

30명의 전신·아바타 파일 및 좌표, 전체 후보 도달 가능성, 무작위 중복·선택 캐릭터 제외, 양 모드의 이름·아바타 연결, 공격·방어·주화 스킬, 다음 판과 저장 불러오기에서 상대 유지, 상대 손패 비공개를 검사했다. 브라우저에서 30명 전신과 아바타, 아이템전1·2의 무작위 상대 변경을 확인했다.

기존 `regional-surfaces-0525.test.tsx`의 패 도안 `opacity="0.22"` 단언은 실패한다. 해당 도안과 테스트 단언은 이 변경에서 수정하지 않았으며, 캐릭터 렌더링/좌표 검사와 별개다.
