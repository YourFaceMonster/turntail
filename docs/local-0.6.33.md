# 0.6.33 · 아이템전 직업·함정·유물 이미지

2026-10-28 로컬 작업. 사용자 요청에 따라 **운영 빌드·소스 push·Sites save/deploy를 실행하지 않았다.** 마지막 보관 배포 기록은 0.6.32 / Sites 97이다.

## 적용 범위와 저장

새 직업 아이템전에만 `combat.itemBattle.version: 1`을 생성한다. 기존 아이템전 저장과 RPG 여정은 이전 직업 동작·자원·장착을 유지한다. 이전 저장을 읽는 것만으로 신규 규칙이나 유물을 덧씌우지 않는다. 기존 12종 RPG 유물 데이터·효과·획득 풀을 유지한다.

## 직업

- 검사: 기존 페어 피해 +1, 스트레이트 피해 +3(판당 1회)에 싱글 승리 피해 +1을 추가했다.
- 성직자: 기존 페어 회복 +1, 풀하우스 회복 +5(판당 1회)에 같은 카드 라운드 두 번째 페어 승리 시 회복 +2를 추가했다. 추가 회복은 해당 라운드에 한 번이다.
- 마법사: 기존 트리플 피해 +2, 포카드 피해 +6(판당 1회)에 첫 5장 족보 승리 피해 +2를 추가했다. 첫 포카드 승리에는 둘 다 적용된다.
- 도적: 새 아이템전에서 싱글 승리 시 숨겨진 바닥 위층 패 1장, 트리플 승리 시 2장(판당 1회)을 비공개 투시한다. 이전 상대 손패 확인·교환은 이 규칙에서 실행하지 않는다. 숨겨진 패가 없으면 투시는 발동 대상이 없다.
- 자동 투시는 아직 확인하지 않은 위층 패 중 무작위로 고른다. 렌즈는 사용자가 대상을 선택한다. 투시된 패는 그 패가 가져가질 때까지 표시한다. 아래층·외곽 접근 규칙을 유지한다.

## 도적의 함정과 렌즈

- 자기 차례에 현재 접근 가능한 바닥패 한 장에 함정을 설치한다. 카드 라운드당 한 번이며, 차례·본 행동 횟수·아이템 수량·아이템 사용 한도를 소모하지 않는다.
- 함정은 칸이 아닌 실제 패 ID에 연결된다. 위층 함정을 제거한 뒤 그 아래층으로 함정이 이동하지 않는다.
- 상대가 가져오면 그 상대에게 기본 피해 4, 설치자가 가져오면 안전하게 제거한다. 가져온 패는 정상적으로 손패에 들어간다.
- 설치 정보는 설치자에게만 표시한다. 비공개 위층에 설치했다고 그 패 내용이 드러나지 않는다. AI도 필터링된 자기 정보로만 결정하며 다른 도적의 설치 위치·사용 여부를 읽지 않는다.
- 새 라운드에는 함정·사용 횟수·정찰 정보를 초기화한다. 발동 시 설치자를 공개하고 폭발·피해 표시를 보여준다. HP 0이면 기존 규칙대로 대전을 끝내고 해당 판 돈 정산을 생략한다.
- 새 아이템전의 정찰 렌즈는 선택한 위층 또는 공개 아래층 패의 내용과 함정 유무를 확인한다. 가격 3P를 유지하며 해체하지 않는다. 탐지 정보도 사용자만 보며, AI는 자신이 확인한 함정을 피할 수 있다.
- 함정 피해는 수호의 봉인이 막는 기존 공격·교환 아이템과 별도다. 기존 유물 `금이 간 심장`의 첫 피해 감소는 적용한다.

## 아이템전 유물 목록

아이템전에서 발동할 수 있는 기존 `금이 간 심장`과 신규 7종으로 별도 목록을 구성했다. 기존의 중복 없는 무작위 3개 지급 방식을 유지한다. 목록 안 각 후보는 같은 방식으로 추첨하며 별도 직업 보정·가중치를 추가하지 않았다. 목록이 달라지므로 과거 목록과 개별 등장 확률은 다르다. 과거 진행판의 장착은 교체하지 않는다.

| 유물 | 효과 |
|---|---|
| 바람의 문양 | 페어 승리 · 상대 각각 피해 +1 |
| 전사의 문장 | 트리플 승리 · 상대 각각 피해 +2 |
| 생명의 문양 | 트리플 승리 · 자신 HP +2 |
| 태양의 문양 | 플러시 승리 · 상대 각각 피해 +3 |
| 붉은 송곳니 | 해가 포함된 족보 승리 · 상대 각각 피해 +1 |
| 구름의 축복 | 구름이 포함된 족보 승리 · 자신 HP +1 |
| 선구자의 눈 | 새 아이템전 첫 분배에만 구름 3을 시작 손패에 포함 |

유물은 승리를 확정한 마지막 족보를 판정하며, 해당 문양이 여러 장이어도 싸움당 한 번 적용한다. 서로 다른 유물과 직업 스킬은 중첩한다. 회복 상한은 100이며 실제 회복량을 표시한다. 태양의 문양은 `플러시`에 적용하고 별도 족보인 `스트레이트 플러시`에는 적용하지 않는다.

선구자의 눈은 다른 손패 또는 바닥에 있는 구름 3과 자신의 기존 패 한 장을 교체한다. 전체 패 구성·손패 수를 보존하고 기존 첫 선 판정을 사용한다. 두 번째 카드 라운드부터 일반 분배다.

## 이미지와 UI

- 내장 `image_gen`으로 신규 유물 7종과 직업 4종을 각각 개별 생성했다. 기존 이미지는 교체하지 않았다.
- 최종 게임 자산: `public/item-battle-v1/relics/*.webp`, `public/item-battle-v1/professions/*.webp`.
- 생성 PNG 원본: 체크아웃 바깥 `artifacts/item-battle-1033-originals/`. 투명 알파를 보존한 WebP 11개 합계 3,363,366바이트다.
- 프롬프트·원본·최종 경로: `docs/assets/item-battle-2026-10-28-images.json`.
- 직업 선택창에 네 직업 그림과 선택 표시·능력 설명을 추가했다. 공유 RPG 선택창의 기존 능력 설명은 유지한다.
- 유물 장착칸과 상태창은 새 유물 이름·효과·이미지를 표시한다. 싸움 결과의 유물 상세와 판 정산의 유물 회복·함정 피해를 연결했다.

## 검증

타입 검사 통과. 새 `tests/item-battle-1033.test.ts`에서 직업 특성, 마지막 족보 기준 유물 중첩, 회복 상한, 투시·함정·렌즈 비공개, 가져온 패 보존, 치명적 피해, 첫 분배 패 보존, 라운드 초기화와 저장 복원을 확인했다. 기존 직업 테스트는 이전 저장 규칙을 명시적으로 검증하며 새 규칙은 새 테스트에서 검증한다.

신규 및 관련 테스트 파일 15개가 통과했다. `hp-item-battle.test.ts`, `hp-item-mode.test.ts`는 기존 0.6.32 HEAD의 별도 비교본에서도 동일 실패를 재현했다. 각각 폐기된 바늘탄 사용과 숨겨진 구형 모드 이어하기를 기대하는 테스트다. 이번 작업에서 이 과거 기능을 되살리거나 실패를 숨기도록 기대값을 바꾸지 않았다.

실제 로컬 Home에서 직업 그림 4장의 로드, 390×700 및 844×390 선택창의 가로 넘침 없음을 확인했다. 사용자 저장을 읽거나 쓰지 않는 별도 메모리 Home 검증 화면에서 함정 설치 후 차례 유지, 렌즈의 적 함정 탐지, 함정 패 가져오기 후 손패 1장 증가와 HP 90→86, 장착 유물 3장의 그림·효과 표시를 확인했다. 브라우저 오류 로그는 없었다. 임시 검증 페이지는 검증 후 제품 소스에서 제거한다.

수치와 밸런스는 프로토타입이다. 현재 검사·성직자·마법사와 함정 피해 4는 사람 플레이로 추가 조정한다. 운영 빌드·사이트 업로드·휴대폰 실기 검증 완료를 뜻하지 않는다.

## 후속 UI 조정 · 직업 그림 확대

사용자 요청에 따라 직업 그림을 선택 카드 전체 배경으로 확대했다. 이미지는 비율을 유지해 칸을 채우고, 이름·직업 설명은 아래쪽 그라데이션 위에 표시한다. 390×844에서 네 그림의 정상 로드, 카드 218px에 이미지 영역 216px, 가로 넘침 없음을 확인했다. CSS 조정이며 새 테스트나 운영 빌드는 실행하지 않았다. 기존 이미지 원본과 게임 규칙은 유지한다.

사용자가 신규 유물 원화를 볼 수 있도록 기존 ImageGen 결과 7종을 모은 독립 미리보기를 만들었다. 체크아웃 바깥 `artifacts/item-battle-relic-gallery.html`은 이미지가 내장된 HTML이며, `artifacts/item-battle-relics-seven-preview.jpg`는 전체 미리보기다. 직업 카드 변경 화면은 `artifacts/profession-cards-full-art.jpg`에 보관했다. 임시 갤러리 파일은 제품 소스에 남기지 않았다. 사이트 업로드는 하지 않았다.

## 후속 이미지 조정 · 정면 직업 초상

사용자 요청으로 기존 네 직업 초상을 각각 내장 ImageGen으로 편집했다. 얼굴·양쪽 시선·어깨·몸통을 카메라 정면으로 맞추고 기존 인물의 머리색·의상·직업 장비를 보존했다. 검사·도적·성직자·마법사의 소품 자세는 각각 다르게 유지한다.

`public/item-battle-v1/professions/*-front-v2.webp`를 선택창에 연결했다. 기존 사선 WebP를 덮어쓰지 않았고 새 PNG 원본은 체크아웃 바깥 `artifacts/profession-front-v2-originals/`에 보관했다. 전체 편집 프롬프트·참조·출력 경로는 `docs/assets/profession-front-v2.json`을 따른다. 네 출력 모두 실제 투명 알파를 확인했으며, 390×844 실제 선택 화면에서 네 이미지가 정상 로드되고 가로 넘침 없음을 확인했다. 카드 확대 표시도 정면 세로 구도에 맞췄다. 검증 화면은 `artifacts/profession-front-v2-preview.jpg`에 보관한다. 게임 규칙 변경·운영 빌드·업로드는 하지 않았다.
