# 0.6.50 · 문양 색상·전투 연출·튜토리얼 게시

사용자 후속 업로드 요청에 따라 로컬 0.6.50을 기존 공개 사이트에 게시한다. [14개 요청별 반영](local-0.6.50.md)과 [생성 이미지·전체 프롬프트](assets/interaction-scenes-0650.json)를 따른다. 엿보는 눈은 AI의 사용과 정보 반영을 확인해 유지했으며, 13번은 사용자 정정대로 튜토리얼 패 비행으로 반영했다.

## 이번 업로드 검증

- 소스·자산 23개 SHA-256을 기록하고 Sites 소스 동기화 뒤 동일함을 확인했다.
- 브라우저 연결이 다시 가능해져 로컬 390×844 화면에서 축소된 메인 싱글 버튼, 튜토리얼 생성 배경, X의 32×32 크기와 모달 안쪽 배치, 가로 넘침 없음을 확인했다.
- 튜토리얼의 문양·숫자 선택과 싱글 제출 비행 1장, 페어 제출 비행 2장을 실제 조작으로 확인했다. 도착 뒤 ‘내가 낸 패’와 다음 단계 진행을 확인했다. 첫 4단계까지만 확인했으며 전체 9단계·실기기 진동 검증은 아니다.
- 아이템전 직업 선택창에서 검사 빨강·도적 노랑·성직자 초록·마법사 검정 배경의 실제 적용과 X가 모달 안에 있음을 확인했다. 새 대전을 시작하거나 저장을 지우지 않았다.
- 관련 검사 9개 통과·CSS 구문 검사·예전 검사 2개 실패의 변경 전 소스 동일 재현은 앞선 로컬 검증 기록이다. 이번 업로드에서 해당 기능 검사를 다시 실행한 것으로 표현하지 않는다.
- 최종 타입 검사와 운영 빌드는 이번 게시 과정에서 새로 실행한다. 소스 커밋·Sites 저장본·배포 결과·운영 확인 범위는 워크스페이스 `artifacts/deployment-0.6.50.json`을 따른다.

인게임 강타·파이어월·기습·설명창·완충 게이지·정산 배치와 전체 팝업을 이번 브라우저 확인에서 모두 재현한 것은 아니다. AI 전체 대전·실기기 모션은 이번에 새로 검사하지 않았다. 사용자 기본 방침은 계속 **별도 빌드·업로드 요청이 없으면 로컬 수정·저장만 진행**이다.
