# 주점·지도 확대와 선택 표시 (2026-11-02, 로컬)

기준 0.6.62. 이전 상단 HUD/주화 위치와 세로 지도 로컬 작업을 보존한 상태에서 사용자의 후속 요청을 반영했다. 이번 빌드·업로드·push는 없다.

- 주점과 지도는 화면 가장자리 4px 안에 그림을 크게 표시한다. 제목·자원·나가기·수첩 등은 작은 반투명 오버레이로 올려 그림이 차지하던 공간을 빼앗지 않게 했다. 기기 비율 차이는 주변 배경을 잘라 처리한다. 클릭 영역과 움직임·빛 레이어는 같은 확대 좌표계를 사용한다.
- 주점의 타원 테두리를 제거했다. 인물 상반신의 다각형 색상 하이라이트와 이름·대화 표시를 사용한다. 정밀한 알파 누끼를 새로 생성한 것은 아니다. 화면 내에서 인물 선택과 피오 대화 팝업을 확인했다. 가방·벽난로 이름은 확대 시에도 화면 안에 보이도록 고정했다.
- 지도 아래의 안내·갈림길 수치 카드·STn 승부 살펴보기 영역을 제거했다. 장소 버튼만 눌러 이동/확인한다. 갈림길의 HP·주화 수치는 장소 버튼에 표시하며 기존 해금/전투/보상 규칙을 유지한다.
- 전용 세로 지도 `public/prologue/moon-castle-map-portrait-v5.png`는 성과 마을을 앞으로 당기고 긴 하단 눈길·하늘을 줄인 새 버전이다. 성문 앞 → 성문 통과 → 성벽 안 마을 → 뒤쪽 성채 관계를 유지한다. 메뉴·여정 지도·ST3 마지막 연결 컷의 세로 참조를 연결했다. 이전 원본은 보존한다.
- TEST는 오른쪽 아래의 38×22px 정도 버튼으로 접힌다. 누를 때만 화면 선택·종료가 열리고 화면 선택 후 자동으로 접힌다.
- RPG 장착 유물에서 숨겨져 있던 조건/효과 두 줄을 복원했다. 아이템전과 같은 힌트 데이터를 사용한다. 작은 가로 화면은 아이콘을 줄여 두 줄이 들어가게 했다.
- 앞선 로컬 작업: RPG 상단과 주화 위치는 아이템전과 공유하며, 지도 상점 구매 가드는 지도/준비 상태를 허용하도록 수정했다. 저장 형식은 바꾸지 않았다.

## 이번 화면 확인

사용자가 열어 둔 로컬 인앱 브라우저 `http://127.0.0.1:5173/`에서 저장하지 않는 화면 테스트를 사용했다. 360×640·390×740 세로, 844×390 가로로 확인했다. 세로 주점의 장면 clientHeight와 scrollHeight가 같고 overflow hidden인 것을 확인했다. 최종 세로 지도 390×740에서 장면 clientHeight/scrollHeight가 모두730px이며 모든 장소 버튼의 전체 사각형이 화면 안에 있다. 피오 클릭→대화 팝업, 지도 버튼→지도, 접힌 TEST→전투 화면 선택, 유물 `첫 피해 / 피해 −8`의 실제 두 줄 표시를 확인했다. 실제 휴대전화·청감·전체 진행은 별도 미검증이다.

캡처와 지도 좌표 증거는 루트 `artifacts/ui-scene-focus/`에 있다. 세로 지도는 내장 image_gen과 승인된 turntale-cartoon-fantasy/imagegen 스킬로 제작했으며 프롬프트는 `scene-focus-map-prompt.txt`다.

타입 검사 통과. 관련 여정·상점·컷씬·프롤로그·테스트 모드·유물 검사19개 통과. 최초 실행에서 접힌 테스트 도구의 한 판 통과 설명 문구가 빠진 검사1개 실패를 확인했고, 해당 설명을 펼친 도구 안에 복원한 후 전체19개를 다시 통과했다.
