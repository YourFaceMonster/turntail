# TURNTALE 0.6.44

결투 화면과 직업 연출을 다듬고, 대전 길이를 보통 7~10판에 맞추기 위해 새 직업 아이템전 시작·최대 HP를 180으로 조정했다. 기존 이어하기와 RPG 여정은 저장된 100 HP 규칙을 유지한다.

- 결투 행 축소, 피해 숫자를 최대 HP 위에 고정하고 검은 음영 추가, 계속 버튼 중앙 정렬, 배경 그림만 반투명 처리.
- 유물창을 작게 줄여 바닥 위쪽으로 이동, 승리 패 주변의 광원 확대·일렁임 및 승리 때만 잘림 해제.
- 주화 발견과 획득자·금액을 한 번에 표시. ImageGen 금화·강타·파이어볼·치유·파이어월 5종 반영.
- 아이템전 10개 배경 테마 무작위 선택·저장, 손패 가까운 강타 대상 선택창, 오른쪽 상대 초상 반전.
- 마법사 게이지별 파이어볼→화염 파동→파이어월 연출. 경험치·레벨 추가 없이 기존 피해량 유지.
- AI가 공개 발동한 상대 유물을 기억해 다음 판단에 사용. 비공개 패·장비·지갑을 읽지 않는다.

로컬 기능 검사 19개 파일·타입 검사·모바일 화면 확인을 완료한 소스와 자산 해시 54개가 이번 게시 시작 시 일치했다. HP 비교는 앞선 로컬 단계에서 탐색 240대전과 별도 검증 256대전을 실행했다. HP180·플레이어 유물3개 별도 시드 64대전은 평균7.875판·중앙값8판·7~10판57건이었다. 이번 게시 단계에서 모의 대전이나 기능 검사 전체를 다시 실행한 결과와 구분한다.

사용자의 후속 빌드·사이트 업로드 요청에 따라 최종 소스 타입 검사와 운영 빌드를 새로 실행해 기존 사이트에 게시한다. 소스 커밋·저장본·실제 결과·실시간 확인 범위는 워크스페이스 `artifacts/deployment-0.6.44.json`에 기록한다.
