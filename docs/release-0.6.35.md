# TURNTALE 0.6.35

사용자 검토 20개 항목의 화면·설명·피드백을 반영했다. 기존 가격·피해·직업 발동 규칙은 유지한다.

- 직업 선택·상태 설명을 축약하고 효과 수치만 강조했다. 정면 캐릭터 4명의 눈높이와 얼굴 크기를 개별 기준으로 맞췄다.
- 함정 이미지를 ImageGen으로 새로 생성했다. 설치 버튼을 줄이고, 내 함정·발견한 함정 표식을 실제 패 내부 귀퉁이에 표시한다. 설치 완료·안전 회수·발동 피해·방어를 구분한다.
- 상대 이름을 왼쪽 `이름 AI`, 오른쪽 `AI 이름`으로 대칭 배치했다. 내 상태의 중복 아이템·유물 목록을 제거하고 화면 밖 상태창의 팝업 위치를 보정했다.
- 모든 재질의 태양·별 문양과 숫자 중심을 맞추고 두 자리 숫자의 폭을 조정했다. 정확한 숫자는 SVG로 유지한다.
- 이어하기에 모드별 삭제 확인을 추가했다. 선택한 진행만 삭제하며 완료 기록·해금·도감·설정·다른 모드는 보존한다. 저장 실패 시 이전 상태를 복구한다.
- 작열탄의 목표와 폭발 기준을 HP 창 아래쪽 가장자리로 옮겼다. 피해 판정과 표시 시각은 유지한다.
- 싸움 결과에서 기본 피해는 상단 식에 한 번 표시하고 각 행에는 추가 피해·방어만 짧게 설명한다.
- 회복 이름과 수치는 밝은 초록 `#4DFF88`, 주화 잔액은 금색, 정산 증감은 초록·빨강으로 구분한다.
- 별빛 상점에서 담은 상품 그림이 상품 버튼에서 구매 칸으로 이동한다. 중복·잔액 부족에는 새 이동을 실행하지 않으며 동작 줄이기를 지원한다.
- 새 아이템전의 정찰 렌즈·수호의 봉인 설명을 현재 동작에 맞췄다. 투시는 공격과 별개이며, 렌즈는 선택한 패의 적 함정도 탐지한다.

## 검증

새 저장 삭제 검사(대상 한정·완료 기록/해금 보존·변경된 저장 방어·부분 실패 복구), 폭발 좌표·간략한 피해 설명 검사와 캐릭터/SVG 조합 검사를 추가했다. 기존 함정 비공개·정찰·직업 전투·아이템·저장 호환 검사를 실행한다. 이번 실행 결과와 운영 빌드·배포 결과는 루트 `artifacts/validation-0.6.35.json`, `artifacts/deployment-0.6.35.json`에 별도로 기록한다.

로컬 브라우저에서는 실제 저장 대신 메모리 저장 검증 화면을 사용했다. 데스크톱 1280×720, 모바일 390×844 및 844×390에서 얼굴 정렬·함정 내부 표식·상대 이름·상태 팝업·회복/주화 색·상품 이동과 중복/잔액 부족 처리를 확인했다. 사용자 실제 저장은 삭제하지 않았다.

이전 0.6.32 기준에 이미 실패하던 폐기 아이템전1/불꽃 다트 기대값 2개는 이번 통과 결과에 포함하지 않는다. 기존 실패 증거는 루트 `artifacts/baseline-0632/`에 보존한다.
