# 0.6.9 — 아이템전 1·2

- 0.6.8 기반. 기존 HP 아이템전을 아이템전1로 유지하고 별도 저장의 아이템전2를 추가했다.
- 아이템전2는 시작 100P, 매판 5개 구매, 판당 2개 사용. 다음 판 준비금 30P와 실제 공격 피해·카드 승리 정산으로 얻은 포인트를 사용한다. 미사용 아이템은 다음 판에 넘기지 않는다.
- 가격: 정찰 렌즈 6P, 뒤바뀐 운명 10P, 수호의 봉인 10P, 작열탄 16P, 응급 약초 8P. AI도 같은 가격과 사용 한도를 적용한다.
- 두 아이템전 모두 첫 싸움이 끝나고 새 선을 정한 뒤 사용 가능하며 매판 제한을 초기화한다.
- 내 패 선택 후 상대를 선택하도록 교환 흐름을 변경하고, 순차 이동·받은 패 표시·교환 내역을 추가했다.
- 아이템 확대, 작열탄 상승·낙하, 도착 시 방패·피격 효과, 아이템과 다음 행동 사이 대기 시간을 추가했다.
- 결과에 HP 증감·사용 아이템을 표시하고, 이름과 HP를 확대했다. 중복 상단 HP와 아이템창 개수 제목을 제거했다.
- 일반 대전도 같은 상태창·테이블 배치를 사용하며 HP와 RPG 전용 기능은 표시하지 않는다.

검증: TypeScript 검사와 기존 HP 아이템전 테스트 통과. 화면·실제 플레이 확인은 사용자가 직접 진행한다.
