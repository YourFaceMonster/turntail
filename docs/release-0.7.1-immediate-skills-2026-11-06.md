# 0.7.1 · 스킬 즉시 적용·정산창 통합 배포

사용자 요청으로 수정·검증·운영 빌드·GitHub push·Cloudflare 배포를 모두 수행했다. 배포 전 공개 버전0.7.0을 확인하고 package.json·lib/version.ts·앱 표시를0.7.1로 맞췄다.

## 반영 내용

- 먼저 표시하던 ‘판 전체 정산’ 리뷰를 제거하고 기존 ‘이번 판 정산’만 사용한다.
- 검사/마법사 공격·성직자 회복·도적 정찰/함정을 발동 즉시 적용한다. 도적은 페어 이상 승리 때 바로 본인에게만 숨겨진 바닥패를 누적 공개한다. 함정을 밟은 피해도 즉시 반영한다.
- HP0 즉시 탈락과 RPG/아이템전의 기존 종료 조건 유지. 싱글 기본 패 피해와 손패 점수/주화만 실제 손패 소진 시 정산하고 이미 반영한 스킬을 다시 적용하지 않는다.
- 기존0.7.0 진행 중 저장은 현재 판의 큐 정산을 보존하고 다음 분배부터 새 규칙으로 바꾼다. 상세 [명세와 이번 검증](local-0.7.1-immediate-skills-2026-11-06.md).
