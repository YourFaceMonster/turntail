# 0.6.31 · 로컬 수정 기록

최초 수정 시 사용자 요청에 따라 운영 빌드·소스 푸시·사이트 배포 없이 로컬에서 검증했다. 이후 사용자의 사이트 업로드 요청으로 이 수정본과 첨부 BGM을 0.6.31 배포 대상으로 확정했다. 빌드·배포 성공 여부와 URL은 체크아웃 바깥 `artifacts/deployment-0.6.31.json`에 별도로 기록한다.

추가 요청한 첨부 MP3를 `public/audio/table-suno-0631.mp3`에 원본 그대로 저장하고 인게임 `table` BGM으로 연결했다. 일반·아이템·RPG 등 플레이 중에 반복 재생하며 기존 음악 켜기/끄기·볼륨·상황별 음량 조정·백그라운드 일시정지를 유지한다. 메뉴와 승패 결과 음악은 기존 곡을 사용한다.

- 작열탄: 새 게임 입장에만 있던 이미지 사전 준비를 공통 경로로 옮겼다. 이어하기도 이미지 준비를 시작하고, 사람/AI의 아이템 사용은 이미지 디코딩이 완료된 뒤 수량을 소비하고 비행 시계를 시작한다. 디코딩된 이미지를 유지하고 동시 요청을 공유한다. 로드 실패는 아이템 사용 전에 중단하며 재시도할 수 있다. 아이템을 쓰지 않는 AI 차례는 로딩에 묶지 않는다.
- 동작 줄이기 설정: 작열탄을 대상 위치에 바로 나타나게 하던 처리를 제거했다. 회전·확대 없는 완만한 직선으로 같은 충돌 시점에 도착한다. 기존 HP 감소·방패·폭발 공유 시계는 유지한다.
- 바닥패: 각 버튼에 원래 인덱스의 행·열을 직접 부여한다. 빈 세 번째 줄도 칸을 유지하며, 남은 패를 가운데로 다시 모으지 않는다.
- 약초: 숫자를 진한 초록 `#277a49`로 조정하고 밝은 외곽선과 어두운 그림자를 추가한다. 회복 표시와 상태창의 초록빛 효과는 유지한다.
- 상점·정산: 내장 이미지 생성 도구로 새 배경 두 장을 제작했다. 상점은 목재 진열대·약병·등불, 정산은 주화·장부·깃펜 테두리다. 중앙은 어둡게 두고 기존 조작·수치를 코드로 표시한다. 모바일 및 가로 화면에 맞춰 높이와 배경을 조정한다.
- 정산: HP 피해 숫자만 빨강, 아이템·직업 스킬 회복 숫자만 초록으로 굵게 표시한다. 나머지 설명과 주화는 보통 굵기다. 주화 부족으로 인한 피해는 두 번째 주화 줄에 `주화 부족 2P → HP −2`로 표시한다. 첫 번째 HP 피해 줄에서 중복 표시하지 않는다.
- 수호의 봉인: 내 상태창의 아바타 위에 겹치던 표식을 HP 숫자 뒤로 옮겼다. 사용 시 사라지는 기존 방어 상태는 유지한다.

이미지 경로와 전체 생성 프롬프트는 `docs/ui-backgrounds-0.6.31.md`에 기록했다.

## 검증

타입 검사와 관련 테스트 14개 통과. 새 테스트는 이미지 실패/재시도, 동시 디코딩과 재사용, 동작 줄이기 비행 경로를 확인한다. 기존 누적 패 피해·주화 정산·직업·저장·교환·HP 연출·레이아웃 테스트도 통과했다.

사용자 저장 대신 메모리 저장소를 둔 실제 Home 화면에서 이어하기 후 왼쪽 AI → 내 상태창 공격을 재현했다. 최초 기록 프레임부터 이미지가 로드되어 있었고, 비행 좌표와 피해 표시를 확인했다. 세 번째 줄 마지막 패를 실제로 가져오기 전후 바닥 15칸의 위치와 크기가 전부 같았다. 봉인 표식은 HP 줄의 인라인 이미지이며 아바타와 겹치지 않았다.

390×700, 844×390, 1100×700 상점·정산을 확인했다. 휴대폰 정산에서 세 캐릭터·내역·접힌 기록·버튼이 보이고, 일반 높이에서 내부 스크롤 없이 표시된다. 낮은 가로 화면에서는 정산창을 스크롤할 수 있다. 구매 상점의 한 줄 상품·고정 창 크기·중복 구매 제한은 유지한다.

스크린샷과 브라우저 측정은 체크아웃 바깥 `artifacts/ui-0631-preview.png`, `artifacts/validation-0.6.31-browser.json`에 저장했다. 검증용 임시 페이지와 메모리 저장 게임은 제품 소스에서 제거했다.
