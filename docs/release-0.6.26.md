# 0.6.26 · 로컬 빌드 확인용

사이트에는 배포하지 않는다. 현재 배포본은 0.6.25를 유지한다.

- 상점 바깥 창의 높이와 너비를 고정하고 본문만 스크롤한다. 구매 목록과 오류 표시 영역을 미리 확보해 담기/취소 때 창이 늘어나지 않게 한다.
- 상점에 ‘내 아이템’과 ‘이번 구매’를 구분해 수량을 묶어 표시한다. 보유 수량은 무제한이며 구매 가능한 주화만 검사한다. 판당 사용 한도 2개는 유지한다.
- 현재 아이템전2의 싸움 피해는 승자가 이번 싸움에서 실제로 낸 패 수 누적으로 계산한다. 싱글 2번은 2, 페어 2번은 4, 5장 조합 2번은 10이다. 승자가 다른 두 명에게 각각 피해를 주며 고유스킬 공격/방어 보정은 유지한다. HP 피해 주화는 계속 지급하지 않는다.
- 제출 수는 새 싸움과 새 판에 초기화하고 저장에 보존한다. 예전 중간 저장은 남아 있는 공개 제출 로그로 복구하며, 해당 로그가 없는 경우 마지막 테이블 조합을 최소값으로 사용한다. 옛 테스트 규칙 2/3의 고정 족보 피해는 보존한다.
- 일반 싸움은 마지막 동작 후 1.25초에 승자 안내·충격을 보여주고, 2.6초에 클릭 확인용 피해 결과를 보여준다. 마지막 패나 HP 0으로 판이 끝났다면 중간 싸움 결과는 건너뛰고 판 정산으로 진행한다.
- 아이템 잠금은 첫 판의 첫 싸움에만 적용한다. 두 번째 판부터 상점/패 배분 연출이 끝나면 첫 선도 사용 가능하다. 엿보는 눈은 상대 선택만 필요하며 내 패 선택은 필요하지 않다.
- 상대 HP의 현재값과 최대값 글자 크기를 같게 하고, 좁은 화면에서도 최대값을 표시한다.
- 2층 투시는 반투명한 평면 패로 구분한다. 상대 손패 미리보기는 입체 음영·테두리 면·변형을 제거한다. 열람 정보는 기존처럼 사용한 사람에게만 공개한다.
- 제출 패 자리는 5장에 맞춘 크기로 미리 확보하고 제목 높이·착지 행을 고정해 조합이나 차례 변경 시 위아래로 재배치되지 않게 한다.
- 작열탄은 기존 생성 이미지를 유지하면서 크기를 줄이고 추가 고리·과도한 확대·그림자를 덜어 충돌을 정리한다.

검증: 누적 피해(싱글·페어·5장 조합), 스킬 보정, 새 싸움 초기화, 마지막 싸움, 첫 판 잠금과 다음 판 첫 선 사용, 패 선택 없는 엿보는 눈, 29개 인벤토리 구매와 가격, 중간 저장 복구, 기존 전투·주화·아이템·스킬·레이아웃 회귀 검사. 브라우저에서 상점 담기 전후 같은 창 크기, 보유 수량 표시, 투시 투명도, 손패 미리보기 평면 스타일, 승자 안내 후 결과 표시, 마지막 싸움 결과 생략을 확인한다.
