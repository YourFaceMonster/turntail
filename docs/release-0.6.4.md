# TURNTALE 0.6.4

## 가로 화면

- 위쪽 왼쪽: 상대 캐릭터 창을 가로로 배치하고 그 아래 바닥 패 표시.
- 위쪽 오른쪽: 내 패, 추천 조합, 제출/가져오기 버튼.
- 아래쪽 전체: 제출자와 족보, 낸 패 최대 5장을 한 줄로 표시.
- 바닥 및 낸 패의 크기는 손패 증가와 독립적으로 유지. 세로 화면 구성 유지.

## 업적 초안 · 일반 16개 + 히든 4개

메인 메뉴와 게임 상단의 메달 버튼에서 업적 수첩을 연다. 전체/도전 중/달성/히든 필터와 진행률을 표시한다. 달성 시 알림을 차례로 표시한다. 히든 업적은 달성 전 이름·조건·진행률을 표시하지 않는다.

| 일반 업적 | 조건 |
| --- | --- |
| 이야기의 첫 장 | 유효 라운드 1판 완료 |
| 첫 번째 빈손 | 첫 승리 |
| 승부의 감각 | 누적 10승 |
| 늘 앉던 자리 | 누적 25판 완료 |
| 세 번의 흐름 | 3연승 |
| 어떤 자리에서도 | 2·3·4인전 각각 1판 완료 |
| 둘이서 한 수 | 페어 누적 10회 제출 |
| 셋의 약속 | 트리플 제출 |
| 이어지는 이야기 | 스트레이트 제출 |
| 같은 빛으로 | 플러시 제출 |
| 빈틈없는 한 패 | 풀하우스 제출 |
| 넷의 위력 | 포카드 제출 |
| 백 장의 선택 | 누적 100장 제출 |
| 여정의 문턱 | 스테이지 1 클리어 |
| 여정의 한가운데 | 스테이지 5 클리어 |
| 마지막 전설 | 스테이지 10 클리어 |

히든의 명칭과 조건은 `lib/achievements.ts`에서 관리한다. 일반 안내에서는 공개하지 않는다.

## 집계 및 저장

- 싱글, 도전, 친구 대전에서 본인의 행동과 유효 결과를 집계한다.
- 유효 라운드 종료 시에만 업적과 누적값을 확정한다. AI 대체 무효 결과는 제외한다.
- 손패 동작과 결과를 중복 집계하지 않는다. 같은 저장판을 다시 열어도 업적이 중복되지 않는다.
- 브라우저 로컬 저장. 기기 간 자동 동기화는 제공하지 않는다.
- 이전 전적 전체의 역산은 하지 않는다. 설치 후 관찰한 판부터 기록한다.
- 이미 진행 중인 판은 관찰한 제출 행동만 반영한다. '가져오기 없이 승리'는 첫 배분부터 관찰한 판에서만 인정한다.

## 검증

- 업적 이벤트/결과 중복, 저장 복구, 무효 제외, 중간 입장, 가져오기, 연승, 친구 좌석, 스테이지 단계, 히든 조건 비노출 테스트.
- 가로 화면 높이·행 배치와 손패 증가 시 바닥 크기 유지 테스트.
- TypeScript 및 프로덕션 빌드.
