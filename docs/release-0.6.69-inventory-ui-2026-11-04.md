# v0.6.69 공통 UI·보관 한도 후속 업데이트 — 2026-11-04

사용자 승인에 따라 수정·커밋·빌드·GitHub/Cloudflare 업데이트. Sites 사용 없음.

- 소문 수첩을 주점 하단 기본 UI 첫 슬롯에 통합. 아바타 전체 표시 및 이름/직업 추가.
- 지도에는 장소 이름만 표시하고 상태는 접근성 레이블/비활성 표현 유지. 잡화점 이름은 의미 단위로 줄바꿈, 생략 제거.
- 소모품 전체/동일 아이템 수량 무제한, 반복 구매 시 매번 정상 차감. 유물은 종류별 하나, 전체 보관 무제한, 장착 최대3. 보상 때문에 기존 유물을 버리지 않음.
- 대화/선택지 글씨 약1.5배, 페이지 분할. 기본 HUD를 이벤트에도 유지하고 대화는 하단 UI 위로 제한. 별도 돌아가기 버튼 제거.
- 로고 클릭 후 확인/취소를 거쳐 메인 이동. 장소 전환 시 그림을 미리 읽고 중복 부모 페이드 제거.
- 파수탑 등잔/유리 빛 위치를 실제 이미지와 cover 크롭 좌표에 맞춤.
