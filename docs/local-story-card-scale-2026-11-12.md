# 이야기 패 — 일반 카드 실물 크기로 수정 (로컬)

사용자 최신 지시: 특별 패도 일반 트럼프 카드 크기로 통일한다. 이전 교정은 짧은 변을 유지하며 높이를 늘려 여전히 큰 판처럼 보였다. 이번 기준은 약63×88mm, 폭:높이 약0.72이며 손바닥·엄지·책·제단과의 비례로 판단한다. 그림 속 실물의 수치를 직접 측정할 수는 없으므로 이는 제작 기준이다.

승인한 왕관·철문·성화·열쇠 문양, 숫자2, 상아색과 금색 장식은 유지한다. 폭과 높이를 함께 줄이고 가장자리를 얇게 표현한다. 일반 승부 패와 돌기둥 문장은 변경하지 않는다.

## 적용 범위

- 프롤로그·ST3 가로/세로 7쌍(14장): `public/prologue/*-special-v3.png/.webp`.
- 성화·열쇠 앞뒤, 진엔딩 기록·마을, 마지막 전달(7장): `public/story/*-portrait-special-v2.png/.webp`.
- 공통 경로 목록: `lib/rpg-story-card-art.ts`. 승인한 독립 앞뒤 그림과 도감은 디자인 참조 원본으로 보존한다. ST3의 문양을 살피는 확대 오버레이는 실물 크기를 표현하는 그림과 구분되는 기존 연출을 유지한다.

원본과 이전 버전은 덮어쓰지 않는다. 생성 원본도 보존한다. [프롬프트·참조·출력·재시도 기록](../artifacts/story-card-scale-2026-11-12/manifest.json), [파일 검증](../artifacts/story-card-scale-2026-11-12/validation.json). `compare-01.jpg`부터 전후 비교, `browser/`에는 실제 컷씬 컴포넌트/CSS의 가로·세로 캡처를 보존한다.

## 이번 검증

- PNG/WebP21쌍의 캔버스 크기·압축 파일 열기 통과. 생성 도구의 1~2px 출력 오차만 원래 캔버스로 정규화했으며 실제 패 수정은 모두 이미지젠으로 수행했다.
- 최종21장 원본 비교와 접촉 시트 육안 확인. 잘못된 참조 배경을 복사했거나 제단 패가 큰 생성본7장은 재생성하고 탈락 이력을 manifest에 보존했다.
- 실제 `ProloguePicture`와 CSS를 SSR한 로컬 페이지를 Edge headless에서390×844·844×390으로28회 캡처. 현재 이미지 경로·자연 크기·cover/contain 선택 검증, 캡처28장 육안 확인. 이는 컷씬 표시 검증이며 전체 게임 진행이나 공개 사이트 실시간 확인은 아니다.
- 관련7파일33검사 통과(실패0, 건너뜀0): `tests.log`.
- `tsc --noEmit` 통과: `typecheck.log`.
- 브라우저 실행 기록: `browser.log`, `browser-report.json`, `browser-sheet-0.jpg`~`browser-sheet-3.jpg`.
