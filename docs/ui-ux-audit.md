# TURNTALE UI/UX 점검 — 1차 정적 점검 / 실제 화면 검증 대기

## 상태와 작업 기준

- 지시서의 참고 버전은0.6.49. 로컬 기록상 마지막 공개본은0.6.50 / Sites109이며, 현재 소스는 이전 요청의 미커밋 변경을 포함한0.6.51이다. 이번에 원격 배포 상태를 새로 조회한 것은 아니다.
- 기존0.6.51 작업을 보존하며0.6.49로 되돌리지 않는다. 이번 점검에서 앱 코드·CSS·이미지·버전·게임 수치·저장 구조를 변경하지 않았다.
- 이번 범위는 기본모드·아이템전의 기존 UI 품질 점검. RPG 수정/통합, AI 전략, 규칙·아이템 가격/효과·직업 수치·HP/주화 정산·유물·메인 메뉴 구조 변경은 제외한다.
- **브라우저 도구가 `Local browser use is disabled in Work settings`를 반환했다. 실제 화면에서 문제를 재현하기 전 수정하지 말라는 지침에 따라, 미확인 후보를 확정 버그로 취급하거나 앱을 수정하지 않았다.** 브라우저 활성화 확인을 요청한 상태다.

## 정적 점검 결과 — 실제 화면 판정과 구분

| 우선순위 / 항목 | 코드·자산에서 확인한 사실 | 실제 검증 및 처리 |
|---|---|---|
| P1 직업 선택 | `RpgProfessionPicker`는4직업을 유지하고 `aria-pressed`, 선택 체크, 별도 상세 영역을 표시한다. `combat-refinements.css`에는 기본4열/600px 이하2열이 이미 존재. `profession-cartoon-0648.css`는 낮은 가로 화면에서 얼굴 기준 크기를52px로 줄임 | 2×2를 새로 무조건 적용하지 않음. 가로4열의 이름·설명·얼굴/모자 잘림은 실제 확인 필요 |
| P1 규칙 펼치기와 시작 버튼 | `HpItemLobby`의 규칙은 기존 `details`, 시작 버튼은 같은 모달의 뒤쪽에 있음. 메뉴 모달의 최대 높이와 스크롤 선언이 존재 | 스크롤로 시작 버튼까지 닿는지, 닫기 버튼과 충돌하는지는 미확인 |
| P1 아이템 상점 | 이름·가격은 실제 텍스트이며 가격을 별도 표시. 헤더/본문/결제 영역이 나뉘고,700px 이하와 낮은 가로 화면의 별도 그리드 규칙 존재. 본문에 고정 높이 행과 `overflow:hidden` 조합이 있음 | 짧은 가로 화면에서 설명·장바구니가 잘리는지 우선 재현 대상. 현재는 후보이며 수정하지 않음. 가격·효과·구매/보유 제한 미변경 |
| P1 정보 우선순위 | `lib/layout.ts`의 손패/바닥/낸패 크기 계산과 고정 영역 규칙 존재. 유물 독·상태·스킬은 별도 요소. `hp-item-mode`와 `classic-mode`로 향후 수정 범위를 한정할 수 있음 | 실제 점유 면적·터치 순서를 재기 전 유물칸이나 테이블 재배치 금지. `.rpg-mode`만으로 범위를 잡으면 RPG에도 적용될 수 있으므로 새 공통 스타일 변경 시 주의 |
| P1 공격·회복·패시브·유물·연속 효과 | 직업 효과는 상태창 좌표를 대상으로 하며 피해/회복 텍스트가 구분됨. 유물 알림은 별도 포털, 결투 확인과 주화 연출은 별도 대기 흐름을 사용 | 코드의 분리는 실제 겹침이 없다는 증거가 아님. 실제 연속 발동을 재현하고 대상·최종 HP·안내 순서를 기록할 때까지 연출을 추가/변경하지 않음 |
| P2 로고 | 실제 자산 `public/turntale-wordmark-v035.png`를 열람. 원본 첫 글자에서‘ㅌ’의 중간 가로획과 받침을 구분할 수 있음. `TurntaleWordmark.tsx`는 이 자산을 기존 SVG 뷰박스로 표시 | 원본에 획 누락을 확정할 근거가 없어 유지. 작은 모바일 가로 화면에서‘던’으로 읽히는지는 미확인 |
| P2 설정 문구 | 현재 `app/`, `lib/`에서‘커짐’ 없음. `GameSettings.tsx` 배경음·효과음·진동은‘켜짐/꺼짐’ | 오타 수정 없음. 실제 렌더링까지 확인한 것은 아님 |
| P2 이어하기 | 저장 없음이면 `disabled={!p.canResume}`와 안내 title이 있고, 새 게임과 다른 클래스/클릭 경로를 사용 | 버튼 구성·메뉴 구조 유지. 비활성 대비와 새 게임/이어하기 시각 구분은 실측 필요 |
| P2 아이콘·모달 X | 메인 하단 아이콘에 여러 화면별 크기 선언이 존재.0.6.50 공통 모달 X는32×32px 선언 | 선언값을 실제 터치 영역으로 단정하지 않음. 다른 미디어 규칙·자식 요소·클리핑이 적용될 수 있어 실측 뒤에만 조정 |
| P2 패 터치와 숫자 | `tileNumberGeometry`는10~15에33px, 한 자리에50px를 지정. 문양은 별도 요소. 레이아웃·문양 보존의 계산/렌더 검사 통과 | 숫자의 시각적 상대 크기는 확인 후보. 실제 가로 화면에서 비교하기 전 확대하지 않음. 클릭 후 바닥 이동·페이지 오류도 재현/로그 없이 버그로 확정하지 않음 |
| 유지 영역 | 메인 배경·버튼 구조, 싱글 내부3모드, 원목 테이블, 카툰 자산, 업적 진행률, 기록실 순위/필터/메달, 튜토리얼 구조, 영문 장식은 유지 | 메인 아이템전 버튼 추가·리디자인·RPG 이식 없음 |

## 이번 실행한 검사

원문과 CSS 위치/조건별 선언94건은 [정적 점검 기록](../../artifacts/ui-ux-audit-static.json)에 있다. 아래 결과는 이번 실행 결과다.

1. `landscape-064.test.ts` — 가로 화면의 계산상 패/조작 영역 적합성 통과.
2. `layout.test.ts` — 인원·패 수·가로/세로 조건의 크기 계산 통과.
3. `tile-art-065.test.tsx` —10재질·4문양·한/두 자리 숫자의 벡터 속성 검사 통과.
4. `tile-original-ornament.test.tsx` —기존 문양 원본 보존 검사 통과.

이 검사는 실제 CSS 최종 계산값, 모바일 렌더링, 손가락 터치, 시간순 애니메이션을 검증하지 않는다. 기존0.6.51의 타입/CSS/관련8개 검사 기록은 이전 작업 결과이며 이번에 새로 실행한 것으로 표시하지 않는다. 빌드·사이트 게시·원격 저장은 실행하지 않았다.
