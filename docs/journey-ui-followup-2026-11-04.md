# 맵·주점·대화·잡화점 후속 UI · v0.6.69 로컬

사용자가 남아 있다고 확인한 UI 수정 전부를 이번에 로컬 반영했다. 기존 문양·세계관·파수탑 수정과 미커밋 작업은 보존했다. 빌드·커밋·push·배포는 실행하지 않았다. 가방 내용/장착/소모품 동작은 보류 합의대로 변경하지 않았다.

## 화면

- 맵과 주점은 공유 `JourneyHud`와 `JourneyDock`을 사용한다. 로고는 왼쪽, 영역/현재 장소는 중앙, 저장/설정은 오른쪽. HP 표시 안에 기존 플레이어 아바타를 배치하고, 별도 아바타 메뉴/전적은 추가하지 않는다. 실제 저장/설정 콜백을 두 화면에 연결했다.
- 그림 위에 얇은 그라데이션 UI가 겹친다. 세로 지도는 그림과 선택 지점이 같은 크기로 확대되어 화면을 채운다. 가로는 장소가 잘리지 않도록 기존 비율 유지. 하단 MAP/기존 가방/장착 유물 구성은 공통이다. 주점의 중복 가방 표식은 숨기고 같은 가방 팝업을 공통 하단 버튼으로 연다. 소문 수첩은 별도 작은 버튼으로 유지한다.
- 앞서 생성한 주점/잡화점 건물이 있는 가로/세로 지도를 연결했다. 검은 소나무 파수탑은 보존한다. 주점은 술잔 PNG, 잡화점은 가죽 가방 PNG로 표시하고 선택 지점/경로를 그림에 맞췄다. ST3 마을 전경과 여정 시작 배경도 같은 지도 계열로 맞췄다.
- 주점·퀘스트 대화창은 세로290px, 짧은 가로174px의 고정 크기다. 폰트15px/같은 줄 간격, 왼쪽 정렬. 긴 대사는 문장/단어 경계로 분리하며 문자 누락 없이 다음 페이지로 넘긴다. 페이지의 원본 인덱스를 유지해 화자/그림이 잘못 넘어가지 않는다. 마지막 페이지에서만 선택지/결과 행동을 보여준다. 선택지는 옅은 배경/테두리로 구분하고 페이지를 넘겨도 대화창 크기는 유지한다. 다음 버튼이 사라질 때 키보드 포커스도 대화창에 유지한다.
- 잡화점은 이미지/가운데 정렬 이름 · 설명 두 줄 · 가격 · 구매의 네 칸을 유지한다. 상품 행은54px로 통일. 긴 설명은 두 줄 이후 생략하며, 이름이나 설명을 누르면 원문 전체와 가격을 기존 팝업으로 확인한다. 가격 계산/구매/해금/수량/효과는 변경하지 않는다.
