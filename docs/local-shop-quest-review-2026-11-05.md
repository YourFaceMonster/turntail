## 변경

- 기존 도둑 가로 v4 / 세로 v5 원화를 직접 편집해 인물·배경·상자·카메라 구도를 유지한 편지 회전 형상 컷 v2를 생성했다. 기존 확대 구도의 spin-v1과 승인 원본은 보존했다. 가로1672×941, 세로941×1672로 원본과 같은 크기. 두 컷의 카메라 확대 애니메이션을 해제해 전환 시 독립 줌을 방지했다. built-in image_gen의 입력·전체 프롬프트·생성 원본·프로젝트 출력은 art-generation-thief-matched-frame-2026-11-05.json.
- 세로 대화창의 하단 앵커와 선택지 크기를 유지하면서, 대사 두 줄+화자에 맞춘 72px 텍스트 영역과 내용에 필요한 높이만 사용한다. 빈 설명/선택지 예약 공간을 제거했다.
- 운명력 보석을 확대하고 대비·밝기를 높였다. 아바타 위에 걸치는 작은 어두운 받침에 3개를 표시하고 소모된 칸은 흐리게 유지한다.
- 퀘스트 대사와 선택지에서 카탈로그 아이템명을 굵게 표시하고 실제 아이템 이미지를 인라인으로 붙인다. 일반 프롤로그 대사는 기존 표시를 유지한다.
- 잡화점 상품 보유 수량을 이름 아래에서 가격 아래로 이동. 고정 제목 밑에 보유/구매 예정 소비 아이템·유물 두 줄을 표시한다. 소비 아이템과 유물 상품 영역은 세로에서 각각 위/아래 절반씩, 가로에서는 나란히 독립 스크롤한다. 팝업 전체 스크롤은 제거했다.
- 구매 버튼은 목록 담기, 예정 물품의 −는 1개 취소, 비우기는 전체 취소다. 합계/구매 후 잔액과 최종 구매 확정을 하단에 고정한다. 확정 전에는 주화/보유 수량을 변경하지 않는다. 닫을 때 미확정 목록은 버린다.
- 최종 구매는 순차 가격·첫 구매 할인·재고·중복 유물·해금·잔액을 모두 검증한 새 상태를 한 번에 적용한다. 실패 시 원래 상태를 유지한다. 기존 단품 구매 호출과 아이템전은 유지한다.
