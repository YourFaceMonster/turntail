# 0.6.62 · 승인 성 지도·주점 상호작용·마을 상점

사용자 빌드·기존 사이트 업로드 요청에 따라 현재 로컬 변경을 게시한다. 성 밖 비석 → 큰 성문 → 성벽 안 마을·광장 → 뒤쪽 성채가 이어지는 승인 지도 v3를 사용한다. RPG 메뉴·여정 지도·ST3 연결 컷에 적용하고 장소 위치를 맞췄다.

- 세린 표정·손·명암을 손그림 카툰으로 다듬었다. 세로 중복 벽난로는 뒤쪽 선반으로 교체하고 왼쪽 아래 벽난로를 휴식 위치로 연결했다.
- 최신 가로 주점은 세로와 같은 방의 넓은 구도로 구성했다. 클릭 영역·인물 움직임 레이어·불빛·촛불·그림자를 각 그림에 맞췄다. 모션 감소 설정에서는 정지한다.
- 인물의 클릭 테두리와 대화 표시를 추가하고 대화/정비/휴식을 화면 중앙 팝업으로 열도록 했다.
- 상점은 지도 속 마을 잡화점으로 분리했다. 기존 재고·할인·소지 한도·구매·저장을 사용하고 피오는 주점에서 이야기하는 인물로 남겼다. 진행·보상·저장 형식은 유지한다.

상세 자산·생성 프롬프트·로컬 이력은 castle-map-local.md, tavern-interactions-v5-local.md, tavern-landscape-v6-local.md를 따른다. 이전 그림·원본은 보존한다. 실제 사이트 배포 상태와 이번 검증/빌드 결과는 루트 artifacts/deployment-0.6.62.json에 기록한다. Work 브라우저 사용이 꺼져 있어 실제 게임 화면 조작·모바일 기기·청감은 이번에 미검증이며 HTTP 응답이나 배포 성공으로 대신하지 않는다. 이후 별도 빌드·업로드 요청 없는 수정은 다시 로컬 저장만 한다.
