# TURNTALE 0.6.43

아이템전 AI가 최종 순위와 생존을 목표로 패·스킬·아이템·바닥 취득을 함께 판단하도록 보강했다. 사용자 요청에 따라 미배포 0.6.42 화면 수정도 함께 기존 공개 사이트에 게시한다.

- 불리한 상황의 2등 확보와 1등 역전을 비교하고 선·응수 모두 자기 직업의 추가 피해·회복·누적 제출 피해를 반영한다.
- 게이지 보존, 회복 후 공격 등 스킬·아이템 순서, 확인한 함정 회피와 직업 투시 회수 피해를 평가한다. 하나씩 실행하고 실제 결과를 받아 다시 판단한다.
- AI 상점은 자기 예산·보유품·HP·직업·손패와 지갑 여유를 고려한다. 게임 가격·효과·주화 보상 수치는 유지한다.
- 결투창은 n번째 결투·승자·족보와 피해·패자 순서로 표시한다. 낸 패의 승리 빛, 새 ImageGen 배경, HP 변화량 정렬, 아이템 이름 외곽선, 강타 효과, 작열탄 밑변 정렬을 포함한다.
- 자동 판 준비금을 제거하고 시작 20P와 기존 지갑·보유품을 유지한다. 아이템은 매 라운드 첫 결투가 끝난 뒤 사용할 수 있다.
- 작은 족보 첫 안내는 2초, 결투 승리 연출은 2초로 조정했다. 손패 회색 필터·포커스 스크롤로 인한 판 이동 경로도 보완했다.

관련 검사 17개 파일·타입 검사는 앞선 로컬 작업에서 통과했다. 별도 시드 평가 288대전과 대조 96대전에서 신규 AI의 1등은 37.5%, 3등은 30.6%였으며 대조군은 각각 33.3%였다. 제한된 전원 AI·유물 제외 비교이므로 실제 체감 난이도나 직업 밸런스를 확정하지 않는다.

패키징에서 최종 소스 타입 검사·운영 빌드를 새로 실행한다. 소스 커밋·저장본·게시 결과는 워크스페이스 `artifacts/deployment-0.6.43.json`에 기록한다. 이전 로컬 화면 검증의 한계와 실제 배포 성공은 구분한다.
