# 0.6.16 — 새 아이템 그림체 통일

엿보는 눈과 바늘탄의 SVG 아이콘을 이미지 생성으로 제작한 투명 배경 일러스트로 교체했다. 기존 작열탄·수호의 봉인을 스타일 참고 이미지로 사용해 금속 질감, 금색 잎 장식, 버건디 포인트, 굵은 갈색 테두리와 입체적인 명암을 맞췄다.

- 바늘탄: 은청색 바늘 끝과 금색 장식, 붉은 손잡이·깃을 가진 작은 투척 무기.
- 엿보는 눈: 금색 눈 모양 장식과 청록색 보석 홍채를 가진 정찰 부적.
- 생성 원본 PNG를 프로젝트에 보관하고 투명 알파를 유지한 512px WebP로 웹에 제공한다. 기존 SVG는 보관하며 실제 화면은 새 파일을 사용한다.
- 공통 아이템 이미지 경로를 교체해 시작 안내·가방·상점·선택·사용 연출·결과 내역에 함께 적용한다. 진행 중인 저장도 아이템 식별자가 같으므로 새 이미지가 표시된다.
- 두 아이템의 효과·가격·초기 지급 수량은 그대로다.

내장 image_gen 사용. 정확한 프롬프트와 참고 파일은 [생성 기록](assets/0.6.16-item-art-generation.json)에 저장했다. 원본·WebP의 투명 알파와 모서리, 실제 파일 및 로컬 응답, 타입 검사와 프로덕션 빌드를 확인한다. 사이트 업로드는 하지 않는다.
