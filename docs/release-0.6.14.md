# 0.6.14 — 아이템전1 캐릭터 고유스킬

로컬 개발·빌드 전용. 사이트에는 업로드하지 않는다.

## 캐릭터와 효과

- 새 아이템전1 시작 전에 토토·로웬·루미 중 하나를 선택한다. 사용자의 프로필 사진과 닉네임은 유지하고 선택한 전투 캐릭터를 함께 표시한다. AI는 나머지 두 캐릭터의 이름·아바타·스킬을 사용한다.
- 토토 / 전력 질주: 다음 싸움에서 이기면 다른 두 명에게 주는 싸움 피해 +1.
- 로웬 / 관문의 수호: 다음 싸움에서 자신이 받는 싸움 피해를 최대 2 줄인다. 피해는 0 미만으로 내려가지 않는다.
- 루미 / 길잡이의 보상: 다음 싸움에서 이기면 즉시 돈 2P를 얻는다.

## 공통 사용 조건

- 매판 1회. 다음 판에 1회로 충전되며 사용 횟수와 준비 효과는 이월하지 않는다.
- 매판 첫 싸움이 끝난 뒤, 자기 차례에서 카드 행동 전에 사용한다. 사용 후 패를 내거나 가져올 수 있다.
- 같은 차례에는 아이템과 스킬 중 하나만 사용한다. 기존 아이템 판당 2개 한도와 스킬 1회는 별도다.
- 사용 즉시 횟수를 차감한다. 진행 중인 싸움이 있으면 그 싸움, 새 선이면 다음에 시작할 싸움의 종료 시 효과를 판정한다. 승리 조건을 만족하지 못해도 다음 싸움으로 넘기거나 횟수를 돌려주지 않는다.
- 공격 스킬의 추가 피해를 먼저 반영하고 방어 스킬로 줄인다. 카드 싸움 피해만 변경하며 수호의 봉인·공격 아이템·돈 부족 피해에는 영향을 주지 않는다.
- 마지막 패로 판이 끝날 때도 스킬을 포함한 싸움 피해를 먼저 적용한다. HP 0이면 기존대로 현재 카드 판의 돈 정산을 생략한다.
- 루미의 보상은 즉시 얻은 돈이므로 카드 판 정산과 구분한다. 해당 싸움으로 대전이 끝나도 이미 얻은 2P는 유지하고 결과에 스킬 보상으로 따로 표시한다.
- 준비한 뒤 카드 싸움 전에 아이템으로 대전이 끝나면 준비 효과는 만료된다.
- AI는 공개 정보와 자기 손패로 판단하며 동일한 횟수·차례 제한을 적용한다. AI 스킬 알림 뒤 약 1.15초의 확인 시간을 둔다.

## 화면과 저장

- 내 캐릭터창 옆 스킬 버튼과 각 캐릭터창 배지에 대기·준비·사용 완료 상태를 표시한다. 상태창에서는 캐릭터와 효과를 확인할 수 있다.
- 스킬 준비 시 사용자 이름과 스킬을 짧게 알린다. 싸움 종료 알림에는 실제 참가자별 피해와 적용된 스킬 효과를 표시한다.
- 결과의 접힌 고유스킬 내역에서 성공·조건 미충족·만료를 볼 수 있다. 돈 정산과 스킬 보상을 구분한다.
- 선택한 캐릭터, 사용 횟수, 준비 효과와 결과 기록을 저장한다. 이어하기·재호출로 다시 사용하거나 중복 보상을 받지 않는다.
- 고유스킬은 새 아이템전1부터 적용한다. 이미 진행 중인 모드1 저장에 중간 추가하지 않으며, 모드2·일반전·RPG는 그대로 유지한다.

검증 대상: 세 캐릭터 배분, 첫 싸움·내 차례 제한, 카드 행동 유지, 아이템과 상호 배제, 공격·방어 동시 적용, 조건 실패·만료, 돈 보상 중복 방지와 카드 정산 분리, 마지막 패 HP 0, 다음 판 충전, AI의 비공개 손패 보호, 저장 복귀, 기존 모드 독립성. 실제 기기 화면은 사용자가 로컬 주소에서 확인한다.
