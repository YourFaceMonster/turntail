# 다음 업데이트 기억 사항

2026-10-28 사용자와 논의 중인 후속 변경. 현재 배포는 0.6.37 / Sites 101이며, 사용자가 빌드하지 말라고 했으므로 이 메모 작성에서 빌드·업로드하지 않는다.

## 반영한 로컬 문구

- 직업 상태창과 선택 설명의 `판당 1회`를 `(1회)`로 축약했다. 설명 렌더링 검사 통과, 미배포 상태다.

## 다음 수정에 포함할 사용자 요청

- 0.6.38 로컬에서 주화 이후 여유와 결과 연출 순서, 상대 상태창 불필요 문구 삭제, 라운드 음영, 상대 남은 패 알림이 바닥을 밀던 문제를 수정했다. [검증 기록](local-0.6.38.md)을 따르며 아직 빌드·업로드하지 않았다.

- 두 자리 패 숫자가 작다는 피드백: 한 자리 숫자와 비슷한 시각적 크기로 다시 키운다. 문양 바깥으로 조금 나와도 괜찮으며, 작게 맞추기보다 가독성과 크기 일치를 우선한다. 자연스러운 폭과 굵기를 유지하며 문양을 숫자에 맞춰 바꾸지 않는다. 아직 숫자 코드는 수정하지 않았다.

## 현재 직업 액티브 기준 — 0.6.39 로컬 반영

첨부 명세와 사용자 정정 “명령서에는 투시로 적어놨는데 함정이 맞아”를 적용했다. 아래의 이전 고정 수치 제안은 대체됐다. 현재 규칙은 [직업 액티브 명세](profession-actives.md), 구현·검증은 [0.6.39 기록](local-0.6.39.md)을 따른다.

- 모두 시작 1칸, 판 종료마다 +1칸, 직업별 최대치까지 충전하고 다음 판에 이월한다.
- 검사 최대 4칸: 지정 상대 피해 1/2/4/6. 마법사 최대 5칸: 상대 각각 피해 1/2/3/4/6. 성직자 최대 3칸: 회복 1/3/5. 세 직업은 현재 게이지 전량 소비한다.
- 도적 최대 4칸: 함정 1개당 정확히 2칸, 자기 턴마다 (1회), 피해 4. 4칸이면 서로 다른 자기 턴에 두 번 설치 가능하다. 기존 자동 투시·회수 피해와 별도로 작동한다.
- 기존 자동 효과는 유지한다. 빌드·업로드는 하지 않는다.

## 이전 논의 기록 — 아래 제안은 현재 규칙 아님

- 각 직업에 직접 누르는 스킬 하나와 기존 자동 발동 효과를 함께 둔다.
- 내 차례에 라운드당 1회 사용하며, 사용 후 패 내기·가져오기를 할 수 있다.
- 도적은 기존 함정 설치 하나로 충분하다. 도적에게 별도의 직접 공격 스킬을 추가하거나 함정/급습 선택지를 만들지 않는다.
- 기존 도적의 직업 투시 패 회수 효과(상대 각각 피해 1)는 유지한다.
- 검사: 지정 상대 공격 / 성직자: 자신 회복 / 마법사: 상대 둘 공격 / 도적: 함정.
- 스킬 구현은 아직 하지 않았으며 현재는 수치를 논의하는 단계다.

## 수치 제안 — 사용자 확정 전

| 직업 | 제안 |
|---|---|
| 검사 강타 | 지정 상대에게 피해 3 |
| 성직자 치유 | 내 HP +4, 최대 100 |
| 마법사 화염 파동 | 상대 각각 피해 2 |
| 도적 함정 | 기존 피해 4 유지 |

집중 공격과 광역 공격, 회복과 조건부 함정의 차이를 둔 첫 플레이 검증용 초안이다. 이 표를 사용자 확정값이나 이미 반영된 게임 규칙으로 취급하지 않는다.
