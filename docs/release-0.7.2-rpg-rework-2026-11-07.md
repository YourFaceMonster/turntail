# 0.7.2 · RPG 장성룰 개편 운영 배포

사용자의 후속 배포 요청으로 RPG 개편을 빌드하고 GitHub main과 기존 Cloudflare Worker에 반영했다. 배포 전 공개 사이트와 로컬 소스의 버전은 모두 0.7.1이었다. package.json·lib/version.ts 및 앱 표시는 0.7.2로 일치하며, pnpm@11.25.0과 잠금 파일은 유지했다.

## 반영 내용

- 새 RPG에서 3인 12장씩, 2인 18장씩, 바닥 24장으로 분배한다. 잔여 패수에 따라 HP를 정산하고 트릭 승리로 비공개 바닥패를 정찰한다.
- 전투 직업·소모품·주화·상점을 제거하고 새 유물 11종을 적용했다. 퀘스트·컷씬·스토리 카드 구조를 보존하고 기존 저장은 판 경계에서 전환한다.
- 기본모드·폭탄시장전·독립 아이템전에는 새 RPG 규칙을 적용하지 않는다. 적용 범위와 저장 복원은 [로컬 구현 기록](local-rpg-rework-2026-11-07.md)에 정리했다.

## 이번 빌드와 게시 검증

- 기능 소스 14c2c939aa500dc97e4db879e577d44260783d00을 GitHub main에 push하고 원격 HEAD를 확인했다.
- TypeScript noEmit·diff 검사, 운영 빌드 5단계 통과. 전체 338개 중 291개 통과·47개 실패이며, 실패 이름 47개가 개편 전 백업에서 재현한 것과 동일하다. 새 RPG 검사 27개가 통과했다. 기존 번들 크기·플러그인 소요시간·라우트 분류 안내가 출력됐다.
- Worker turntail 배포 성공. 새 Worker 버전 b004ddb5-a809-4f79-8853-e161324e9b41, 트래픽 100%, 배포 ID ff93c9da-ebb7-4c88-9c0d-8b2c827e584c. 이전 운영 Worker 버전 4821424f-cc27-4f43-a615-07f2a01b0f20. 기존 D1 바인딩을 그대로 사용했으며 마이그레이션은 수행하지 않았다.
- [공개 사이트](https://turntail.yousexybaby.workers.dev/) 홈페이지 HTTP 200과 0.7.2 표시 확인. 공개 JS·CSS 17개가 최종 로컬 빌드의 SHA-256과 일치하고, 앱 번들에 새 RPG 저장 전환 코드가 포함됐다. 폭탄시장전 공개 경로도 HTTP 200을 반환했다.
- 공개 Chrome의 저장 없는 RPG 테스트에서 2인 18장씩·바닥 24장 안내, 12스택, 탈락 좌석, 장갑 정찰, 주화 버튼 제거를 확인했다. 단일 정산창에 HP 70→78·공동 2등·유물 후보 2개가 표시됐고 테스트를 종료했다. 실제 운영에서 여정을 끝까지 플레이하거나 운영 모바일 기기로 조작하는 검증은 수행하지 않았다.

[배포·공개 확인 JSON](deployment-0.7.2-2026-11-07.json). 작업 루트 artifacts에 build-0.7.2-2026-11-07.log, tests-0.7.2-2026-11-07.log, tests-comparison-0.7.2-2026-11-07.json, deploy-0.7.2-2026-11-07.log, public-0.7.2-rpg-settlement.png를 보관했다. 기존 로컬 배포 산출물은 작업 루트 local-backups/rpg-release-0.7.2-2026-11-07/dist-before에 보관했다.

이전 로컬 시뮬레이션에서 운영 AI 표본 ST1이 43판 후에도 진행 중이었다. 목표 판수 미충족은 그대로 남아 있으며 이 배포에서 밸런스 수치나 정산식을 임의 조정하지 않았다. 다음 변경 배포는 0.7.3 이상으로 올리고, 명시적 요청 없이 빌드나 배포를 수행하지 않는다.
