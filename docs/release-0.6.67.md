# TURNTALE 0.6.67 · 주점 퀘스트와 푸른 유리

- 모르의 봉인 편지 → 별도 시장 뒤 골목의 3판 승부 → 편지 반납으로 주화 10개와 유물 소문을 받습니다. 패배해도 재도전할 수 있습니다.
- 길가의 여행자에게 응급 약초를 건네 주화 8개와 파수탑 단서를 받고, 성벽 안 돌틈에서 실제 유물 **파수꾼의 푸른 유리**를 얻습니다.
- 푸른 유리를 장착하면 응급 약초 회복량이 **10 → 15**로 늘어납니다. 최대 HP를 넘지 않으며 상대의 약초에는 적용되지 않습니다. 장착 자리가 있으면 자동 장착됩니다.
- 가방이 가득 차면 미장착 유물을 직접 골라 교체하거나 나중에 받을 수 있습니다. 이미 유리를 발견했던 기존 저장도 파수탑을 다시 방문해 받을 수 있습니다. 보상은 한 번만 지급됩니다.
- 퀘스트 전용 세로·가로 컷씬, 대사와 선택지, 지도에서 이야기 다시 보기를 추가했습니다. 골목과 여행자, 파수탑의 배경을 성벽 안으로 맞추고 발·팔·소품 원근과 밤의 밝기를 수정했습니다.
- 파수탑의 숨겨진 돌틈에만 푸른 빛이 은은하게 맥동합니다. 화면 비율이 바뀌어도 그림 속 틈을 따라가며 동작 줄이기 설정에서는 정지합니다.
- 잡화점을 간략 목록 + 클릭 상세 설명 방식으로 바꿨습니다. 할인 변수 오류, 주점 배경 흔들림을 고치고 벽난로 온기는 유지했습니다. 주점 명칭을 통일하고 게시판과 이전 눈길 부탁을 제거했습니다.
- 시장 뒤 골목을 잡화점과 떨어뜨렸고 모르의 대사는 편지 진행 상황에 맞춥니다. 패의 간헐적인 초기 글리치는 재현되지 않아 별도 수정하지 않았습니다.

## 검증

이번 실행: TypeScript 검사, RPG 전술 아이템 회귀 검사, RPG 여정/주점/미니게임/저장 회귀 검사, 푸른 유리의 획득·회복·가방·기존 저장 검사, 활성 컷씬 12개 PNG와 로컬 HTTP 검사 통과. 로컬 UI에서 잡화점 구매 → 약초 전달 → 파수탑 조사 → 유물 획득과 자동 장착 표시를 확인했습니다. 세로 기본 화면과 1280×720 가로 화면에서 돌틈의 빛 위치를 확인했습니다. RPG 기본 정산·1~3단계·유물 발동·테스트 모드·잡화점 회귀 검사도 통과했습니다. 운영 빌드 5단계도 통과했습니다. 큰 클라이언트 청크 안내는 남아 있으며 오류는 아닙니다. 실제 배포 결과는 완료 후 별도 기록합니다.

원화 원본과 이전 수정본, 생성 프롬프트는 보존합니다. 아래 로컬 작업 문서의 ‘이야기 전용 유물’과 ‘미배포’ 설명은 당시 기록이며 이 릴리스에서 변경됩니다.
