# 노르문 마을·회복 호환·원화 정합성 (로컬 미게시)

버전 0.6.69 유지. 기존 미게시 변경과 사용자 저장은 보존한다. 사용자 확정 마을명은 **노르문 마을**, 상위 지역명은 **철문의 영역**이다.

## 변경

- 이전 방식의 보상 수령 전 저장은 기본 클리어 회복이 이미 지급되어 있다. 새 보상을 받을 때 기록된 `clear.baseHeal`을 30에서 제외한 나머지만 더하도록 수정했다. 예: 클리어 전 HP40 → 구 저장 HP50 → 보상 수령 HP70. 새 방식은 HP40 → 수령 HP70. 상한100·중복 차단·유물/조합의 별도 추가 회복을 유지한다. 지급 완료 저장의 HP와 지급 기록을 소급 변경하지 않는다.
- 프롤로그 P09의 '달의 마을'을 '노르문 마을'로 변경했다. 지도 이야기 메뉴·여정 진입 지도 설명·프롤로그 감상 소개에도 확정 이름을 반영했다. 저장 식별자와 상위 지역명은 유지한다.
- 관문/광장/성채의 가로·세로 기본/대사 자세별 원화20장 및 먼 마을 전경2장, 총22장의 깃발을 승인된 D 철문 문양으로 맞췄다. 먼 마을 전경은 현재 지도와 건축 배치도 맞췄다. 기존 인물/포즈/구도/빛/개인 장신구·석조 부조·패와 비석의 비밀 표식은 보존한다.
- 기존 원화는 보존하고 `*-iron-v1.png`20장과 `normun-village-distant-{wide,portrait}-v2.png`2장으로 새로 저장해 실제 소비처에 연결했다. built-in image_gen 사용. [전체 프롬프트·참조·생성 원본과 저장 경로](art-generation-normun-2026-11-05.json).
- 포코·밀라 얼굴 아바타를 실제 ST2 밤 원화와 같은 이미지에서 가져오도록 맞췄다. 로웬·루미도 새 관문 원화를 사용한다. 기존 인물 ID는 유지한다.
- 실제 가로 지도에서 여행자/파수탑 안내가 겹쳐 여행자 지점을 가로17/43으로 조정하고 경로도 함께 이동했다. 세로는20/34를 사용하며 지도와 같은 종횡비 기준으로 전환한다.
- 지도 이야기 메뉴에서 컷씬을 선택하면 메뉴를 닫아 컷씬을 가리지 않도록 수정했다. 스테이지 다시 보기의 상단 장소도 현재 저장 스테이지 대신 선택한 장면의 장소를 표시한다.
- 기존 result-progress 검사의 배경 기대값055가 실제0520 파일과 달랐던 부분을 수정했다. 이전 실패 기록은 당시 기록으로 보존하며 이번에는 통과했다.
