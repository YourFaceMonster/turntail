# 0.6.56 · 픽셀 버전을 제외한 사이트 게시

2026-11-01 사용자 후속 요청: “픽셀버전제외하고 사이트업로즈해줘”. 기존 Sites 프로젝트 `appgprj_6ad9b09474d88191a6bff316295bed46`와 공개 설정을 유지한다. 이번 요청은 빌드·소스 저장·기존 사이트 게시를 포함한다.

## 게시 내용

- 기존 일반모드 `Home`을 직접 공유하는 폭탄시장전: 기존 나무 테이블·패·캐릭터·추천·더블탭·드래그·패 비행·입장 연출, 공개 시장, 구매·패스, 3초 폭탄 반응, 5판 누적 정산 및 전용 저장/전적. 자세한 구현은 [폭탄시장전 0.6.56](bomb-classic-0656.md)을 따른다.
- 앞선 로컬 0.6.53 RPG 지도·주점·분리 대전 및 저장 연결도 보존한다. [RPG 로컬 기록](rpg-journey-0653.md). 일반 AI의 비공개 패 접근 금지와 기존 저장 호환을 유지한다.
- 별도 픽셀 일반모드는 **게시하지 않는다**. `/classic-pixel` 경로, 메뉴, 픽셀 CSS·컨텍스트·패/재질 렌더러·저장 어댑터와 공개 이미지 37개를 체크아웃에서 제외했다. 일반 화면에서는 원래 그래픽과 원래 저장 키를 직접 사용한다.

픽셀 원본은 삭제하지 않았다. 워크스페이스 `pixel-version-hold-20261101-0656/edition/`에 전용 파일 45개, `integration-before/`에 연결 파일 9개의 수정 전 전체 소스를 보관했다. `manifest.json`에서 옮긴 모든 파일의 SHA256 일치를 검증했다. 이 보관 폴더는 Sites 소스·게시 아카이브 밖에 있다. 브라우저의 기존 픽셀/일반/RPG/폭탄 저장은 삭제하지 않았다. 이전 픽셀 문서와 자산 생성 기록은 역사 자료로 보존한다.

## 이번 검증과 이전 검증 구분

- 이전 턴의 전체 검증은 162개 중 141 통과·기존 실패21개였다. 이는 픽셀 검사가 포함된 당시 코드의 결과다.
- 이번 게시용 검증은 픽셀 검사12개를 보관하고 게시 제외/원래 그림 렌더링 검사2개를 추가한 현재 소스를 대상으로 실행했다. **152개 중131 통과·21 실패**이며 실패 파일21개가 앞선 기준과 정확히 같다. 이 중 폭탄/표시 연결/기존 모드 격리/픽셀 제외 관련37개는 모두 통과했다. 로그는 워크스페이스 `artifacts/publish-0656/`의 `regression-final.log`, `types.log`, `exclusion-final.log`를 따른다.
- 새 제외 검사는 일반/아이템/RPG/폭탄 메뉴 유지, 픽셀 메뉴·전용 경로·공개 폴더·공용 코드 연결 부재, 기본 패 및10개 기존 재질의 모든 문양 앞/뒷면 렌더링을 포함한다. 2개 통과했다.
- 폭탄·AI·시장·정산·저장 및 일반전/10판 도전 완주·기존 저장 보존 검사는 이번 전체 실행에도 포함한다. 기존 실패를 모두 해결했다고 표현하지 않는다.
