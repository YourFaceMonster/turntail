- 시작 1칸, 판 종료 +1칸. 턴이나 싸움 종료에는 충전하지 않으며 동일 판 중복 충전을 막는다. 게이지와 HP를 다음 판으로 이월한다.
- 검사 최대 4칸: 지정 상대 피해 1/2/4/6. 마법사 최대 5칸: 상대 각각 피해 1/2/3/4/6. 성직자 최대 3칸: HP 1/3/5 회복. 현재 칸을 전량 소비한다.
- 도적 최대 4칸: 함정 하나당 2칸, 자기 턴 (1회), 피해 4. 4칸이면 같은 판의 서로 다른 자기 턴에 두 번 설치할 수 있다. 안쪽 바닥패에도 설치 가능하며 같은 패에 자기 함정 중복 설치는 거절한다.
- 잘못된 대상·만피 회복·게이지 부족은 소비 없이 거절한다. 수동 스킬은 패 행동·아이템 사용 횟수·자동 효과 사용 여부를 소비하지 않는다.
- 기존 자동 투시와 본인 회수 시 상대 각각 피해 1을 유지한다. 정확한 패 ID 기준으로 한 번만 발동하며 렌즈만으로 본 패는 제외한다. 소비 기록과 함정 위치·상대 게이지는 공개 뷰에서 숨긴다.
- 기존 저장의 누락된 게이지는 1칸으로 복구하며 과거 판 수를 소급 충전하지 않는다. AI는 자기 게이지와 필터링된 뷰의 정보로 판단한다.
