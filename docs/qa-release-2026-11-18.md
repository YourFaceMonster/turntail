## A. 고쳐야 할 것
1. **엔딩·스테이지 뒤 장면 깜빡임:** 엔딩이 진행되는 도중 10~15초마다 "이야기를 펼치는 중…" 화면이 잠깐 끼어든다. 원인: `RpgPrologue`가 장면 목록(`cuts`)이 바뀔 때마다 그림을 처음부터 다시 불러오는데, 정산 창(`RpgReworkResult`)은 다시 그려질 때마다 새 목록을 넘긴다. 장면 자체는 끝까지 나온다. 장면 id로 비교하면 고쳐진다.
2. **탭 아이콘 없음:** 공개 사이트 `/favicon.ico`가 404. `public/favicon.svg`는 기본 템플릿 파란 네모 그림이고 연결도 안 돼 있다.
3. **공유 설명이 옛날 내용:** 페이지 설명이 "공중섬 스테이지 도전"(예전 기획). 지금은 10스테이지 스토리·요트다이스·오늘의 판. 카카오톡 등에 링크를 보낼 때 뜨는 미리보기 그림(og:image)도 없다.

4. **스토리 장면(컷씬)은 무음:** 프롤로그·스테이지 앞뒤 장면·주점 도착 대화·서브퀘스트 대화 동안 배경음이 꺼진다(효과음·바람 소리는 남음). 11-13 문서에 "일부러 끔, 넣을지 결정 필요"로 남아 있는 상태.
