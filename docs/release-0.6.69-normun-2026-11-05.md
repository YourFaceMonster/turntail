# v0.6.69 노르문 마을·철문·승인 UI 업데이트

## 반영 범위

- 세린 이번 판/최종 결과를 순위·아바타·이름 한 줄로 정리하고 중복 누적 순위를 제거.
- 기본 클리어 회복을 보상 30 HP로 통합. 과거 미수령 저장에 지급된 기본 10 HP는 차감하여 기본 회복 합계 30 유지. 최대 HP와 중복 지급 차단, 별도 유물 효과 유지.
- HP 틀 내부 아바타 위 운명력 보석 3칸, 승인 A/C 혼합 철문 SVG, 철문의 영역·노르문 마을 이름 적용.
- 주민·시장·파수탑 비율·정문 로웬/루미를 맞춘 가로/세로 지도, 밤 광장 컷씬과 아바타, 관문/성채 깃발, 먼 마을 전경 연결.
- 여행자 도움 전후 원화, 도둑 상자 높이 보정, 편지를 돌리는 첫 대화 컷 추가. 원본과 생성 기록 보존.
- 지도 다시 보기 메뉴 닫힘/선택 장면 장소명, 가로 지도 안내 겹침 수정. 여정 진입 및 전투 상단 장소명을 관문·광장·성채로 통일. 일반 모드와 기존 RPG 이름은 유지.
- 4스테이지 이후 변경은 사용자 요청대로 보류. 버전은 기존 작업 기준 0.6.69 유지.
