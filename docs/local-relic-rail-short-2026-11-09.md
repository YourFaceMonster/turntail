# 2026-11-09 · 새 RPG 장착 유물 칸 짧은 문구 (로컬 · 미배포)

사용자 제보: 휴대폰 세로 화면에서 오른쪽 장착 유물 칸의 설명이 길어서 잘리고 아래 아이콘과 겹친다.

## 원인
- 유물 칸은 "조건 / 효과" 두 줄 요약을 보여 주는 자리다.
- 새 RPG 유물에는 요약 문구가 없었다. 그래서 위 줄에는 "장착 효과"가, 아래 줄에는 효과 전체 문장이 그대로 들어갔다.

## 변경
- `lib/rpg-rework.ts`: `RPG_REWORK_RELIC_SHORT`(사용자 확인)

  | 유물 | 위 줄 | 아래 줄 |
  |---|---|---|
  | 승부사의 장갑 | 5장 승리 | 정찰 +1 |
  | 금이 간 심장 | 최대 HP | +20 |
  | 두 번째 심장 | 최대 HP | +10 |
  | 회복의 등불 | 클리어 | HP +5 |
  | 파수꾼의 푸른 유리 | 판 시작 | 투시 1장 |
  | 멈춘 모래시계 | 선견지명 | 정찰 +2 |
  | 마지막 매듭 | HP 10↓ | HP +5 |
  | 두 번째 반지 | 2등 | HP +3 |
  | 모르의 깃펜 | 주점 | 소문 +1 |
  | 쌍침 나침반 | 보상 | 미리 보기 |
  | 갈라진 거울 | 보상 | 후보 +1 |
  | 하로의 상아 주사위 | HP 50↓ | HP +2 |

- `app/components/RpgEquippedRelics.tsx`: 새 RPG도 위 요약을 쓴다. 유물을 누르면 뜨는 팝업에는 전체 설명이 그대로 나온다.
- 예전 RPG 저장과 아이템전의 유물 칸은 바꾸지 않았다.

## 검증
- 새 테스트 `tests/relic-rail-short.test.tsx`
  - 모든 새 RPG 유물에 요약 문구가 있는지, 각 줄이 6자 이하인지 확인한다.
  - 유물 칸에 긴 문장이 나오지 않는지 확인한다.
- `rpg-rework` 테스트의 기대 문구를 짧은 형식으로 바꿨다. 관련 테스트 30개 통과, 타입 오류 0
- 브라우저 375×812, ST3 전투 화면: 장갑·깃펜·두 번째 심장 세 칸이 두 줄로 표시되고 겹치지 않는다.
