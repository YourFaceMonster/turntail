## 19. 도적 투시와 정찰 렌즈

두 경로는 같은 개인 투시 데이터와 바닥 패 표시를 사용한다. 기본적으로 패의 내용을 나만 확인하고 해당 패를 누군가 가져갈 때까지 정보를 유지한다.

| 구분 | 도적 직업 스킬 | 정찰 렌즈 |
|---|---|---|
| 발동 | 싱글 승리 / 트리플 승리(판당 1회) | 자기 차례 아이템 사용 |
| 대상 선택 | 아직 확인하지 않은 숨겨진 위층 중 무작위 | 사용자가 바닥패 한 장 선택 |
| 장수 | 싱글 1장 / 트리플 2장 | 1장 |
| 함정 탐지 | 없음 | 선택한 패의 적 함정 유무도 확인 |
| 전부 공개된 바닥 | 스킬로 새로 투시할 대상 없음 | 공개 아래층의 함정 탐지에도 사용 가능 |
| 아이템 사용 횟수 | 소모하지 않음 | 기존 한도와 수량 소모 |

따라서 패 내용 표시 효과는 공통이지만, 대상 선택과 함정 탐지 기능은 다르다. 상점·아이템 설명 중 예전 `2층 패만 확인` 또는 `도적 패 교환 방어`를 적은 문구도 새 아이템전의 실제 동작에 맞춰 정리할 대상이다. 과거 저장의 기존 규칙은 구분한다.

## 20. 투시한 패를 가져왔을 때의 공격

현재는 투시와 함정이 독립된 기능이다. 이전 논의의 `확인한 패를 가져오면 기습`은 함정 방향으로 바뀌었으며 해당 기습 보너스는 구현하지 않았다.

- 일반적으로 투시한 패를 가져오기: 추가 공격 없음.
- 내가 설치한 함정 패를 상대가 가져오기: 그 상대에게 기본 함정 피해 4. 방어·남은 HP에 따라 실제 피해는 달라질 수 있다.
- 내가 내 함정 패를 가져오기: 안전하게 해제, 추가 공격 없음.
- 내가 적의 함정 패를 가져오기: 내 HP에 함정 피해 적용.

공격 여부를 알아보기 쉽게 `함정 설치 완료`, `내 함정 회수`, `○○ 함정 발동 · HP −4`, `함정 피해 방어`를 구별해서 보여주는 것이 적절하다. 이 검토만으로 투시 패 취득에 새 공격 효과를 추가하지 않는다.
