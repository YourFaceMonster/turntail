# 아이템전1 — 확정 규칙

2026-10-27 사용자 피드백을 반영해 로컬 0.6.12에 구현했다. 사이트에는 업로드하지 않는다. 기본 전투 규칙은 [0.6.12 변경 기록](release-0.6.12.md), 새 대전의 캐릭터 고유스킬과 즉시 보상 예외는 [0.6.14 변경 기록](release-0.6.14.md)을 따른다.

- 새 모드1 대전부터 적용한다. 이전 저장은 기존 규칙으로 이어진다.
- 싸움 종료 시 마지막 승리 족보로 승자 외 두 참가자를 각각 공격한다. 싱글 1, 페어 2, 트리플 3, 스트레이트·플러시 4, 풀하우스 5, 포카드 6, 스트레이트 플러시(로티플) 10 피해다.
- 아이템 공격·회복은 사용 즉시 반영한다. 첫 싸움이 끝난 이후 사용 가능하며 자기 차례 1개, 한 판 2개 한도를 유지한다.
- 싸움 또는 아이템으로 HP 0이 되면 즉시 대전을 끝내고 현재 판의 돈은 정산하지 않는다. 마지막 패를 낸 경우에도 마지막 싸움 공격을 돈 정산보다 먼저 처리한다.
- 정상 완료한 판은 기존 남은 패 차이 점수를 합산해 돈으로 정산한다. 손실은 보유 돈으로 지불하고 부족한 1P당 HP 1을 차감한다. 정확히 0P가 되거나 상점에서 돈을 모두 쓴 경우에는 추가 피해가 없다.
- 양수 점수는 전액 지급한다. 돈 부족으로 HP 0이 되면 모든 참가자의 정상 판 정산을 함께 마친 뒤 대전을 종료한다.
- 시작 HP 100, 돈 20P, 기존 기본 아이템 5종 각 2개와 무작위 유물 3개를 지급한다. 돈은 카드 판 점수에서만 발생하며 매판 준비금과 RPG 포인트 보너스 유물은 없다.
- 정상 판 결과 → 상점 → 다음 판 패 배분 순서로 진행한다. 구매는 선택이며 미사용 아이템은 계속 보유한다.
- 수호의 봉인은 적대적 아이템만 방어한다. 싸움 피해와 돈 부족 피해는 방패·유물로 줄이지 않는다.
- 결과에는 싸움 피해, 아이템 피해·회복, 돈 부족 피해, 돈 증감을 구분한다. 중도 종료는 이번 판 돈 미정산을 표시한다.
- 최종 순위는 기존처럼 HP 우선, 동률이면 남은 패 수로 결정한다. 아이템전2는 기존 규칙을 유지한다.

족보 피해, 마지막 패 종료, 즉시 회복·공격, AI 중단, 돈 부족·동시 정산, 상점 순서, 저장 복귀·중복 방지와 모드2 독립성을 자동 검사했다. 화면·소리는 사용자가 확인한다.
