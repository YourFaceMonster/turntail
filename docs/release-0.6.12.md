# 0.6.12 — 새 아이템전1 싸움 공격

로컬 수정·빌드 전용. 사이트 업로드와 배포는 하지 않는다. 사이트는 0.6.10을 유지하며, 로컬 0.6.11 변경 위에 이번 규칙을 추가했다.

## 적용 범위

- 새로 시작한 아이템전1에 `hpItemRules: 2`를 기록한다. 진행 중인 이전 모드1 저장은 원래 규칙으로 이어지며 자동 전환·초기화하지 않는다.
- 아이템전2의 판 종료 HP 정산·시작 상점·준비금·아이템 피해 포인트는 변경하지 않는다.

## 확정 규칙

- 한 번의 싸움이 끝나 새 선이 정해질 때 승자가 다른 두 참가자에게 각각 공격한다. 마지막으로 이긴 족보를 기준으로 하며, 패를 냈는지 바닥 패를 가져왔는지에 따른 면제는 없다.
- 피해: 싱글 1, 페어 2, 트리플 3, 스트레이트 4, 플러시 4, 풀하우스 5, 포카드 6, 스트레이트 플러시 10. 로티플은 현 엔진의 스트레이트 플러시와 같은 10피해로 취급하며 별도의 족보 서열을 추가하지 않는다.
- 마지막 손패를 내서 판이 끝나는 경우에도 싸움 공격을 먼저 한 번 적용한다. 이 공격으로 HP 0이 나오면 해당 판의 돈은 지급·차감하지 않고 대전을 종료한다.
- 아이템 공격·회복은 즉시 HP에 반영한다. 아이템으로 HP 0이 되어도 현재 판 돈을 정산하지 않고 종료한다. AI와 Worker 대체 처리도 추가 카드 행동을 하지 않는다.
- 수호의 봉인은 적대적 아이템만 막는다. 싸움 피해와 돈 부족 피해는 방패·유물로 감소시키지 않는다. 아이템에 대한 기존 피해 감소는 유지한다.
- 시작 HP 100, 돈 20P, 기존 기본 아이템 각 2개와 무작위 유물 3개 지급. RPG 포인트 보너스 유물은 새 모드1 지급에서 제외한다.
- 정상 완료한 판의 남은 패 차이 점수를 기존대로 합산한 뒤 돈으로 정산한다. 양수분은 계산된 금액 전체를 지급하고, 음수분은 보유 돈을 먼저 지불한다. 부족한 1P당 HP 1을 차감한다.
- 정확히 돈이 0이 되거나 상점에서 돈을 모두 쓰는 것만으로 HP가 감소하지 않는다. 돈이 0이어도 다음 판에서 이기면 다시 돈을 얻을 수 있다.
- 정상 판의 돈 부족 정산으로 HP 0이 되는 경우에는 모든 참가자의 정산을 한 번에 마친 뒤 종료한다. 싸움·아이템에 의한 중도 종료와 구분한다.
- 싸움 승리·아이템 공격 자체로는 돈이 생기지 않는다. 매판 준비금 8P도 없다.
- 정상 판 결과 → 상점 → 다음 판 패 배분 순서다. 최초 판은 기본 지급품으로 시작한다. 구매 없이 진행할 수 있고 미사용 물품은 계속 보관한다.
- 첫 싸움 이후 아이템 사용, 매판 첫 싸움 제한 초기화, 자기 차례 1개·판당 2개 한도는 유지한다.
- 누군가 HP 0이면 대전 종료. 최종 순위는 기존대로 남은 HP 우선, 동률이면 남은 손패 수다.

## 표시·보관

- 싸움 승자·족보·피해를 알리고 상대 상태창에 피해를 표시한다. 새 모드1의 HP와 돈은 진행 중에도 바로 갱신한다.
- 결과에서 싸움 피해·아이템 피해·회복·돈 부족 피해와 돈 정산을 구분한다. 중도 종료에는 이번 판 돈 미정산을 명시한다.
- 싸움 식별자와 돈 정산 식별자를 저장해 새로고침·이어하기·재호출 시 중복 차감을 막는다.

검증: 새 모드1 족보별 피해, 마지막 승리 족보, 두 상대 공격, 마지막 패·즉시 아이템 종료, 회복으로 생존, AI/Worker 종료, 돈 부족·정확히 0·정산 순서·중복 방지, 상점 순서·무지원금, 기존 저장·모드2 독립성, 결과 UI 회귀 검사를 수행했다. 실제 기기 연출·소리는 별도 확인 대상이다.
